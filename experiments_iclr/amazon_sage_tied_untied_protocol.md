# Amazon Ratings SAGE initially matched tied-versus-untied propagation extension

**Frozen 2026-09-25 UTC, before any result from this extension existed or any GPU arm was run.** This optional second-graph diagnostic uses the corrected public Amazon Ratings NPZ already pinned in `experiments_iclr/data_manifest.json`: SHA-256 `4c3a3e3b9d9f6cba0fede4625a00aad8c5721c1a36ed771367f446763241c7dd`, 24,492 nodes, 300 features, 93,050 raw edges, and five classes. It is a post hoc extension of the Roman Empire SAGE control, not a replacement for it. Archived Amazon benchmark CSVs are not used to select this extension’s masks, variants, or training settings.

## Fixed six-arm design

- Use exactly the first three official Amazon Ratings masks, **0, 1, 2**, in that order. Set the optimization seed to the official mask index, respectively **0, 1, 2**, for both members of each pair. No seed, mask, arm, or order substitution follows score inspection. There are six fresh arms: mask 0 GNNM then untied, mask 1 GNNM then untied, mask 2 GNNM then untied.
- Use `projector_controls.py` model definitions: `gnnm` has one shared residual SAGE propagation stack; `untied_backbone` deep-copies its initialized stack four times, with shared BatchEnsemble input/output projectors and output normalization. The copied stacks start bitwise identical and occupy distinct parameter storage. Both variants have four members, five SAGE layers, hidden width 512, LayerNorm, and dropout 0.2. No trained parameter is transferred.
- Immediately before each model construction call `set_seed(mask_index)`. Require matching canonical initial parameters and CPU/CUDA RNG states within a pair, and all initial member logits to differ by at most `1e-6`. A failed initialization check stops the affected run before training. The runner saves the initial audits for independent reconstruction.
- Use AdamW with learning rate `3e-5` and zero weight decay. Optimize the arithmetic mean of four member cross-entropies. Train for at most 5,000 steps. Evaluate arithmetic mean member logits on the official validation mask at step 1 and every ten steps. Save the first checkpoint with strictly greater pooled validation accuracy; ties retain the earlier checkpoint. Stop after 300 validation-counted steps without a strict improvement. Test labels are used only after restoring that checkpoint.
- Use the repository loader with bidirected edges and self loops, as in the Roman control. Do not tune depth, width, learning rate, patience, objective, checkpoint rule, or mask panel on Amazon test results.

## Source and result integrity

The only result root is `experiments_iclr/amazon_sage_tied_untied_results/`. Its `source_manifest.json` pins the corrected NPZ; imported data/model/seed modules; the Roman control model definitions; this protocol; the Amazon runner, independent verifier, and one-shot launcher. The runner and verifier refuse changed or missing pinned inputs. Each arm is written under `maskN/variant.inprogress` and renamed to a complete directory only after its checkpoint, validation trace, initial-state audit, initial logits, saved test predictions, result JSON, and SHA-256 hashes exist. An interrupted arm is not silently resumed. The one-shot launcher accepts only a pristine root containing `source_manifest.json`.

The independent completion gate requires exactly the six expected arm directories and no partial directory; all declared artifact hashes, configuration, official masks, seed rule, initial-state and initial-logit equality, validation trace and earliest-tie selection, strict checkpoint load, fresh full-graph inference from each selected checkpoint, pooled validation and test metrics, and saved test predictions. It writes `completion_audit.json` only after every check succeeds. A failed or incomplete attempt is reported as such and cannot be substituted under this protocol.

A just-in-time start can therefore finish by 07:45 UTC, leaving more than four hours for author audit, review, and packaging before the 11:59 UTC submission deadline. If prerequisites are still active at 03:00, omit this extension. Do not shrink the panel, truncate training, or displace the existing queue to force a result.

Roman Empire historical tied/untied SAGE averaged 0.335/0.340 seconds per step, and its masks 0-2 consumed approximately 18,680 total effective steps across six arms. Amazon has 8% more nodes and 2.83 times as many raw edges; a conservative 0.45-0.60 seconds per step suggests 2.3-3.1 GPU hours for training, plus roughly 15-30 minutes for artifact replay. This is a projection, not a measured Amazon GPU profile. Later validation improvements or 5,000-step caps could exceed the hard limit; in that case the attempt remains incomplete and is not used in the paper.
