The author signature's `data.y` slot is empty and never read by the replacements. Every initializer checks its indices equal the580supplied TRAIN IDs. `train_only=True` is mandatory in both configuration and the unchanged author C&S call; VALID/test split slots are empty. This prevents the author's default TRAIN+VALID union and full-array class-count inference.

Author diffusion, residual scaling/fallback, clamping, fixed-anchor behavior and addition/smoothing remain unchanged.
