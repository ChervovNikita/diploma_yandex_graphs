3. Methodology

FedDES operates in a fully decentralized, peer-to-peer setting in which each client performs three main operations locally: (1) training a set of heterogeneous base classifiers on its local data and exchanging the models with peers to obtain a shared pool of MM classifiers; (2) evaluating all models in the shared pool on its local data to construct a decision-space representation of samples and build a heterogeneous graph where nodes represent data samples and candidate classifiers; (3) training a GNN meta-learner that produces sample-specific ensemble weights. Figure 1 provides an overview of the complete pipeline.

3.1. Stage 1: Training Base Classifiers and Decentralized Model Exchange.

Each client partitions its private dataset 𝒟k\mathcal{D}_{k} into three subsets: (i) a training set used to fit the local base classifiers and to supervise the GNN meta-learner, (ii) a validation set for early stopping during base model training and tuning GNN hyperparameters, and (iii) a test set reserved for final performance evaluation. Clients train one or more models on their local data, producing model sets ℱk\mathcal{F}_{k} with Mk=|ℱk|M_{k}=|\mathcal{F}_{k}| classifiers. These models may vary in architecture and are not limited to gradient-based methods. After training, clients exchange their classifiers via P2P communication, so that each locally retains a copy of the full pool of M=∑kMkM=\sum_{k}M_{k} base classifiers.

3.2. Stage 2: Decision-Space Representation and Graph Construction.

After exchanging models, each client constructs a decision-space representation of its training data. Since the base classifiers are trained on non-IID data using heterogeneous architectures, their confidence scores may not be directly comparable. Each client therefore calibrates the received classifiers using temperature scaling, aligning confidence estimates with the local data distribution and preventing poorly calibrated classifiers from distorting the decision-space representation.

For each sample xix_{i}, every classifier fmf_{m} produces a probability vector pm​(xi)∈ℝCp_{m}(x_{i})\in\mathbb{R}^{C} where CC is the number of classes. We define the projection function ϕ:𝒳→ℝM⋅C\phi:\mathcal{X}\rightarrow\mathbb{R}^{M\cdot C} which maps a sample into the decision space, the concatenated outputs of all MM classifiers:

ϕ⁡(xi)=[p1​(xi),p2​(xi),…,pM​(xi)]∈ℝM⋅C.\phi(x_{i})=\big[p_{1}(x_{i}),\,p_{2}(x_{i}),\,\ldots,\,p_{M}(x_{i})\big]\in\mathbb{R}^{M\cdot C}.

Let 𝐱i:=ϕ⁡(xi)\mathbf{x}_{i}:=\phi(x_{i}) denote the decision-space embedding of sample xix_{i}. Stacking these embeddings yields the decision-space matrix 𝐏k∈ℝNk×(M⋅C)\mathbf{P}_{k}\in\mathbb{R}^{N_{k}\times(M\cdot C)}. To supervise the meta-learner, each client constructs a binary meta-label matrix 𝐙k∈{0,1}Nk×M\mathbf{Z}_{k}\in\{0,1\}^{N_{k}\times M}, where Zi,m=1Z_{i,m}=1 indicates that classifier fmf_{m} correctly predicts the label of xix_{i}. These meta-labels serve as targets for learning sample-specific ensemble weights. Each client then constructs a heterogeneous graph over data samples and classifiers, linked by two edge types: sample-sample edges encoding decision-space similarity, and classifier-sample edges encoding local competence.

Sample-sample edges. These edges encode similarity in the decision space. Instead of using standard global kk-NN, which is known to be sensitive to class imbalance, we perform class-aware selection. For a target sample xjx_{j}, we identify the kk nearest neighbors from each class based on L1L_{1} distance in the decision space, forming a class-balanced neighborhood:

𝒩⁡(xj)=⋃c=0C−1{xnc,1,xnc,2,…,xnc,k},\mathcal{N}(x_{j})=\bigcup_{c=0}^{C-1}\{\,x_{n_{c,1}},\,x_{n_{c,2}},\,\dots,\,x_{n_{c,k}}\,\},

where nc,1,…,nc,kn_{c,1},\dots,n_{c,k} index the selected neighbors from class cc. While class-stratified sampling ensures representation of minority classes for downstream GNN training, it introduces a tradeoff: to meet per-class quotas, we may include neighbors that are relatively distant from the target sample and therefore provide less reliable signals. More broadly, dynamic ensemble selection is inherently sensitive to noise and class overlap near decision boundaries, which can distort the local context that guides ensemble selection. We address this by assessing the stability of each class’s local structure around xjx_{j} using Cumulative Mean Distance Weighting (Abdalla et al., 2025) and adjusting the influence of neighbors accordingly. Classes whose neighbors form compact, coherent clusters receive higher aggregate weight, while scattered or distant neighborhoods are downweighted. Formally, neighbors are ordered by increasing distance and the class stability is quantified by the average drift of the cumulative neighborhood mean from the target:

(1) d¯c=1k​∑r=1k‖𝝁c,r−𝐱j‖1,\bar{d}_{c}=\frac{1}{k}\sum_{r=1}^{k}\left\|\boldsymbol{\mu}_{c,r}-\mathbf{x}_{j}\right\|_{1},

where 𝝁c,r\boldsymbol{\mu}_{c,r} is the cumulative mean of the rr closest class-cc neighbors. Thus, smaller values of d¯c\bar{d}_{c} indicate xjx_{j} lies within a reliable region of class cc, while large values suggest the nearest class-cc neighbors may be unrepresentative of the broader class distribution. Finally, neighborhood influence is distributed through a hierarchical weighting scheme. Class-level influence is first allocated as πc∝1/(d¯c+ε)\pi_{c}\propto 1/(\bar{d}_{c}+\varepsilon), and then distributed among individual neighbors within each class through softmax over negative distances, yielding final edge weights wi​jw_{ij} for each neighbor xi∈𝒩⁡(xj)x_{i}\in\mathcal{N}(x_{j}), which sum to one across the entire neighborhood. Thus, edge weights reflect both class stability and sample-level proximity.

Classifier-sample edges. These edges encode classifier competence within the decision-space region local to the target sample. Given the weighted neighborhood 𝒩⁡(xj)\mathcal{N}(x_{j}), we evaluate each classifier fmf_{m} by computing a gain score G⁡(fm,xj)G(f_{m},x_{j}), which quantifies its performance relative to the pool average:

(2) G⁡(fm,xj)=∑xi∈𝒩⁡(xj)wi​j​(𝕀⁡(fm​(xi)=yi)−c¯i)G(f_{m},x_{j})=\sum_{x_{i}\in\mathcal{N}(x_{j})}w_{ij}\left(\mathbb{I}(f_{m}(x_{i})=y_{i})-\bar{c}_{i}\right)

where wi​jw_{ij} are the sample-sample edge weights, 𝕀⁡(⋅)\mathbb{I}(\cdot) is the indicator of correctness, and c¯i=1M​∑m′𝕀⁡(fm′​(xi)=yi)\bar{c}_{i}=\frac{1}{M}\sum_{m^{\prime}}\mathbb{I}(f_{m^{\prime}}(x_{i})=y_{i}) represents the mean accuracy of the pool for neighbor xix_{i}. By prioritizing marginal contribution over absolute accuracy, this metric identifies local experts that succeed on difficult samples where the majority fail. To resolve ties where classifiers achieve identical gain, we use the weighted log-loss over 𝒩⁡(xj)\mathcal{N}(x_{j}) as a secondary criterion, favoring higher confidence on correct predictions. We select the top-kk classifiers (k=5k{=}5) and assign edge weights by normalizing their gain scores.

Sample node features. Depending on the data modality and input dimensionality, sample node features may be the raw input features or a fixed embedding of them. This provides a complementary signal to the decision-space representation, which captures only how classifiers respond to a sample and discards input-level structure.

Classifier node features. While classifier–sample edges capture local, sample-specific performance, the classifier node attributes characterize each model’s global behavior. Classifier features include per-class recall, the standard error of per-class recall, per-class confidence, overall accuracy, and balanced accuracy.

3.3. Stage 3: Training meta-learner

The objective of the meta-learner is to learn a sample representation that captures both local data context and classifier behavior. Operating on the graph constructed in Stage 2, a heterogeneous GNN aggregates information from neighboring nodes to refine sample embeddings. Through iterative message passing over sample–sample and classifier–sample edges, each sample node incorporates information about nearby samples and locally competent classifiers. A final linear projection maps each embedding to an MM-dimensional vector of logits that quantify the predicted competence of each classifier for the given sample.

Specifically, for sample xix_{i}, the meta-learner takes the heterogeneous graph as input and outputs a vector of logits 𝐬i=(si,1,…,si,M)∈ℝM\mathbf{s}_{i}=(s_{i,1},\dots,s_{i,M})\in\mathbb{R}^{M}, where si,ms_{i,m} represents a score quantifying the predicted competence of classifier fmf_{m} for sample xix_{i}. Training is supervised using the meta-label matrix 𝐙\mathbf{Z}, where each entry Zi,m∈{0,1}Z_{i,m}\in\{0,1\} indicates whether classifier fmf_{m} correctly predicts the label of sample xix_{i}. Specifically, training minimizes

(3) ℒmeta=1Ntrain​∑i∈𝒟train(1M​∑m=1MℓBCE​_​logits​(si,m,Zi,m)),\mathcal{L}_{\text{meta}}=\frac{1}{N_{\text{train}}}\sum_{i\in\mathcal{D}_{\text{train}}}\left(\frac{1}{M}\sum_{m=1}^{M}\ell_{\mathrm{BCE\_logits}}(s_{i,m},Z_{i,m})\right),

where ℓBCE​_​logits\ell_{\mathrm{BCE\_logits}} denotes the binary cross-entropy loss with logits. This training objective can be viewed as a multi-label learning problem at the sample level, where each sample may have multiple positive targets corresponding to the classifiers that correctly predict its label. Notably, the loss is defined exclusively over sample nodes. Classifier nodes are not prediction targets and thus do not contribute directly to the loss, instead providing contextual information through classifier–sample edges.

At inference time, we apply the sigmoid function to map the raw logits to normalized competence scores in [0,1][0,1], consistent with the binary cross-entropy training objective. Classifiers with competence scores exceeding 0.5 are selected for the ensemble:

(4) qi,m=σ⁡(si,m),wi,m={qi,mif ​qi,m>0.50otherwiseq_{i,m}=\sigma(s_{i,m}),\qquad w_{i,m}=\begin{cases}q_{i,m}&\text{if }q_{i,m}>0.5\\ 0&\text{otherwise}\end{cases}

The competence scores of selected classifiers are then normalized to sum to one across the selected subset. In cases where all classifiers have competence scores at or below 0.5 (i.e., no classifier is deemed competent), the system falls back to uniform weighting across all classifiers to ensure a valid prediction.

The learned weights serve a dual role: classifiers with competence score exceeding 0.5 are selected for the ensemble, while their normalized scores determine their voting strength. The final prediction for xix_{i} is obtained by aggregating the hard predictions of the selected classifiers according to their normalized weights w~i,m\tilde{w}_{i,m}:

(5) p^(y∣xi)=∑m=1Mw~i,m 1{y^m,i=y},y^i=argmaxyp^(y∣xi).\hat{p}(y\mid x_{i})=\sum_{m=1}^{M}\tilde{w}_{i,m}\,\mathbf{1}\{\hat{y}_{m,i}=y\},\qquad\hat{y}_{i}=\arg\max_{y}\hat{p}(y\mid x_{i}).

This competence-weighted voting mechanism enables FedDES to dynamically determine whether, and how much, each peer client contributes knowledge for each sample.
