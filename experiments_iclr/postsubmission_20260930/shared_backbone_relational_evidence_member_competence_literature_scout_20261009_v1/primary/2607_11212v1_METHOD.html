3 Problem Setting and Information Boundary

Let G=(V,E,X)G=(V,E,X) be a graph with n=|V|n=|V| nodes, normalized homogeneous edge set EE, feature matrix X∈ℝn×dX\in\mathbb{R}^{n\times d}, and binary labels yi∈{0,1}y_{i}\in\{0,1\}. For outer split ss, the node memberships are 𝒯s\mathcal{T}_{s}, 𝒱s\mathcal{V}_{s}, and 𝒬s\mathcal{Q}_{s} for training, validation, and test. The three sets are disjoint within a split.

All methods receive the same node features, normalized adjacency, and split indices. Training labels yjy_{j} for j∈𝒯sj\in\mathcal{T}_{s} may train a classifier or construct evidence. Validation labels may select a candidate, checkpoint, mixture, and decision threshold. Test labels are available only to the final metric evaluator.

3.1 Relational evidence as provenance-typed knowledge

We distinguish three information types. Attribute knowledge KX=(X,E)K_{X}=(X,E) is available without labels and may be used by every split. Training-derived relational knowledge KR(s)K_{R}^{(s)} consists of statistics whose label sources belong exclusively to 𝒯s\mathcal{T}_{s}. Decision knowledge KD(s)K_{D}^{(s)} consists of validation scores, the selected candidate, and its threshold; it may control routing but may not alter KR(s)K_{R}^{(s)}. Test labels belong only to the evaluator and to none of these knowledge objects.

This typing makes the validity condition compositional. A representation is admissible for split ss only if each label-dependent component can be traced to KR(s)K_{R}^{(s)} and each adaptive choice can be traced to KD(s)K_{D}^{(s)}. The following contract instantiates that condition for neighborhood evidence.

3.2 Label-access contract

For node ii, the eligible labeled neighborhood is

𝒩~s​(i)={j∈𝒩⁡(i)∩𝒯s:j≠i}.\widetilde{\mathcal{N}}_{s}(i)=\{j\in\mathcal{N}(i)\cap\mathcal{T}_{s}:j\neq i\}. (1)

The j≠ij\neq i condition is mandatory even when ii is a training node and the normalized graph contains a self-loop. Validation and test nodes can contribute their raw attributes and structural position in the transductive graph, but their labels cannot contribute to evidence.

If the training prevalence is estimated automatically, a training node receives a leave-one-out prevalence:

πs,−i=∑j∈𝒯syj−yi|𝒯s|−1,i∈𝒯s,\pi_{s,-i}=\frac{\sum_{j\in\mathcal{T}_{s}}y_{j}-y_{i}}{|\mathcal{T}_{s}|-1},\qquad i\in\mathcal{T}_{s}, (2)

whereas validation and test nodes use the complete training prevalence πs\pi_{s}. This prevents a node’s target from entering its own evidence through the smoothing prior.

3.3 Prediction and review-budget objectives

Each method produces a fraud probability pip_{i}. A threshold τs\tau_{s} is selected on 𝒱s\mathcal{V}_{s} by maximizing validation Macro-F1 and is frozen before test inference. At review fraction b=0.05b=0.05, the review set consists of the top ⌈b​|𝒬s|⌉\lceil b|\mathcal{Q}_{s}|\rceil test probabilities. We report its precision and recall, together with AUPRC, Macro-F1, AUROC, Brier score, and ECE.

4 PREF-Gate: Evidence Construction and Decision Fusion

4.1 Graph normalization

Each released graph is converted to a homogeneous representation. For every edge (u,v)(u,v), the reverse edge (v,u)(v,u) is added; duplicates are removed in a deterministic lexical order; and one self-loop is inserted per node. Missing feature values are mapped to zero, with infinite values clipped to finite sentinels. The same normalized graph is passed to every independent method and to external adapters that require homogeneous adjacency.

Let

x¯i=1|𝒩⁡(i)|​∑j∈𝒩⁡(i)xj\overline{x}_{i}=\frac{1}{|\mathcal{N}(i)|}\sum_{j\in\mathcal{N}(i)}x_{j} (3)

denote the incoming one-hop feature mean, with a zero vector for an empty neighborhood. Because the normalized graph includes self-loops, the operator has a stable value for every node.

4.2 Label-free context expert

The label-free context vector is

zi(C)=[xi∥x¯i∥|xi−x¯i|∥log(1+deg(i))∥𝕀[deg(i)>0]].z_{i}^{(C)}=\left[x_{i}\,\|\,\overline{x}_{i}\,\|\,|x_{i}-\overline{x}_{i}|\,\|\,\log(1+\deg(i))\,\|\,\mathbb{I}[\deg(i)>0]\right]. (4)

It captures three complementary views: the node itself, the average local context, and the magnitude of disagreement between the two. The final two terms expose neighborhood scale and availability.

A histogram gradient-boosting classifier fCf_{C} is fit on {(zi(C),yi):i∈𝒯s}\{(z_{i}^{(C)},y_{i}):i\in\mathcal{T}_{s}\}. The fixed configuration uses 180 iterations, learning rate 0.05, 31 maximum leaf nodes, L2L_{2} regularization 1.0, balanced class weighting, and random state s+303s+303. Its validation and test probabilities are denoted pi(C)p_{i}^{(C)}.

4.5 Evidence context expert

The evidence expert receives

An Extra-Trees classifier fEf_{E} with 200 trees, minimum leaf size 10, balanced class weights, and random state s+404s+404 is trained on 𝒯s\mathcal{T}_{s}. Its probability is pi(E)p_{i}^{(E)}. The model is deliberately different from fCf_{C} so that the evidence path can learn non-linear interactions among raw risk, support, and posterior uncertainty.

4.6 Finite validation-adaptive gate

The pre-specified candidate family is

𝒫={p(C),p(E),wp(C)+(1−w)p(E):w∈{0.25,0.50,0.75}}.\mathcal{P}=\left\{p^{(C)},p^{(E)},wp^{(C)}+(1-w)p^{(E)}:w\in\{0.25,0.50,0.75\}\right\}. (13)

There are exactly five candidates. For each candidate cc, validation Macro-F1 determines a candidate-specific threshold τc\tau_{c}. The gate score is

Sc=12​MacroF1𝒱s⁡(c,τc)+12​AUPRC𝒱s⁡(c).S_{c}=\frac{1}{2}\operatorname{MacroF1}_{\mathcal{V}_{s}}(c,\tau_{c})+\frac{1}{2}\operatorname{AUPRC}_{\mathcal{V}_{s}}(c). (14)

Candidates are ordered by ScS_{c}, then validation AUPRC, validation Macro-F1, and finally candidate name. The selected candidate cs⋆c_{s}^{\star} and threshold τs⋆\tau_{s}^{\star} are frozen before either expert is asked for test probabilities.

4.7 Why the gate is conservative

The earlier full gate included structural, raw risk, empirical-Bayes risk, context, and evidence experts plus every pairwise mixture at three weights. With five base experts this produced 35 candidates. Maximizing over many correlated validation scores creates a multiple-comparison effect: an insignificant validation fluctuation can change the chosen model. The reduced gate asks a narrower mechanism question and avoids unrelated weak candidates.

This design also permits an interpretable fallback. If evidence is not supported, p(C)p^{(C)} remains a valid final model rather than an emergency exception. If evidence improves validation, a pre-specified mixture can be selected. The fallback is therefore part of PREF-Gate’s method definition.

4.8 Complexity

Constructing one-hop means and evidence is O⁡(|E|​d+|E|)O(|E|d+|E|) with sparse aggregation. The context design matrix has dimension 3​d+23d+2; the evidence matrix adds seven columns. The finite gate evaluates five vectors over the validation set, O⁡(5​|𝒱s|)O(5|\mathcal{V}_{s}|), and has no trainable parameters. Memory is dominated by the graph and feature matrices. The method avoids dense n×nn\times n adjacency construction.
