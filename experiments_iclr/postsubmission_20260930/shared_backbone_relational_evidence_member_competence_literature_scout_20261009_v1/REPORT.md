These are versioned arXiv scopes. Accepted-body equivalence, source execution,
empirical benefit and transfer to WikiCS are unverified. Public abstract results
were exposed in discovery metadata and are not adopted.

FedDES concatenates classifier probabilities for sample similarity, builds
class-balanced decision-space neighborhoods, and adds classifier nodes using
local competence. Correctness vectors supervise BCE. Inference selects sigmoid
competence above 0.5, normalizes selected weights and **votes over hard class
predictions**; it is not the current native/label probability mixture. Its local
TRAIN role fits own base classifiers and supervises the meta-learner, so it does
not certify out-of-fit competence targets for the current own-selected backbone.

There is also a precise algebraic limit. Let A_m be weighted local correctness
and c its mean over models. FedDES Eq. 2 gives G_m=A_m−c. For a fixed query this
common subtraction leaves top-k member ranking unchanged, with the same ties.
It is not a new marginal-selection ranking. Later edge normalization/GATv2 can
still differ; complete-model equivalence is not claimed. All-equal competence
makes every gain zero, while signed gains are possible. The printed normalization
needs source qualification before reuse; no author code was inspected.

PREF-Gate explicitly removes a TRAIN query's own neighbor label and its
contribution to prevalence. Its global empirical-Bayes concentration is estimated
from supported TRAIN nodes, without a corresponding whole-Q rule in this scope.
If transferred as label-derived context, it must be recomputed from permitted
masked labels; if treated as a fitted parameter, that supervision stage must be
stated. Neither self-exclusion nor leave-one-out prevalence alone certifies the
current stronger exclusion from all label contexts. This is a porting boundary,
not a claimed TEST-label leak or an implementation finding.

The source also discloses revising its earlier 35-candidate gate after exploratory
benchmarking, then freezing five candidates for later executions in the same
program. That is not independent confirmation. Its finite mixture selector is
established validation selection, and is not proposed as a new coefficient grid.

## What is already established

FiLM changes incoming value coordinates from receiver features; gate15 already
uses that attributed primitive. GOODIE jointly learns FP/LP embeddings and a
combined classifier. LP/GAMLP/UniMP supply label propagation and masking ancestry.
CoGNN learns communication actions before aggregation; Node-MoE learns graph
filter/expert use. None of these primitive ideas is newly invented here.

Query-dependent attention is also established GATv2/graph-transformer capacity.
The current score `(Q_m H_i)^T(K_m H_j)` already depends on the query: a scalar
query changing from +1 to −1 reverses ranks of keys +1 and −1. That restricted
function-class observation is not a measurement. Changing a label-only route's
attention score does not itself change the class-value domain. The GATv2 classic
citation is a locator, not a new direct primary read; the newly read FedDES method
explicitly uses heterogeneous GATv2. Saved PolyFormer/GAMLP/Node-MoE scopes already
cover node-dependent filter/channel selection.

The saved inaccessible method boundary for Information Fusion DOI
[10.1016/j.inffus.2024.102461](https://doi.org/10.1016/j.inffus.2024.102461) remains
unresolved. No blocked recovery route was repeated and no exact complete-rule

META-DES, MoE-NP and the saved graph-residual-stacking proposal already address
local competence, output profiles and learned fusion. FedDES supplies a closer

native TRAIN predictions are not automatically honest meta labels; posthoc

## One retained next question, with a bounded empirical gap

The root-supplied saved note records 2512 nodes with no visible TRAIN-label class
and 1733 with one visible class among 5274 development nodes. These counts were not
recomputed. For every no-label context, the current bias-free label message is
zero. Multiplicative receiver FiLM keeps it zero; explicit serving fallback stays
native. This is an operator support boundary that gate15 cannot remove, even if
its one-class directional capacity helps elsewhere. It proves no alternative's
quality benefit.

Retain exactly one inactive question: **do standard feature-valued neighbor
messages on the same protected capable backbone improve complete-task decisions
beyond node-only extra capacity and a capable joint attention predictor?**
A concrete source-attributed operator uses detached neighbor H_j as values,
learned query/key attention over the same observed incoming nonself records,
and a readout of H_i plus the aggregate. Each member can learn which neighbor
features to use even without a labeled anchor. No heldout labels become value
inputs. This is ordinary graph attention/relational continuation, with CoGNN,
Node-MoE and PREF-Gate's label-free context as nearest antecedents; a frozen
private-filter continuation question is already catalogued in v72. There is no
new mechanism, novelty or sharing theorem.

The decisive controls are a capable nonlinear joint four-head single with the
identical message bank; fully untied same-native routes; and a capacity-matched
H_i-only readout. A prospectively fixed graph-alignment control keeps H and
record counts while reassigning neighbor values without labels. Since H already
encodes the original graph, this is conditional evidence alignment, not global
graph causality. Whole-population repairs/harms, accuracy/NLL and member safeguards
must decide; a no-anchor subgroup cannot rescue the result. An ordinary independent
native ensemble remains necessary before stronger quality claims, with its
acquisition cost charged.

Drop this question if the competent native/H_i-only readout or same-evidence joint
single matches, gains are canceled by harms/member weakening, or graph alignment
adds nothing. If the active private-attention study already covers the identical
question, finish/reuse it instead of duplicating a fit. Keep gate15 unchanged and
unopened. A second learned-competence/stacking proposal is not added: it repeats
saved memory and needs authenticated meta-label custody.

The defensible gap is therefore local and empirical: the new scopes do not answer
whether useful label-free relational information, rather than extra classification
capacity or router selection, repairs the current zero-label-support region under
strong matched controls. They do not establish global absence, novelty or benefit.
