## What could remain scientifically useful

For a fixed linear incoming mean matrix A and a node-independent featurewise diagonal factor D_m, A(H D_m)=(A H)D_m. Thus that factor alone does not change this stage's node transport weights or support. A private edge kernel P_m changes the node operator, and the feature union provides genuinely absent paths. This elementary associativity observation is a bounded methodological rationale for measuring parameter ownership, support acquisition and operator weighting separately; it is not new algebra, a new theorem or a diversity guarantee. Preceding and following nonlinear maps can change route states and predictions, so it gives no blanket statement that BE cannot change evidence or expressivity. Private GAT/attention already supplies the strongest direct remedy prior.

The ownership analysis is falsifiable: feature-union versus admitted unchanged anchors measures the whole support/implementation intervention; common/fixed compares learned weighting on the same union; private/common compares private operator ownership. Neither a different operator nor private metric movement establishes complementary correct predictions. Member competence, correct-alternative coverage, pooling losses, net repairs/harms, and equally equipped single/I4 quality/cost remain the required outcomes. Fixed/private alone confounds weighting and ownership, and positive private/common cannot establish an attention-escaping mechanism. Any causal support claim still needs the conditional actual-feature-association control described below.

One falsifiable graph-specific hypothesis is that continuing feature-neighbor paths acquire and serve correct class evidence on native common-rival cases, while a shared kernel/dense bank provides a measured quality/storage frontier. The current record does not establish that missing paths caused those errors. New paths may add nuisance evidence; private kernels may collapse or harm competence.

The fixed/common/private and equipped M1/genuine-I4 recipe distinguishes generic added support, learned weighting and practical shared-bank utility. Private-over-common does not isolate a new attention mechanism. An equally supported tied-value attention or learned-kNN SAGE control could reproduce it exactly or explain a score-parameterization gain; an identical re-expression must not be trained twice and counted as new evidence. These are **remaining conditional controls**, not new arms admitted here or a claim those controls will fail.
