## Mechanism and concrete falsifier

Write member probabilities p_k, their mean pbar, and canonical point probabilities pstar=softmax(mean raw logits). The scalar edge input is

`a_uv = mean_k p_k(u)^T p_k(v) − pbar(u)^T pbar(v)`.

It asks whether **the same member tends to regard the two endpoints as compatible more than independently pooled member predictions do**. Normalized q divides by endpoint centered squared spreads. It is a conventional matched-member soft-compatibility excess, not a new uncertainty principle. It can inform whether to attract or repel neighboring class scores, only if source supervision learns a useful relationship.

This dot contraction sums same-class covariance and discards all off-diagonal/class-specific cross-covariance. Equal a/q can hide different class relationships needing different corrections. GPN preserves class-specific evidence, and HeAD already uses scalar pooled compatibility. The unchanged gate applies a scalar to a whole class-score difference; no unfrozen class-covariance matrix or variant grid is added. Common shared-backbone errors may also be invisible after centering private deviations.

**Concrete falsifier:** a separately competently fitted shuffled gate preserves every node's full member multiset, pstar/pbar and graph features but breaks cross-node member correspondence. If it matches/beats aligned correction at valid independent calibration, or the marginal gate does so, the proposed correspondence increment does not earn promotion. Algebraic information distinction alone does not establish useful labels or novelty.
