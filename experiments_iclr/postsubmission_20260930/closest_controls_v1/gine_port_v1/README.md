# Chemical graph-layer BatchEnsemble comparator

This comparator tests whether a copied-private GINE layer is useful beyond putting inexpensive member factors inside every graph layer. It adds the missing chemical factor-placement control to the pending MolHIV study. It supplies no new predictive result.

The fixed model keeps the existing four-member, width128, three-layer molecular GNNM. Both affine maps in every GINE MLP receive the exact validated SAGE member wrapper, giving six factorized hidden maps and **13,824 additional scalar parameters**. Original GNNM input/output projectors are inherited. Atom lookup, per-layer bond lookup, LayerNorm and trainable GINE epsilon remain shared. All members retain complete node hidden states. There is no propagation or activation-memory saving claim.

The closest source is Kim's2023 KAIST thesis, which uses graph-layer rank-one factors and probability averaging. This is a **declared GINE adaptation**, with bond features and the existing residual/readout recipe. Exact author code and some initialization details were unavailable. It is neither an exact thesis reproduction nor a novelty claim. `METHOD_SPEC.json` gives the construction and primary source link.

Existing runners, freezes and reported scores were not changed.
