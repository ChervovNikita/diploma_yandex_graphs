## Critical remaining explanation: factorized optimization

The new single and four-loss references explicitly prohibit factor wrappers. Shared own-only adds55,772 r/s coordinates around native dense maps. For one fixed member, the source affine map `linear(x*r,W)*s+b` has effective weight `diag(s) W diag(r)` and the same bias. In real arithmetic it can be represented by an ordinary native dense map at each site; floating implementation equality is a separate question.

Thus extra coordinates can change optimization and regularization without enlarging that member's native function class or adding information. Adam and weight decay operate on W/r/s separately, so folding a selected endpoint does not reproduce its training trajectory. Coupled factorized optimization is a serious alternative to a useful plurality/sharing mechanism. The plain native four-loss result does not test it. A factorized M1, with ordinary and four-loss learning, remains the highest-priority discriminating control; it is established practice and cannot supply novelty by itself.
