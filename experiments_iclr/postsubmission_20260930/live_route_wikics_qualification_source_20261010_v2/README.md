Initially Q/K/V/B cotangents are zero because U/C is zero; per-weight maximum gradients are recorded in both modes without a posthoc magnitude gate. Global parameters/head must have gradients in global mode and be absent in local mode; the local head must be inactive in global mode.
4. Per-update actual work: two joint attempts/completions, eight stems, eight calls to each of seven local GAT convolutions, zero baseline or two added-block calls. Local mode has eight local heads and zero global calls; global mode has eight global module/head calls and zero local heads.
