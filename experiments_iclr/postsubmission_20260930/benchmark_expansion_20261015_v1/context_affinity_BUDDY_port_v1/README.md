# Factual context affinity for native BUDDY

Source prepared; native CPU qualification is pending. This separate port adds
the declared C3 common/split auxiliary to the actual source year2007 BUDDY
four-route own-loss model. It does not change the existing BUDDY expansion,
private-BN, NCN or NCNC packages and makes no scientific readiness claim.

The native model, shared source BN, 1024-query mixed minibatch, source negative
sampler, weighted graph/hash features, hydration, dropout, Adam/LR/WD and
ordinary joint BCE remain unchanged. Every sampled row remains in task risk F.
The arithmetic mean of four raw native logits remains the serving output.
There are no new parameters, optimizer groups, source forwards, inference
features, projector or teacher.

The passive call observer captures the live 1040-wide native task prehead
before the final boundary input factors, and authenticates its original
source-hydrated input objects and four-route query order. It reuses the exact
qualified tensor core in `context_affinity_v1/core.py`, with `reduction='joint'`.
The all-block update is F+0.05A, one backward and one original Adam transition.
Common gives every route the average A/B donor target. Split gives A to
routes0/1 and B to routes2/3; there is no assignment search.

Factual targets reuse unchanged `context_affinity_link_port_v2/context.py` and
the frozen `TASK_CONTEXT_SPEC.md` plus link support addendum. The auxiliary
target graph contains all actual source TRAIN positives after native year2007
filtering, then removes loops and deduplicates undirected pairs only for the
target calculation. Source predictor graph/hashes/features are untouched.
A contains sorted endpoint log1p degrees after own-query exclusion. B contains
log1p common-neighbor count, log1p Adamic-Adar sum and log1p resource-allocation
sum. Pair exclusion applies equally to both source groups. The reused code
records support, missing witnesses, zero contexts and preparation/update time.

The fixed link hash selects at most512 distinct nonself, nonconflicting queries
per source group from the existing minibatch. Same-group duplicates retain the
earliest row; cross-group conflicts are omitted only from AUX. Compatible
donors share native relation and observed source group and differ in semantic
identity. The auxiliary uses the joint mean over supported anchors, preserving
BUDDY's source convention without added class balancing. Sampled negatives
are not labeled verified nonlinks.

Checkpoints bind method, source, seed, full target graph, actual query cohort,
factual tensors and support/statistics, plus the complete native optimizer,
sampler, RNG and module-mode state. Restore reconstructs the actual previous
minibatch IDs from the saved original DataLoader RNG/permutation/cursor, then
rebuilds factual targets from those source rows before loading the native state.
Original model/Parameter identity and optimizer ownership are preserved.

The optional paired `context_manifest` / `context_manifest_sha256` settings
enable a passive engineering audit against the authenticated seed0/year2007
materialization. The frozen BUDDY v2 data authenticator checks source provider,
static features/degrees/hash tables and exact saved materialization bytes.
The port then checks the first two original TRAIN batches and complete VALID
hydrated roles without replacing them. This is the new native year2007 context,
not the retained legacy year0 cache. Without this optional audit, targets still
derive from the actual native source graph and sampler for the declared seed;
no materialized queries are substituted. Representative native execution for
this source generation remains pending for either setting.

`METHODS.json` names the two explicit family bindings. `SOURCES.json` pins every
reused dependency. `SMOKE_PLAN.md` declares the minimum real source gate. Only
compile/source review has run here: zero native construction, forward, update
or TEST operation. Full-worker/selected-export/device/pair admission and TEST
reconstruction remain separate from this source port.
