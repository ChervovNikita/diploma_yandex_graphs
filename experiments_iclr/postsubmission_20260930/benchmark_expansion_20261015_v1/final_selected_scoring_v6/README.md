# BUDDY role-dataset argument repair

Source-only successor to `final_selected_scoring_v5`; every predecessor stays frozen.
The role-specific BUDDY helper now hydrates `subgraph_feature_batch_size` from
the exact declared recipe, requires equality with the frozen author preset
(11000000), and rejects a conflicting existing producer value. It modifies only
the deep-copied serving namespace. No source training, model, state, split,
batching choice, tolerance, producer identity or checkpoint changes.

The only other executable change is the successor source schema. All other
functions and source bindings remain identical. The fix covers the BUDDY branch
of this scorer, including VALID/TEST dataset construction; it grants no TEST
authorization. Node, molecular, NCN and NCNC bypass this branch. The original
`final_test_serving_v1/link/backend.py::_buddy_dataset` remains historical code;
these scorers use their own repaired `native_link.buddy_dataset` and retain only
its `_buddy_predict` inference helper.

Run the shared source-only check at
`qualification/composed_BUDDY_selected_VALID_v1/check_source.py`. Actual
zero-training selected replay is separately admitted from that package. Source
fixtures do not claim numerical parity or full-campaign readiness. No campaign
metadata is regenerated by this repair.
