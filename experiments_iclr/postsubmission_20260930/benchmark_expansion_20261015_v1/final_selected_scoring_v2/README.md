# Final scoring of frozen own selected states

**Source preparation only.** No model/tensor library, dataset, checkpoint,
VALID inference or TEST payload has been executed or opened for this package.
Metadata checks do not establish numerical parity, resources or execution
readiness. Published portable/reporting/training sources remain unchanged.

This package supplies the missing inference source for the adopted27presets:
eight PolyFormer, sixteen OGB molecular and three Collab link presets. It
retains original GNNM on the new datasets and excludes the original paper's
five-dataset experiments. There are no added training fits or hyperparameters.

## Interfaces and phase ordering

Import as a Python package, with the expansion folder on `sys.path`:

```python
from final_selected_scoring_v2.contracts import compile_roster
from final_selected_scoring_v2.seal import build_training_seal
from final_selected_scoring_v2.backend import score_fit, aggregate_i4
```

`compile_roster` is a pure metadata function. Supply the exact reporting index
receipt, all27loaded profiles, each preset's frozen TEST role-contract receipt
and loaded contract, and the final output root. The function retains all
physical native bodies, original GNNM, extensions and prescribed diagnostics.

The **same campaign review and user GO cover training and frozen final
scoring**. The existing `portable-human-GO-v2` record includes `final_scoring`
binding this source manifest, scoring roster and exact training release.
The runtime caller provides the existing host/source/resource admission
callback. This package never creates a human authorization or another prompt.

Every original training task must first be terminal. `build_training_seal`
verifies all6,730durable task-state/terminal authorities and derives the exact
available own checkpoint/epoch/VALID-export bindings. It refuses pending,
running or interrupted work. Failed, launch-failed, no-winner and failed-I4
dependency outcomes remain present. No TEST output is involved in this seal.
The seal is a deterministic machine artifact under the existing campaign GO.

Only after this full outcome/selection seal may final workers run. Transfer
the immutable seal and needed evidence once; no online coordinator, heartbeat,
expiring lease or connection to the other Mac is needed during inference.
The current sealer consumes the current single-allocation release containing
all6,730tasks. A later distributed training release needs root's offline
host-shard merge/transport binding before this same global phase can be used;
it must not treat a partly finished host as a finished campaign.

`score_fit(request, go_pin, root, admit_runtime=...)` runs one predetermined
selected-state task in a fresh, reservation-owned worker. It binds the task,
registry/profile, descriptor, terminal training RESULT, sealed selection,
source closure and role contract. It reconstructs through the **current
portablev3 controller and adapter factory**, restoring its exact callback,
extension, optimizer/private state and selected RNG. It never calls the fit
loop. Every optimizer's `step` is disabled for inference.

It first reconstructs complete VALID predictions and compares them with the
already exported selected VALID logits/IDs/labels, using frozen tolerances.
Declared same-bank means and link endpoint order must match too. Parameters
and buffers must remain unchanged. Failure prevents TEST access. Then it
restores the selected state/RNG again, checks the official TEST population
authority and serves that role once. No checkpoint/arm/readout/seed choice,
calibration, TEST-driven retry or tuning follows. All outcomes and costs persist.

## Exact serving behavior

- **Node:** unchanged native transductive graph, normalized features and
  polynomial basis; use each selected job's literal source split and TEST mask.
  Existing `_routes(False)` preserves private input/state contexts.
- **Molecules:** native categorical features, GCN/GIN/virtual-node backbone,
  official scaffold TEST indices, original batch32 PyG collation and singleton
  skip rule, observed-label semantics and OGB ROC-AUC evaluator. Every skipped
  graph ID is retained; a reduced population cannot silently pass.
- **NCN/NCNC:** unchanged source role inference and full official query order.
  TEST uses source TRAIN-plus-positive-VALID adjacency. Native route contexts,
  predictors and NCNC recursive/top-level factor scope remain active.
- **BUDDY:** original year>=2007weighted TRAIN plus weighted VALID topology,
  fresh role-specific original HashDataset/hash/SIGN/query features, and the
  original combined-query inference function. TRAIN/VALID caches are not used
  for TEST. The prior prepared source helpers are reused after the current
  adapter factory has restored the actual method state.

All route calls remain **sequential**. Routes are not concatenated into a new
batch. Native/shared or private BN ownership and the original probability/raw
logit convention remain intact. `readout_policy` classifies all current methods
and compiler runtime aliases. A declared aggregator must be found as exactly
one restored registered module; it cannot fall back to a uniform mean. Input
residual and other inference hooks remain attached. Aggregation takes logits,
never TEST labels. Source risk-only auxiliaries are not rerun during inference.

The TEST tensor export contains the actual served logits, all route outputs,
labels, IDs, link endpoints, own selected checkpoint/epoch, native metrics and
readout/source authority. Per-route metrics are descriptive. Where declared,
the mean of the **same** bank outputs is exported with the same checkpoint and
epoch, labeled diagnostic, with no extra forward or reselection. The scalar
RESULT preserves missingness, convergence/stop flags, role/selection/GO pins,
VALID reconstruction, wall/stage/resource costs, actual metrics and failures.

`aggregate_i4` consumes the four exact native TEST exports. It checks each
own job/hash/seed/body/selection, common cohort/population/order and exact
body0/M1 reuse; averages raw logits and calls the native evaluator. There is
no new model, TRAIN update, TEST forward, common selected epoch or fitted weight.
