## Forward, losses and parameter ownership

Each update uses the original `_next_train_batch`, zeroes the original optimizer,
and executes exactly four existing route forwards at the same old parameters.
F is the mean of the original `_native_loss` values. W uses observed FP32 BCE
records from those same predictions, multiplied by fixed FP64 weights, reduced
by the same within-route mean and mean across routes. This matches the retained
responsibility law and the native mask/casts; weights are not a class-balanced
replacement for native BCE. The source has zero explicit loss regularizer.

An exhaustive identity-checked partition contains:

- **Shared:** every original native parameter, including BN affine and the
  original native head.
- **Private:** exactly the original residual down/up tensors, shapes
  `[4,8,300]` and `[4,300,8]`, totaling 19,200 learned coordinates.
- **State:** private BN running buffers and the fixed TRAIN weight table are
  not gradient parameters.

The residual wrapper lacks the old BE `_source_parameters` API. A small explicit
partition view supplies that API to the unchanged source
`training_rules.step_private_responsibility`. It collects `dF/d(shared)` and
`dW/d(private)` before assigning any gradients, then performs one original Adam
transition. Production uses two reverse collections, four native route forwards
and no extra view. Model parameter objects, optimizer groups, ownership and
options are checked before/after updates and restore. No native parameters are
frozen. This block field is not claimed to optimize one global scalar, and later
shared trajectories can differ as private parameters learn.

The update's `loss` is the weighted private diagnostic W. Logs separately name
`native_unweighted_F`, `private_weighted_W` and each native member loss. Whole
VALID selection and mean raw-logit prediction remain the unchanged native path.

The producer checks exact zero up matrices at construction, with no second zero
gate. After training, nonzero up matrices are accepted on restore. Keeping the
initial native function is not preserving a trained competent model or proving
useful specialization.
