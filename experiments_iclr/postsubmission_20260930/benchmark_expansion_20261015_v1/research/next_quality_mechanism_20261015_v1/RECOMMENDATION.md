## 1. First choice: balanced structural private supervision

**Hypothesis.** Different private routes can learn reliable responses to different
graph regimes while retaining native task supervision everywhere. A native
initial function avoids a large imposed starting disturbance; balanced tasks
then supply a persistent source of different prediction gradients. This is
especially worth distinguishing from random responsibility, rather than
assuming size/degree is a useful task partition.

Use the existing exact rule [S1]. Within each observed TRAIN class, divide
atom-count ranks for molecules, or incoming-degree ranks for nodes, into four
equal-mass quartiles. Split tied ranks fractionally. For membership q_m(i), set

`w_m(i) = .5 + 2 q_m(i)`.

Every weight is between .5 and 2.5; every route retains the original total mass
of every class; every record's mean weight across routes is exactly one. Native
mixed-batch BCE/CE reductions remain unchanged. Shared parameters receive
unweighted mean native own risk F; private parameters receive weighted own risk
W, from the same old state before one original optimizer transition. This block
field need not be a single scalar gradient. Later shared trajectories can differ.

The target composition uses the **current residual-only parameter partition**,
with the same private BN policy where native BN exists. It adds no learned
coordinates, graph rewrite, projector, auxiliary embedding loss or new head.
It adds a fixed four-by-TRAIN weight table and a second reverse collection;
unchanged route forwards do not imply unchanged runtime or memory. The current
standalone structural bridge targets BE and rejects extended sessions, so this
composition is **not implemented or qualified by its existing CPU pass**.

Native parity is parity with an **untrained** native constructor, not retention
of an already competent learned model. At zero residual up matrices, down
gradients initially vanish; up gradients can learn through different down frames.
The weights change that supervised up-gradient signal without needing a second
zero gate [L1]. No competence, diversity or accuracy guarantee follows.

**Predicted signature.** Relative to the uniform residual bank, routes should
improve task margins in their emphasized TRAIN-defined size/degree regimes;
the corresponding VALID accounting should show fewer common wrong rivals or
positive–negative reversals and net served repairs after full-population harms.
Mean/worst member AUC or accuracy and BCE/NLL must expose any competence cost.
A larger union of correct members without served benefit fails the quality
hypothesis. Regime association is descriptive, not causal evidence of new graph
information.

**Decisive paired experiment.** On the same MolBACE GIN protocol and seeds
101/202/303, compare the paid uniform residual-only bank with two prospective
procedures: the fixed structural rule and its existing whole-vector within-class
permutation control. That control preserves every weight value, route/class mass
and per-object total while randomizing its association with size. Six new shared
fits would answer this one question; no new M1/I4/G0/private-BN controls are needed
when their exact receipts are reusable. Keep all those references visible.

A structural win over uniform but a tie with permutation supports generic
responsibility/regularization, not structural specialization. Loss to uniform,
or extra common errors/served harms outweighing repairs, rejects this fixed
recipe; do not change quartiles, strength or descriptors afterward. An incremental
gain that still trails genuine I4 remains an incremental result.

If this question earns continuation, repeat the same structural-versus-permuted
contrast on the already proposed **Coauthor-CS native PolyFormer setting** [S3]:
node classification, polynomial/attention backbone and no native BN. Exact native
M1/genuine I4, original GNNM and uniform residual controls must be available under
that protocol; old SAGE controls cannot substitute. This is a representative
transfer question, not an additional recipe grid or a claim that degree is useful
for every task. Do not invent a link “class table” for dynamic native negatives;
link reductions and query populations need their own definition before transfer.

## 2. Second choice: conditional aggregation with an objective control

**Hypothesis.** Existing route confidence/disagreement contains TRAIN-learnable
information about which predictions survive pooling. The existing 20-parameter
gate [S2] starts at exactly the raw-logit mean, uses detached normalized entropy
and JS-to-bank descriptors, and serves convex raw logits with weight
`alpha_m = .05 + .8 softmax(score)_m`. All four routes remain active. Train
`J = .5 F + .5 native_loss(actual_served_logits)` using native task reductions.
This adds 20 FP32 parameters/80 parameter bytes and 160 dense Adam moment bytes,
plus small descriptor activations; it adds no backbone or native forward.

The relevant screen is the existing **mean-J / global-weight-J / conditional-J**
comparison, three paired seeds on one setting: nine new shared fits if chosen.
Uniform own-F remains the paid baseline. The mean-J control identifies an
objective change; global-J identifies average route reliability; conditional-J
must add something beyond both. A same-selected-bank gate-versus-mean readout
isolates its serving effect, while separately trained banks estimate the whole
learning/serving procedure. No VALID fitting or final gate refit is allowed.
All three must use the same genuine native-initialized producer and normalization;
the current standalone bridge does not yet qualify that composition.

**Predicted signature.** Same-bank conditional serving should reduce lost useful
alternatives with positive net repairs, with weights related to actual conditional
reliability rather than merely greater confidence. A gate that only matches
global weights supplies no conditional explanation. Improvement only against
own-F, with no gain over mean-J, supplies no aggregation explanation. Retain
pooled AUC/accuracy and proper-loss tradeoffs against M1, genuine I4 and original
GNNM. Any later sharing attribution additionally needs the same objective/readout
opportunity for genuinely independent members; ordinary I4 is still a quality bar.

There is a useful limit for deciding whether this deserves priority. At a fixed
multiclass bank, a rival above truth in every member remains above truth under
nonnegative route weights shared across classes. For binary ranking, input-dependent weights
can repair a pair reversed by every member, so the fixed-mean pair barrier must
**not** be transferred to this gate. Instead, with the declared floor, feasible
scores lie in

`[.05 sum_m z_m + .8 min_m z_m, .05 sum_m z_m + .8 max_m z_m]`.

If a positive's upper endpoint is below a negative's lower endpoint, no such gate
can repair that pair at this bank. This is elementary convex-score algebra, not
a new theorem, computed result or attainable oracle. Authentic completed-bank
diagnostics can distinguish lack of usable predictions from poor fixed pooling.
Do not commission aggregation because coverage alone looks large. The earlier
single-seed probability-mean diagnostic was mixed in AUC and worsened BCE [E9].

## Why these two, and the stopping boundary

TabM supplies early private adapters, own losses and collective selection, not
a guarantee of competent heads; GNCL already supplies own/pool mixtures; CMCL
already supplies learned specialization/confidence control [L2,L3,L4]. The proposed
distinction is an explicit target/credit intervention and a separately controlled
readout. No fresh primitive, prior-art clearance or new paper-reading credit is
claimed. A cheap affine-head ensemble over one identical prehead collapses to
its mean head [L5]; no observed bottleneck currently warrants paying for a new
decoder family. Added sparse paths/endpoint builders also have substantial
negative or cost evidence [E4,E10].

Choose **one** question after the current terminal report, freeze its exact
producer, convergence/selection rule and practical quality/loss criteria before
new fits, and preserve every seed and cost. Do not combine these candidates,
add teacher acquisition, or tune a failed setting into success. Three seeds
on an already exposed VALID split are development evidence. A useful result
would justify separately frozen representative confirmation, not universal
