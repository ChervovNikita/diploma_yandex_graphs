# Four explicit native BUDDY interactions

This factory constructs one fresh original BUDDY boundary session and assembles
fixed tensor components directly. Its own source package is distinct from NCN,
NCNC, standalone BUDDY ingredients, C3 and private BatchNorm. Native weighted
year2007 graph/hash hydration, SIGN-k0, shared BN, dimensions, sampler, route
RNG, every original affine Parameter and Adam group/options remain intact.

All four routes retain every original mixed1024 TRAIN row. F is the mean of
four original joint BCE losses. I1 uses shared F and private F+0.05 endpoint
contrast; I2 uses shared F and private0.5 corrected endpoint-v2 weighted risk
plus0.5 mean-logit BCE. Both collect their two declared block gradients from
the same old state, then apply one original Adam transition. I3 uses one
all-block0.5F+0.5 mean-served BCE; I4 substitutes the fixed conditional20 served
BCE. Endpoint support, floor0.25, temperature0.2,1024 anchors/16 alternatives,
query scope and BUDDY joint reductions use frozen ingredient helpers.

I1/I3/I4 retain BE and append rank8 portable-v2 residuals to both original
input affine outputs: label_lin_layer width16 and lin_feat width1024. These
add66,560 private Parameters. They preserve the qualified small-width frame
policy, isolated seed+901003+104729*branch and exact zero-up initialization.
I2 has no input residual. The conditional gate adds20 Parameters; mean adds0.
Every extra Parameter joins its native anchor's existing Adam group.

The authenticated source context checks the exact seed0 native model provider,
static graph/hash/features and first two original TRAIN batches plus both
whole VALID roles. No artificial balancing, rows, source forward or objective
is added by the observer. The checkpoint includes native state plus source
sampler IDs and query/contrast/responsibility receipts; restoration rebuilds
those receipts from the original saved DataLoader law before loading state.

VALID serves arithmetic means for I1/I2/I3 and conditional logits for I4,
using the original source evaluator and diagnostic-loss law for each. The
same-call mean is also returned and cached with the update clock; its getter
adds zero forwards and is invalidated by TRAIN or restore. Production selected
checkpoint export still requires a separate full-runtime gate.
