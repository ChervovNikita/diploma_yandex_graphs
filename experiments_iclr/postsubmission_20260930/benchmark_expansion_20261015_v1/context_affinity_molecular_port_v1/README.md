# C3 molecular context affinity port

The two methods implement the exact frozen root context core and task target specification on live native molecular graph preheads. `context_affinity_molecular_common_v1` gives all four routes the same average factual target. `context_affinity_molecular_split_v1` gives routes0/1the atom target and2/3the bond target. There is no assignment search. Existing native observed-label BCE is unchanged and remains active on every native batch supervision record.

A is concatenated per-field atom-category frequency histograms. B is concatenated per-field bond-category frequency histograms from actual source directed bond records, with no coalescing or symmetrization. Vocabulary sizes come from the actual native AtomEncoder/BondEncoder embedding tables, with source file pins and all layer bond vocabularies checked. Full nine atom and three bond fields remain native. Edgeless molecules have zero B; zero context produces the core's uniform donor target. Canonical CPU FP32 histograms make saved target signatures reproducible independently of model device. Only permitted existing native input records are used.

Each existing native minibatch supplies all graph IDs; only observed TRAIN labels define the auxiliary. Donors must be distinct graph IDs in the same observed class. Missing-label graphs are absent from auxiliary targets; zero-context and donor-unsupported anchors are reported. The frozen core unit-normalizes factual contexts and live preheads, uses temperature0.2, detached factual donor probabilities, supported-anchor class-balanced reduction, and nativeF+0.05A with ordinary all-block backward. No head, projector, model, inference context or extra backbone pass is added. Native parameters, Adam groups/options, graph features/operators, source sampler/skip rules, shared sequential BN behavior and mean-logit prediction remain unchanged. The auxiliary does not directly train the downstream output bank.

Checkpoints bind source/core/spec, exact native vocabulary sizes and encoder files, permitted graph identities/labels and actual histogram signatures. Restore rebuilds the last context from authentic source TRAIN graphs before loading state and rejects a changed signature. Construction and auxiliary host wall times are logged, without claiming synchronized GPU latency.
