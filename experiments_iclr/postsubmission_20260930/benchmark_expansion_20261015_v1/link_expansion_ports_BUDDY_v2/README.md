# Separate native BUDDY compatibility generation

Prepared source for C6 mean/global/conditional and corrected responsibility
unit/query/endpoint around the unchanged native BUDDY session. Existing portable
input v2 remains unchanged and is checked through its existing callback with
an external materialized-context auditor. NCN and NCNC packages are separate.

BUDDY training uses its original mixed1024-query BCE batch mean. C6 computes
J=.5F+.5L_actual_served with that joint reduction for every block. It adds the
frozen0/4/20-parameter readout to the existing native final-head Adam group.
Responsibility assigns shared-F and private-W gradients from one old state;
weights normalize within the one original joint source batch, with no added
positive/negative balancing. No NCN group reduction is used for training.

The source native session retains year2007 filtering, weighted graph coalescing,
SIGN-k0, both native input branches, hashes, negative sampling, outer sample
permutation/DataLoader order, shared native BN and dropout/private RNG. Passive
observers authenticate actual selected links, labels, hydrated inputs and route
outputs. No native model class, Parameter or source operator is replaced.

The old retained year0 cache is an incompatible context and is not reused.
`CONTEXT_PLAN.md` describes the prerequisite source context materialization.
The new callback requires the exact successful context manifest SHA256 and
checks native static features, degrees, hash banks, filtered source positives,
both authentic TRAIN batches and both complete VALID input roles. Context data
is validated against the actual source session, rather than injected into it.
This prepared context is seed0 only; other seeds remain unqualified.

VALID Hits@50 uses all60,084 positive plus100,000 negative source queries.
C6's served and same-bank mean diagnostic losses use joint BCE; the unchanged
source callback's split-group diagnostic is retained separately and does not
select a state. Checkpoints retain the exact source/context/method binding,
native sampler, global/private RNG, optimizer and readout parameters.

Actual CPU qualification is conditional on a passed native materialized
context and current memory preflight after NCNC's sequential checks end.
The finite BUDDY supervisor has eight fixed cases, two updates and three full
VALID calls per case, fresh-source restoration, two CPU threads,64GiB address
space and1,800 seconds per child. It stops on the first failed case; no retry
is automatic. Until those receipts exist, these are prepared ports only.

No full fit, convergence, GPU training, TEST, server77, final TEST reconstruction
or campaign admission is provided. The frozen native bridge, runtime, prior
pilot and completed NCN/NCNC source generations are not edited.

V2 corrects the method-binding metadata to require all three context fields,
retains joint BCE diagnostics consistently for all six new methods, and records
BUDDY forward/query work in future epoch summaries. The staged source-only v1
is preserved; neither BUDDY generation has executed a model check yet.
