# Expanded source binding audit

Every shared method in the proposed 27-setting matrix now has either an exact
source entrypoint or an explicit missing-port record. `BINDING_AUDIT.json`
contains 511 method/setting entries, representing all 5,110 proposed shared
fits. Native source reproductions and four independent bodies remain separate.

| Source projection | Proposed physical fits |
| --- | ---: |
| Entrypoint exists, execution qualification pending | 4,940 |
| Native port still missing | 170 |
| Required native source reproductions | 270 |
| Required matched native bodies | 1,080 |
| Total proposed | 6,460 |

The 170 missing fits are four interaction recipes on each link architecture,
context targets on NCNC/BUDDY, and BUDDY private BN state. They are present in
the scientific roster; no dummy callback or silent method substitution fills
those entries. New ports will require a new binding-audit generation.

Existing source is only one preparation step. BUDDY's new source-context
manifest is not yet bound. NCN context v1 has a known CUDA reconstruction gap.
Whole epochs, all source splits, selected serving, stop/resume, measured
resources and three-GPU deployment remain explicit gates. CPU checks of one
architecture do not qualify another architecture or GPU execution.

`build.py` uses only the standard library, parses source definitions without
importing models, pins source bytes and checks the complete roster projection.
It creates no per-fit descriptors, training processes or launch commands.
There are zero runnable jobs in this audit. Existing frozen descriptors for
the earlier 2,480-fit proposal remain intact as predecessor evidence.

This audit records a snapshot, including sources still under their separate
finite qualification. It is not a final campaign manifest or a claim that
4,940 fits are ready to run. Only the dedicated allocation is authorized now.
