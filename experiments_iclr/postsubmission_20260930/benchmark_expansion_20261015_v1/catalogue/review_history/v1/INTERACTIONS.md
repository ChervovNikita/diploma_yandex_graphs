# Selected interaction studies

These are chosen questions, not an authorization, complete matrix or fit total.
Each needs the retained matched M1/GNNM/independent4 references. Genuinely
independent models retain their own training and selectors; a cross-body coupled
objective creates a separately named joint-untied control.

## I1 — private input capacity × graph alignment/variance

**Already frozen by root:** the existing MolBACE pilot contains original boundary
GNNM, alignment/variance alone, zero-start private input residual alone, and both.
This catalogue preserves that experiment without editing its source, settings,
criteria or launch. It asks whether useful molecular task geometry needs more
than boundary diagonal capacity. The main effects and interaction concern pooled
ROC-AUC/BCE and errors, not auxiliary loss or latent variance alone.

Use `delta = Q(both)-Q(adapter)-Q(auxiliary)+Q(base)` on the same predeclared
task-quality scale, together with complete member/pool results and actual costs.
A favorable interaction can coexist with an unfavorable final combined model;
it is not sufficient to advance a combination. Do not reinterpret the closed
historical node alignment/residual interaction as the molecular result.

## I2 — structured private responsibility × pooled private credit

Shared weights receive ordinary mean native own risk F in every cell. Let W be
the source-reduction-preserving structured weighted own risk; W=F in the uniform
control. Private coordinates receive `(1-lambda)*W + lambda*L`, where L is native
loss of the declared served pool and lambda is fixed to 0 or .5. This defines
four exact learning rules without subtractive or negative supervised weights.

Question: does a persistent task assignment complement ensemble credit, or does
pooled credit merely undo assignment? An assignment-shuffled control preserves
class/group/member mass; an IID control separates structure from generic noise.
Those are targeted controls rather than a second crossed grid. Freeze a task's
assignment and native loss groups first; retain genuine I4 plus any separately
labelled coupled untied test needed for a sharing claim. Private-only credit
does not guarantee preserved shared trajectories after later updates.

## I3 — private nonlinear capacity × TRAIN-fitted aggregation

All cells use the same native task objective convention: half mean-own F and
half loss L of their actual served output. The aggregation factor is fixed mean
versus a zero-start mean-initialized conditional gate. The capacity factor is
no residual versus the one declared zero-start private nonlinear residual.

Question: do members acquire useful alternatives that a mean cancels, or does
the extra gate simply supply a stronger classifier? A parameter-matched shared
adapter and nonlinear concatenation gate are necessary attribution controls.
Fit gates on TRAIN jointly, or a separately frozen TRAIN cross-fit protocol;
never fit a new combiner on selected VALID. Preserve source query groups for
links and graph-level rows for molecules. This is prepared after the separate
capacity/aggregation implementations and cost/role checks, not selected by a
posthoc search over combinations.

## I4 — private input adaptation × running-BN ownership

Compare boundary GNNM versus the fixed input adapter under original shared BN
buffers versus private per-route buffers, retaining shared affine Parameters,
native BN operations, original batches and route order. The hypothesis is that
an adapter changes route distributions enough that one shared EMA partly hides
its utility at eval. It could instead be an irrelevant calibration effect.

Where the assumptions in BN_STATE.md hold, private running state does not alter
the instantaneous TRAIN normalization. Prospectively record route banks and
compare same-weight, same-epoch eval outputs before requesting extra fits. This
requires actual saved route state: a shared EMA cannot reconstruct four private
histories. The current frozen pilot is not modified to obtain missing buffers.
If output selection affects future training, compare controllers explicitly;
do not equate same-weight readout with a complete stopping-policy experiment.

## Selection/readout control, separate from the interaction factors

TabM (correct source `2410.24210v3`, §3.3–3.5 and §5.1) motivates collective
selection and measuring individually overfit but collectively useful submodels.
GNNM's selected checkpoint remains one complete shared body and factor bank.
Selecting a different historical checkpoint for each route would require
different slow-weight states; it is not the same cheap shared model. Independent4
retains four own selections. A future same-epoch readout can diagnose selection
effects only when those exact checkpoints/predictions were saved prospectively;
scalar epoch curves cannot reconstruct unavailable bank outputs. No new such
analysis or result is claimed here.
