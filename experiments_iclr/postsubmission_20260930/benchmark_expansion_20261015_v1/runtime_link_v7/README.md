# runtime_link_v7

Narrow successor for authentic non-interaction link metadata. The fixed allowlist binds callback, outer manifest, extension, schema, method and source receipts. C6 consumes the three same-call mean fields already returned by its native VALID call; unchanged-mean methods export their actual serving once. No model/input/optimizer/training source changes.

The accepted `LinkSameCallMeanAdapter` class is byte-identical to v6. Six other runtime files are byte-identical. The new source authority file is pinned in runtime dependencies, so old checkpoints are not migrated.

25 verbatim published metadata declarations pass the source protocol check and refuse altered callback identity. Production BUDDY C6/private-BN schema shapes are source reviewed; that is not an actual native pass. No Torch/model/tensor/native work was performed by these checks. NCN/BUDDY minimal combined proposals live in the dispatcher successor.
