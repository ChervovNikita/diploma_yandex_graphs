# C1 node class geometry

Two named methods attach a task-aware auxiliary to the unchanged native PolyFormer boundary GNNM: `task_node_class_alignment_v1` and `task_node_class_alignment_variance_v1`. This is an explicit multiclass adaptation of the frozen molecular helper; that helper and its active pilot remain unchanged. The local helper exactly matches the molecular formula and gradients for binary labels. It extends the class loop to arbitrary observed categorical labels.

The input is the live `[4,N,H]` native TRAIN prehead tensor from the same four source activation-checkpointed forwards used for CE. Every original TRAIN node retains the original unweighted CE reduction. The auxiliary sees at most512distinct TRAIN nodes selected once per fit. Nodes are SHA256-ranked by fit seed/class/ID inside each class and selected round robin across sorted classes; selected rows retain native source order. The cohort never changes across epochs, depends on no current loss or VALID result, includes every class and at least2nodes/class when available, and fails if that minimum cannot fit. Class-balanced cohort selection is not an unbiased estimate of a full-population auxiliary. No node is removed from native CE.

On unit-normalized selected preheads, positives are other existing same-class route/node records, including the same node in other routes. All other observed classes provide alternatives. The denominator first averages exponentiated similarity inside each class, then sums classes; anchor losses are averaged inside class and across eligible classes. Temperature is.2. One observed class gives zero alignment; there are no fabricated instance negatives or prototypes. A singleton class can have three same-node cross-route positives but cannot supply distinct-node variance.

The second method adds the same molecular within-route/class variance hinge, measured across distinct nodes after unit normalization. The target std is.5/sqrt(H), variance epsilon1e-8 and normalization epsilon1e-12. Classes with fewer than2selected nodes are not included in the variance mean. A one-class cohort may still have variance support. At exact within-class collapse, a positive penalty can have zero gradient; it does not guarantee avoidance of collapse. It does not require routes to differ and is not indiscriminate route repulsion. Missing-label rows have zero auxiliary influence in the standalone helper; native source node CE requires observed long categorical targets and supplies no missing targets in this bridge. Every update logs selected/observed/missing counts, class/positive/variance support, one-class gating and singleton classes.

Both methods use ordinary all-block backward on `F+.05*A` or `F+.05*(A+V)` and one original Adam transition. The coefficient.05 is not a bound on auxiliary gradient magnitude. All source operators, dimensions, graph preprocessing, parameters, optimizer groups/options, activation checkpointing and mean raw-logit readout remain unchanged. Preheads are upstream of the final lin3 layer and its boundary factors, so the auxiliary does not directly train that output block; native CE still does. No extra native forward, projector, augmentation, routing, RL or trainable parameter is added.

## Relation to the retained within-route SupCon baseline

`boundary_own_within_route_supcon` remains unchanged and separate. It uses all TRAIN nodes, treats each route separately, uses same-class other-node positives, a denominator over all other nodes, and a node-weighted anchor mean. Its source assumes each class has a distinct-node positive. The new objective changes cross-route support, class balancing and auxiliary cohort together. Comparing these methods does not isolate only cross-route alignment or only variance; the alignment-versus-alignment+variance pair does isolate the added variance term at the same cohort/settings.

This attributed experimental composition builds on SupCon/BCL/VICReg ideas; it is not their exact reproduction or an established methodological novelty. No predictive improvement follows from engineering checks. Planned qualification is only two complete CiteSeer-Cheb CPU TRAIN updates per named method, full VALID, fresh-session state restore, two threads, hidden CUDA. No TEST, GPU, Physics/link/full fits or full campaign GO is included.
