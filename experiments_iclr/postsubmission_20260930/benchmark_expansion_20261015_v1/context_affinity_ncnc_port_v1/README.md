# Prospective factual context affinity for native NCNC

This new source port retains exactly the frozen C3 common/split target law,
cohort/hash/deduplication gates, coefficients and device-safe reconstruction
of context_affinity_link_port_v2. It targets actual NCNC/ogbl-collab only.
No NCN or BUDDY execution is admitted here.

The original qualified TaskCallScope owns recursive dispatch and task-only
output-bank application. A new passive outer observer records source task
depth, captures only depth-one original task preheads, and leaves every
recursive completion query, call, operator and RNG operation native. The
frozen prehead hook uses the original depth-one gate, so recursive final
leaf activations are not auxiliary objects. Original task/recursive dispatch
and output-bank receipts must match the passive observer after each update.

F still includes all65,536positive+65,536negative top-level source queries in
each of4routes. The original whole-minibatch predictor graph mask is untouched.
All recursive predictions remain in the native computation graph. Factual
context supervision uses the full simple TRAIN-positive graph excluding only
the current selected top-level pair; it is not substituted into the predictor.
A is sorted log1p endpoint degree. B is log1p of CN, AA_sum and RA_sum, all three
coordinates. The original fixed support addendum is included unchanged.

At most512unique, nonself, nonconflicting existing queries per source group
enter AUX via the original hash. Same-group duplicates use the earliest native
row. F retains all source rows. Compatible distinct donors share source group
and relation; zero contexts yield uniform targets and unsupported anchors are
reported. Common assigns0.5qA+0.5qB to each route; split assignsqA to0/1 andqB
to2/3. Both use the original separate-group mean sum,4route mean, temperature0.2
and F+0.05A. No new parameter, head, forward or inference feature is added.

The auxiliary may reach the SHARED source task head through original recursive
completion paths. It has no direct path to private output banks because those
banks apply only after the observed top-level prehead and are bypassed in
recursion. Native Parameter identity, original source Adam/options, complete
sampler/global-and-privateRNG/TaskCallScope/epoch state, source/target hashes,
actual selected tensors and semantic support receipts are preserved. Restore
uses explicit colocated endpoint gathers followed by CPU authentication.

Status: frozen source/local helper checks only; NCNC native qualification is
pending a separately approved finite smoke plan. Existing NCN CPU evidence and
qualified NCNC standalone observer evidence are lineage, not this method's
accuracy or native readiness. No TEST, GPU update, scientific fit, convergence
claim or novelty claim. CUDA lifecycle, two-worker resources, full-worker and
final TEST reconstruction remain separate gates.
