The retained server51 diagnosis shows matching GRAPH/TRAIN/VALID bytes and SHA256
and matching fixed configuration. Provider v2 rejected only the allocation
absolute path embedded in the static authority. The successor provider validates
exact typed relocation between the two known project roots. It keeps actual
native receipts unchanged and records both paths. Static tensor equality and all
numerical code remain intact.

`PATCHSET.json` enumerates every source file in four minimal successor packages.
`REGISTRY_DELTA.json` provides exact callback, package manifest and authority
identities, plus the allowed execution-descriptor replacement map.
`link_authority.py` is the byte-identical predecessor source with three explicit
registry additions; no historical entry changes. All three consumer session.py
files and the compact static provider authority are byte-identical to parents.

Deployment integration belongs to the successor port producer. It must use the
new callbacks and provider manifest identities in actual execution descriptors,
rederive composed parent bytes/receipts and reporting presets, and prepare fresh
smoke inventories and execution plans. Canonical fit IDs, ownership, scientific
contracts, fixed settings, seeds, split, body and training policy remain fixed.
Existing failed smoke attempts remain in their prior state/output directories.

The original normalization adapter explicitly checks the portable-dispatcher
parent factory's source path. A successor producer must handle that actual
source contract honestly; redirecting the factory without a matching explicit
successor binding will fail. No module alias, fake receipt view, or in-place
change to old provider/runtime sources is part of this patchset. Paid selected
replay and original inference helper sources remain available unchanged.

Validation: six stdlib metadata tests cover the actual remote failure fixture,
unchanged allocation identity, rejection of changed content/role/path/root,
absence of input mutation, exact unchanged numerical source comparison, and
