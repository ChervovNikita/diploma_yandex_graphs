# Preserved predecessor descriptor preparation

`prepare_descriptors.py` prepares concrete runtime_v2 descriptors from the exact
frozen 27-cell ROSTER, 2,480 PLAN fit entries and actual smoke recipes. The 270
source-reference fits remain separate from the 2,210 main fits. This number is
the predecessor census; it is not the final expanded study count.

Run the allocation copy only, through the reviewed allocation guard. It uses
stdlib metadata validation, hashes source/data bytes without deserializing
tensors, and writes each full descriptor under a new remote `generated_v1`.
Every descriptor retains its complete original PLAN entry and contract hash.
The generated index, logical banks and 540 statistical jobs stay remote.
Local copies are limited to this source and compact manifests/readiness.

Main M1 is the exact I4 body0 fit. Every I4 has four distinct native fit IDs,
initialization seeds, optimizers and selection authorities. No I4 fit is added.
Node split seeds and role bindings come directly from the frozen recipe; this
metadata preparation does not materialize masks or qualify unsmoked splits.

Source/main policies are node 2000/patience250 versus10000/min2000/patience100;
OGB100 fixed source epochs versus1000/min100/patience50; and pinned link100 fixed
source epochs versus1000/min100/patience50. Eligible source OGB descriptors pin
the existing audited omitted-TEST-iterator CPU RNG bookkeeping. TEST inference
and metrics stay omitted. Link explicitly pins its own integration/policy and
discloses VALID-only adaptation. Source BUDDY can end `no_selected_state`.

Historical worker assignments are preserved as source metadata. All descriptors
remain in allocation custody. Server77 root, environment, device mapping and
deployment remain blocked and unverified. No scientific process is launched,
no measured resources/costs are fabricated, and no campaign admission, compiler
output or human GO is supplied by this package. Runtime guards are unchanged.
