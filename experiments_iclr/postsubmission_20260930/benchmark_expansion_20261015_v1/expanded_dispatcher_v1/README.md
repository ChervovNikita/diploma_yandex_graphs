## Dispatch, claims and restart

The predecessor's measured resource contract and physical probe/admission code are reused by exact source pin. At most two owned children occupy a physical GPU from startup through reap, including I4 export tasks. Serial profiles exclude overlap; pairs require reciprocal measured peer profiles, total process VRAM, host RAM, disk and explicit headroom. Unknown owned GPU PIDs block admission. Allocation physical-GPU and legacy worker leases prevent duplicate supervisors.

Only fixed `run_fit.py` and `aggregate_selected.py` handlers can dispatch. Source/interpreter/job/gates/GO/readiness are rechecked before every admission. There is no arbitrary command or shell payload. Native runtime provenance, including bounded-source/full-campaign labels, is preserved; the mandatory campaign-scope bridge must explicitly resolve it.

Each physical task has a permanent immutable claim, durable state and separate immutable attempt START/PID/terminal/stdout records. Complete/no-selected results are skipped after exact identity and selected-export receipts are verified. Unknown/live/orphan claims are never stolen or killed. Existing unclaimed output blocks execution.

Interrupted/failed fit work requires `--resumes` with an exact `expanded-reviewed-resume-map-v1`; each `expanded-same-fit-resume-v1` binds the unchanged manifest/job/science hash, previous attempt START, own complete-epoch `recovery.pt` receipt and reviewing instruction. It preserves optimizer/selector/RNG and all prior/unknown partial costs through the native runtime's existing resume path. A retained STOP additionally requires `--continuation`, accounting for every immutable STOP receipt. No automatic retry or fresh-seed replacement is performed. A launch with no recoverable checkpoint remains blocked for reviewed reconciliation.

An already reaped terminal transaction is recovered without scoring again. If a supervisor was lost before reap, `--reconciliations` can supply a reviewed exact native terminal adoption instead of running another prediction. This checks the unchanged task/attempt/result/selected-export authority and retains the unknown exit status. Known failed reaps cannot be relabeled through this path.

Failure/source/claim/authority errors stop new admissions and drain existing owned children. They are not killed. Normal external resource shortage returns pending work so the same command may be resumed later with unchanged authority. All native attempt costs remain separate; missing work is unknown, never zero.

## Output ownership

Main M1 reuses I4 body 0 exactly. I4 waits for all four own selected VALID exports and consumes them once, with no native model/data reconstruction or member prediction forwards. A no-selected outcome blocks dependent I4. Shared actual/same-call-mean exports remain each fit's selected-finalization bookkeeping, with zero extra scheduler scoring replicas.

A native `complete` claim is accepted only after its own selected export validates. Missing, changed or foreign export authority records **failed**, clears selected authority, stops admissions and drains peers. The root-review collector defect and its regression are recorded in `REVIEW_FIX.json`.
