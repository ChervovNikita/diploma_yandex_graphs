This source successor leaves V2, portable dispatchers V3/V4, their jobs and
checkpoints unchanged. It does not regenerate a roster or authorize a fit.
Original GNNM remains a comparison on new datasets. The original five paper
datasets remain excluded by the inherited training driver.

## Implemented paths

`runtime/run_fit.py` is a genuine producer entrypoint copied from the frozen
portable V3 link driver, which already supports molecular jobs. The only
producer changes are the composed constructor and runtime-binding builder.
The five supporting runtime modules are byte-identical to their V3 sources.

`runtime_bridge.create_adapter` calls the exact V2 constructor with its pinned
V3 native factory, at fresh construction before training or restore. It adds
the genuine producer manifest and entrypoint to the complete normalization
checkpoint envelope. Original V2 checkpoints cannot be relabeled as this
producer. Shared parameters, optimizer ownership, loss, native operators and
the V2 BN law are unchanged.

The public runtime binding identifies the entrypoint that actually ran and
contains an explicit `unchanged_helper_runtime` view. Parent bind/export
checks receive only that authenticated helper view. Their original source
checks are executed unchanged. The bridge separately authenticates the public
producer binding, retains the full composed selected envelope through V2, and
invalidates selected authority after restore or new TRAIN. Caller checkpoint
payloads are not mutated. Exported same-call means carry the public producer
identity and the separately named helper identity; they add no forward.

`final_scoring` is a concrete successor of the existing final scorer. Its
request/GO, frozen selection seal, complete population and source authority
checks are retained. Composed jobs use this same genuine constructor and
selected binder. VALID/TEST prediction enters the literal normalization-owned
inference operation. Model fingerprints use guarded model plus external BN
bank state, excluding loader RNG. Existing M1/I4/original GNNM paths remain
the original V3 runtime branch. This source does not grant TEST access.

The V4-derived host/classifier adds only the exact typed pointer
`/normalization_composition/parent_descriptor/path`. It validates its seven-key
declaration, normalized confined JSON receipt, source hashes and canonical
parent identity. The actual host verifies the parent and reconstructs the
exact V2 migration before construction. No subtree is exempted. Generic
relocation refuses normalized jobs: future relocation must first produce and
authenticate an explicitly rebound parent artifact, then derive its child.
Allocation execution is the currently supported deployment; server77 remains
disabled in the unchanged host configurations.

## Finite native qualification source

`qualify_native.py` implements two separate possible root-admitted cases:

| Case | Actual method and preset | Seed | New TRAIN updates |
|---|---|---:|---:|
| `molbace` | `interaction_input_conditionalJ`, MolBACE GIN/dropout0 | 1 | 38 |
| `buddy_seed1` | `interaction_input_conditionalJ`, Collab BUDDY | 1 | 1,585 |

One case is one worker process, one complete native epoch, and one fresh
output. It derives only its engineering descriptor from the supplied pinned
compiler parent. The finite controller is explicitly different from campaign
training and cannot establish convergence or predictive superiority.

The first two updates audit finite shared, boundary-private, correction and readout gradients;
zero-initial residuals may obtain a nonzero gradient on update two. The same
trajectory then completes the real epoch. Every active native tracked BN must advance
each of four private banks equally; unused native modules retain all-zero
increments and are reported by name. At least one native BN must be active.
The genuine driver saves/loads/selects
epoch1, binds the complete selected envelope and exports its same-call mean.
A stopped finalization resume adds zero TRAIN work. One fresh constructor
then restores that selected state and runs the real scorer's complete VALID
serving path under the owner. Serving checks the official population, selected
readout tolerance and unchanged model/bank state. TEST payloads are not read.
This costs three constructors and four complete VALID passes per case; BUDDY
also builds the original fresh VALID HashDataset serving context.
Zero down-gradients at an initially zero up-matrix are permitted; the check
requires nonzero credit for each component group somewhere in updates1–2,
not a nonzero gradient for every parameter on every update. The MolBACE
qualification deliberately uses the original dropout0 preset; it is not an
extension or numerical continuation of the separate dropout0.5 residual pilot.

Root must review the frozen manifest, exact parent and role-contract receipts,
free worker/resource slot, update bound and finite wall bound before providing
the admission JSON. Use `ROOT_ADMISSION_TEMPLATE.json`; the command is:

```sh
CUDA_VISIBLE_DEVICES=0 /path/to/qualified/python -B /repo/phase/benchmark_expansion_20261015_v1/composable_normalization_runtime_v1/qualify_native.py --project-root /repo --admission /repo/path/to/root_admission.json
```

The source starts no child or retry. It preserves every own fit invocation and
failure. A case's pass covers only that molecular or nonzero-seed BUDDY
representative, not all candidate methods or the massive study.
