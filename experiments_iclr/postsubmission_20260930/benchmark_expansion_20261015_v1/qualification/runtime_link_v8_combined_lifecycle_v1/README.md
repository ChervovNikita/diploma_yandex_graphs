# Two bounded native link lifecycle checks

Source only. Neither job is admitted or launched. Root must publish and bind one current, applicable resource/peer admission per case. Current two occupied CUDA worker slots exclude another launch.

The package contains two exact engineering jobs using real runtime_link_v8, unchanged native settings, source split/evaluator, optimizer groups and task reductions. A new explicitly bounded policy changes only the horizon to two epochs. Root's accepted exploratory reporting contract is attached; independent confirmation is not a prerequisite for exploratory TRAIN/VALID work.

| Case | Updates | TRAIN queries | TRAIN native forwards | VALID native forwards | Constructions | Whole VALID | Mean exports | Wall cap |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| NCN conditional C6 | 34 | 4,456,448 | 136 encoder calls | 16 encoder calls | 3 | 4 | 2 | 1,800 s |
| BUDDY seed1 conditional interaction | 3,170 | 3,245,620 | 12,680 model calls | 32 model calls | 3 | 4 | 2 | 3,600 s |

NCN drops the original 64,940 positive tail each epoch. BUDDY includes its native 794-query final batch in each of 1,585 batches per epoch. Four VALID calls each use all 60,084 positives and 100,000 negatives. Each case has four exact adapter/global-RNG restores. Mean export makes zero extra inference calls.

One own trajectory stops immediately after durable epoch1 recovery/selected/CURVE/PROGRESS, resumes only epoch2, exports its own strict first-best actual selection, then performs a fresh stopped zero-update finalization. The accepted NCNC driver supplies the control flow. No duplicate uninterrupted trajectory, numerical replay/tolerance test, node/molecular/NCNC repeat, TEST access or campaign GO.

The driver charges attempt/completion counters, native forward attempts/completions, sampled provider work and streamed per-update costs. The supervisor records total-process GPU/RSS, CUDA allocator peaks, CPU/wall, output disk, memory events and failure/in-flight uncertainty. First unexpected failure stops; the fixed watchdog sends TERM, waits five seconds, then KILL/reaps only its own child. No retry or device fallback.

BUDDY's engineering job uses the accepted `body: 0` bookkeeping because provider v1 currently converts the field with int(). Compiled shared `body: null` is an identified production schema issue; its versioned provider/overlay correction is separate. Native bodies, inputs, model parameters and training are unaffected.

After review and publication, root fills a fresh actual admission derived from the relevant ADMISSION_TEMPLATE. The reviewed invocation is `.venv/bin/python -B supervise.py --admission <exact-root-admission.json> --output <that-admission-output>`. Templates explicitly fail admission. `check_source.py` is source/metadata only and imports no tensor library.
