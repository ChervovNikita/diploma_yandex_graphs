# C1 node class geometry: bounded qualification

Two named methods are implemented in the separate frozen `task_geometry_node_port_v1` package: `task_node_class_alignment_v1` and `task_node_class_alignment_variance_v1`. The multiclass helper preserves the pinned binary molecular formula; eight local semantic tests include exact binary loss and gradient equality for both modes, independent multiclass scalar/reference and finite-difference checks, missing/singleton/one-class handling, downstream gradient support, fixed hash-cohort selection and explicit invalid-role/configuration rejection. Frozen molecular sources/pilots and the old node SupCon method remain unchanged.

Both methods passed actual native PolyFormer CiteSeer-Cheb CPU qualification. Each update used the complete native CE on1,929TRAIN nodes of the3,327-node graph, with the unchanged source nonreentrant activation checkpointing and source Adam groups/options. The auxiliary used512fixed once-per-fit nodes covering all6classes:86,86,85,85,85,85. It gave2,048eligible route/node anchors with339–343same-class positives each and distinct-node positives for every anchor; all6classes had variance support. There were no missing targets, singleton classes or one-class gate in this native case; those cases were separately checked in tensor tests.

Each method completed two optimizer transitions, with fresh-session restore between them and three complete665-node VALID passes. Four optimizer attempts completed across four native constructions, six full VALID passes total. Initial and restored output differences were zero, native Parameter identity and optimizer groups/options/owners were retained, and changed topology or auxiliary settings were rejected. Wall time was34.41seconds onTorch2.1.2+cu118, two CPU threads, CUDA hidden. Checkpoints remain on the allocation; local receipts contain their hashes.

Alignment uses cross-route same-class positives with class-mean denominators and class-balanced anchor reduction. The added variance is within route/class across distinct nodes after normalization, not route repulsion. The two new methods share the exact same fixed cohort/settings and differ only in adding variance. Their comparison with retained old wholeTRAIN within-route SupCon changes several factors and cannot isolate only cross-route positives. Native fullTRAIN CE is never subsampled. Selection does not change epochs and is not claimed to be an unbiased full auxiliary estimator. The.05coefficient is not a gradient bound; exact collapse may retain zero variance gradient. The auxiliary has no direct gradient to the final output layer/bank, which remains supervised by CE.

No GPU model, TEST access, convergence study, scientific fit, publication or accuracy/novelty conclusion is included. Other node cells, CUDA/pair-resource checks, full workers and final-serving reconstruction remain unqualified.
