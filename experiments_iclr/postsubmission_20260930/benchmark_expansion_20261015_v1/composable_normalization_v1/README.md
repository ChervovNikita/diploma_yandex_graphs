# Composable native normalization — source successor

This package implements the approved-in-principle comparison policy as a new
construction/state API. It does not alter any frozen callback, runtime, roster,
job, selected checkpoint or running session. No production jobs are generated.
The package is **source-prepared, not native-qualified or campaign-admitted**.

## Small construction seam

`contracts.migrated_job(parent, declaration, roster)` is a pure, explicit
proposal operation. It requires an eligible native-BN candidate/control,
preserves every native/scientific field, adds the exact source/parent policy,
creates a distinct fit ID and updates the expanded scientific contract hash.
Original GNNM, explicit private-BN controls, native bodies, source references
and BN-free presets are ineligible. No output is written by this function.

A future source-bound producer calls
`adapter.create_adapter(torch, job, policy, root, parent_factory=...)`.
Before construction it verifies its own immutable source, the retained parent
descriptor, the exact proposed new JOB and the pinned original adapter factory.
That existing factory receives the **same complete new JOB**, runs all original
candidate validators and assembles every ingredient first. The normalization
owner attaches before any TRAIN update, epoch or state restoration. This keeps
original callback, loss/gradient, private correction, aggregation and same-call
mean-provider logic intact; their job hashes do not describe another job.

The two existing native route seams are molecular `model.run_member` and BUDDY
`native._route`. Both use the unchanged `private_bn_state_v3/banks.py` law.
All native weights, BN modules/affine parameters and candidate optimizer objects
remain the original objects. BN banks are owned outside the parent model, so
the parent module/state layout remains unchanged. Only existing native tracked
BN is eligible; no BN is inserted, and SyncBN/recomputed-BN or concurrent routes
remain unsupported. Parent source/native invariants remain active.

## State and inference

The new checkpoint envelope contains the exact parent adapter state, complete
private BN banks and the genuine new job/source identity. Parent source states
are not converted or relabeled. A matching new producer constructs fresh,
attaches banks, then restores this envelope through its own `load_state`.
Wrong producer/state identity, active task state access and direct native or
bank checkpoint access outside that owner refuse. Parameter/optimizer identity
and canonical buffer objects/values are retained. An admitted restore failure
or inference bank mutation invalidates the owner; cleanup remains possible.

`inference_operation('VALID'|'TEST')` supplies an explicit read-only eval
context, restores module modes even on exceptions, rejects nested TRAIN/state
operations and checks native/private buffer identity and values. It authorizes
no TEST access, obtains no role data and selects no checkpoint. The real serving
caller must enter this owner around the existing role-specific inference. The
original unmodified serving entrypoints do not yet do so for this new producer.

Parent training and mean-provider state stay with the parent adapter. Added
execution metadata states that running buffers are private, while preserving
the parent-reported BN flag separately when present. This avoids presenting a
parent shared-buffer flag as the effective composed normalization policy.

## Minimal migration, not a new roster

`MIGRATION_PROPOSAL.json` retains 6,460 physical fits and 270 export-only tasks:
2,890 candidate contracts change (2,720 molecular, 170 BUDDY); 3,570 scientific
definitions remain unchanged. `contracts.migrated_controls` rebinds migrated
ingredient fit IDs and supplies the existing same-cohort private-BN-only fit as
the primary attribution reference. Original GNNM remains a distinct total
comparison, and native I4 body IDs remain unchanged. No extra control fits are
created. The 1,690 affected direct G0 symbolic links keep their original
comparison and acquire the matched-normalization attribution reference.

Broad descriptor/registry/reporting/portable/final-roster regeneration is not
performed. Existing native data and population proofs remain applicable to
unchanged native inputs/operators. A genuine producer/runtime hook, selected
state/serving integration and reviewed resource/source authorities still need
binding before any production migration. These source files do not bypass an
existing guard or make the old 6,730-task authority accept a new method.
The future portable schema must explicitly type the parent descriptor as a
runtime authority; the current strict path classifier is not silently relaxed.

## Focused verification and remaining native work

`check_source.py` uses only standard-library scalar fixtures. Three named
interface cases cover molecular geometry/input, molecular conditional/input
and BUDDY residual-only route seams; checkpoint roundtrip, role/state refusal,
exception-safe inference modes and control links are checked. These fixtures
are not real model compositions, gradient checks, BN numerics, memory profiles
or accuracy evidence. Seven unchanged parent source pins are checked. No Torch,
dataset tensor, host probe, native job or TEST payload is used.

The smallest genuinely new native scope is the **new owner and state envelope**:

1. One molecular composed representative with private parameters plus learned
   aggregation/same-call mean (candidate `interaction_input_conditionalJ`): two
   native TRAIN updates, complete VALID, new-envelope save/restore and owned
   selected VALID inference. Reuse existing native/lifecycle/population evidence.
2. One BUDDY composed representative at an actual nonzero seed with the same
   update/VALID/state/inference checks, including source route/RNG dispatch and
   inactive BN branches. Prefer the agent's existing residual-only composition
   if it adopts this exact owner; otherwise retain it as a separate witness.
3. Add a separate geometry/capture or residual-only witness **only if** source
   inspection or those checks leave an actually distinct route seam/state path
   uncovered. Do not create a 17-method, 27-preset or per-seed test matrix.

These are future bounded engineering checks, not new completed scientific
fits. Capture actual work/cost once and attach resource observations there.
Do not rerun passed old qualification merely for this source successor.

The completed MolBACE factorial motivates a fair control; it establishes no
universal BN advantage, novelty, TEST transfer or independent-ensemble win.
