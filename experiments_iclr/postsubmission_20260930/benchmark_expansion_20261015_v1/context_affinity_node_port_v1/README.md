# C3 node factual context affinity

`context_affinity_node_common_v1` and `context_affinity_node_split_v1` reuse the exact frozen root core/task specification and the unchanged C1 class-preserving512-node selection helper. Selection is fixed once per fit by seed/ID hash and never changes epochs. Complete original native TRAIN CE remains active; only the auxiliary is bounded.

A is the actual source-preprocessed feature vector at each selected TRAIN node. B is a single symmetric degree-normalized incoming propagation of the same features. The target builder removes native self records for this auxiliary only, retains all nonself records with direction and multiplicity, and adds one self contribution per node. Degrees use all original nonself incoming records plus one self at every node. A sparse selected_count byN operator computes only selected destination rows of D^-1/2(A_nonself+I)D^-1/2x. It never constructs an additional fullNbyD propagated matrix. Native predictor topology/features/operators and polynomial bases remain unchanged.

Only source TRAIN IDs/classes define anchors and compatible distinct-node donors. Public full transductive native features/topology contribute factual context. Both targets are detached; the root core learns donor probabilities from live existing route preheads with temperature0.2 and class-balanced supported-anchor reduction. Common gives every route the average factual target; split assigns A to routes0/1and B to2/3. Both use ordinary all-blockF+0.05A and one unchanged Adam transition. No new head, projector, learned parameter, serving context or native forward is added. Original nonreentrant activation checkpointing is retained. The auxiliary has no direct gradient to the downstream output layer/bank.

Checkpoint identity pins full native feature/topology bytes, exact selected TRAIN cohort, target construction/core/source hashes and actual A/B tensor values. The bounded CPU targets are saved on the server and checked on restore. Zero-context, omitted donor support and actual A/B target distinction are reported. Context preprocessing and instrumented auxiliary host times are recorded without claiming synchronized GPU latency.

Local extraction checks compare the selected sparse result with an independent scalar formula on a directed multigraph, including duplicate edges, self records, unselected-neighbor features and edgeless/zero contexts. Planned native qualification is exactly two complete CiteSeer-Cheb CPU TRAIN updates per common/split variant, wholeVALID, fresh-session restore, active distinct targets and actual shared/private gradient support, maxfour optimizer transitions total, two threads and hidden CUDA.
