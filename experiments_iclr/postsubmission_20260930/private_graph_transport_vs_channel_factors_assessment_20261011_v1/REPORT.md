## A minimal statement that changes interpretation

Freeze two row-stochastic node operators A and P on the same n nodes. Let H be an arbitrary incoming n×d feature field, W≠0 a message channel map and R a root channel map. Consider

```
M_private(H) = P H W + H R
M_common(H)  = A H B + H C,
```

where B and C may be **arbitrary node-independent channel maps**. Assume A has at least one off-diagonal nonzero entry. Then

```
M_private(H) = M_common(H) for every H
if and only if
P = a A + (1−a) I,
B = a W,
C = R + (1−a) W
```

for a scalar a. Require P to remain nonnegative/row-stochastic; this restricts admissible a. Common affine biases do not change the result: evaluation at H=0 first equates the biases.

For necessity, inspect the coefficient of an independently varied sender row H_u at receiver v≠u: P_vu W=A_vu B. One nonzero off-diagonal A entry fixes B=aW. Every other off-diagonal entry must then satisfy P_vu=aA_vu, including zero-support locations. Diagonal coefficients require C−R=(P_vv−aA_vv)W to be constant across v. Row sums one force that constant to be1−a. Substitution proves sufficiency. This is elementary linear algebra, not a new theorem.

Without a root path, the same row-normalization condition reduces channel-only absorption to P=A and B=W. The saved commutation `A(H D)=(A H)D` is correct, but the native SAGE root path gives the additional exception above. In particular, a route-constant change in self mass can mimic a propagation difference through channel/root maps. Operator variation or private metric movement alone does not establish different useful neighbor evidence.

This is a conditional isolated-stage statement. It grants B/C more freedom than the restricted BE diagonal factors have: membership in the mixture family does not guarantee exact absorption by the actual factorized maps. Conversely, an operator outside this span gives a genuinely different **stage map for some H**, not a strict whole-network capacity theorem. Actual H is generated by preceding route-specific nonlinear computation; P is generated from raw X and learned metric parameters. Whole-network states can change, fixed data can lie in a nullspace, later normalization/head computation can erase the difference, and final predictions can coincide. A nonzero operator difference need not improve a class margin or acquire a correct alternative.
