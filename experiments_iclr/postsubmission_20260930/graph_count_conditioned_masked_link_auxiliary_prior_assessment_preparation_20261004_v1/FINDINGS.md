# Count-conditioned masked-link reconstruction: scoped prior-work assessment

Assessment date: 4 October 2026. Source-only literature and symbolic analysis. No fit, model/data access, numerical qualification, manuscript edit, or scientific execution release.

## Scientific conclusion

The inspected sources do not establish the complete proposed operation: reconstructing two native masked TRAIN-incidence supports with an exact binary fixed-count likelihood, using one uniform latent member identity across both supports, as an auxiliary to an otherwise unchanged discriminative NCNC ranker. This is a bounded observation about the declared sources, not an absence or novelty certificate.

The ingredients have close prior ancestry. Masked graph topology reconstruction and degree supervision are direct graph prior work. Count-conditioned reconstruction with a probability budget is established in recommendation through multinomial likelihoods. Shared edge-intent routing, paired expert alignment, latent user/item weighting, auxiliary contrastive training, coherent linkset prediction and learned joint graph refinement are established in graph/recommendation methods. Conditional Bernoulli likelihoods, ESP normalization, fixed-size set prediction and mixture responsibilities are established operations. None should be claimed as a new generic principle.

For count one, a conditional Bernoulli component is exactly categorical softmax. With one member, the two-side loss is a sum of two categorical/InfoNCE-form cross-entropies. With multiple members and one shared member identity, the loss is categorical cross-entropy on pair labels under a restricted mixture-of-products parametrization. Count n-1 is also categorical, over the omitted identity. A genuinely multielement binary-subset comparison needs min(k,n-k)>1. Any useful claim must therefore name the support, graph adaptation, responsibility coupling and unchanged serving objective precisely.

The most informative immediate contrast is J_K against J_K_sep. At fixed logits they have exactly the same whole per-side distributions and unary marginals, while differing in cross-side member association. This makes the comparison sharper than comparison against a count-only control or generic InfoNCE. Training changes the logits, so equality of the fitted per-side distributions is not promised. A favorable result supports the chosen auxiliary adaptation; bank necessity still needs a capable structured single.

## What may still be worth testing

The narrow hypothesis is that conditioning away the observed source count reallocates auxiliary effort toward identity assignment, and that one shared component assignment across both endpoint supports provides useful training signal for the unchanged target ranker. These are two effects: count conditioning changes the auxiliary task; shared association changes the joint law. The latter can be isolated by J_K_sep without claiming a new loss principle.

The remaining graph-specific question is whether this likelihood is a useful adaptation to the permitted native residual supports, mask process and tied recursive scorer. Repeated local masks are not independent graph observations. A locally normalized law does not by itself define a globally coherent missing-graph posterior, recover true nonlinks, preserve endpoint/slot symmetries, or justify using teacher counts at serving. Uniform mixing after conditioning is also a deliberate different model from conditioning the old unconditioned mixture.

## Disqualifying theoretical and empirical outcomes

1. **A generic loss or paired-latent novelty claim fails now.** Exact count-one/complement categorical reductions, fixed-size subset ancestry and graph routing/mixture priors already establish the underlying operations.
2. **No informative support defeats the proposed mechanism.** k=0 or n has loss/gradient zero. If either side is extreme, cross-side association disappears. If min(k,n-k)=1 in all active supports, the experiment cannot establish an ESP-specific multielement-subset benefit. Count strata must be exposed, without dropping extreme queries or changing normalization after seeing outcomes.
3. **A source-incidence proxy gain without target-ranking gain fails useful transfer.** Count-conditioned NLL, responsibility specialization or prettier reconstructed patterns alone do not meet the discriminative LP goal.
4. **J_K matching J_K_sep defeats shared-association utility in that recipe.** NLL improvement attributable only to one-side competence, a loss-scale change or count-prevalence suppression supports a narrower interpretation. Fitted per-side competence must be reported because the fixed-parameter equality does not survive different training automatically.
5. **A claim of bank necessity fails if a capable identity-sensitive single matches it.** A terminal affine head or C_mu count-only potential cannot be the sole strong control: C_mu cancels at fixed counts. If a capable single is unqualified/infeasible, necessity remains unsupported.
6. **Calibration and served-score mismatch remain real risks.** Conditional losses ignore common side logit shifts. Target BCE may constrain them, but the auxiliary supplies no direct count/offset calibration signal or guarantee for pooled raw target-logit ranking. Learned responsibilities can starve members or collapse; auxiliary joint probabilities need not select the members useful to the served average.
7. **Teacher leakage or mislabeled zeros invalidates the interpretation.** Counts and identity teacher bits belong only to permitted TRAIN observations under masks. VALID/TEST adjacency/counts, hidden target links or teacher bits cannot enter visible features/completion or serving. Observed TRAIN zero is an observation label, not verified latent absence.
8. **Local consistency must not be advertised as graph coherence.** Overlapping residual supports, duplicate records, endpoint exchange, slot permutations and repeated graph contexts can produce incompatible local predictions. The component subset odds use unary logits and the two-side probability matrix has nonnegative rank at most M; the law cannot express arbitrary dependencies.
9. **A partial/resource-failed run cannot count as a successful representative pilot.** Exact ESP scalar work is O(n min(k,n-k)) per component per side, plus autograd and native graph work. This is not a demonstrated full-batch wall-clock or memory bound. Empty/extreme handling and complete source/data/physical gates precede fitting.
10. **Retrospective selection defeats the decisive screen.** Route, lambda, masks, seeds, count strata, early termination and checkpoint selectors must not be chosen from these outcomes. An adverse or null result must remain in the record; a positive one-seed result only motivates separately fixed replication.
