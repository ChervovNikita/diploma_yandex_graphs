# Decisive falsifiers

The proposal is an attributed, inactive learning-rule hypothesis. Do not replace a failed condition with a larger search.

| Test | Result that rejects the corresponding claim |
|---|---|
| Competent complete-task ordinary references | A weak/nonlearning single, teacher or independent ensemble means the comparison is unqualified. It cannot establish new steering or a negative geometry result. |
| Shared contrast vs same-context teacher-hardness CE, paired warmup/assignment/recipients | Matching original-input VALID quality and measured cost explains the effect by ordinary masked supervision/error weighting. The added predictive contrast has no demonstrated role. In the exact `r=p_native_null` limit it is ordinary CE algebraically. |
| Learned ownership vs fixed random balanced ownership | Matching full-input quality means global learned assignment is unnecessary. Different assigned contexts or TRAIN context scores are not sufficient evidence. |
| Genuine complete independent encoders with the same teacher, contexts, labels and auxiliary opportunity | If independent models recover the frontier, the proposed sharing/geometry placement has no demonstrated advantage. Charge all four complete paths; do not use a shared encoder as this control. |
| Single predictor receiving the same context tasks; capable joint multi-transport readout | Recovery means context supervision/multiple geometry representations suffice. Predictive committee pooling is not uniquely needed. |
| Factorized original BSNN; state-conditioned/global-latent sampler with the same J | Recovery means inspected factorization, state feedback or global latent structure explains the result. Persistence/BE is not a new geometry principle. Do not omit KL/MC/operator differences or declare a weak configuration competent. |
| Flat/node-frame, layer-shared plus matched node capacity, feature/head-private contrast | Recovery rejects a requirement for private incidence ownership or gauge-inequivalent matrix geometry. A useful coordinate adapter is still a possible explanation. |
| TRAIN context learning vs new VALID queries using frozen TRAIN-source contexts | Improvement limited to the fixed TRAIN query panel indicates memorization or view mismatch. No masked-query score may select strength, patches or checkpoints. |
| Full-input own/pooled quality | Context contrast improving while original-input pool NLL/AUROC fails to improve, or while own member competence degrades without collective recovery, rejects useful ensemble steering. |
| Source correspondence | If a predeclared within-context permutation of source feature identities preserving the view/label/forward budget recovers the ordinary gain, evidence correspondence is unnecessary. Do not reinterpret it as learning irreducible transport. |
| Unused propagation or mere matrix spread | With all native right maps zero, J has zero private-geometry gradient. In general, moved/different maps without different useful predictions supply no mechanism evidence. No extra matrix-distance or float-diagnostic campaign is proposed. |
| Checkpoint and work | A selected checkpoint before epoch100 tested no contrast. An effect reproduced by the predeclared extra-full-input stochastic-supervision control is paid training work, not a context-learning consequence. |

Even survival supports only a representative exploratory utility result. Ordinary Tolokers is an original benchmark. Priority, Bayesian validity, broad superiority and fresh-task confirmation remain unestablished; no experiment is released by this packet.
