Algorithm 1 Nash-MTL
Input: [MATH \theta^{(0)}] – initial parameter vector, [MATH \{\ell_{i}\}_{i=1}^{K}] – differentiable loss functions, [MATH \eta] – learning rate
for [MATH t=1,...,T] do
Compute task gradients [MATH g^{(t)}_{i}=\nabla_{\theta^{(t-1)}}\ell_{i}]
Set [MATH G^{(t)}] the matrix with columns [MATH g^{(t)}_{i}]
Solve for [MATH \alpha] : [MATH (G^{(t)})^{\top}G^{(t)}\alpha=1/\alpha] to obtain [MATH \alpha^{(t)}]
Update the parameters [MATH \theta^{(t)}=\theta^{(t)}-\eta G^{(t)}\alpha^{(t)}]
end for
Return: [MATH \theta^{(T)}]
