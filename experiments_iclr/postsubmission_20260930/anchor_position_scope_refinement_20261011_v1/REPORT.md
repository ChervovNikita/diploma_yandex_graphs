## What original rank-one factors cannot supply

Current `FactorLinear` uses member-specific **channel** vectors, shared across nodes:

\[
f_m(x)=((x\odot r_m)W^\top)\odot s_m+b.
\]

For fixed learned parameters, equal attributed rooted two-hop neighborhoods yield equal deterministic outputs in the native depth2 local SAGE path: the initial node-wise transform agrees, equal neighbor multisets give equal means, and the per-node residual/feed-forward/LayerNorm maps agree. Repeat for the second block. Changing globally shared channel factors cannot break that equality within a route. This exact-arithmetic argument applies to these channel factors; free node-indexed lookup parameters would be a different model.

A distance field can make those rooted input neighborhoods differ. For a symbolic witness, take disjointC6 andC8 cycles with constant original features. Node-shared mean-SAGE produces the same representation everywhere, regardless of channel factors. A nonempty anchor set confined toC6 gives positive finite-distance fields there and zero onC8. The added attributes distinguish the components. This is a possible distinguishing feature, not a native-fit result, a probability guarantee for the saved sampler, a WikiCS diagnosis or a representative cost experiment.

Actual features may already distinguish locations. If a field matrix satisfies `D=XB` on the finite graph, an ordinary single linear stem can absorb its contribution into the original feature weights. Nonlinear recoverability can also make the fields redundant. No rank, symmetry or reconstruction diagnostic was executed. ## The assignment mask reduces exactly to existing factors

Let a route receive `[x,d⊙M_m]`, where `M_m` selects32 of128 anchor coordinates. Define

\[
r'_m=[r_m^X,\;M_m\odot r_m^D].
\]

Then

\[
(([x,d\odot M_m]\odot r_m)W^\top)\odot s_m+b
=(([x,d]\odot r'_m)W^\top)\odot s_m+b.
\]

Thus the unrestricted all-anchor shared model can represent the assigned model at the same428-column stem shape. All-anchor single/I4 bodies likewise contain their assigned counterparts by zeroing unused stem columns. Hard masks correspond to **permanent** zero constraints; merely initializing freely trainable factors to zero is not an equivalent training procedure.

Assignment changes field exposure, gradient duty cycle and optimization. Each selected stem column receives gradient credit from one route, so part of the added shared tensor is functionally private. The original feature stem and propagation remain shared. Beating the common all-anchor control would support a useful constrained procedure, without proving greater information, an enlarged architecture or measured interference reduction.
