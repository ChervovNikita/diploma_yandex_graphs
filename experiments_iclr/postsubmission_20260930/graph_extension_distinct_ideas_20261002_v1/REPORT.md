## 1. Learned channel mixing in a dynamic equilibrium maintainer

### The source-supported need

[Efficient Dynamic Algorithms for Graph Neural Networks with Non-Linear Propagation, arXiv:2609.32929v1](https://arxiv.org/html/2609.32929v1), submitted 26 September 2026, maintains nonlinear coordinatewise graph diffusion after edge changes. Its saved paragraph **19** explicitly states that propagation has no learned weights, feature mixing or attention, and leaves learned feature mixing open. Paragraphs **39–51** define estimate/preactivation/residual invariants and a residual-to-state error bound. Paragraphs **54–71** describe push and graph-update operations. This is primary evidence for a concrete boundary of that method, not proof that the boundary is unsolved everywhere.

The saved IGNN/DEQ/IGNN-Solver report already establishes learned graph equilibria, private recurrent factors, constrained well-posedness, residual bounds and trained solvers. The retained Round02 report already establishes finite-depth incremental inference, normalized degree handling, shared event queues and dense batching through RIPPLE++, NeutronRT and related methods. Those ingredients receive attribution. The proposed delta is a specific graph-update invariant and residual-push maintenance rule for **learned feature-coupled equilibria**, with an explicit contraction/error/cost condition.

### Clear algorithm

Freeze a competent trained M=4 model, its factors, forcing encoder and heads. For an undirected self-looped graph use the row mean P. Member m solves

    Z_m = hardtanh(alpha X_m + (1-alpha) P Z_m V_m),
    V_m = diag(r_m) W diag(s_m).

Require a verified rho_m=(1-alpha)||V_m||_1 < 1. The member maps genuinely differ; all members keep their own states. A shared-map bank with different solver starts converges to one state and is already rejected by the saved implicit-ensemble assessment.

Keep separate Z_m, Y_m and R_m arrays with Y_m=alpha X_m+(1-alpha)PZ_mV_m and R_m=hardtanh(Y_m)-Z_m. Edge insertion/deletion repairs only the two changed normalized rows using the stored Y and endpoint states. A node push moves its residual into Z, applies the learned channel map once to that residual, updates its graph neighbors, and recomputes their residuals. Stop each member only when its own residual satisfies the declared contraction-adjusted tolerance. A tagged union worklist and common W row stacking are optional attributed execution choices.

[DERIVATION.md](DERIVATION.md) provides the endpoint formula, invariant, proposed potential argument and maximum state/logit/CE error bounds. The specific proof outline is new local work; it is not yet an independently reviewed theorem. It fixes beta=1 rather than borrowing a general normalized-graph guarantee. Learned matrices stay frozen throughout the stream. Parameter updates, attention and arbitrary global normalization invalidate this specification.

### Strongest comparisons and benefit

The main comparison is the **same frozen learned-equilibrium predictor** solved after each graph snapshot by a competent warm-started full solver: fixed-point iteration and an established Anderson/IGNN-Solver path, all at the same certified output tolerance. Reusing the prior solution is essential. A comparison only with cold restart would be weak. Add separate vector residual-push queues with the same packing/shared graph index to test whether the union queue adds anything; ordinary batching must be offered to both.

The source's fixed coordinatewise nonlinear maintainer is an attribution/reference control, but it represents a different predictor and cannot establish acceleration of the learned map. Competent IGNN and finite-depth GraphSAGE on the same declared information are required before a task-quality or GNNM utility claim. An independent implicit ensemble with norm-qualified member maps tests parameter sharing; it must also receive batched execution. No accuracy improvement is expected from a faithful maintainer: its purpose is faster update-to-fresh-prediction at the same learned-model outputs.

The plausible benefit is avoiding whole-graph equilibrium recomputation after localized graph changes while retaining learned feature coupling and separate member states. Unlike the older finite-depth queue, an equilibrium update can affect arbitrarily long paths; the residual certificate controls the remaining effect. Unlike a shared posterior memory shortcut, it preserves each declared member's model. The normative bound can still be so loose or restrictive that a competent full solver is faster.

### Novelty limits and failure risks

This is a vector extension of a recent residual-push algorithm applied to an established equilibrium model. Its invariants and potential use familiar contraction arguments. A source's “left open” sentence is not a global novelty certificate. A closer dynamic IGNN implementation, cached learned solver or generic nonlinear fixed-point maintainer could substantially close the claimed delta. That specific question needs a bounded next source review, including the final published IGNN-Solver version if it changes the relevant method. Do not reread the retained versions merely to increase the literature count.

The method works for independently learned channel matrices too. BatchEnsemble contributes known parameter sharing and an inexpensive way to make distinct V_m, not the proof or dynamic operation. Shared W does not eliminate private states or per-active-member message arithmetic. A rho cap near one weakens the certificate and potential bound; a strong cap can impair long-range task competence. Solver error must never be presented as ensemble diversity.

The scalar-to-vector push is an ordinary asynchronous fixed-point update, so changing its name cannot supply novelty. The actual new candidate operation is constant-size endpoint repair of the learned vector preactivation under degree normalization, followed by vector residual cleanup with a dimensional cost account. Whether that is a sufficiently distinct maintenance result remains unresolved. No factor-specific arithmetic saving beyond weight storage and known batching is established by this operation. The adaptive shared-update factorization in the separate note is the explicit possible arithmetic delta; it has not earned its required rank/cost property.

### Actual resource boundary

No elapsed training/serving time was measured. This is not the scalar source's O(1/epsilon) result and is not a wall-time forecast. ## 2. Feature-axis compression of private contrast transport

This idea is saved but **not recommended for a new method/GPU lane now**. The earlier low-rank/task-directed reports compress the member axis with a global member projector. A different operation preserves the full current member mean and all three member-contrast identities while projecting each contrast into a common r-dimensional **feature** basis B:

    mu = mean_m Z_m,
    C_m = Z_m - mu,
    message_m = P mu + (P C_m B) B^T.

B has orthonormal columns and is global across nodes. One can choose it from the right singular space of the stacked transported contrasts [P C_1; ...; P C_M], using a randomized range sketch computed through P^T. A separate independent feature probe estimates the discarded transported energy. Increase rank or fall back to exact messages under a frozen tolerance rule. Basis construction uses only supplied states/topology; no labels, new diversity loss or graph-error cotangent is involved. Each layer uses its own current private states. Mean preservation at a message site does not preserve the whole nonlinear predictor.

This is not the earlier fixed member-axis projector, but graph-metric PCA, randomized range approximation, error probes and adaptive approximation are established ingredients. The saved task-directed report already limits broad sensitivity/compression novelty claims. The recent [CoRe-GNN, arXiv:2608.02128v1](https://arxiv.org/html/2608.02128v1), saved paragraphs **15–59**, supplies a capable graph propagation approximation with local restoration, graph-dependent efficiency and explicit restricted-subspace assumptions. Its node-axis operation is not identical to the feature projection; neither difference establishes a new compression principle. Sketch-GNN was only located at Crossref metadata scope and remains unread; that is a material nearest-prior uncertainty.

The strongest controls are packed exact member transport; ordinary source-state PCA at the same feature rank; a fixed random feature subspace at the same rank; the saved complete-contrast destination correction; and the earlier member-axis restriction when compared as separately trained architectures. A graph-conditioned basis must earn its graph weighting beyond raw PCA at equal rank and full measured cost. A shared mean or multiple private heads alone is not a sufficient control.

At one fixed site sparse transport drops from M h channels to h+(M-1)r before checking overhead. A per-forward error probe adds (M-1)s channels; constructing the graph-weighted basis also requires dense reductions O((M-1)N h q), QR/reconstruction and either precomputed P^T probes or additional thin sparse products. Private O(MNh) states and all member dense/nonlinear work remain. Finite-confidence norm bounds with small probe counts can be very loose; probes cannot be sold as a cheap CE guarantee. Precomputing the dual sketch is valid only for its actual graph/version and must be charged. For dynamic graphs it must be updated or rebuilt.

If reopened for utility, use complete products plus Reddit2, frozen qualified exact-model checkpoints from three fresh seeds, and one predeclared rank/tolerance policy. Compare complete recurrent forward quality and total latency against exact, same-rank raw PCA and random projection; use common-state replay only for the approximation attribution. Require the current frozen quality-retention margins and a meaningful speed floor prospectively fixed by the root, with basis/probe/setup amortization included. Stop if useful exact-versus-mean contrast is absent, raw PCA matches it, rank approaches h, numerical fallback dominates, or total latency/memory loses. Confirm on a different complete graph with locked rules and new seeds before broader claims. This is a falsifier specification, not execution admission.

The idea is currently below the first candidate because there is no inspected evidence of a useful feature-axis low-rank contrast property in the target models, the nonlinear task boundary remains, and the monitor/basis cost can consume the proposed saving. It must not become a rescue sweep after unfavorable current initializer results.
