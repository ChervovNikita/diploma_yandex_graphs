## The SAGE operation, without a renamed mechanism

At one native SAGE layer with `project=False`, denote the mean incoming state by `mu_m,v` and the root state by `h_m,v`. Static internal-BE around the native affine branches has the form

```
y_m,v = D_sN_m W_N D_rN_m mu_m,v
      + D_sR_m W_R D_rR_m h_m,v + b_N + b_R.
```

Bias ownership/order, native concatenation/FFN, normalization and nonlinearities remain part of the actual model; this equation describes only the two affine branch sites. Replacing each factor by a function of allowed context `c_v` produces receiver-conditioned dynamic channel maps. If `c_v` is the same for all neighbors of v, an input factor commutes through that receiver's linear mean:

```
D_r(c_v) mean_u h_u = mean_u D_r(c_v) h_u.
```

It does not assign a distinct weight to each incoming neighbor at that stage. Output modulation is FiLM-style conditional affine adaptation; input/output modulation together is a restricted generated message matrix. Separate root and neighbor generators allow a context-dependent root/neighbor balance, but native SAGE already has separate learned root/message maps. This is additional conditional capacity, not proof of a missing graph capability or an ensemble-only operation.

If `c_u` is applied to each source before the mean, or `c_vu` depends on both endpoints, the induced incoming-message map changes before summation. That can retain contributions which a restricted common linear aggregate would alias. It is already the ECC/GNN-FiLM/attention site. Inserting a new per-message nonlinearity also changes the operation and cannot be described as merely relocating the same factors. A global graph summary, constant over one graph, supplies no node-selective branch choice; live summary dependence may change the nonlinear parameterization but needs a separate same-information control.
