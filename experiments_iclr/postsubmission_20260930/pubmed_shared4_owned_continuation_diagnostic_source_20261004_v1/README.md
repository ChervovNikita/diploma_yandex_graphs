## Source finding

`abs(candidate-reference) <= atol + rtol*abs(reference)` with the advertised
128*float32epsilon tolerances. It is not exact equality. Its report maxima and
counts are updated only for tensors, so failed scalar loss records can show
zero diagnostic differences. A numerical pass cannot be inferred from that.

The unchanged native `restore` passes the supplied `state['Adam']` directly to
`optimizer.load_state_dict`. This permits a concrete alias hypothesis: live
non-capturable Adam CPU step tensors may share storage with the loaded saved
tree. Training the first copy could advance the saved counters before the
second restore. This packet tests that hypothesis before any kernel explanation.
