# Accuracy-first graph ensemble direction

**Retain one bounded GNNM quality hypothesis; simplify the saved private-path candidate before proposing an experiment.** Common weights may transfer class-relevant learning across members exposed to different neighborhood evidence, while complete private member trajectories preserve complementary reliance on that evidence. The useful outcome is a better native-graph ensemble prediction. Parameter savings and response separation are neither the objective nor evidence of success. This is an attributed empirical hypothesis, with no new mechanism or novelty claim and no execution admission.

The expected failure is **correlated reliance on misleading local evidence within a class**: some nodes benefit from same-class neighbors, while others need feature/long-range evidence because local neighbors are mixed or misleading. Seed variation can leave members with the same reliance and therefore the same mistakes. GNNM's common maps could share robust class features learned across these cases; its private trajectories could retain different evidence responses. Conversely, common updates can impose the same shortcut on every member or make the regimes interfere. Neither failure has been demonstrated in the current Amazon study, whose partial predictive results remain unopened.

A competent Polynormer/PolyFormer single already models multiple scales and can solve this problem. There is no claimed expressivity impossibility for a single. An independent ensemble already has enough capacity to specialize. The remaining question is whether **tying common weights improves useful specialization and pooled accuracy relative to the same untied trajectories**, rather than merely reducing storage. If independent members or a capable single solve it as well, the GNNM quality hypothesis fails.

The saved `graph_contrastive_private_paths_quality_gap_20261003_v1` is unnecessarily elaborate for that question: frozen common maps/heads, private-only continuation, conditional groups/fallbacks, response-energy bands, repeated control-loss guards, backtracking, and eight continuation arms test a restricted optimizer composition. The stored closest-prior assessment proves its squared-cosine penalty is exactly a degree-two function-space kernel energy. It does not establish useful error complementarity. Freezing common weights also prevents testing the beneficial shared-learning mechanism above. Archive that specification unchanged; do not relabel its penalty as a new graph objective.

The simpler attributed test uses the existing source-qualified modern backbone and complete GNNM trajectories. Fix two modest deletion views using **fit-role TRAIN labels only**: remove sampled edges between equally labeled endpoints, or differently labeled endpoints; retain self-loops and recompute native normalization. Keep the saved 10% rule as an explicit unvalidated probe choice. Assign two of four members to each view. Train each member with ordinary native CE plus its assigned-view CE, with common and private weights trainable. Serve all four on the complete native graph using the same fixed probability pool. Do not add a response penalty, a learned gate, or a competence/energy acceptance optimizer. Measure native-minus-view probability responses as diagnostics after complete fitting. Both view types may teach identical invariance or harmful shortcuts; useful differences are an empirical question.
