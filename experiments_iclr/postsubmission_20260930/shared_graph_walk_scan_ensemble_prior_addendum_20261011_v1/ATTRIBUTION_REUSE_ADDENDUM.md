## R4 changes amplitude and conditioning as well as memory

R4 removes the carry and retains q=(1−a)u. At the proposed initial retention a=.99, its pointwise state is .01u. For a constant input and constant gate in a long component, the full recurrent state after t tokens is

\[
s_t=(1-a^t)u,
\]

which approaches u, approximately100 times R4's state. This is an illustrative constant-input limit, not a claim that real graph states have that ratio.

W_o initially equals zero, so neither arm initially injects a nonzero scan residual. Their potential gradients and subsequent optimization nevertheless differ because the input to W_o has different amplitude. Trainable W_o and gates can compensate, but Adam, source clipping, finite optimization and SELECT do not guarantee matched conditioning or learned scale.

Thus SW4 beating R4 alone does not identify a nonlocal-information benefit. R4 is a retained-carry ablation whose intervention also alters amplitude and conditioning. The complete PV1/V1/C4/WI4 controls still make the fixed utility study meaningful: equipped same-four-tour single controls, distinct versus common tours, and genuine independent equipped predictors can refute the main claim. Passing the fixed R4 contrast supports this recipe's utility attribution only with the stated confound; no amplitude-matching grid is added.
