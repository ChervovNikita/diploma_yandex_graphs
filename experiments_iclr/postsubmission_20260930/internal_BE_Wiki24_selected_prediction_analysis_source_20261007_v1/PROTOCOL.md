## Definitions and summaries

Member predictions use original logit argmax; pooled predictions use the original mean-softmax argmax. Report each member's competence and NLL, member mean/minimum/maximum/range, served accuracy/NLL, any/all member correctness, all-member errors, unanimous wrong-class errors, common-competitor errors, pool rescues and harms. Report a fixed ten-class served confusion matrix, counts of the smallest qualifying common-competitor class, and rescue/harm counts by truth class. No per-node IDs, labels, predictions, masks or representations are mirrored.

A **common competitor** is one same nontruth class whose original logit strictly exceeds the truth logit in every member. Ties are excluded. If multiple competitors qualify, retain the smallest class index in server-only baseline arrays and report its fixed class counts. A **pool rescue** is correct served prediction despite every member being wrong. A **pool harm** is wrong served prediction with at least one member correct. Also report actual pool harm despite all members being correct and actual common-competitor nodes where the pool succeeds; these are diagnostic counts, with no tiny floating-point invariant gate.

Member NLL uses float32 `log_softmax` of the original logits at the truth class. Pooled NLL uses the stable true-class log mean probability, `logsumexp(member_log_p_truth) - log(M)`. This loss summary is computed from the same original logits while serving retains its original rounded float32 mean-softmax probabilities. No clamp, epsilon or recalibration is introduced. Descriptive means of stored row losses are accumulated in float64; any nonfinite row loss is counted and its corresponding mean is null rather than silently replaced or dropped. Empty cohorts have null rates/means.

The primary paired comparison is `be_init -> be_init_contrastive`. For every fixed cohort and seed, report wrong-to-correct repairs, correct-to-wrong harms, net repairs, both correct, both wrong with same/different wrong served class, accuracy change, served NLL change and member competence/NLL changes.
