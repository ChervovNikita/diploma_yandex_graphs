## The strongest remaining candidate and why it is not retained

The most concrete information repair considered was **a private query-conditioned structural correction after a shared graph encoder**. For a link query `(u,v)`, write shared states as `h_i = f_theta(G,X)_i`, native member scores as `b_m(h_u,h_v)`, and a prospective correction as

`z_m(u,v) = b_m(h_u,h_v) + delta_m(h_u,h_v,e_uv(G,h))`.

Here `e_uv` would describe observed pair-relative context: common-neighbor membership, relative reachability and higher-order common-neighbor roles. Each `delta_m` would be a trainable nonlinear private route, trained by member supervision and served through the fixed uniform logit pool. It would introduce neither transfer episodes nor a new optimizer rule.

The graph-dependent failure is real in a restricted model. If two queries have identical decoder-visible endpoint states but different target-relevant pair context, every terminal private transform of those states gives the same output for both. A private readout cannot reconstruct information that its inputs have discarded. A pair-relative correction can change that interface. This is a conditional representational fact, not evidence that the current nonlinear NCN has these collisions or that its errors arise from sharing. Independently trained endpoint-only predictors can have the same defect; NCN already receives common-neighbor context.
