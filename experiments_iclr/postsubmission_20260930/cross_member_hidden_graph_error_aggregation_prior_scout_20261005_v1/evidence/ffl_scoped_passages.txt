  All experiments were conducted in the Torch framework. We used ResNet [1] and wide residual networks (WRN) [2]
architectures for several experiments. The fusion module consists of a single 3×3 depthwise convolution layer and a single
1×1 pointwise convolution layer. The fusion module used both batchnorm and ReLU nonlinearities for both layers. Similar
to burn in steps in Codistillation [28], in our method, each student network is trained somewhat independently before some
epochs so as to limit the distillation at the beginning of the learning using the weight ramp-up function proposed by [29],
which is also used in On-the-ﬂy Native Ensemble (ONE) [18].
