# Two missing quality controls now have numerical component evidence

The ordinary view-augmented independent control and the structured single endpoint-pattern control passed their bounded CPU checks on the authorized 18.77 repository. CUDA was hidden; each process used two CPU threads. They performed zero optimizer steps and read no real graph dataset, selected checkpoint or experiment outcome.

The ordinary control acquired four native networks with disjoint parameter storage. In both local and global stages, all eight member/stage gradient cases agreed with an independent per-pass autograd oracle for the native-plus-assigned-view objective. The successful child used 4.473 seconds wall and 4.130 CPU seconds; peak RSS was 646,832,128 bytes.

The structured single retained one native scalar target path with four auxiliary density emissions. On the constructed six-node fixture, native and adapter scalar scores had maximum absolute difference zero in both evaluation and same-RNG training mode. Support coordinates and CPU RNG agreed; emission rows differed; auxiliary gradients reached the actual encoder/scorer tensors; main gradients remained detached from completion scores and the new head. The child used 3.834 seconds wall and 3.892 CPU seconds; peak RSS was 660,467,712 bytes. These observations do not prove equality on every graph or CUDA execution.

The first ordinary-control attempt exited because its bound source dependencies had not yet been copied to 18.77. The first structured-single attempt exited because the caller omitted the existing repo-local TorchSparse PYTHONPATH. Both failed attempts and their measured outer wall times remain recorded; failure CPU times were not captured. The fixes copied only missing exact source and used the existing qualified dependency path. No library was installed or host setting changed. The second attempts used unchanged scientific model/objective source. No attempt was restarted on an observation timeout.

These are correctness checks, not representative predictive pilots. They make the controls implementable for complete real-graph comparisons after prospective selection of an experiment schedule. Full-shape resources, native-size CUDA behaviour, complete fitting, selected-state replay and predictive competence remain unverified. No extra optional component tests are needed now.

A successful GNNM development result must still beat competent singles and an ordinary independent ensemble. The structured single supplies a sharper auxiliary-information comparator: if it obtains the same gain, the benefit need not require four full target trajectories. A further strong independent reference can give each independently trained native model that same structured auxiliary and then pool its four scalar predictions; source preparation here does not supply or silently freeze that additional experiment. Any future source/control adaptation must be specified before its scoring and its full cost reported. The existing frozen cohorts and original paper scores are unchanged.
