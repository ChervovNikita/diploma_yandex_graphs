## 2. What the two mechanisms actually change

**GM4 changes private memory dynamics.** Each route retains its own preceding hidden state. Shared dense recurrent/input maps, privately factored gates and two private bias vectors respond to that state; graph tours supply route histories and repeated-node readout. The selected native first-layer cache and common live graph decoder constrain the learning problem. Compared with the closed affine scanner, state feedback, dense mixing, cell convention, staging and placement change together. A win cannot isolate any one of them.

**LM4 changes private parallel addressing.** Each16-slot group has learned offsets over graph-anchored queries; all routes share write/read/value maps and the live native class head. The full eval pre-lin3 H256 of the factorized PolyFormer source stays un-clipped; only memory U is normalized. Two distance-biased attention exchanges collect remote content and return node summaries. This has no recurrent state chain. Its partitioning changes slot competition, objective and final prediction aggregation relative to S64.

Both mechanisms acquire alternatives under common class coordinates, own supervised losses and the original probability mean. A zero residual readout initially contains the source function and delays memory gradients. It gives engineering containment and SELECT eligibility, not a later DEVELOPMENT guarantee. Frozen native compression can discard essential evidence; common maps can homogenize members; more correct alternatives can remain weak or be outweighed by harms.

The earlier literature memo's **inactive Physics LM4 fallback** is ancestry/design history. The current **PubMed LM4 v1** specification is its own authority for PolyFormer identity, H256 placement, no native clipping, roles, Adam, landmarks and sources. The two should not be silently interchanged.

## 5. Evidence required for a methodological contribution

**A useful allocation result** requires the full frozen raw/member conjunctions against strong same-information singles and genuinely equipped independently selected bodies, retained proper-loss verdicts, full-population repairs/harms and measured acquisition/serving costs. Comparisons must preserve reference source/selection custody: GM4 uses one P1 ancestor while independent bodies acquire four; LM4 sources are all freshly selected on new SELECT. Small parameter storage does not imply speed, training efficiency or superiority over stronger architectures.

**A mechanism attribution requires the relevant matched contrast.** The existing root-requested GRU promotion policy already names CT4/common-tour and PO4/within-component order permutation, outside the current v2 roster and only after a raw/member utility pass. PO4 preserves multiplicities/components/readout denominators; CT4 tests the whole private-tour ingredient. Their separately bound positive contrasts would support the stated history/order ingredient, still conditional on changed sequence conditioning. This report adds no arm or fit authorization. LM4's current T16/S64 contrasts test private address capacity and partitioned allocation jointly with their optimization/objective differences. They cannot isolate graph-relative distance bias or private addressing alone. Any future topology/private-address claim needs an independently frozen matched-memory comparison that changes only the claimed ingredient before that claim is promoted; no such family is nominated here.

**An original method claim needs more than composition and a pilot win.** State the contribution at the supported allocation/placement level, acknowledge direct GRUBE and Graph Perceiver/MemGNN ancestry, and resolve a concrete remaining novelty question with targeted primary evidence before claiming firstness. Claims against graph-GRU or original graph-latent architectures require capable attributed comparators, not inference from a stripped control. Coherent confirmation/transfer evidence is a later root decision. Two positive packages on different encountered datasets/cells would be qualitative corroboration of the allocation idea; their different sources, operators, widths and selectors do not estimate a common causal effect or establish universal transfer.
