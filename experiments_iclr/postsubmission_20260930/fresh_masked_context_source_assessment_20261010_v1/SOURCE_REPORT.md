# Fresh static source assessment — masked-context BE/PolyFormer

Assessed on 2026-10-10, before reading experimental outcomes for this assessment. Scope: the original `masked_context_be_source_prototype_20261010_v1` packet and its exact local pinned provider source. This is code and method qualification, not a manuscript review, competence finding, or acceptance verdict. No numerical imports, construction, data/checkpoint reads, numerical tests, server calls, or original-packet edits occurred. Source and read bindings accompany this report.

The source implements its principal stated objective correctly. Four BE routes share a live native PolyFormer body and use separate trainable rank-one factors; missing features are removed before every polynomial token is rebuilt; all TRAIN labels receive factual and masked CE. The main unresolved comparison defect is the fourfold decoder-gradient normalization difference in the untied auxiliary control. The source also has two admission/provenance gaps and a serving-state restoration defect. These should be fixed in a new source generation before qualification or causal attribution.

## Verified model and gradient semantics

**Native predictor.** The retained class bodies are extracted from the pinned provider via AST, with the model’s module-level seed calls and unrelated imports omitted. The monomial launch row agrees with `NATIVE_MONO`: K=2 means three tokens, width 256, two blocks, eight heads, expansion 512, FFN 32, q=1.6, dropout .5, attention/context/FFN dropout .8. Preprocessing is exactly the retained `mono_base` path: `gcn_norm` followed by a SciPy sparse roundtrip to float32 and `[X, AX, A²X]`.

The native attention is token attention within each node: LayerNorm, token-specific two-layer ReLU maps for Q/K, `tanh(QKᵀ/sqrt(32))`, learned head/token bias scale times `(j+1)^(-1.6)`, and dropout. It has no softmax and no learned V/O maps. Values are normalized input tokens. Attention and FFN have residual additions. The predictor sums the three tokens, applies dropout, a 256-by-256 map, ReLU, dropout, and the class map. The captured reconstruction representation is the actual post-ReLU/post-dropout input to `lin3`, not an earlier cached factual hidden state.

**BE and reset.** The existing helper wraps all native `nn.Linear` sites as `((x*r_m) Wᵀ)*s_m + b`: shared bias is added after the output factor. Unit r/s are installed after the native constructor/reset, without a later reset. Shared matrices/biases, LayerNorm parameters, attention bias scales, and private factor rows remain live. There are no additional factor sites or private normalization bodies. Name-based optimizer assignment preserves the author’s attention-versus-base LR/weight-decay grouping; factors inherit the group of their wrapped map. The decoder uses base Adam settings. Source-level grouping/reset is correct; no numerical parity is established.

**Mask/label custody.** Eligible anchors are public-feature nonzero rows; SHA256 of fixed seed 190101 and public node IDs defines four balanced, disjoint quarters. This is label-free, but deliberately dependent on fixed node identity. Full feature rows in the assigned quarter are zeroed, and all three polynomial tokens are recomputed from that masked X. Thus no factual own-feature term remains in the masked polynomial bank, including return paths through A². Other nodes’ features and public graph structure remain available as intended transductive context. A member also sees full X in its factual CE, and shared weights see all routes’ factual/masked losses: the hypothesis concerns auxiliary context training, not permanent exclusion of those features from learning.

No TRAIN subset is dropped in masked CE. Zero-feature nodes stay in classification and are excluded only from reconstruction. The provided NPZ loader accepts exactly X, edge_index, train_ids, train_y; no held-out masks or labels are loaded. Native split production necessarily belongs to a separate role-custody step. The qualifier’s size/type/finite checks cannot authenticate normalized features or official graph semantics without that external evidence.

**CORE-style objective.** For each eligible masked anchor, z_i is the common linear decoder’s output and x_i is frozen normalized input X_i. Both are L2-normalized with epsilon 1e-8. The finite-temperature loss is `-log exp(cos(z_i,x_i)/.2) / [exp(cos(z_i,x_i)/.2) + sum_(32 other k) exp(cos(z_i,z_k)/.2)]`, averaged over anchors. Floyd sampling supplies 32 distinct other indices uniformly without replacement; the anchor is excluded. Both z_i and gathered z_k remain differentiable; x_i is not. This is angular instance discrimination, so it does not establish reconstruction of feature magnitudes or coordinate-level fidelity. No original CORE paper was reopened, so exact primary-source parity or novelty is outside this assessment.

**Ownership and routes.** CORE reaches the common decoder, upstream shared weights, and the current member’s upstream private factors. It cannot reach the class map after the hook; the class map and its private factors receive factual and masked CE. Sequential route backwards accumulate the stated scalar objective at one parameter state, then every optimizer steps once. There is no selective gradient filter or intermediate parameter update. The auxiliary audit uses `autograd.grad(..., retain_graph=True)` for inspection; ordinary backwards supply the optimizer gradients. It checks nonzero group reachability only for the first route, not all parameters/routes, and is not gradient-equivalence evidence.

**Controls and exposure.** The all-view single has exactly one factual CE plus .5 times the mean of four masked CEs plus .1 times the mean of four COREs. It executes five training forwards and preserves the intended total auxiliary mass. `independent4_native` constructs four distinct native objects at seeds seed+1009*m, each with its own optimizer and native own CE; no decoder, factors, auxiliary loss, or best-member reuse is present. Member 0’s constructor and factual-dropout seed agree with `single_native`. Independent member checkpoint selection and full science training are deliberately absent/pending. The untied auxiliary control has four separate bodies but is coupled through a common decoder and is correctly named as such; decoder normalization remains the comparison issue above.

**RNG and serving.** Separate persistent Torch streams exist for member/view pairs; the single’s masked streams are indexed by quarter. Construction, negative draws, and ownership permutation have separate seeds/streams. Shuffled ownership assigns all four quarters once per update. Outer Python/NumPy/CPU Torch and the target CUDA RNG are restored around construction. Forward dropout uses only Torch; its caller Torch state is restored. Author all-device seed calls are omitted. No deterministic CUDA/bitwise guarantee follows from these scopes. Serving uses the factual bank, eval mode, no gradients, and mean class probabilities, with no decoder call or labels; the mode-restoration gap remains.
