# Density, stable DP and exact conditional sampling

Source specification only; no likelihood implementation or numerical test was run.

## Stable likelihood

For finite t and R>0, center only the DP logits: u_r=t_r-mean(t). The conditional subset law is invariant to a common shift, because both the numerator and e_K acquire the same K-fold factor. Keep the original t/q for the count-head context. No t clipping or probability epsilon is admitted.

In FP64 define F[j,k]=log e_k(exp(u_1),...,exp(u_j)). Initialize F[0,0]=0. For j=1,...,R,

    F[j,0] = 0
    F[j,j] = u_j + F[j-1,j-1]
    F[j,k] = logaddexp(F[j-1,k], u_j + F[j-1,k-1]), 0<k<j.

Impossible cells have constant -infinity and are not evaluated through a `logaddexp(-inf,-inf)` autograd path. DP never materializes exp(t), subset products or a probability normalizer. Compute log pi by FP64 logsoftmax of the head logits, and

    log P_C(Z) = log pi_K + sum_r u_r Z_r - F[R,K].

The score/count neural maps remain FP32 under the native runtime profile; cast their outputs to FP64 for density/DP/sampling arithmetic and propagate auxiliary gradients back through the casts. This precision addition and its cost are explicit comparator changes. R=0 uses log P(empty)=0 and auxiliary0 without count-head training. For K=0 or K=R, the conditional likelihood equals1; no division by count or logarithm of zero is used.

Evaluate all feasible counts. For a query, all forward cells costO(R^2); four conditional backward samples costO(4R). The reconstruction backward can recompute the prefix DP and reverse it inO(R^2). A planned memory-bounded custom backward stores logits and K, not every query's full DP: compute/recompute one query's prefix at a time, withO(max_query R^2) workspace plus the retained neural graphs/slot tensors. This is an implementation target that must be qualified. It is not a current performance receipt or an authorized algorithm shortcut.

## Exact sampling interface

1. Detach t and pi. Sample a count k by inverse CDF from pi, using a separate uniform in(0,1). Compare log U to cumulative logsumexp values to avoid treating rounded probability sums as an artificial final class. The last class closes the exact cumulative mass; numerical nonfinite/inconsistent CDF state fails qualification.
2. Traverse slots backwards from j=R down to1 with remaining count k. If k=0, set remaining bits zero; if k=j, set remaining bits one. Otherwise

       log p_include = u_j + F[j-1,k-1] - F[j,k].

   Draw B_j=1 iff log U_j < log p_include, then decrement k when included. Every slot uniform is assigned by deterministic counterpart-slot identity. The forced-boundary path does not borrow unused uniforms from another slot/query.
3. The sample has exactly the drawn count. The prefix ratios telescope to exp(sum u_r B_r)/e_k(exp(u)), so the full sample law is P_C. Repeat with four independent uniform keys; all four draws use one predicted law and one decoder parameter set.

The source formula has log p_include<=0. A later implementation may round a positive value to0 only if it lies within a prebound FP64 roundoff tolerance1e-10; a larger violation fails. This is a rounding guard, not a probability epsilon or a statistical change. Open-interval uniforms are generated by `(integer53+.5)/2^53` from a domain-separated counter stream. Keep the integer mapping and hash/library version in the qualified source manifest.

## Marginals and gradients

For a fixed count k,

    mu_{r|k} = exp(t_r) * e_{k-1}(exp(t_except_r)) / e_k(exp(t))
             = d log e_k(exp(t)) / d t_r.

The actual marginal is mu_r=sum_k pi_k mu_{r|k}; E[K]=sum_k k*pi_k. For diagnostics, all mixture marginals can be obtained by a reverse pass through `sum_k stopgrad(pi_k)*F[R,k]` **with respect to u treated as independent DP inputs**, which costsO(R^2), rather than a separate excluded-slot DP for every r and k. If an implementation instead differentiates through u=t-mean(t) with respect to original t, that derivative is mu_r-E[K]/R; it must add E[K]/R to recover mu. The shift cancels correctly in the full auxiliary likelihood, but an isolated centered-normalizer derivative is not the marginal. Do not return sigmoid(t) under the name actual marginal.

For C64-M4 use these actual mu values in independent Bernoulli draws, compare log U with log mu for each slot, and handle exact mu0/mu1 as forced bits. There is no count draw or conditioning on another sampled slot. The count-trained pi/t influence the marginal parameters through context, but the sampled conditional law factorizes. This holds marginals fixed while removing the joint law's count-induced dependence. Qualification must verify its count distribution and marginal identity separately from the C64-D4 exact-count sampler.

Holding the count head/context fixed, the auxiliary partial derivatives are

    d L_C / d t_r = (mu_{r|K} - Z_r) / R,
    d L_C / d a_k = (pi_k - 1[k=K]) / R.

The implemented **total** t gradient also includes the count-head path through mean q, mean q^2 and max q in usable context. That path is permitted auxiliary learning. State the fixed-context partial derivative separately from total autograd; do not suppress the head-context gradient or claim the partial formula is the total formula. Max has its standard subgradient and must use the qualified tie rule.

Main loss uses detached sampled B, so no main gradient reaches t/pi via a draw. h' is not detached: main gradients still reach outer xlin, encoder and decoder. Decoder/encoder parameters reused by the auxiliary scorer can therefore receive both permitted gradient sums. TRAIN teacher Z/K participates only in the scalar reconstruction loss and its gradients; it is unavailable to the sampling/count-context interface.

## Analytical sanity properties for later checks

- At equal logits, the conditional law is uniform over all size-k subsets.
- If pi_k is the Poisson-binomial count distribution of independent sigmoid(t_r) bits, the law reduces algebraically to the factorial Bernoulli distribution. This is a density-interface check; it does not assert the learned count MLP implements that pi exactly.
- Adding a common constant to t while holding pi fixed leaves the conditional law and likelihood unchanged. The count head may change through q context, so the whole neural model is not required to be shift invariant.
- K=0 and K=R have deterministic conditional patterns; their fixed-context slot gradient is zero.
- Slot permutation changes only enumeration, not the density. Endpoint exchange changes neither context nor support counterpart identities.
- All finite t/pi logits assign finite density to every feasible pattern; no exact structural zeros or arbitrary same-count interactions are claimed.

The prior even/odd three-slot witness is explained by count distributions and equal logits. The scout's six-slot witness removes that explanation for the abstract law, but supplies no measured comparator result. Numerical enumeration, gradcheck, RNG frequency checks and tensor execution remain future qualification work.
