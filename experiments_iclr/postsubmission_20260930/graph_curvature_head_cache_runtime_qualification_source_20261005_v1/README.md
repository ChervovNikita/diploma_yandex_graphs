# Native cache closure qualifier: source only

This sealed packet prepares an engineering comparison of the preserved final-head cache v2 against the original head-only closure. It has not imported or executed numerical code. It supplies no runtime release, data/checkpoint loader, warm fit, continuation, remote launch or predictive-score reader. Root must inspect the source and separately admit execution.

`qualifier.qualify_from_native_warm(native, optimizer, metadata, warm_rng, graph_name, graph, train, canonical_edges, admission)` takes one root-custodied, prescribed cfg0 seed17 endpoint for Squirrel or Photo. There is no validation-label argument. It requires the caller's current RNG to equal the supplied endpoint RNG, the exact original preprocessed `teacher_input` and `teacher_edge_index` used by that warm fit, and an explicit root admission. It does not certify freshness/custody from a metadata dictionary. Root must establish those before the call. It records the latest witness helper's logical model/Adam/RNG digests and graph/TRAIN fingerprints; it never recomputes preprocessing or compares independently serialized checkpoint file bytes as a state identity.

The code mirrors the existing driver preparation once: native copy, identity K1 and K4 clones, one native/K1/K4 identity audit, original named Adam transport, original normalized adjacency and full-node mapping. Both closures bind the **same K1 object and exact graph arguments**. Both selectors receive the **same K4 prototype, frozen named optimizer, head identity vector, adjacency, full-node IDs, TRAIN labels, seed17, original constants and endpoint RNG**. The prototype is not trained. Each selector is invoked exactly once through the unchanged driver-imported selector function. Original common descent, every graph/permuted/random candidate, scalar matcher, safeguard, trial, null and abstention path run unchanged.

Only the closure input differs. Full-model `one_adam_trial` is neither replaced nor instrumented; it continues creating disposable K4 copies, differentiating every live shared/private parameter, applying the original coupled Adam step and doing its original full post-step forward. There are at most 10 maps per case, 20 per graph, 40 across the proposed two representatives. No extra Adam probe, warm update or continuation is added. The shared prototype, its named optimizer and the native donor are checked unchanged, including gradients, RNG, buffers, module modes and restored instrumentation.

The sealed installation-witness runner/helper v3 is reused for exact diagnostics, synchronized costs and the live-object installation recorder. Its helpers wrap the actual selector and installer, call the original functions once, capture actual intended slices and actual frozen prototype state, and restore both helper bindings in `finally`. Each branch's five returns must exactly match its own source witnesses and source inputs. A narrow comparator adapter normalizes only nonempty named tensor-state mappings (`dict`/`OrderedDict`) to `dict` on both sides before calling the original exact predicate. This repairs v3's incidental CPU-snapshot/live-state container mismatch; it changes no keys, tensor dtype, shape or values and leaves optimizer/RNG structure predicates unchanged. Own prototype/K1 and paired return snapshots are likewise normalized identically. The qualifier then compares actual returned model/Adam/RNG/mode snapshots across branches. It does **not** call `independent_reconstruction`, independently rerun common descent to invent an expected installed head, or conflate an independent FP32 reconstruction discrepancy with source custody. Earlier unresolved native qualification remains unresolved; a cache comparison cannot promote it.

Checks are bounded to what this substitution needs:

1. Exact paired common-center/trial/bank/basis receipts, D0 fixed-first reference, all original gap/radius matching traces and candidate statuses, trial counts, selections, abstention and actual installed slices. All five actual model/Adam/RNG/mode return snapshots must compare exactly. The matcher is exercised by the two existing selector calls; it is not duplicated under another radius grid.
2. Complete forward logits at identity and unique actual installed head vectors (at most 38 points per closure). No new scientific candidate is constructed. If rank/D0 nulls prevent matching, the missing noncommon matching coverage is explicitly unresolved; there is no replacement basis or redraw.
3. Paired JVP primal/tangent, arbitrary full-output VJP, TRAIN residual VJP and ordinary autograd TRAIN CE gradient at identity and the **actual witnessed** common center. The inherited seed17/three-direction construction is reused. Cross-closure comparisons use exact dtype/shape/`torch.equal`; no tolerance is loosened. The within-implementation manual-residual VJP versus ordinary CE gradient uses only the bound integration's existing gradient tolerances.
4. The existing initializer's three-direction, two-fixed-epsilon AD interface at that common center for both closures, with its original duality/finite-difference predicates. No epsilon search is added.
5. Source hashes before/after, exact supplied-input fingerprints before/after, actual source custody, unchanged native/K1/K4 state/gradients/modes/hooks, and exact restored RNG. This comparison returns JSON diagnostics; usable models, optimizers, tensors or warm artifacts are not saved.
