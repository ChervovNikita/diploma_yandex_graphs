# Prior limits and rejected alternatives

## Exact known components

**ECNN (arXiv1912.00181; linked AAAI2021 DOI10.1609/aaai.v35i11.17169)**
already uses binary/q-ary class partitions, coded ensembles, shared network parts,
code distances/column diversity and joint training. Its inspected main method
uses meta-classifiers, a shared prediction transform, entropy regularization and
a tanh code decoder. Parameter sharing is explicit in the inspected paragraph.
We do not adopt its independence/continuous-sample lemmas for correlated graph
nodes or claim a verified graph result.

**HXE (arXiv1912.09393; CVPR2020 DOI10.1109/CVPR42600.2020.01252)**
already sums native class probabilities into hierarchy probabilities and changes
only the loss, retaining a native flat classifier at inference. Proposed full
CE +λ one-group CE is exactly depth-two HXE. The equation is not a new loss.

**Spectral ECOC (ICCV2009 DOI10.1109/ICCV.2009.5459355)** metadata/abstract
already constructs a class-similarity graph and thresholded graph-Laplacian
eigenvectors for output codes, considering code separation and classifier quality.
The primary publisher route failed; its complete implementation and use of
different member-level losses were not audited. This remains a close unresolved
collision, never absence evidence. The proposed max boundary-coverage tie rule
differs from the described spectral construction; changing the optimizer alone
does not clear a methodological contribution.

**Deep N-ary ECOC (arXiv2009.10465)** was found in metadata. Its supposed ar5iv
method request redirected to the abstract. It supplies no completed primary
method read or code/learning guarantee in this packet. Related hierarchical
ensemble, B-CNN and learned-hierarchy metadata leads remain uninspected.

The proposal therefore borrows class partitions and proper hierarchical risk.
The bounded complete-rule difference is a different graph-conditioned full-class
risk pack for each live shared-backbone BE route, with ordinary scalar gradients
and unchanged native serving. No global exact-rule absence or new principle is
established. It is a conditional experiment candidate, not a cleared paper claim.

## Alternatives not retained

| Alternative | Reason |
|---|---|
| Full DCT with clean-peer/pseudo-label consistency | Can preserve common wrong labels; DCT/DVERGE/EIO already cover the learning principle. |
| Ground-truth cross-FGSM shared paths presented as new | Different attack criterion, but shared peer-vulnerability learning is established EIO ancestry. Retain only as a baseline. |
| Recipient-protected projected graph attacks | Aggregate risk hides per-node harms; local projection cannot protect finite margins; identical routes may give zero exclusive direction. No feasible justified rule established. |
| Coarse-only ECOC members | Partial meta-class competence is not full-class member competence; cannot establish a gain over capable native classifiers. |
| A separate auxiliary code head behind unchanged class predictions | Can fit questions in task-unused coordinates; does not require changed full-class decisions. |
| Soft Bernoulli code decoding advertised as nonlinear correction | For signed code B, `sum_j log sigmoid(B_cj*u_j)` equals `.5*B_c*u` plus a class-independent term. Its softmax is a linear class-logit map; no correction miracle or common-rival escape follows. |
| Graph smoothness claimed from class-edge counts | Counts are a TRAIN association. They do not prove which context causes errors or what preserves labels. |
| Code distance or hidden separation used as success | Neither is factual pooled accuracy/NLL or protected mean/worst member quality. |
| Own CE and group risk claimed to force independent predictors | All proper risks may have the same Bayes optimum; finite-training differences and useful pool lift must be measured. |

The source-qualified modern single, all-pack single and independently trained
ensemble are essential. If they match, simplify the explanation or close the
shared-ensemble hypothesis. No coefficient/codebook/seed replacement follows a
negative result. Previous failed methods and original paper scores remain sealed.
