# Degree-preserving3x3 conditional assignment loss

Source only, unexecuted. This packet contains exactly `module.py` and this README. It adds no scorer, graph/data loader, fitting, optimizer, server access, source framework or changes to the completed single/independent4 driver. It implements the algebra and permutation ordering already saved in `informative_structural_exposure_gap_20261005_v1/matching_objective_sketch.py`, rather than introducing another method proposal. That assessment attributes degree-switch ancestry to Maslov–Sneppen and mixture responsibilities to GRAN; maximum-entropy/exponential-family ingredients are standard. This is not a new theorem or novelty clearance.

Call `matching_losses(native_logits, observed_assignment)`. Logits are the actual per-member native target outputs with shape `[M>=1,B>=1,3,3]`, evaluated on all nine edges between two disjoint node triples, using one shared visible context excluding those targets and their reverses. The caller enforces that context and supplies detached TRAIN-observed assignment indices. Labels do not enter either law. No inferred TEST truth or changed hard-negative support is permitted.

Indices0..5 correspond to permutations `(012),(021),(102),(120),(201),(210)`; their parity vector is `s=(+,-,-,+,+,-)`. Each member scores permutation `pi` by `sum_i logits[m,b,i,pi(i)]` and softmaxes across all six complete assignments. `qJ` is the chosen uniform mixture of these normalized conditional matching laws. It is not automatically an unconditional Bernoulli mixture conditioned on matching degrees: that conditioning would reweight members by their constraint probability. Each assignment gives every left and right node degree1. Return values include both bundle-mean NLLs, per-bundle NLLs, member laws, `q_joint`, `q_max_entropy`, their full3x3 **matching-law edge marginals** under keys `matching_law_edge_marginals_joint/max_entropy`, and the scalar entropy root. These margins are neither native sigmoid probabilities nor served mean scores. No calibrated population probability or lambda is supplied.

For this six-assignment incidence map, every law with the same nine edge marginals is `qJ+s*c`. The interior entropy maximum satisfies

`sum_even log(q_even+c) = sum_odd log(q_odd-c)`,

with `-min_even(q) < c < min_odd(q)`. Its equation is strictly increasing; this module solves it by bracketed bisection. Backward uses the analytic implicit derivative

`dc/dq_i = -s_i / ((q_i+s_i*c) * sum_j 1/(q_j+s_j*c))`.

Reciprocals are evaluated as the equivalent normalized ratios `min(r)/r_i` to avoid overflow; probabilities are never clipped. The custom derivative supports first-order autograd only. Every additive single-member law already maximizes entropy for its own edge marginals. Identical-member mixtures therefore give a null; general mixtures may leave that family. A `qJ-qME` difference identifies finite-state dependence beyond these margins, without asserting a predictive benefit, model-class superiority or a full-graph likelihood.

The loss casts native outputs to FP64 without changing the native FP32 forward. All inputs and additive scores must be finite. `qJ` and the solved law must be strictly interior. FP64 softmax underflow that removes a mixture assignment, a nonrepresentable interior solution or failure to resolve the root raises an error. No epsilon, clipping, temperature, renormalization or tolerance-relaxation fallback exists.

Fixed numerical resolution is declared explicitly: root log-equation residual at most `16*eps64*(1+sum(abs(log(r))))`; input mass error at most `32*eps64`; output mass and each edge-marginal difference at most `64*eps64`. At most1077 bisections cover the FP64 significand/subnormal range on the probability interval. Bisection can stop at adjacent representable values; it then succeeds only if the same residual certificate passes. Close-to-boundary cancellation or softmax underflow can reject mathematically valid real-arithmetic inputs. Such a failure is preserved, not repaired. Bounds concern this small probability calculation, not graph/model precision or calibrated latent links.

Its three constructed3x3 matrices favor the three even assignments: each matching-law edge margin is1/3, whereas `qJ` differs from the uniform maximum-entropy law. The oracle uses `h=eps64^(1/3)` and fixed error budget `128*h^2*(1+max(abs(gradient),abs(oracle)))`; neither is a fitting/search choice. It checks the combined two-NLL autograd path through actual logits and implicit root, performs no updates and does not populate parameter gradients.
