## Exact numerical changes

C4 applies `message *= 2*sigmoid(A*stopgrad(H_query)+b)` after the existing 64D
label-value aggregation and before its 10-class BE output. A=b=0 is the identity;
there is no random gate initialization or additive FiLM shift. The erased C4
uses the same architecture but permanently supplies a uniform 10-class code at
visible anchor value lookup, equivalently the original embedding matrix's row
mean. Actual CE targets, TRAIN roles/labels, Q exclusion and native H stay intact.
The erased policy is construction-bound and guarded on all role checks.

Controls gate each 64D aggregate before readout/concatenation. The nonlinear joint
single has one common gate across four untied messages, then the original
bias-free 256→256→10 readout. U4 has four independent gate modules in its route
ModuleDicts, owned by its four fresh private Adams. One-path has one gate and one
fresh Adam. Its bank-wide optimizer includes the common gate. C4 and erased C4
have one fresh Adam each. Static ownership guards require every learned
coordinate to have exactly one owner; actual runtime ownership remains to be
qualified. The original old-parameter CE/backward schedule is retained.

and stable log mixture. Original own-selected native acquisition remains a spent
cost, with no new native training or native forward during label updates.

mask,579/290 training value scale, serving scale 1 and full 5274 development selector
remain fixed. Five banks require 15 complete endpoints. No threshold, mixture,

The collector keeps the two original-style co-primary contrasts (gated C4 versus
gated joint single and fully untied U4), with mean accuracy gain ≥ 0.2 pp, positive
