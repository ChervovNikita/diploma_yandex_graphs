# Independent source audit of modern native teacher amendment v1

Date: 2026-10-02. Scope: engineering source/protocol review of the immutable packet. This is not a paper acceptance review. No author history or desired verdict was assumed.

The packet is a coherent source-only starting point for guarded full-graph qualification. I found no unconditional source-level exception or wrong pooling/optimizer/stage implementation that must prevent the proposed qualification from running. That is not numerical qualification: dependencies, real graph/provider identity, finite full-graph behavior, gradients, local/global Adam restoration, resource feasibility and replay remain untested. Its automatic `passed=True` receipt needs supplemental evidence before it is used to admit scientific fits.

Scientific admission/reporting needs versioned repairs for delayed final-label closure, registered attempt/failure custody, identical label-pack pairing, and graph-bound qualification evidence. None of those gaps establishes that an invalid run or label leak already occurred.

### Q1 — The pass receipt is broader than the executed assertions

The CLI asserts eval identity logits/common-body and boundary-weight gradients, one-or-more nonzero gradient tensors, finite train/validation loss, and selected checkpoint replay. It does not assert all-node finite logits/gradients, member-wise connectivity, expected optimizer membership/rates, copied private biases, dormant-owner exclusion, or equality of restored local Adam tensors and step counters. The qualification receipt nonetheless writes passed=True and calls its scope finite training and stage restoration.

### S1 — Per-cell correction report bypasses six-freeze closure

### S2 — Successful-cell selection does not enforce the no-favorable-retry rule

## Source behavior that is well supported

The primary selector uses cross entropy of `z.mean(0)` and saves `logits.mean(0).softmax(-1)`. Correction fixed inputs, serving and CPU64 reports retain that mean raw logit primary; arithmetic mean member probabilities is a fixed secondary and the covariance centering choice. I found no source drift back to mean-probability primary selection. See [prototype/modern_teacher_adapter.py](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/continuous_graph_efficiency_gap_v1/modern_backbone_teacher_amendment_v1/prototype/modern_teacher_adapter.py:229>), [prototype/modern_teacher_adapter.py](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/continuous_graph_efficiency_gap_v1/modern_backbone_teacher_amendment_v1/prototype/modern_teacher_adapter.py:239>), [prototype/modern_teacher_adapter.py](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/continuous_graph_efficiency_gap_v1/modern_backbone_teacher_amendment_v1/prototype/modern_teacher_adapter.py:294>), [prototype/aligned_score_correction.py](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/continuous_graph_efficiency_gap_v1/modern_backbone_teacher_amendment_v1/prototype/aligned_score_correction.py:119>), [prototype/correction_screen_driver.py](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/continuous_graph_efficiency_gap_v1/modern_backbone_teacher_amendment_v1/prototype/correction_screen_driver.py:676>).

The boundary wrappers transfer native W ownership and copy native bias into private B; replace dormant owners with Identity; keep four complete body/attention/global reduction calls; and do not reset the native model after wrapping. The written loop bodies match the pinned native operations at source level. Independent families retain native width and one synchronized family checkpoint, and the seed reset prevents different initialization consumption from shifting the initial training RNG. These are useful, reviewable integration choices; functional and gradient equivalence still requires root's numerical checks.

The PolyFormer optimizer preserves the native `attnmodule` name rule and rates/decays. The Photo loop performs 200 local plus 1000 global updates for a scientific fit; it loads the selected local model and Adam state, enables global stage, resets the global NLL selector, persists the non-state_dict stage flag and requires a global final checkpoint. The short qualification uses three Squirrel or two local plus two global Photo updates and remains report-ineligible. I did not identify a contradictory stage/optimizer source defect. Those properties should be verified in the actual runtime, especially optimizer state device/step restoration.

The four configurations, three seeds, earliest exact checkpoint tie and listed configuration tie are explicit, and the selection code requires all 12 successful config/seed cells per family and all six families for study closure. The designs share validation opportunity and declared native widths, with no matched-compute claim. Native split/selection differences, 20 percent teacher training, native-bias copying and mean-logit pooling are disclosed as prospective integration choices, so native-paper score reproduction should not be inferred.

The correction fit explicitly deletes its teacher/graph/inputs and clears CUDA cached allocations before serving profiling (correction_screen_driver.py lines 606–612). I found no supported retained-teacher serving contamination defect. Host maxrss is intentionally a process-lifetime quantity, and aggregate fit timing/peak does not supply separate local/global update or CPU checkpoint-copy measurements; root should collect those declared qualification costs separately.

## Root qualification handoff

A guarded report-ineligible qualification can proceed once root verifies actual dependency/device fingerprints, the immutable source bytes and real provider/row identity. Record the certificate's existing scope accurately and add the following evidence before full-fit admission:

- full N/F/C, complete edges/tokens/blocks and every member trajectory;
- finite full-graph logits and active per-stage parameter gradients, member connectivity and expected optimizer ownership/rates;
- identity-boundary outputs/common-weight gradients at the frozen tolerances, copied B values and dormant-owner removal;
- exact selected local model and Adam tensors/step counters at the Photo transition, fresh global selector and global-only replay metadata;
- selected checkpoint constructor/load replay, full preprocessing and per-stage update/host/GPU/checkpoint costs;
- graph-bound qualification receipt plus a distinct full-schedule feasibility decision.

Those checks cannot be replaced by AST parsing or source attribution. Qualification configurations need not become new scientific results; their labels remain confined to the admitted compact train/predictor-validation packs. Scientific fit/reporting should wait for the separate protocol/custody repairs above. A source repair should be made in a new versioned packet, preserving this v1 and the failures/evidence produced under it.
