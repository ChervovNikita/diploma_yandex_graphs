## The candidate operation being compared

The candidate retains mean-own full-input CE for the shared weights θ and private incidence factors η_m, and serves the mean of full-input member probabilities. Four fixed graph patches supply feature-masked auxiliary contexts. A common frozen feature-only teacher supplies an offset. After warmup, a balanced assignment pairs each persistent member with one context. The auxiliary loss updates only its private incidence factors; shared stems, feature maps, epsilon vectors and heads receive only the main loss.

For one context query, write native logits z, analytic no-message logits z0 and frozen teacher probabilities r. The independent assessment establishes

`J = CE(z + log(r) - z0, y)`.

The offset is independent of η during its update. For two classes and finite logits,

`grad_eta J = stopgrad(alpha) * grad_eta CE(z,y)`,

`alpha = (1 - p_corr(y)) / (1 - p_ctx(y))`.

This is a gradient equivalence, not equality between the scalar J and `alpha*CE`. An implementation using the detached weight must preserve the candidate's J values for the one-time assignment, its stochastic realizations and its optimizer state to reproduce the complete private update. Replacing the allocation cost with a different weighted-loss value can change the assignment. That distinction does not make the contrast a new gradient mechanism.

The specified frozen comparator `1-r(y)` is a different weighting curve and can have a different gradient scale. A win against it would not separate contrast from conventional adaptive context weighting. At `r=p_null`, the offset cancels up to a class constant and J is ordinary context CE. The teacher is a training reference; the proposed served predictor does not combine it with graph experts at inference.

## The remaining empirical question

The candidate combines established ingredients in a specific update: private graph-operator parameters receive adaptive context CE while shared parameters receive full-input own CE, with persistent graph-wide context ownership. No inspected source settles whether this combination improves the paid quality/cost frontier. Its exact complete priority is also unresolved. Those two uncertainties do not establish a novel mechanism.

The potentially nonredundant question is:

> Does fixed correspondence between informative graph-source features and persistent private incidence recipients yield useful full-input ensemble predictions beyond ordinary context supervision, loss-based specialization and matched classification capacity?

The independent assessment supplies necessary qualifications before that question is meaningful: exclude the repeated query panel from the auxiliary teacher's fitting or use charged cross-fitted teacher predictions; retain an all-zero-source control; and fix an out-of-panel context transfer population and coverage. Biased stems, live graph normalization and structural priors can make the graph contribution nonzero even with no informative source features. A no-message subtraction does not certify source-feature evidence.

Relevant contrasts are already largely specified, and no experiment is released here:

| --- | --- |
| Same adaptive-weight rule with the same allocation costs and draws | An equivalence check, not a distinct scientific comparator. It cannot substantiate contrast-loss novelty. |

| Frozen random balanced ownership versus loss-selected balanced ownership | Whether learned assignment adds utility. TRAIN context scores alone cannot establish this. |
| All-zero-source and within-context source-identity controls with the same teacher, panels, assignment and work | Whether informative source features and their correspondence are needed beyond graph bias/structure. |

If ordinary weighting, source-free propagation or a capable same-information predictor explains the result, no geometry/context mechanism gap remains. Even survival would support a bounded empirical placement/sharing result, with prospective confirmation still needed. A failed utility result cannot be rescued by assignment differences, matrix spread or a contrast label.
