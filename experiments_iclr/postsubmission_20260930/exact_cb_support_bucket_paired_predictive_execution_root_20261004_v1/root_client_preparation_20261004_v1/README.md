Stage transports exact source, independent review, client and pinned source/receipt metadata through the proven native relay. It accepts the explicit `.txt` and `.gitignore` pins. Existing remote files must match; nothing is overwritten. The source/review/client packet directories are made immutable. The execution root itself has no manifest or seal and remains available for owned outputs.

Admission creates nine external one-cell releases and a queue release, verifies canonical existing prerequisites via INPUT_BINDINGS, observes GPU1/interpreter identity, and runs the existing stdlib preflight/admission contract. There is no numerical QA ladder or new scientific gate. Current free GPU memory is observed, not reserved.

Launch checks the exact completed admission and review/source/client pins, then spends one exclusive launch marker before starting the detached queue. The queue spends one family marker and a marker for every attempted cell. It waits for and reaps the original fit supervisor, stops at the first failed cell, and preserves the remaining unattempted cells. It performs no retry, resume, private selection/logit read or automatic family analysis.

The owned monitor checks PID/start-time/argv/cwd/exe/session identities for the queue, fit supervisor and scientific child. It fetches count-only progress and owned accounting/terminal/artifact metadata and bounded stderr tails. It sends no signals and reads no private selection, checkpoint payload, EPOCHS, or prediction vectors. A lost launch transport receipt can be reconciled from the exact remote launch or queue-started handle; do not retry launch blindly.

After any failed transport or admission, retain all spent markers, command receipts and partial outputs for inspection. There is no combined run mode, automatic retry or alternate invocation.
