## Scientific finding

**PIFM is a material missing direct comparator.** Chen, Zilberstein and Segarra's *Prior-Informed Flow Matching for Graph Reconstruction*, arXiv:2601.22107v2 (18 June 2026), explicitly uses depth-one NCNC as an edge prior, then learns a graph-conditioned flow to recover dependencies that marginal edge predictions omit. Its paper also provides an edge-centered Cora variant and logit averaging over overlapping subgraph predictions. Consequently, neither “NCNC plus learned joint structural refinement” nor “marginal completion can miss coherent configurations” is a sufficient new methodological claim for the proposed bank.

The inspected operation is nevertheless different from the complete J/F definition: PIFM transports a prior adjacency matrix through a second graph model; J supervises the existing four shared NCNC completion scorers with the likelihood of an entire native residual observation-incidence vector, while retaining detached soft completion and the equal mean of raw target logits. **No complete equality is established by these scopes.** An implementation difference, an unresolved public route, or the absence of a named operation in a bounded scope supplies no novelty clearance.

The elementary 00/11 ambiguity witness is already present in PIFM §4, with unequal mode frequencies. The present proposal should attribute that reasoning as established. PIFM's predictor being called a posterior mean is an approximation claim: §4.1 assumes access to latent coordinates/inversion before identifying edge probabilities with conditional means. Applying sigmoid to learned NCNC scores does not itself establish calibrated posterior inference.

The sparse-loss discussion is relevant to the current observation proxy. PIFM §E.4 says weighting rather than CE alone changes threshold behavior. Its weighting changes the statistical objective; it cannot be silently copied into J/F while claiming a matched comparison or unweighted observation likelihood. Dense zero competence, marginal competence, joint coherence, and served ranking remain distinct criteria.

The source initializes global priors before flow training (`main_sub.py:804–816`). `utils/denoiser.py:228–355` confirms shared graph attention/message passing, adjacency-power channels, and time-conditioned normalization. Code inference uses K repeated full dense subgraph denoiser passes (`main_sub.py:1575–1587`). `pifm_sub/stitch.py:10–46` clips each probability to [1e-6,1−1e-6], converts it to a logit, averages **over the subgraphs that cover that edge**, and applies sigmoid. This is established logit averaging but differs from J/F's fixed four raw NCNC target logits, member identities, and detached completion association. It is not arithmetic probability-mixture serving.

Prior pretraining, all-pair prior construction, source feature/eigensolver work, graph sampling, dense subgraph denoising K times, coverage, stitching and selector evaluations all count. ## Prospective practical comparator settings

PIFM's declared public tasks include TU **IMDB-BINARY, PROTEINS and ENZYMES**, with disjoint training/evaluation graphs and random known pair masks, and transductive **Cora**. The former provide clean source-observation reconstruction tasks but require a separately specified GNNM/NCNC multi-graph adaptation; they are not native official link-ranking comparators. Cora is the smallest direct overlap between PIFM and public HeaRT link-prediction settings. Citeseer and Pubmed are nearby authentic HeaRT tasks, with PIFM transfer still unqualified. Collab is the target-relevant comparison, but the paper/source does not establish complete official Collab or HeaRT support or sufficient resource feasibility.

The authentic public evaluation contract was read from [Juanhui28/HeaRT](https://github.com/Juanhui28/HeaRT), current default `master` HEAD **`c447cbff4c493b60d14b6544c3c39d3b9c5ddff0`**. The README distinguishes existing OGB settings from HeaRT. `HeaRT_small/main_ncn_CoraCiteseerPubmed.py:36–93` loads supplied positive splits and per-positive `heart_valid_*`/`heart_test_*` negative arrays; `259–312` scores each positive and its own candidate row. `benchmarking/evalutors.py:29–34,96–129` computes average optimistic/pessimistic rank per positive. These scripts are primary author source, not certification of downloaded artifacts. No split, features or candidate file was accessed.

PIFM's `graphsage_heart` **prior architecture name does not establish HeaRT evaluation**. Its `compute_split_metrics` uses newly sampled random full-graph nonedges, AUC/AP, and a broadcast common negative pool for MRR (`main_sub.py:1654–1753`). That differs from per-positive HeaRT rows. HeaRT's README also says Collab negatives deliberately may include TRAIN/VALID positive samples. Filtering them out would change the benchmark.

Smallest explicit adaptations for an eventual PIFM-based HeaRT comparator:

1. Bind supplied public positive splits and the authentic per-positive candidate arrays rather than PIFM's independent random split/nonedge sampler. Preserve candidate identities, order, ties, complete ranking and selection; keep existing OGB shared-negative Hits@50 separate.
2. Give TRAIN flow examples **TRAIN-only truth**. Build the interpolant from that truth and synthetic TRAIN removals only; no VALID/TEST entry may enter a TRAIN graph, interpolant, prior, node sampler, feature, loss or cache. Restrict VALID labels to prediction scoring/selection. Rebuild the allowed visible graph and its context features at the same masking granularity as the comparator contract.
3. Resolve and pin the depth-one native NCNC prior adapter, input features, clamp/probability interface and scorer context. The inspected generic prior arrays or cached unmasked GraphSAGE state do not qualify it. The paper's weighted-CE route also needs a distinct implementation qualification if selected.
4. Score every positive and every supplied hard negative through the same label-independent context provider, with complete coverage. Preserve known TRAIN observations under the chosen input contract, including candidates that are observed TRAIN edges; do not condition removal rules on candidate labels. If stitching is retained, predefine the common unlabeled context bank and the covering-subgraph readout. Avoid a positive-only context bank plus default scores for uncovered negatives.
5. Bind source support explicitly. Native PIFM predicts all masked subgraph pairs and caps nodes; J/F supervises every native residual slot without caps. A pragmatic separately declared PIFM comparator may retain its original cap, reporting that difference and actual work. A support-matched mechanism control must preserve all native residual slots; silently dropping them is inadmissible.
6. Charge prior training, all graph/feature work, every denoiser step and candidate scoring pass, graph covers/stitching and the same complete selection budget. This is a **qualified PIFM-based adaptation**, not a native paper reproduction or a one-line matched J/F ablation.

No implementation or experiment is authorized by this scout. These are qualification requirements, not a newly adopted pilot.

## One bounded graph-specific opportunity

An appropriate question is whether **identity-aware higher-order residual closure** learned from the observation proxy improves a nonlinear target predictor after marginal competence, counts, covariance and a capable full-context structured single are accounted for.

For a query endpoint j, suppose three exact native residual slots refer to a,b,c, and the visible TRAIN graph contains the triangle a–b–c–a. The restored rooted four-clique event has indicator

`H_jabc(Z)=A_ab A_bc A_ca Z_ja Z_jb Z_jc`.

Its expectation under J is `A_ab A_bc A_ca * (1/4) sum_m q_m,ja q_m,jb q_m,jc`; F uses the product of the three means. This makes the opportunity graph-specific and identity-aware: the arrangement of residual candidates changes which triple closures matter, and a count pair does not specify which triangle was jointly closed. Equal first/second moments still need not specify this triple event. This is a source-only mathematical observation, not measured evidence that such configurations are common/useful or that native NCNC expresses the event exactly.

The edge-dependency paper supplies motif ancestry; PIFM supplies coherent graph refinement; KREPE/ARK supply a capable higher-order single construction. Thus the opportunity concerns this restricted learner/support/supervision/readout and useful target ranking, with full-context autoregressive/latent alternatives. It does not claim a new general motif or mixture principle. A richer same-context single may learn the same information or reproduce the grouped bank.

Four factorial components also impose a real limitation: all cross-group dependence travels through a four-state latent component. For disjoint residual groups A,B, `I(Z_A;Z_B | context) <= H(component)=log 4` by conditional independence/data processing. The between-component covariance has rank at most three, plus conditional Bernoulli diagonal variance. The bank may represent higher-order effects, but it is not an arbitrary joint law. These are analytical boundaries, not experiments or a proposed component-count search.
