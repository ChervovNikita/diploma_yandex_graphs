# Compact closed9 readout adapter

Prepared API only; no results, prediction archives or scientific inputs were
opened. Root owns whole9/terminal custody and collection admission.

`readout.run(output, collection, pins)` reuses the unchanged audited Wiki12
summary, paired errors, NLL/Brier and descriptive three-seed intervals, which
already reuse Wiki24 contracts. `pins` retains the existing
`audited_Wiki24_analysis` binding. No new statistical framework is introduced.

Collect COMMON selected predictions first for all three fixed seeds and freeze
their error cohorts before collecting ROUTE/permuted predictions. Reuse the
existing collector's one pass per member, fixed raw archive fields and original
native inference. Maximum36 member calls. Its compatibility filenames
`plain_cohorts_<seed>.npz` contain COMMON-frozen cohorts; metadata/report must name
COMMON as the reference. Raw logits, representations, masks, IDs and truth remain
server-only. The complete nine original1100-epoch endpoints and terminal custody
must pass before any prediction collection; no reselection or fitting occurs.

The adapter expects conditions shared_common/shared_route/shared_route_permuted
and seeds8101/8203/8307. It adds pool-minus-mean-member benefit and strictly
acquired rankings against the same frozen baseline wrong competitor, alongside
all repairs and introduced errors. It applies the unchanged prospective Stage1
gate only after all three paired slots are available. A passing gate authorizes
no job by itself and establishes no superiority.

The original collector's restore callback needs the new context snapshot
identity: config from integrationv2 configured_recipe; RUN arm equals condition,
underlying_session_arm is be_unit_contrastive; correct source/native/data hashes;
verified_frozen_targets archive80d30ed...; saved global flag and strict-first
selected epoch preserved. Use a source-specific callback, not fabricated legacy
mechanism_ablation metadata. Native construction still uses the shared unit arm,
then loads the original selected weights and original member RNG streams.

Known limits are explicit: target concentration/entropy changes with Qm versus
Qbar; permutation preserves positive counts rather than public graph degrees;
X is one context so topology causality is unproved; nontrivial target variation
can give zero gradients at parallel normalized embeddings. The same selected
development population is reused, and three seeds are not three independent
graphs. Competent diversity, broader quality and novelty remain unproved.
