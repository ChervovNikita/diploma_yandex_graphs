# Root assessment of the label-conditioned correction hypothesis

8 October 2026. Retain the agent's narrow hypothesis for a source prototype and
a prospectively fixed representative comparison. This note admits no training,
outcome opening, coefficient choice, dataset change or new scientific claim.

The changed operation is explicit observed-label evidence in private prediction
paths: one native feature-only backbone supplies states and base logits, while
four attention correctors pass only available TRAIN-label values. Their fitting
does not send correction gradients into the backbone. Query labels must be
removed from every route and every label-derived field before prediction.
This can supply new prediction information relative to feature-only serving,
without acquiring independently trained teachers. It does not add labels to
the allowed training population or establish that sharing improves accuracy.

UniMP establishes label inputs and masked-label prediction. C&S establishes
graph label-residual correction. The earlier staged private graph family already
establishes protected donors and private corrections. The method is an attributed
composition whose utility and complete-recipe novelty remain unresolved.
Concurrency, stop-gradient or masks alone do not supply a novelty claim.

Before source adoption, resolve two concrete design points: the attention
normalization population when some neighbor labels are unavailable, and the
learning signal when the native base already fits TRAIN labels confidently.
Corrected-prediction CE can then give little useful correction feedback. That is
a possible failure mechanism, not a measured failure of this unimplemented
method. Do not silently add a second loss or change the proposal after observing
its scores. A source successor must define masking, native/corrector RNGs,
old-state update ordering, selected-state serving, empty-neighborhood behavior,
parameter ownership and full work counters before a representative fit.

The same-context capable single and same-operation untied ensemble are decisive
for the stated goal. Live-gradient, faithful C&S, strong label-aware methods and
label-free capacity controls isolate the proposed explanations. A feature-only
baseline gap alone would not establish ensemble benefit. Preserve all errors,
harms, failures and costs; any positive exploratory result still requires
unused-data confirmation and fresh manuscript review.

The complete running graph12/Mol18 families retain their original recipes,
gates and opening rules. A supported incumbent direction must finish its
necessary references and confirmation before a new branch displaces it.
No broad graph-, link- or molecular-task claim follows from this initially
transductive node-label hypothesis.
