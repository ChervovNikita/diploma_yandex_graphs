## Exact private site and native computation

The prepared bank shares all original stem, second-input, left/right feature, head, epsilon and incidence slow parameters by object identity. Only `sheaf_learners[layer].linear1` receives private r/s. It is the original bias-free ordered-endpoint map, with 2c inputs and d² outputs. For this root configuration c=d·h=64, d=4 and h=16.

For one member and layer,

`z_(v,u)=concat(H_v,H_u)`,

`A_m=diag(s_m) W diag(r_m)`,

`F_(m,v,e)=reshape[tanh(A_m z_(v,u))]`.

Output scaling is before tanh. It is not generally `S*tanh(Wz)`. No private bias, stem, feature transform or classifier is installed. The input factor can be described as a feature-coordinate change **inside the map generator**, but it does not apply that same change to the native propagated feature path. Folding A_m into a separate incidence W_m is BatchEnsemble algebra; it does not make the learned graph operator invariant.

The original general builder computes node degree blocks and signed paired cross blocks,

`D_(m,v)=sum_(e incident v) F_(m,v,e)^T F_(m,v,e)`,

`C_(m,v,u)=−F_(m,v,e)^T F_(m,u,e)`.

At evaluation its augmented inverse square root uses D_v+I. Training adds the original shared-over-nodes, coordinatewise random diagonal jitter before the SVD power. The original relative singular-value cutoff, entry clamp to [−1,1], reverse-incidence pairing and sparse assembly all matter. There are no LP/HP added dimensions in this prepared scope.

Let L_m denote the **actual normalized, clamped, assembled operator**. The `.L` field set on the sheaf learner stores the detached *unnormalized paired cross products*, not this deployed L_m. A comparison of that cache alone can miss degree normalization and diagonal action.

At evaluation, the actual layer has the form

`H_(m,l+1)=Ω_l H_(m,l)−ELU[L_m(H_(m,l)) T_l(H_(m,l))]`,

where `T_l(H)=A_l H B_l^T` is the shared left/right feature transform and `Ω_l=diag(1+tanh epsilon_l)` is the shared residual multiplier. The sparse message includes diagonal blocks as well as neighbor blocks despite an adjacent source comment mentioning adjacency. The shared biased linear head then produces native log probabilities.

## Gauge scope and the complete network

An edge-stalk orthogonal change F_(v,e)'=O_e F_(v,e), applied to both incidences of each edge, leaves degree and paired Gram blocks exactly unchanged. The bank directly represents the narrower layerwise diagonal-row-sign case through s and tanh oddness. Its finite diagonal scales do not generally represent arbitrary O_e or arbitrary node-specific frame fields.

A node frame change is different. In a Euclidean unclamped evaluation construction, maps `F_(v,e)'=O_e F_(v,e) Q_v^T` would give a block conjugacy `L'=Q L Q^T` when inverse-square-root semantics are compatible. The actual entry clamp need not commute with arbitrary rotations. Training coordinate jitter also needs the corresponding transformed realization. General GL(d) changes require transformed inner products/adjoints and cannot inherit an orthogonal claim.

Even an operator conjugacy does not imply an invariant deployed predictor while the shared feature transforms, residual scales, biased stem/head and ELU remain numerically fixed. For example, `ELU(−1)=exp(−1)−1` differs from `−ELU(1)=−1`; ELU is not sign/rotation equivariant. A fully compensated whole-model coordinate reparameterization must preserve the complete input/output function. The prepared bank does not install member-private compensation of those shared components.

Consequently a node-frame or flat-connection adapter can change and improve a prediction through feature alignment. Such usefulness does not establish irreducible relational geometry. The general tanh matrices may be singular, and their paired transpose products are not inverse-consistent orthogonal parallel transports. Raw matrix products are not certified holonomy. A different spectrum is an obstruction to operator conjugacy; equal spectra or equal probe norms are not a complete equivalence test.
