## What would justify going beyond this question

First require a complete competence-and-proper-risk gain over U and capable references; a GAT result alone is not cross-backbone success. A surviving recipe then takes an unchanged GCN/SAGE transfer and unused graph evidence priority over a new mechanism. A claim about shared ensembling additionally needs capable same-operation single/independent controls.

If competent routes still miss the **same** residual nodes that capable I4 misses, a genuinely different acquisition branch becomes relevant only when a declared changed-evidence predictor actually supplies correct, served decisions there without larger harms. That is the missing observation in the saved graph-supply assessment. If evidence instead shows shared updates erasing correct margins, a training-credit remedy needs that causal observation. If new correct alternatives exist but are lost in serving, acquisition is no longer the immediate deficit. None of these observations is supplied by the present aggregate outcomes; no new branch is specified or nominated now.
