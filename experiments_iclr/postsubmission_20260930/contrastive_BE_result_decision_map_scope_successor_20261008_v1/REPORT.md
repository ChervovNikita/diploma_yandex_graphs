## Direct12 primary counts

- **Pooled repairs/harms:** native wrong→fitted correct, and native correct→fitted wrong.
- **Coverage repairs/harms:** native no correct member→fitted at least one correct member, and the reverse.
- **Old-rival ordering:** one same fitted member strictly outranks every original native common wrong rival. A new rival can still defeat truth; this is not correctness.
- **Strict member repair:** an original all-member-wrong/common-rival node acquires an actually top1-correct fitted member. Record actual pooled repair separately.
- **New errors:** retain full-population fitted all-wrong/common-rival transitions. Losing an ordering reversal alone is not the harm definition.
