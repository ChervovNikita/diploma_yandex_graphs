# Analysis companion for the complete initializer study

Prepared on 2 October 2026 while all Squirrel continuations were complete and the first Photo continuation was running. Root had inspected completion/cost metadata and its update count, but no final-pool outcomes. This companion changes neither the registered study nor selection, pooling, checkpoints, labels or reporting admission. The study remains an exploratory, outcome-aware cfg0 screen.

## Purpose

The existing final report retains all arms, seed pairs and decision changes. This companion makes uncertainty and measured cohort costs visible. It runs only on the completed, separately admitted final report and all 72 completed supervision receipts. It never opens labels, checkpoints or logit arrays.

The primary endpoint remains pooled raw-logit NLL. For each of the two graph/backbone settings, compare graph initialization with each of the four controls using the three registered paired seed/split contexts. Preserve every difference. Report the paired mean, range, sample standard deviation and a 95% paired t interval with two degrees of freedom. The interval assumes independent, approximately normal context differences conditional on this setting. With three contexts it is imprecise; shared nodes and coupled seed/split variation limit its interpretation. It is not a confidence interval over new graphs.

Also give a two-sided sign-test reference p value under independent symmetric signs, with zeros excluded, and Holm correction across all eight primary graph/control contrasts. This is not a randomized causal test. With three nonzero pairs, the smallest two-sided p value is .25; this cohort cannot establish significance through this test. Accuracy receives the same paired summaries as a secondary descriptive endpoint, without a separate significance claim. Do not pool settings into a fictitious six-graph sample or bootstrap correlated test nodes as independent observations.

The source-specific contracts govern interpretation: comparisons identify the complete safeguarded initialization operations, including accepted step sizes and fallbacks. They do not isolate graph-band orientation or prove spectral specialization. Warm, initialized, native midpoint and selected diagnostics remain as originally saved; no terminal checkpoint or outcome-selected timepoint is added.

## Costs

Sum each of the 72 outer completed-phase supervision durations once. Report the shared qualification/warm cost and each arm's initialization/continuation cost. A standalone per-arm replay account charges its setting's shared qualification/warm cost plus that arm's initialization/continuation. These overlapping standalone accounts must not be summed as actual cohort expenditure. Data acquisition, environment/deployment work, earlier failed studies and final scoring are outside this narrow counter and require separate disclosure. No runtime, memory or latency advantage follows from parameter storage.

## Use

After genuine cohort closure and the existing separate final-report admission:

```sh
python analyze_complete_report.py \
  --report /absolute/project/path/to/report/FINAL_REPORT.json \
  --coordinator-run /absolute/project/path/to/coordinator_run_v3 \
  --output /absolute/project/path/to/new_analysis_directory
```

The output directory must be new. The reader checks exact settings, seeds, arms, all 30 report rows, all 24 paired contrasts, 72 completion receipts and their phase-terminal hashes. It fails rather than dropping an incomplete or unfavorable cell. Selected tensor/source integrity remains the responsibility of the original admitted reporter. This source has not been executed on scientific outcomes.
