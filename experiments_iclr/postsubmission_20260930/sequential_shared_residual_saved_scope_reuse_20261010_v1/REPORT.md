## What preservation requires

For an earlier route `z_j(theta, phi_j)`, freezing its private parameters
`phi_j` leaves the common parameter displacement free to change its output
through `J_theta z_j`. Exact preservation of its deterministic function requires
freezing the relevant common weights or a separately specified exact functional
preservation rule. Sequential updates of private blocks with live common
weights are coupled learning, rather than automatically frozen-stage boosting.
Recomputed residual targets do not remove that distinction. Fully corrective
boosting deliberately revisits earlier learners and has established ancestry.

When common weights and old routes are frozen, a new private correction can
still change its own upstream nonlinear graph computation if its architecture
permits it. That is broader than a final head refit. It cannot recover a
label-relevant distinction absent from all its retained inputs. Supplying raw
features or new graph context changes that information boundary and requires
same-information capable single controls.

## Common false rivals and the serving rule

A common strict wrong rival among unchanged probability members cannot be
repaired by a convex pool of those unchanged members. Residual training can
escape that obstruction only by changing the learned evidence or prediction
functions. Preserving earlier routes does not itself create a repair.

For one newly fitted member and preserved members `j`, a uniform probability
pool can rank truth `y` above a particular rival `r` only if

`p_new(y) - p_new(r) > sum_j [p_j(r) - p_j(y)]`.

This is direct score arithmetic. A new member has a probability margin at most
one, so it cannot offset an arbitrarily large accumulated wrong margin from
the preserved members. All rival classes must be beaten for a correct decision;
an error targeted on TRAIN can still introduce more harms elsewhere. There is
no guarantee from residual targeting, own CE anchoring, or a diversity metric.

An additive logit correction instead needs

`alpha * [h(y) - h(r)] > F_old(r) - F_old(y)`.

Its correction is not restricted to a probability simplex, so the original
unchanged probability pool obstruction does not bound that new score function.
This changes the serving rule and directly collides with functional boosting.
It establishes a representational opportunity, without showing that the learner
fits the necessary margins or generalizes. A capable single can implement an
additive correction too.

For the fixed mean probability CE objective, the active route gradient is its
own CE logit gradient multiplied by `p_m(y) / sum_j p_j(y)`. Calling this factor
a residual responsibility does not create a new objective. The saved staged
pool Brier rule likewise uses the ordinary pullback of a probability residual.
