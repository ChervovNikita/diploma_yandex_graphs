## Exact reference and required verification

The private native adapter loads the pinned `model.py`/`utils.py` only for root's later engineering checks. It cannot replace portable code or confer runtime compatibility through source availability. The mandatory one-member unit-factor check copies every corresponding native encoder/decoder value, including unused ptlin and fixed buffers. It compares eval and training-mode raw logits, feature gradients and every corresponding native parameter gradient, with identical reset RNG. It also compares sparse common/exclusive candidate sets against the portable enumeration. Independent explicit-set and affine oracles avoid relying solely on two similarly structured implementations.

The native single model has no pooling step. Equality for the four-identical-member evaluation limit separately checks the private/pool switch. Member permutation simultaneously permutes all private factors, normalization affine parameters and beta, while shared maps stay fixed. A weight-only permutation can change the score and is not an invariance. No best association or permutation is selected.
