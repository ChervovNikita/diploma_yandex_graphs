## Corrections

- Boundary hooks now compute the declared
  `S * native_affine(R * x) + delta_bias`. The former added
  `native_bias * (1 - S)`, which implemented a different bias law. Native
  modules and W/b Parameters remain the original objects.
- NCNC's original `multidomainforward` dispatch is wrapped only for the three
  boundary procedures, using a depth counter. Its unchanged method body and
  original `forward` recursion still execute. At task depth one, the final
  affine receives factors; at recursive depth greater than one, both final
  pre/post hooks pass through the original input/output. Grad-enabled status
  does not determine scope, so the same rule holds during no-grad VALID.
- Actual dispatch and final-affine counters are retained per route in
  `work.NCNC_output_routing`. Every successful callback verifies one applied
  final task affine per top-level dispatch, one unmodified final affine per
  recursive dispatch, and zero recursive factor applications or outside-scope
  calls. Counters are preserved by session save/load.
- All native/wrapper sessions now include verified adapter byte/SHA256 receipts
  in `source_metadata`, including the frozen manifest receipt. This also
  covers each native member used by the parent's independent bank.
