# Native author-source snapshots

These are byte-identical copies of the locally audited, saved author source texts. MANIFEST.json records every original path, fresh path, byte count, SHA256, and the four entrypoint mappings.

NCN and BUDDY retain their saved artifact filename prefixes. This snapshot is source evidence, not a reconstructed runnable upstream repository or qualified provider. Data, tensors, model states and caches are absent. No imports, fits, scores, remote actions or historical-source edits occurred.
