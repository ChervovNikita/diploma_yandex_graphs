# Conditional remedy, declared before the count readout

No resident result has been read in this preparation. There is no present finding of lost alternatives and no admitted remedy experiment.

## What would be a distinct failure symptom

Nonzero wrong-pool/any-correct-member events show that an existing correct decision was available and lost by factual pooling on those events. This differs from all-members-wrong events. Three-correct-member/wrong-pool events give a narrower symptom: native probability averaging discarded a correct hard majority. The probability magnitudes can explain such a reversal algebraically, but this count alone does not establish a calibration defect, its training cause, practical recoverability, or an effect of parameter sharing.

The competing evidence is reported simultaneously: correct-pool events with only one correct member show useful pooling despite an incorrect hard majority. One- and two-correct-member lost alternatives generally need more information than majority voting. Role3's stronger average member F1 is not proof of any of these cohorts. All comparisons retain source selection/provider differences, and the missing untied same-J comparator continues to block a causal sharing claim.

## Exactly one prospectively fixed remedy to consider

If the narrower three-correct-member symptom exists, consider a separately frozen comparison of **hard majority decisions, with two–two ties retaining the original uniform-probability-pool decision**. Use each original member's native strict >0.5 binary decision, no learned weights, confidence threshold, calibration fit, source assignment, label-specific choice or favourable-role choice. Apply the same fixed rule to every predeclared shared and independent committee. This packet does not produce a majority prediction or evaluate its score.

This rule can repair discarded correct majorities and can harm correct pools supported by only one correct member. It does not solve missing alternatives or arbitrary minority-correct events. A later release would need the actual member decisions through an explicitly approved route; correctness masks are truth-dependent diagnostics and are not a deployable router. The present readout does not authorize opening targets, reconstructing probabilities from observed-event probabilities, running forwards or using any extra fields to evaluate the rule.

Any later comparison must freeze whole-cohort quality, all-role signs, capable controls and cost requirements before new quality-score calculations, and retain the unchanged original scores as historical records. Hard voting is a decision rule; retaining the original probability pool for proper-risk reporting cannot be presented as improved probability quality. Binary repair-minus-harm totals alone cannot establish a micro-F1 gain because they omit positive/negative TP/FP/FN structure. This is consumed-development evidence, not unused confirmation, and no count threshold here automatically advances the rule.
