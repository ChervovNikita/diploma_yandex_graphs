
## What ordinary Adam actually does

WriteR=r^c/c andS=c*s^c. Moment transport is

```
m_r^c=m_R/c, v_r^c=v_R/c^2;
m_s^c=c*m_S, v_s^c=c^2*v_S.
```

With the **same native learning rateeta andepsilon** in the scaled coordinates, the exact unit-coordinate rule is

```
R+ = R - (eta/c) * mhat_R / (sqrt(vhat_R)+c*epsilon),
S+ = S - (eta*c) * mhat_S / (sqrt(vhat_S)+epsilon/c).
```

This identity applies throughout matched trajectories with transported histories and fixedc; it is not just a first-step sign observation. Shared parameters retain ordinary Adam at mapped states. Eachr/s parameter is a matrix of members, so the equivalence is tensor-row rates/epsilon, not necessarily literal separate PyTorch parameter groups. An explicit unit-coordinate row-rate implementation is the same algorithm and must not be fitted as a distinct scientific competitor.

At zero epsilon, private absolute steps in scaled coordinates are the same as unit Adam, but relative steps differ. At the unit effective start, to first order,

```
DeltaA_c = -eta*[d_W + c*diag(d_s)W + (1/c)*Wdiag(d_r)] + O(eta^2),
```

where d are unit-coordinate bias-corrected Adam directions. With nonzero nativeepsilon, use the adjusted denominators above. SGD instead induces input/output rateseta/c^2 andeta*c^2. No prediction/competence conclusion follows from these different effective updates.

A **gauge-equivalent** Adam preserving the ordinary unit trajectory would use, in scaled coordinates,

```
r: learning ratec*eta, epsilonepsilon/c;
s: learning rateeta/c, epsilonc*epsilon,
```

with the stated moment transport, equal clocks and shared histories. This is an algebraic duplicate of unit training, not another performance arm. Retraction/canonicalization, untransported moments, extra decay or clipping would implement different optimizers.
