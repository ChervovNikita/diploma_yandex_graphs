A pass would establish useful **shared allocation at the tested graph/recipe**: one common competent source plus private memory routes can beat capable same-information singles and genuinely equipped independent banks while retaining required competence. Full-population `correct=C−L+A` and paired repairs−harms should show whether the benefit comes from acquired correct alternatives, their retention or aggregation-only corrections. Parameter counts, surrogate diversity and a favorable hard cohort cannot replace those outcomes.

The cheap singles sharpen the conclusion. If G1/GF1 or S64/FS64 improves over the source while the private candidate fails its conjunction, retain general memory augmentation only. If the candidate also passes against those singles, the allocation package earns its incremental practical comparison. Existing independent references remain mandatory; an attractive single contrast cannot waive them.

## What stays unattributed after a win

**GM4 versus GF1** changes private gate/bias capacity and optimization as well as route-conditioned adaptation. Both already see all four tours. It does not isolate topology, long-range history or previous-state gating as the cause. The separately recorded CT4/PO4 policy remains outside the current roster; this memo adds no controls or fits.

**LM4 versus S64** changes per-group read normalization, separate prediction paths and the supervised objective together. S64's joint read is a partition-function-weighted mixture of group reads; LM4 retains four logits and averages their softmax. T16 additionally changes offset tying/parameterization. These comparisons support the specific allocation package, not private addressing alone. An ordinary grouped-attention network with the same tying, losses and outputs is exactly LM4 and would reproduce the result; fitting that renamed graph would provide no independent attribution.

A useful structural allocation contribution is therefore possible even though established architectures explain the computation. A new-method/firstness claim, isolated mechanism claim, universal transfer claim, speed claim or acceptance verdict would require additional evidence appropriate to that claim. No such conclusion or experimental grid is proposed here.
