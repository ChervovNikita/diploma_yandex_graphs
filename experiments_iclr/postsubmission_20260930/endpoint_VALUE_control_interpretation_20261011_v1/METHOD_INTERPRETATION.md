# What the endpoint control can establish

This is an interpretation of the prospective native SAGE operator, not an experimental result or a new theorem claim. Its edge-conditioned-message ancestry is recorded in the source assessment. The full model still has shared slow weights, member factors, ordinary member cross-entropy and probability averaging.

## Actual prediction change

Each member forms a small matrix from the live source and receiver states of an edge. That matrix mixes four groups of source features before native SAGE averages its incoming messages. The native graph, root contribution, subsequent maps and final pooling remain fixed by the protocol. The added generator weights are shared; member factors modulate those generators. No output router selects one member.

The receiver control uses the same generator dimensions and parameter count, with receiver features and their nonlinear transform as its inputs. It therefore supplies a competent context-dependent transformation without access to the individual source state at that generator. The baseline, equipped single and equipped independent ensemble separate added capacity, ensemble utility and sharing from the endpoint comparison.

## Why the location is meaningful

For a fixed receiver and nonself neighbours, a receiver-only linear map can be moved through the native mean:

`mean_u[T_v h_u] = T_v mean_u[h_u]`.

The protocol leaves actual self messages unchanged. If a self edge exists, its original contribution is handled separately; the equality above concerns the nonself contribution. This is an identity at fixed hidden states. It is not an equivalence of complete trained procedures with different upstream representations.

An endpoint-dependent map generally requires more information than that same mean. A simple algebraic example lies inside the proposed operator class. Keep the receiver state zero and let only one source coordinate be nonzero. Set the target generator to zero and one source-generator entry to `k a`, where `a` is that source coordinate and `k>0`. With the fixed four-dimensional block, its transformed coordinate is

`a + 0.5 a tanh(k a)`.

Two neighbours with coordinates `-1,+1` and two neighbours with coordinates `0,0` both have native mean zero. Their transformed means are respectively `0.5 tanh(k)` and zero. A receiver-only matrix acting on the zero mean cannot make this distinction at that stage. This example is an algebraic illustration, not a dataset, training run, measured improvement or causal explanation of the recorded errors.

This observation does not establish greater expressivity than every GNN. Earlier nonlinear layers can encode useful neighbour statistics; standard edge-conditioned models already motivate source-dependent messages. It also proves no increase beyond the relevant graph-isomorphism limitations. The useful empirical question is whether this particular shared, member-modulated placement improves predictions against the complete declared controls.

## Initialization and forward bound

Both added affine generators start at zero, so their incidence matrices and transport start at identity. Existing native parameter objects and random streams are preserved. The added fast factors begin at one; their gradients can be zero on the first update while the generator weight is zero. The full-input qualifier checks that their learning path becomes active after a discarded update. That check supplies implementation evidence only.

For block dimension `d`, each incidence matrix is `I + tanh(A)/sqrt(d)`. The entrywise bound on tanh gives an operator-norm bound of `1+sqrt(d)` for each incidence matrix, and `(1+sqrt(d))^2` for their product. Here `d=4`, so each transported feature block has amplification at most nine relative to its source block. Repeating the same matrix across feature blocks does not enlarge that spectral bound. The unchanged self message also satisfies it.

This bounds the added forward map. It does not guarantee invertibility, global network stability, bounded derivatives of the context-dependent operation, calibration or accuracy. Native weights and the complete learned prediction still determine those outcomes.

It would not identify a same-checkpoint causal intervention or establish a new edge-conditioning primitive. The candidate must also improve the unchanged shared bank and the equipped genuine independent ensemble; a stronger equipped single limits an ensemble-specific claim.

Report newly acquired and removed correct alternatives, which survive averaging, introduced errors, confidence and actual costs.
