# One source epoch1 admission proposal

**Do not execute this prepared program until the root has read and independently
admitted its exact source, case and owner budgets.** The release template is
explicitly disabled. No scientific GO or automatic queue is made here.

The program imports the exact retained LinkPrototype helper bytes and reviewed
`replay_qualification.full_batch`/`replay_provider` sources. It decodes only the
prepared factory GRAPH/TRAIN tensors; it does not read SELECT, CAL or EVALUATE
files, construct a model or optimizer, or fit/score anything. CUDA device0 is
bound to the one-GPU allocation before source operations. Source factory flags,
interpreter bytes and numerical dependency/version identities must be supplied
from the actual root-reviewed runtime; the program does not invent them or
change the factory flags. The proposed stream key contains the actual runtime
and entire bound source/input/geometry identities.

The fixed source helper produces one epoch1 authority under source master

compares the full permutation, full returned negative draw, dropped tail and
all17complete native graph/query/support/coordinate contexts. The original

and102positive/negative support enumerations, not32epochs or an autoqueue.
The unchanged source provider's RNG isolation surrounds that proof; pre/post
complete RNG digests must match. Model and optimizer constructors are actively
denied inside the child process. Two prospective proof-only consumer leases
bind the exact same immutable shared fixture manifest; the second read cannot
call the source producer. This fixture is not a scientific replay-store donor.

monotonic bounds or an ETA. Root supervision must identify the exact owner
PID/startticks and descendants, monitor normal host RSS/CUDA/time/bytes, retain
all failures and close the exact child after termination. Preserve the existing

insufficient or source geometry cannot fit the ceiling, leave the proposal
unexecuted and continue other preparation. Do not resize/kill/modify Physics or
other users' jobs. No mount, filesystem namespace or host setting changes.

Remaining root bindings include the actual factory runtime profile/version/
binary pins, frozen adapter/bridge/common/shared-store source pins, exact output
and supervisor authorization, registered forbidden target paths, exact fixture
consumer labels and accepted resource ceilings. The template documents missing
bindings and will fail rather than treating them as inherited authority.
