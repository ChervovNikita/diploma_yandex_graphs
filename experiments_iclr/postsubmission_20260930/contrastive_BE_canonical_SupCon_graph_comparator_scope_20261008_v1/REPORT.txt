## Actual current operation

The unchanged WikiCS predictor uses the complete 11,701-node graph and all 580
TRAIN labels in ordinary own cross-entropy. Its auxiliary alignment uses a
fixed 512-node panel selected by the original linspace operator/order, with
CPU/device identity verification. Thus complete task training does not mean
that every TRAIN node is an auxiliary anchor. Preserve this distinction.

Frozen graph signatures [X, X-PX, PX, P^2X] use directed destination-row
aggregation through deduplicated A+I, exactly one self-loop per node. Each
route selects up to 16 other same-class TRAIN nodes plus self on all 580 rows;
restriction to the512-node panel is followed by row normalization. Q_m is
fixed, nonnegative, row stochastic and external to differentiation. Same-class
nodes omitted by a route remain denominator distractors. These signatures
prepare targets; they do not replace the native predictor graph.

The objective is mean-member two-view own CE + 0.05 alignment, temperature 0.2.
The actual contrastive representation is the active task head's input. There
is no extra projector. The auxiliary reaches all upstream shared/private
predictor paths, including trainable stem factors. The captured active task
head receives own-CE gradients only. Both stochastic views are differentiated;
one joint scalar update preserves the existing recipient policy.

## Exact numerator and denominator

Let M be the number of routes, B=512 the auxiliary nodes, a_mi and b_mj the
normalized representations from the two views, and
S_mij = a_mi dot b_mj / tau. Let n_c count class-c nodes in this same panel.

Operation                     Positive target                  Denominator per anchor
----------------------------  -------------------------------  --------------------------
Current route alignment        frozen Q_mij, restricted        B opposite-view nodes,
                               same-class support + counterpart including own counterpart
Class-full cross-view control  1/n_c on every opposite-view    B opposite-view nodes
                               same-class node,0 otherwise
Canonical SupCon Eq2           1/(2 n_c-1) on every same-label  2B-1 nodes across both
adaptation                     view except exact anchor        views, excluding only self

Current symmetric loss, with row softmax and identical Q in both directions:

C_Q = -(1/(2MB)) sum_(m,i,j) Q_mij [log softmax(S_m)_ij
                                  + log softmax(S_m^T)_ij].

Only the scores transpose when switching views. The source does not transpose
Q. Both anchor directions still mean the directed identity relation i->j.
For uniform class-full Q, this is the BotSCL Eq13–14 loss operation in the
saved PDF4–5 scope. It is not the full original BotSCL recipe: that recipe also
uses class-aware feature swaps, edge removal, a two-MLP projector, contrastive
first-stage training, and a later class-weighted LR on concatenated features.

For canonical Eq2, concatenate z_m=[a_m;b_m], K=2B, let
s_mkt = z_mk dot z_mt/tau, A(k)={all K positions except k}, and
P(k)={t in A(k): label_t=label_k}. Then

L_SupCon = -(1/(MK)) sum_(m,k) (1/|P(k)|) sum_(t in P(k))
           log[exp(s_mkt)/sum_(u in A(k)) exp(s_mku)].

The positive average is OUTSIDE the logarithm. Each positive has its own log
ratio with the common denominator. An implementation that logs a sum/average
of positive exponentials implements Eq3, not Eq2. SupCon's original framework
adds a discarded projection network and later fits a classifier on frozen
encoder representations. The proposed joint-CE native-BE control is therefore
a canonical Eq2 adaptation, not a complete original SupCon reproduction.

For the class-full cross-view control, all target mass is in the other view.
For canonical Eq2 the same-view mass is (n_c-1)/(2n_c-1), and opposite-view mass
is n_c/(2n_c-1). The own counterpart remains positive. Canonical SupCon changes
the target weights of existing cross-view positives and adds same-view
positives as well as same-view negatives; it is more than a negative-count
change. For a singleton class in the panel, the counterpart is still its one
positive. At B=512, the canonical denominator has 1023 entries.

## Exact gradient differences

Suppress m. Let P_ab=rowsoftmax(S), P_ba=rowsoftmax(S^T). Since rows of Q have
mass 1, the current loss's derivative with respect to one scaled cross-view
score is

dC_Q/dS_ij = [P_ab,ij-Q_ij + P_ba,ji-Q_ji]/(2MB).

The candidate role carries Q_ji, so directed targets contribute Q+Q^T through
the shared pair score. This does not change the source's use of the same Q
for both anchor directions. A same-class node with Q_ij=0 has a positive
softmax contribution in row i; selection does not remove it from the
denominator. The upstream a_i gradient is the sum of these pair derivatives
times b_j/tau; b_j receives the corresponding candidate and reverse-anchor
contributions. Q has no gradient.

For canonical Eq2, let R_kt be the softmax over A(k) and U_kt=1/|P(k)| for
positives,0 for other allowed candidates. Treating directed score entries as
independent,

dL/ds_kt = (R_kt-U_kt)/(2MB), k!=t.

Because both score occurrences depend on the same normalized representations,

dL/dz_k = (1/(2MB tau)) sum_(t!=k)
          [(R_kt-U_kt)+(R_tk-U_tk)] z_t.

There are same-view anchor/candidate terms absent from cross-view alignment.
The exact-anchor diagonal has neither softmax nor target contribution. Eq3
would replace fixed U_kt by the within-positive softmax
1[t in P(k)] exp(s_kt)/sum_(p in P(k)) exp(s_kp), which makes positive target
weights depend on current scores. This is another reason not to substitute it.

Above the normalization epsilon, dL/dh_k =
(I-z_k z_k^T)(dL/dz_k)/||h_k||. Preserve the actual F.normalize epsilon/floor;
below that floor the normalization Jacobian differs. The coefficient 0.05
multiplies these auxiliary gradients; native own-CE gradients are then added.
Changing the loss supplies no new head/stem recipient restrictions or claim
that routes become independent.

## Stable implementation guidance, not executed source

Use [M,2B,D] representations and one loss averaged across M times2B anchors:

    z = cat([normalize(a), normalize(b)], dim=1)
    raw = z @ z.transpose(-1,-2) / 0.2
    self_mask = eye(2*B, dtype=bool)
    y = labels.repeat(2)
    positive = (y[:,None] == y[None,:]) & ~self_mask
    log_den = logsumexp(raw.masked_fill(self_mask,-inf), dim=-1)
    loss = mean(log_den - (raw * positive_float).sum(-1)
                         / positive.sum(-1))

Use finite raw scores in the positive multiplication. Multiplying a masked
-inf score by zero can produce NaN. Preserve both view gradients, normalize
per anchor, retain lambda 0.05/tau 0.2, and contrast within each route only.
The paper's written sum over anchors must be rescaled to a mean in this native
objective or the auxiliary coefficient would silently change by 2B.

For guidance only, a Q-preserving two-view extension could use
U_((v,i),(w,j)) = Q_ij *1[(v,i)!=(w,j)]/(2-Q_ii).
It reduces to uniform canonical targets for class-full Q, but restricted Q
produces context-weighted SupCon-style support, not canonical SupCon. It is
not an additional recommended arm.

## Cost interpretation

Both losses represent the same two views times four members: eight distinct
member/view evaluations. The active VJP implementation executes eight no-grad
shadow forwards plus eight differentiated replay forwards per training update
(16 executed member forwards), eight member VJPs and one shared Adam update.
SupCon needs no additional backbone pass relative to that path. For the same
M4/B=512 float32 score storage, cross-view M*B^2 is 1,048,576 entries (4 MiB);
canonical M*(2B)^2 is 4,194,304 entries (16 MiB), before other buffers/backward.
This is four times the score storage, not a fourfold backbone cost estimate.
Wall time, peaks, target preparation and retrieval/storage need actual
measurement. A declared all 580-auxiliary alternative would use 1159 candidates
and 5,382,400 scores (about 20.53 MiB); it is outside this matched proposal.
