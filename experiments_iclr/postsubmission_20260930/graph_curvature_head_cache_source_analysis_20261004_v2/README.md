# Frozen final-head cache: source assessment v2

V2 preserves v1 and changes only the context-query API in the candidate. The intended one-GPU runtime is Torch 2.1.2. It explicitly binds `is_inference_mode_enabled()`, CUDA `is_autocast_enabled()` and CPU `is_autocast_cpu_enabled()`, checks that each query is callable, and calls each without arguments. Missing queries raise a named error. Ordinary no-inference/no-autocast semantics and all cache/selector/trial computations remain unchanged. There is no API fallback or generalized compatibility layer. `DIFF_V1_V2.patch` is the complete candidate source diff.

Status: SOURCE ONLY; candidate unexecuted and unqualified. This directory changes no existing package and supplies no execution release. Only source text was read. No numerical library, array, checkpoint, server, score or manuscript was opened or executed.

The opportunity is present. `selector.py:101–110` reconstructs the frozen replacement dictionary and calls the entire K1 boundary wrapper on every `logits_fn(theta)` call. It does not cache a hidden state. Freezing parameters prevents their derivatives; it does not skip their forward operations. `initial_metrics:208–209` calls that closure for four antithetic member slices and again for the center. `match_pair:239–256` repeats all five at the cap and every bisection midpoint. If all nine slots reach measurement, the single reference plus eight matched slots can require `5 * (1 + 8 * (1 + B)) = 45 + 40B` complete K1 forwards, where B is the frozen bisection limit. This is a source call-count bound, not measured time or a claim about the current run's completed slots.

The common-only initializer also invokes the closure for one VJP primal and four forwards per common line-search attempt. Each graph/permuted bank creates one further VJP primal; its retained pullback services five cotangents without a separate primal for each cotangent. Actual-head qualification invokes one VJP primal, three JVPs and twelve finite-difference forwards; affinity adds three forwards. Those closure calls all enter the complete wrapper. Full native/K1/K4 identity and live-factor/Adam checks serve separate purposes and remain full-model checks.

Photo caching before `global_attn` would still repeat the global body. Neither cache point is at logits, before a nonlinear final body, or at a local Photo head. Eval must apply to every module and Photo `_global` must be True, as in the original binder. The source has no path from the replaced final `R` into either cached input P.

With that frozen P, the head Jacobian is independent of theta. In real arithmetic its JVP is `linear(P * d, W) * S[0]` and its VJP is the column sum of `P * ((cotangent * S[0]) @ W)`. These expressions explain why detaching P preserves derivatives **with respect to the final R**. The candidate deliberately calls the original `BoundaryProjector.forward` rather than substituting either analytic formula, folding S into W, omitting B, precomputing a dense Jacobian or reconstructing an affine response. Native multiply/linear/multiply/add order and the original stack/index operation remain present.

`cached_head_candidate.py` is a small, opt-in binder. It requires exact executed-source markers for the original selector and boundary APIs, reuses the original identity/eval/K1/final-stage guards, temporarily captures the final head's input through one call of the **original frozen closure**, removes the hook in `finally`, and copies the exact final head parameter state seen during that call. The capture uses ordinary `no_grad`, never inference tensors. Subsequent calls use a private copy of the unchanged final projector with only its R replacement connected to theta. They return `[N,C]` in the same native dtype/device, retain strict parameter/buffer inventory and do not mutate the donor. The cached hidden state is private, scoped to one fixed binding and never saved or shared across endpoints.

The cache size is N*H elements (source dimensions imply 2,276,352 bytes for Squirrel and 15,667,200 for Photo at FP32). These are shape calculations, not measured storage or peak memory. Cache construction and retained state must be charged. Upstream frozen replacement tensors can be released after capture; ordinary caller K1/K4/native copies and full trial peaks still exist.

The optimization applies only to head-only common descent, construction, scalar matching and their head interface checks. `one_adam_trial:298–335` must continue cloning the entire K4 model/optimizer, doing its own full member forward, differentiating all live shared/private parameters, stepping coupled Adam, and doing a fresh full post-step forward. Detaching that trial's prehead would remove shared/stem/body gradients. A pre-step cache is stale after Adam, even though eval disables dropout. Native warm acquisition, identity/optimizer qualification, returned arm state, native training mode, validation selection and continuation in the bound integration source must keep their existing full paths.
