# Fixed complete-graph predictive family, source v1

This packet implements a prospective comparison on the complete Reddit2 and
ogbn-products graphs. It contains no dataset, numerical result, fitted model or
scientific admission. It has never been executed on Torch, CUDA or a remote host
by its author. The five arms and seeds 0–2 give exactly 30 fits of 100 epochs.
The root coordinator must first qualify the complete inputs, source, execution
equivalence and expanded resource forecast. Missing evidence closes launch.

## Model and selection

The source recipe is fixed in `contract.RECIPE`. Every fit creates fresh source
parameters and a fresh AdamW optimizer. Candidate, detached, exact and naive
arms have paired initial parameters, member dropout and color streams. BASE has
the literal source single model initialization. No fit resumes, tunes, shortens
its epochs or replaces a graph. Native controls receive no unrelated CSR GPU
storage.

Each epoch uses all official training labels and one complete-node validation
forward. Serial paths stream member logits once: copy official validation
slices before in-place raw-logit pooling. Packed paths similarly use one
forward. CPU metrics, slice copies and serialization are timed and charged.
Store all 100 checkpoints with canonical and training-layout parameters,
optimizer moments, Torch RNG states, complete PCG64 color schedule/state and
dropout key. Store validation-only member and exact pooled logits for all 100
epochs. No full-node logits are persisted each epoch.

Select lowest complete pooled validation CE, with earliest epoch on exact tie.
A separate replay verifies all 100 stored metrics, then recomputes the selected
and epoch100 validation forwards through the already frozen deployment path.
The selected member has lowest own-member validation CE at that pooled
checkpoint; the smallest member index breaks ties. Replays store validation
slices only. All30 fits and replays, initializations, checkpoints, member
selectors and execution paths must pass audit before the pretest family lock.

The final evaluator uses each selected cell's official test targets once for
quality metrics and persists one test-slice member/pooled logit artifact. It
reports every outcome and every fixed gate. A failed or ambiguous gate rejects
promotion. It cannot establish originality, generalization across graphs or
conference acceptance.

## Execution and resources

All raw timings call the sealed `pooled_inference` helper unchanged. For each
task/seed, all five selected deployment arms are resident for 10 warmup and 50
timed rounds in paired shuffled arm order. The outcome-independent PCG64 order
seed is 20260930+50000+1000*task_index+optimizer_seed. Root must qualify this
complete resident family's memory either by a conservative sum of individual
peaks or by actual complete-family residency measurement. Summed ephemeral
activation peaks need not be treated as a necessary condition when the actual
resident family qualifies. The runtime still enforces60GiB reserved memory.

Propagation instrumentation is installed only in a separate 10+50-forward
phase with paired shuffled arm order from independent seed offset 60000. The
shared semantic scope is normalized states to unparameterized
neighbor aggregates, before learned SAGE maps. Candidate includes centering
and combining. Native PyG propagation hooks include gathering and mean
aggregation; CSR serial paths time full or naive aggregates. Summed CUDA events
measure this component; synchronized full-forward wall time remains the raw
latency measure. Unavailable hooks or missing layer/member events fail the
evaluation. The CSR operation ledger does not count native gather/scatter work;
native executed aggregation counts are reported by hooks, never asserted zero.

The final evaluator also records cold prediction, individual memory, graph
payload, full input replay/H2D/setup, actual supervised complete fit wall and a
separate complete-node candidate contrast trace. Test labels do not enter that
trace. Paired intervals use three optimizer seeds per fixed graph, never
independent-node or graph-population inference. Exact's validation-chosen member
is the common comparator for half-gain retention; candidate's own chosen-member
positive gain is assessed separately.

Preparation charges for the fit-cost gate are arm-specific and frozen from
root-qualified measured or conservative attributable costs. Exact must not be
charged candidate-only color-building overhead. The overall resource budget

Expanded forecast must include all artifact writes,100 metric replays per
