## The actual context9 rule

Each route has ordinary two-view own CE plus 0.05 symmetric cross-view target CE at temperature 0.2. Its frozen row-normalized Q_m uses same-class TRAIN neighbors selected from X, X−PX, PX orP²X, then restricted to the same deterministic auxiliary panel. The public graph supplies signatures; predictor topology/architecture is unchanged. Targets are not learned from model predictions or differentiated through.

The contrastive term averages log probabilities **outside** the positive sum. Candidates are the opposite-view panel. Unselected same-class nodes remain denominator distractors. Both directions reuse the same directed Q_m; only scores transpose, so the target-dependent symmetric difference sees(Q_m+Q_m^T)/2. Qbar is the exact route mean after the same restriction/normalization.

This is one scalar joint objective, with no stopped/shared-private recipient split. Context gradients reach all active shared/private parameters upstream of the captured head input. The active task classifier is downstream of that capture, so it receives own CE, not a direct context gradient. A statement that every trainable parameter receives the scalar objective does not imply every loss has a nonzero path to every parameter. Untied references receive their own unscaled CE+0.05 alignment. Serving is the original mean of four class probability vectors; there is no router, projection readout or inference adaptation.

## What a passing context9 would establish

Stage1 can support the narrow finding that persistently repartitioning the same aggregate target among shared routes is useful under this backbone/optimizer/selector, and that factual signature incidence helps relative to the chosen shuffled relation. It cannot establish a new loss, spectral/filter principle, information estimator, class-collapse cure or graph-topology cause; one route is feature-only and target entropy/support also differ.

Only complete prescribed Stage2 ordinary and regularizer-matched single/untied references can address practical benefit. SingleQbar matching favors ordinary representation regularization; untiedQ_m matching or winning removes an established quality benefit of sharing. Useful correct ranking acquisition and full-population net serving/risk—not hidden spread or favorable cohorts—remain decisive. An unused split/task with the same fixed candidate and competent controls is needed before a broad contribution claim.

The potentially useful result is **measured utility of persistent graph-context supervised target assignment through a shared fast-factor predictor**, with clear competence/complementarity and cost boundaries. The ingredients are inherited; whether the complete recipe is methodologically distinct remains unresolved even after a positive pilot.
