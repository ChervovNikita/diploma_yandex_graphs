# Ordered path operator and sampler preparation

**Preparation only.** This packet supplies a reusable operator, label-free sampler and native source factories. It has no provider, numerical imports, optimizer, trainer, selector, owner, launcher or admitted study. Root owns data custody, source/provider binding, actual qualification and the finite run roster. Current E/Penn sources and metrics were not opened or changed. Earlier inactive path memos remain preserved.

## The single operation

Reuse each native route's already computed nonlinear stem. Concatenate the four positions of each of eight frozen incoming three-edge walks, apply a shared 4h→h FactorLinear and GELU, average walks, then apply a shared h→h FactorLinear. Add this residual **before the original final normalization**. The original native graph modules and classifier remain. Both maps have common W/b and existing private r/s vectors; shared bias is outside s. The second W/b starts at zero. There is no extra loss, teacher, router or independent pretraining stage.

This is an attributed adaptation of PathMLP ordered concatenation/nonlinear path encoding and path aggregation, combined with native BatchEnsemble/TabM factors. The new question is observed utility of this integrated common training pathway under capable controls. Neither path aggregation nor sharing is a new primitive, and useful ensemble-specific learning remains a hypothesis. Initial zero-residual equality is not retained trained competence or accuracy evidence.

## Fixed sampler contract

`ordered_path_sampler.py::sample_walks` receives only a positive node count and plain Python integer `(source,target)` records from root's authorized public provider. It returns immutable `[N,8,4]` tuples, an immutable `[N,8]` Boolean swap mask, a digest and counters.

- Walk seed **11709**, eight walks per node, three incoming steps. Every draw is uniform over incoming **nonself edge records**, with replacement. Original duplicate-record multiplicity is preserved and lists are sorted by predecessor ID. This is uniform per step, not uniform over complete three-edge walks.
- Use the current node itself only when its incoming nonself list is empty. This is a walk-slot fallback; it does not insert any native propagation edge. Backtracking over actual nonself edges is permitted.
- Every arm/member reuses the same table. No feature similarity, labels, roles, predictions or fitted states select walks. Uniform incoming walks and fallback are explicit adaptations from PathMLP, not an author reproduction.
- A domain-separated local RNG produces one independent frozen Bernoulli intermediate-position swap per original tuple. Root and terminal remain fixed. Sampling/masking never change global training RNG.

The provider converts these immutable records to same-device int64 indices and Boolean mask. Before any numerical call, root must call `validate_walk_tensors` and bind the sampler digest to the exact full native row/edge custody. The helper checks shape, root identity and bounds; root binds edge support and record multiplicity. Forward shape/device checks are not that custody qualification.

## Dormant attribution switches

The same factory also supports `mode="marginal"` and `mode="order_breaking"`. They are source support for a **subsequent prospectively fixed triggered phase**, not a current additional fit roster and not substitutes for M1/I4/depth3 controls. No radius-two attribution source is added here.

Marginal mode averages identical tuple positions over walks before the same maps/GELU. Its parameters and tuple observations match, but it has fewer first-map evaluations. Order-breaking mode independently swaps the two intermediate positions using the frozen per-tuple mask during both training and serving. A fixed global swap would only reparameterize positions. The root/terminal and all tuple data remain, with native graph computation unchanged.

The order control scrambles consistent intermediate-position semantics, not every possible structural signal. Repeated IDs/features can make a swap ineffective; the fixed input may permit order recovery. The sampler reports ID-changing swaps, but that is not an estimate of feature-level intervention strength. Neither switch establishes a beyond-1-WL or motif representation claim.
