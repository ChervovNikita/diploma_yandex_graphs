## Scientific conclusion

The new reads establish several relevant operations: conditional sequence diffusion, shared latent community reconstruction, subgraph generation for training, score expert routing, and representation expert routing. They do not establish the complete frozen NCNC contract. The defensible candidate remains the task-specific placement of whole-pattern supervision on native record-masked TRAIN residual support, with its exact gradient and component serving association. The Bernoulli mixture likelihood itself already has GRAN ancestry in index_v40. A positive J-versus-F result would identify a difference between two supervised learning procedures; it would not by itself identify latent graph ambiguity, calibration, or a need for multiple retained hypotheses.

## Frozen objective and serving interpretation

Let `ell_mr = log Bern(Z_r; q_mr)` on the exact native ordered unilateral residual slots, with `R>0`. The frozen objectives are:

- `J = -log(mean_m exp(sum_r ell_mr))/R`.
- `F = -sum_r log(mean_m exp(ell_mr))/R`.

J has one training responsibility per member and complete query pattern, `rho_m = softmax_m(sum_r ell_mr)`. F has one responsibility per member and slot, `rho_mr = softmax_m(ell_mr)`. With native logit `t_mr`, their auxiliary derivatives are respectively `rho_m(q_mr-Z_r)/R` and `rho_mr(q_mr-Z_r)/R`. Thus the intervention is query-coherent versus slot-specific supervised assignment, as well as joint versus factorized observation likelihood. Empty support contributes zero. These expressions are an analytic reading of the frozen plan, not numerical or implementation verification.

The teacher supplies TRAIN observation membership `Z` only. Source zero means unobserved in supplied TRAIN, not a verified latent nonlink. The teacher is absent from model, head, and serving inputs. The frozen J/F serving route uses each head's own soft completion weights and raw-logit mean; it does not sample Bernoulli patterns or use teacher-conditioned responsibilities. Consequently an auxiliary-density gain and a predictive component-association gain are distinct claims.

## Three actionable controls, each with a falsifier

### 1. Test the count explanation first

Use the already prepared C64-D4 structured single on the same support and teacher contract. Its law is `pi_K exp(sum_r t_r Z_r)/e_K(exp(t))` over every count `K=0..R`; count context includes the frozen endpoint/neighborhood summaries. Report target ranking under the official complete VALID roles alongside observation-pattern likelihood and TRAIN mask diagnostics stratified by `R` and observed `K`. Density diagnostics must not become a selector or latent-graph ground truth.

**Falsifier:** if the qualified C64 single matches or exceeds J's target-ranking benefit under the declared comparison uncertainty, the interpretation that a gain requires several retained completion heads is falsified for that comparison. Count structure and shared context remain sufficient explanations. If J exceeds C64, this only leaves a gap: C64 is additive within a fixed count and is not a universal same-count pattern law.

### 2. Keep a capable shared-context single as the remaining scientific gap

If the count control leaves a J advantage, compare against one conditional pattern predictor that can express interactions among configurations with the same count. TGSBM verifies why conditional Bernoulli factorization does not rule out marginal dependence; SDG and FLEX verify alternative routes for coherent structural supervision. A prospective transport must use the same residual labels, available context, mask/support law, outer target decoder capacity, and supervision budget, with any latent integration/ELBO approximation and paid work disclosed. This is a scientific requirement for a stronger claim, not an already specified or authorized new run.

**Falsifier:** if such a capable single retains the target-ranking gain without distinct independently served completion heads, a claim that the useful information requires a retained multi-head hypothesis set is falsified. A positive J/F contrast can still be useful, but supports the particular supervised factorization/optimization choice rather than necessity of explicit head modes. Extra temporal/multilayer features or changed support would invalidate this control.

### 3. Separate learned pattern dependence from serving association

At the selected fixed banks, retain the frozen J/F own/cyclic-crossed/pooled-soft-weight diagnostics. Separately, use the prepared C64-D4 versus C64-M4 comparison: M4 draws independent Bernoulli slots from the **actual C64 marginals**, preserving the selected bank, features, decoder, alpha, draw count, and raw-logit pooling. Pair finite draws as specified and disclose their noise. The J/F soft-weight diagnostic tests component-to-decoder association; D4/M4 tests prediction-route retention of dependence. They are not the same intervention and neither alone isolates auxiliary training effects.

**Falsifier:** if the declared paired comparison finds no supported target-ranking or score benefit from own versus crossed/pooled association and from D4 versus actual-marginal M4, the serving-retention explanation is unsupported in that bank. An auxiliary NLL improvement cannot rescue that claim. If only one intervention matters, limit the conclusion to that operation.
