3.2. Overlapping Stochastic Block Model

BLOCK 32 p S3.SS2.p1.1
Real-world networks often exhibit overlapping community structures, where nodes belong to multiple communities simultaneously. For instance, a researcher might be active in both machine learning and database communities. The Overlapping Stochastic Block Model (OSBM) ( Latouche et al., 2011 ; Miller et al., 2009 ; Zhu et al., 2016 ) provides a principled generative framework for such networks.

BLOCK 33 p S3.SS2.p2.1
Community memberships. OSBM assumes each node may belong to multiple communities. Let K denote the number (or truncation level) of latent communities, and \mathbf{b}_{i}=(b_{i1},\ldots,b_{iK})\in\{0,1\}^{K} denote the binary overlapping membership of node i . A common prior treats coordinates as independent Bernoulli variables:

BLOCK 34 table S3.E2
(2) p(\mathbf{b}_{i}\mid\boldsymbol{\alpha})=\prod_{k=1}^{K}\alpha_{k}^{b_{ik}}(1-\alpha_{k})^{1-b_{ik}},

BLOCK 35 p S3.SS2.p2.2
where \boldsymbol{\alpha}=(\alpha_{1},\ldots,\alpha_{K}) parameterizes community prevalence, and the all-zero vector is permitted to represent outliers.

BLOCK 36 p S3.SS2.p3.1
Edge generation. Conditional on memberships, each edge (i,j) follows a Bernoulli distribution with logistic natural parameter:

BLOCK 37 table S3.E3
(3) a_{ij}=\mathbf{b}_{i}^{\top}W\,\mathbf{b}_{j}+\mathbf{b}_{i}^{\top}U+V^{\top}\mathbf{b}_{j}+W_{\ast},

BLOCK 38 table S3.E4
(4) \Pr(A_{ij}=1\mid\mathbf{b}_{i},\mathbf{b}_{j})=\sigma(a_{ij}),

BLOCK 39 p S3.SS2.p3.2
where W\in\mathbb{R}^{K\times K} captures inter-community and intra-community affinities, U,V\in\mathbb{R}^{K} encode community-specific edge propensities, and W_{\ast}\in\mathbb{R} provides global sparsity control. The block interaction term \mathbf{b}_{i}^{\top}W\,\mathbf{b}_{j} promotes edges between nodes sharing communities, while the sender/receiver terms capture asymmetric community tendencies.

BLOCK 40 p S3.SS2.p4.1
Compact representation. For notational convenience, we augment \tilde{\mathbf{b}}_{i}=[\mathbf{b}_{i};1]\in\{0,1\}^{K+1} and define \tilde{W}=\begin{pmatrix}W&U\\ V^{\top}&W_{\ast}\end{pmatrix} , yielding:

BLOCK 41 table S3.E5
(5) a_{ij}=\tilde{\mathbf{b}}_{i}^{\top}\tilde{W}\,\tilde{\mathbf{b}}_{j}.

BLOCK 42 p S3.SS2.p5.1
Under this formulation, edges are conditionally independent given latent memberships.

BLOCK 43 p S3.SS2.p6.1
Computational challenges. While OSBM provides an elegant theoretical framework, inferring latent memberships \mathbf{B} and community parameters from observed graphs poses significant computational challenges. Traditional approaches rely on variational EM or MCMC methods that scale poorly to large networks. TGSBM addresses these limitations by employing a sparse Graph Transformer encoder to efficiently infer variational posterior parameters while preserving OSBM’s interpretable latent structure.

4.2. Variational Posterior and Reparameterization

BLOCK 63 p S4.SS2.p1.1
Following variational approaches to OSBM inference ( Mehta et al., 2019 ) , we employ a structured variational family that respects the hierarchical nature of OSBM (Figure 2 (b)): global stick variables \mathbf{v}=(v_{1},\ldots,v_{K})\in\mathbb{R}^{K} control community prevalence via stick-breaking construction ( Teh et al., 2007 ) , binary memberships \mathbf{B}\in\{0,1\}^{N\times K} determine node-community assignments, and Gaussian strengths \mathbf{R}\in\mathbb{R}^{N\times K} modulate membership intensities.

BLOCK 64 p S4.SS2.p2.1
Factorized variational family. Our approximate posterior factorizes as:

BLOCK 65 table S4.EGx1
\displaystyle q(\mathbf{v},\mathbf{B},\mathbf{R}\mid\mathbf{X},\mathbf{A}) \displaystyle=\prod_{k=1}^{K}\mathrm{Beta}(v_{k}\mid c_{k},d_{k}) (9) \displaystyle\quad\cdot\prod_{n=1}^{N}\prod_{k=1}^{K}\mathrm{Bern}(b_{nk}\mid\sigma(\ell_{nk})) \displaystyle\quad\cdot\prod_{n=1}^{N}\mathcal{N}(\mathbf{r}_{n}\mid\boldsymbol{\mu}_{n},\mathrm{diag}(\boldsymbol{\sigma}_{n}^{2})),

BLOCK 66 p S4.SS2.p2.2
where the encoder representations \mathbf{H}=(\mathbf{h}_{1},\ldots,\mathbf{h}_{N})\in\mathbb{R}^{N\times D} parameterize distributions via specialized heads:

BLOCK 67 table S4.E10
(10) \boldsymbol{\ell}_{n}=W_{\pi}\mathbf{h}_{n},\quad\boldsymbol{\mu}_{n}=W_{\mu}\mathbf{h}_{n},\quad\log\boldsymbol{\sigma}_{n}=W_{\sigma}\mathbf{h}_{n},

BLOCK 68 p S4.SS2.p2.3
with projection matrices W_{\pi},W_{\mu},W_{\sigma}\in\mathbb{R}^{K\times D} .

BLOCK 69 p S4.SS2.p3.1
Stick-breaking integration. Stick variables induce community prevalence priors via v_{k}\sim\mathrm{Beta}(c_{k},d_{k}) and cumulative probabilities \pi_{k}=v_{k}\prod_{i=1}^{k-1}(1-v_{i}) . The posterior membership logit combines encoder evidence with hierarchical priors:

BLOCK 70 table S4.E11
(11) \lambda_{nk}^{\text{post}}=\ell_{nk}+\log\frac{\pi_{k}}{1-\pi_{k}}.

BLOCK 71 p S4.SS2.p4.1
Reparameterized sampling. For gradient-based optimization, we employ standard reparameterization techniques. Binary memberships use Binary-Concrete relaxation ( Jang et al., 2017 ; Maddison et al., 2017 ) :

BLOCK 72 table S4.E12
(12) \tilde{b}_{nk}=\sigma\left(\frac{\lambda_{nk}^{\text{post}}+g_{nk}}{\tau}\right),\quad g_{nk}\sim\mathrm{Gumbel}(0,1),

BLOCK 73 p S4.SS2.p4.2
while continuous strengths follow Gaussian reparameterization:

BLOCK 74 table S4.E13
(13) \mathbf{r}_{n}=\boldsymbol{\mu}_{n}+\boldsymbol{\sigma}_{n}\odot\boldsymbol{\epsilon}_{n},\quad\boldsymbol{\epsilon}_{n}\sim\mathcal{N}(\mathbf{0},\mathbf{I}).

BLOCK 75 p S4.SS2.p4.3
The final node embedding \mathbf{z}_{n}=\tilde{\mathbf{b}}_{n}\odot\mathbf{r}_{n} ensures only active communities contribute to the representation, enabling low-variance path-wise gradients, where \tilde{\mathbf{b}}_{n} denotes the relaxed binary membership vector from Equation ( 12 ).

4.3. Decoder and Likelihood

BLOCK 77 p S4.SS3.p1.1
The decoder translates OSBM’s latent community embeddings \mathbf{Z}=(\mathbf{z}_{1},\ldots,\mathbf{z}_{N})\in\mathbb{R}^{N\times K} into edge probabilities while preserving the interpretable generative structure (Figure 2 c). Following neural OSBM approaches ( Mehta et al., 2019 ) , we employ a learned nonlinear transformation to capture complex community interaction patterns beyond simple bilinear forms.

BLOCK 78 p S4.SS3.p2.1
Neural decoder architecture. Edges are decoded via a two-layer MLP followed by an inner product and a logistic link:

BLOCK 79 table S4.E14
(14) f(\mathbf{z})=\mathbf{W}_{2}\,\mathrm{ReLU}(\mathbf{W}_{1}\mathbf{z}+\mathbf{b}_{1})+\mathbf{b}_{2},\qquad\tilde{\mathbf{z}}_{n}=f(\mathbf{z}_{n}),

BLOCK 80 p S4.SS3.p2.2
where \mathbf{W}_{1}\in\mathbb{R}^{d_{\mathrm{hidden}}\times K} , \mathbf{W}_{2}\in\mathbb{R}^{d_{\mathrm{mlp}}\times d_{\mathrm{hidden}}} , e.g., d_{\mathrm{hidden}}=2K and d_{\mathrm{mlp}}=K .

BLOCK 81 p S4.SS3.p3.1
The edge likelihood factorizes over evaluated pairs \mathcal{S} :

BLOCK 82 table S4.E15
(15) p(\mathbf{A}\mid\mathbf{Z})=\prod_{(n,m)\in\mathcal{S}}\mathrm{Bernoulli}(A_{nm}\mid\sigma(\tilde{\mathbf{z}}_{n}^{\top}\tilde{\mathbf{z}}_{m})),

BLOCK 83 p S4.SS3.p3.2
where \mathcal{S} includes observed positive edges and uniformly sampled negatives for mini-batch training. This design maintains OSBM’s symmetric structure while enabling flexible community interaction modeling.

BLOCK 84 p S4.SS3.p4.1
Optional feature reconstruction. When node features \mathbf{X} are available, we include reconstruction terms with feature-specific parameters, enabling joint edge-feature modeling for improved community discovery.

4.4. Objective and Optimization

BLOCK 86 p S4.SS4.p1.1
Following the variational autoencoder framework for OSBM ( Mehta et al., 2019 ) , we minimize the negative of the evidence lower bound (ELBO) with OSBM priors p(v_{k})=\mathrm{Beta}(a,b) , stick-breaking membership priors, and Gaussian strength priors p(\mathbf{r})=\prod_{n}\mathcal{N}(\mathbf{0},\mathbf{I}) :

BLOCK 87 table S4.EGx2
\displaystyle\mathcal{L}=\mathrm{KL}(q(\mathbf{v})\|p(\mathbf{v}))+\mathrm{KL}(q(\mathbf{B})\|p(\mathbf{B}\mid\mathbf{v})) (16) \displaystyle\quad+\mathrm{KL}(q(\mathbf{R})\|p(\mathbf{R}))-\mathbb{E}_{q}[\log p(\mathbf{A}\mid\mathbf{Z})]-\mathbb{E}_{q}[\log p(\mathbf{X}\mid\mathbf{Z})],

BLOCK 88 p S4.SS4.p1.2
where \mathrm{KL}(q(\cdot)\|p(\cdot)) denotes the Kullback-Leibler divergence. The final term represents optional feature reconstruction when node features \mathbf{X} are available; when features are absent, we omit this term. Links \mathbf{A} are conditionally independent given the node embedding matrix \mathbf{Z} .

BLOCK 89 p S4.SS4.p2.1
Training procedure. We employ stochastic gradient variational Bayes (SGVB) ( Kingma and Welling, 2013 ) with the reparameterization techniques from Equations ( 12 )-( 13 ). Beta stick variables are sampled via Kumaraswamy approximation ( Nalisnick and Smyth, 2017 ) , and mini-batch edge sampling balances positive and negative pairs for reconstruction term estimation. The sparse attention design enables efficient scaling to large graphs while maintaining the interpretable OSBM latent structure. Algorithm 1 provides the complete training procedure.

5.1.3. Hyperparameters

BLOCK 99 p S5.SS1.SSS3.p1.1
We tune learning rate in \{10^{-3},5\times 10^{-3}\} , dropout in [0,0.3] , and weight decay in \{0,10^{-5},10^{-4}\} . Expander degree d_{\exp} is searched over \{6,8,10,12\} , number of layers in \{3,4,5,6\} , with 4 attention heads. For the variational components, we use Beta (10.0,0.1) priors for stick-breaking, tune Concrete temperature in \{0.8,1.0,1.2\} with prior temperature 0.5, and apply KL annealing from epoch 0 to \{60,80\} over 200 total epochs. Hidden dimension is 128 for Cora and Pubmed, 256 for Citeseer. We use GELU activation, BatchNorm, gradient clipping at 5.0, and report means over 3 random seeds.

5.1.4. Evaluation Metrics

BLOCK 101 p S5.SS1.SSS4.p1.1
Each positive test edge is ranked against a set of negative candidates. We evaluate using three metrics: AUC (area under ROC curve), MRR (mean reciprocal rank), and Hits@K (proportion of correct links in top-K predictions). For Cora, Citeseer, and Pubmed, we follow Li et al. ( Li et al., 2023a ) and report AUC and MRR. For OGB datasets under HeaRT, we report MRR as the primary metric.
