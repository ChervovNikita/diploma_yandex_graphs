Appendix B Bootstrapped DQN implementation
Algorithm 1 gives a full description of Bootstrapped DQN.
It captures two modes of operation where either [MATH:k] neural networks
are used to estimate the [MATH:Q_{k}] -value functions, or
where one neural network with [MATH:k] heads is used to estimate [MATH:k] [MATH:Q] -value functions.
In both cases, as this is largely a parameterisation issue, we denote the
value function networks as [MATH:Q] , where [MATH:Q_{k}] is output of the [MATH:k] th network or
the [MATH:k] th head.
A core idea to the full bootstrapped DQN algorithm is the bootstrap mask [MATH:m_{t}] .
The mask [MATH:m_{t}] decides, for each value function [MATH:Q_{k}] , whether or not it should train upon the experience
generated at step [MATH:t] .
In its simplest form [MATH:m_{t}] is a binary vector of length [MATH:K] , masking out or including each value function for
training on that time step of experience (i.e., should it receive gradients from the
corresponding [MATH:(s_{t},a_{t},r_{t+1},s_{t+1},m_{t})] tuple).
The masking distribution [MATH:M] is responsible for generating each [MATH:m_{t}] .
For example, when [MATH:M] yields [MATH:m_{t}] whose components are independently drawn from a
bernoulli distribution with parameter [MATH:0.5] then this corresponds to the
double-or-nothing bootstrap [17].
On the other hand, if [MATH:M] yields a mask [MATH:m_{t}] with all ones, then the
algorithm reduces to an ensemble method.
Poisson masks [MATH:M_{t}[k]\sim{\rm Poi}(1)] provides the most natural parallel with the standard non-parameteric boostrap since [MATH:{\rm Bin}(N,1/N)\rightarrow{\rm Poi}(1)] as [MATH:N\rightarrow\infty] .
Exponential masks [MATH:M_{t}[k]\sim{\rm Exp}(1)] closely resemble the standard Bayesian nonparametric posterior of a Dirichlet process [15].
Algorithm 1 Bootstrapped DQN
1:
Input: Value function networks [MATH:Q] with [MATH:K] outputs [MATH:\{Q_{k}\}_{k=1}^{K}] . Masking distribution [MATH:M] .
2:
Let [MATH:B] be a replay buffer storing experience for training.
3:
for each episode do
4:
Obtain initial state from environment [MATH:s_{0}]
5:
Pick a value function to act using [MATH:k\sim\text{Uniform}\{1,\dots,K\}]
6:
for step [MATH:t=1,\ldots] until end of episode do
7:
Pick an action according to [MATH:a_{t}\in\arg\max_{a}Q_{k}(s_{t},a)]
8:
Receive state [MATH:s_{t+1}] and reward [MATH:r_{t}] from environment, having taking action [MATH:a_{t}]
9:
Sample bootstrap mask [MATH:m_{t}\sim M]
10:
Add [MATH:(s_{t},a_{t},r_{t+1},s_{t+1},m_{t})] to replay buffer [MATH:B]
11:
end for
12:
end for
Periodically, the replay buffer is played back to update the parameters of the value function network [MATH:Q] .
The gradients of the [MATH:k] th value function [MATH:Q_{k}] for the [MATH:t] th tuple in the replay buffer [MATH:B] , [MATH:g_{t}^{k}] is:
[MATH:\displaystyle g_{t}^{k}]
[MATH:\displaystyle=m_{t}^{k}(y^{Q}_{t}-Q_{k}(s_{t},a_{t};\theta))\nabla_{\theta}Q_{k}(s_{t},a_{t};\theta)]
(3)
where [MATH:y^{Q}_{t}] is given by (2).
Note that the mask [MATH:m_{t}^{k}] modulates the gradient, giving rise to the bootstrap behaviour.
