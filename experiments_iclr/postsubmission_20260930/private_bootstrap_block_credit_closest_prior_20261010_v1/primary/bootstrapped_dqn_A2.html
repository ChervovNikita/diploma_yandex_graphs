Appendix B Bootstrapped DQN implementation

Algorithm 1 gives a full description of Bootstrapped DQN. It captures two modes of operation where either kk neural networks are used to estimate the QkQ_{k}-value functions, or where one neural network with kk heads is used to estimate kk QQ-value functions. In both cases, as this is largely a parameterisation issue, we denote the value function networks as QQ, where QkQ_{k} is output of the kkth network or the kkth head.

A core idea to the full bootstrapped DQN algorithm is the bootstrap mask mtm_{t}. The mask mtm_{t} decides, for each value function QkQ_{k}, whether or not it should train upon the experience generated at step tt. In its simplest form mtm_{t} is a binary vector of length KK, masking out or including each value function for training on that time step of experience (i.e., should it receive gradients from the corresponding (st,at,rt+1,st+1,mt)(s_{t},a_{t},r_{t+1},s_{t+1},m_{t}) tuple). The masking distribution MM is responsible for generating each mtm_{t}. For example, when MM yields mtm_{t} whose components are independently drawn from a bernoulli distribution with parameter 0.50.5 then this corresponds to the double-or-nothing bootstrap [17]. On the other hand, if MM yields a mask mtm_{t} with all ones, then the algorithm reduces to an ensemble method. Exponential masks Mt​[k]∼Exp​(1)M_{t}[k]\sim{\rm Exp}(1) closely resemble the standard Bayesian nonparametric posterior of a Dirichlet process [15].
