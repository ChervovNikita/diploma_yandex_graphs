2.1 Preliminaries: Problem and Notation

The goal of multi-task learning is to find parameters θ\theta of a model fθf_{\theta} that achieve high average performance across all the training tasks drawn from a distribution of tasks p⁡(𝒯)p(\mathcal{T}). More formally, we aim to solve the problem: minθ⁡𝔼𝒯i∼p⁡(𝒯)​[ℒi​(θ)]\min\limits_{\theta}\mathbb{E}_{\mathcal{T}_{i}\sim p(\mathcal{T})}\left[\mathcal{L}_{i}(\theta)\right], where ℒi\mathcal{L}_{i} is a loss function for the ii-th task 𝒯i\mathcal{T}_{i} that we want to minimize. For a set of tasks, {𝒯i}\{\mathcal{T}_{i}\}, we denote the multi-task loss as ℒ⁡(θ)=∑iℒi​(θ)\mathcal{L}(\theta)=\sum_{i}\mathcal{L}_{i}(\theta), and the gradients of each task as 𝐠i=∇ℒi​(θ)\mathbf{g}_{i}=\nabla\mathcal{L}_{i}(\theta) for a particular θ\theta. (We drop the reliance on θ\theta in the notation for brevity.) To obtain a model that solves a specific task from the task distribution p⁡(𝒯)p(\mathcal{T}), we define a task-conditioned model fθ​(y|x,zi)f_{\theta}(y|x,z_{i}), with input xx, output yy, and encoding ziz_{i} for task 𝒯i\mathcal{T}_{i}, which could be provided as a one-hot vector or in any other form.
