## One falsifiable mechanism implication

**Fixed private supervised weighting can be useful only if it changes the acquired private predictions enough to yield retained, served complementary correctness at acceptable risk.** At a fixed parameter/dropout state, changing these weights leaves the immediate shared gradient unchanged. Any later shared-trajectory change is mediated by learned private functions. Consequently this rule is not an immediate shared-gradient conflict remedy, and E[w]=1 at a fixed state supplies no learned-risk guarantee.
