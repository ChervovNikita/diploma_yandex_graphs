## Concrete source findings

### F1: Once-only final release is scoped to a reproducible comparison artifact, not to the registered study

compare has no exclusive study-level comparison/release claim and accepts a fresh arbitrary output directory each time. Two compare calls against the same closed registry and same fit admission create two valid COMPARISON_FREEZE files with different output_root values and different hashes. report constructs its exclusive claim from comparison_root/name/hash, so both calls can independently open the same six final label packs. This does not alter the frozen fit selection, but violates the promised once-only read/release and allows a failed report to be retried through another comparison artifact.

## Source behavior traced

The implemented schedule is native PolyFormer warm50 followed by up to1950 continuation updates with patience250. Photo pays200 local updates, restores the earliest strict validation-NLL best-local model **and named Adam state**, keeps the RNG reached after all200 local updates, enables global, warms50 global updates, and continues950 global updates. Its paid budget is1200 even when restored local Adam counters are below200. The selected continuation predictor is global only.

The donor is deep-copied before native boundary ownership transfer. K1 and K4 use copied warm W/body/bias with all R/S at identity. K4 shares one W/body and carries private R/S/B rows, then executes four complete member trajectories in fixed order. All five arms resume the exact same post-warm Python, NumPy, Torch CPU and all-CUDA RNG arrays after cloning/qualification/initialization. Member dropout draws differ within an update, and begin paired across arms.

Warm-copy repeats the exact identity slice. Common-only uses safeguarded common descent and omits graph bands/JVPs. Random tangents use seed+70000 and the graph tangent Frobenius norm in the same zero-mean/common-gradient-orthogonal space. Topology permutation uses seed+80000 and node permutation of S with unchanged labels/features. Budgets, K4 parameters and optimizer transport are shared across arms; initializer work differs and is charged.

The named optimizer map enumerates aliases, rejects splitting/merging, checks copied values and complete native/inactive parameter coverage. At K=4 and identical dropout-off routes, mean member CE gives each B row gradient g/4. With coupled decay w/4, its Adam q is (g+wB)/4. Transport m/4, v/16, AMSGrad max-v/16 and epsilon/4 preserves the bias update in real arithmetic with unchanged step, betas, learning rate and bias correction. Shared W/body updates need no scaling. New R/S begin with empty state and inherit their native boundary-weight options. This argument is limited to ordinary coupled Adam and identical routes with new factors frozen.

A disposable native-versus-K4 one-step gate compares active/shared and four-times-private-bias gradients, every mapped parameter, every moment/step, inactive state and final member logits. Native/K1/each-K4 initial logits are also checked. Cold qualification and each actual warm arm must pass fixed source tolerances. No numerical pass is inferred here.

The initializer uses actual full predictive logits through an eval K1 torch.func.functional_call closure with detached common snapshots and fresh buffers. Train CE residual is the only injected label signal. Cubic Bernstein filters act on the full released topology; cotangents are masked back to train rows before VJP, preserving sum h=g. Tangents are centered and projected orthogonal to g, then class-centered real JVP pair RMS detects functional null/gauge/duplicate directions. Six fixed Armijo attempts require finite all-member and pooled train CE descent plus finite-step functional separation. Failure falls back to common descent, then unchanged warm. Three fixed AD directions and two fixed epsilons test duality, centered-logit finite differences and CE directional derivatives without adaptive search.

Validation selection is fresh at initialized epoch0 and each continuation update, with earliest strict ties and fixed mean raw-logit pooling. The comparison requires30 completed source fits and72 current phase terminals before final labels. Report uses frozen selected logits, fixed primary pooling and secondary probability averaging from those same logits. Ordinary phase exceptions retain partial initializer/epoch records, costs and failed terminals; exclusive claims also leave incomplete attempts blocking closure. These protections need the F1/F2 custody repairs above.
