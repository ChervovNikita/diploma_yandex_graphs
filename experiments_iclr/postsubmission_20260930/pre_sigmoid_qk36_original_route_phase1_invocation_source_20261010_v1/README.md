# Fixed original-route phase1 invocation

Source-only once-only invocation glue in the existing launch/supervise/attest style. Nothing was launched. Root uses copied source-backed releases after publication/sync and the saved metadata preflight.

`phase1_once.py --mode launch --release ABSOLUTE_ENABLED_RELEASE --release-sha256 SHA` creates one exclusive route supervision directory, starts one detached stdlib parent, and records its actual boot-bound identity, argv, source hash and release. The parent starts exactly the original route Python `-B collect_route.py --release ... --release-sha256 ...`. It records actual `/proc` parent/child argv, ppid and boot-bound identities in PROCESS_WITNESS.json. `root_observed=true` means these actual metadata samples were made by this source invoked by root; the observation program is bound. The source imports no numerical package.

The parent reuses unchanged owned.identity/same/members/stop/gpu_rows and lane.environment/resources/timer/interrupted. It samples only its own parent and isolated child group, directly waits for the child and retains the real CHILD.EXIT.json, failures, signals, inclusive parent costs and combined active/cleanup cost. The child is limited to 3600 active seconds plus 15 cleanup, 24 GiB GPU, 8 GiB RSS and 4 GiB combined output/logs. Root's legacy 24 GiB envelope, exact runtime, nine baseline calls and collector policies remain unchanged. No scheduler, generic owner, namespace mapping, metric policy, or numerical source is added or changed.

After the detached parent and child tree are absent, root invokes the same source with `--mode attest`. It records actual identity/group/CUDA absence for that exact parent and witnessed child tree, binds collection/COST, the original release and actual process witness, and points cleanup_cost_and_failures to the same unmodified CHILD.EXIT.json. TERMINAL.json is accepted only by unchanged V2 gate_route.phase_terminal; an ATTESTATION_RESULT.json retains success or a concrete failure. Detached parent direct OS wait and OS exit remain false/null; parent absence and PARENT_FINISH.json are not substituted for OS exit proof. Separated cleanup duration remains unavailable/null.

ROOT_INVOCATION_EXAMPLES_DISABLED.json gives all three exact original-route commands, with the enabled release hash explicitly pending root. SUPERVISION_ADDITIONS_DISABLED.json gives three code-custody fields to add to root copies of existing EXTERNAL_SUPERVISION: parent_invocation_program, original_resource_helper, original_environment_helper. Root then recomputes the supervision binding in the enabled release. These are source identity fields, with no new approval flags or enlarged envelope. The original collector release/supervision flags remain disabled in the preserved preparation packet. All scientific starts remain with root.

Failure/partial collection files are retained without retry. The once-only supervision directory is a launch reservation, so an existing claim/output is never reused. Phase2 and the global baseline freeze remain the existing V2 source contract and are outside this phase1 glue.
