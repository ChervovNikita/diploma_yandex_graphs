# Structure-conditioned specialization: bounded quality scout

## Decision

**No new learner is promoted.** Five new scoped primary methods were read after checking all163 record titles and relevant conclusions in literature memory `index_v39`: four graph methods from2025 and the older sMCL training-specialization ancestor. The pass leaves one unadopted utility question, with explicit controls. It establishes no predictive gain, complete published-method absence, novelty or manuscript verdict.

The retained frontier already separates full-support graph-response initialization, covariance selection, and shared-update preservation. This packet changes none of those proposals or the frozen NCNC J/F pilot. It introduces no implementation, training, dataset/checkpoint read, remote process or canonical edit.

## One precise remaining utility question

A structure-based **training assignment** could give member-private factors different risk emphasis while leaving the shared body on native unweighted mean-member supervision. For four routes, let the native per-query loss be ell_m(q). Keep the shared gradient of `(1/4)sum_m E ell_m`. Give private route m the gradient of `(1/4)[0.5 E ell_m +0.5 E(ell_m | structural cell m)]`, from the same pre-update forward, then commit one unchanged native optimizer transition. The fixed half anchor gives every member global supervision.

The prospective degree-rank cells use only public TRAIN support, excluding the queried edge if present. There is no output gate, graph modification in the native forward, added parameter, repulsion, new initialization or Bernoulli pattern teacher. The candidate changes training cotangents throughout the budget. Its common/private assignment differs from the saved shared-pool/private-own policy, while inheriting that policy family’s block-routing ancestry and nonconservative-update limitation.

This is a conditional optimization question. It does not supply a scalar pooled-descent guarantee or a reason that degree partitions are predictively useful. A common body can erase advantages, limited private capacity can underfit, ties can make assignment nearly random, and uniform pooling can weaken specialist gains. The anchor and cell rule are untested declared choices. They cannot be repaired through an outcome-driven grid.

## Closest controls and one representative test

The closest controlled operation is the **identical private-risk allocation with balanced random cells**. sMCL supplies the closest new training-specialization ancestor; a matched loss-assigned adaptation must use the same anchor, shared/private routing, normalization and serving, and must not be called a native sMCL reproduction. The closest new capable structural single is GPM; existing BUDDY/LPFormer singles also expose target-pair structure. A richer-context single cannot be replaced by a weak terminal affine head.

A separate prospective comparison uses the complete ogbl-Collab graph, released TRAIN/raw/VALID roles and locked TEST, three paired seeds and five arms: candidate, uniform shared4, random assignment, loss assignment, and a source-qualified structural single. This is15 owned run groups, not an executed schedule. Native architecture, loss reductions, query streams, full update budgets and selectors must be bound before execution. Single-model source/recipe harmonization, small-cell behavior and exact same-state block gradients remain unresolved; the design is not launch-ready.

The primary readout is uniformly served official VALID Hits50 across every paired seed. Structural allocation must beat uniform and matched random allocation; loss assignment must not explain the same gain. If the capable single matches quality at comparable paid work, an ensemble-specific advantage is unestablished. Lower TRAIN loss, higher member-oracle coverage or larger spread cannot rescue the primary claim. All member competence, predeclared regime scores, endpoints and complete costs remain visible.

No resource feasibility is asserted. Context extraction, reverse sweeps/recomputation, one complete epoch, state/RNG qualification, every arm’s peak memory and complete native-budget forecast require measurement before a resource decision. Existing failures and source limits are retained; resource limits do not establish that the hypothesis is false.

## Rejections retained

Ordinary topology gating repeats retained graph MoE work and is excluded here. Different walk scales/masks plus averaging repeat sampling/view ingredients. New observation-pattern reconstruction would duplicate the NCNC J/F/GRAN/MaskGAE line. Private counterfactual response preservation would repeat the existing conditional-response frontier. Pure winner-take-gradient already has sMCL ancestry. Temporal-history specialization must first compare with a history-capable single.

The bounded conclusion is a null promotion, with a fully attributed test question saved for root’s judgment. Full FAGEL reconciliation, previously blocked GENN routes and two index_v39 primary leads remain unresolved. This search does not convert inaccessible or uninspected sources into evidence of absence.
