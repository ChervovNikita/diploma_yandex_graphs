# One prospective comparison, no tuning or execution release

This design is an analysis deliverable. It neither amends the existing P0/J_P/F_P/C_mu screen nor authorizes a fit. Algebraic/numerical fabricated qualification, original native empty-call disposition, complete full-batch resource qualification, and separate root source/data release precede execution.

## Required named conditions

| Label | Source auxiliary | Purpose |
| --- | --- | --- |
| P0 | None | Check whether the candidate helps served ranking. |
| J_P | Existing unconditioned uniform whole-pattern mixture | Compare conditioning against its actual unchanged ancestor. |
| J_K | Uniform mixture of per-member two-sided conditional laws | Candidate. |
| J_K_sep | Product of independent per-side conditional mixtures | Isolate a shared member across sides while matching whole per-side laws at fixed parameters. |
| W_K | Mean per-member conditional NLL | Contrast responsibility-weighted learning with fitting each member. |
| S_K | One capable count-constrained contextual autoregressive auxiliary, attached to one native width64 predictor | Limit a claim that retained predictive members are necessary. |

All bank conditions use identical fresh bank initialization and the existing detached pooled completion, member target BCE, uniform raw-logit serving, data roles, replay and complete selector. Preserve coefficient1 and division by `max(n_L+n_R,1)` over all queries, including extreme-count zero-loss queries. Do not renormalize only informative queries. Conditional objectives remove signal and change gradient magnitudes even with this shared coefficient; report that rather than treating coefficient equality as equal regularization strength.

Keep the frozen single seed/replay, 100×17 full65536-record updates and complete first-maximum VALID selection. Each condition keeps its complete actual update/evaluation/state receipts and selected-state replay. Failed and adverse outcomes are retained. No earlier trained state is loaded, no route/lambda/seed is selected, and no TEST is used. The source-only assessment does not prescribe a fitted outcome or substitute a partial batch/epoch for this protocol.

## Concrete capable-single family to freeze before implementation

`S_K` can use one native encoder/recursive unary scorer and a width64 contextual auxiliary head. For each canonical native residual slot, form its visible endpoint/node features and native unary logit, plus pooled visible support features and summaries of earlier selected slots. The head predicts the next bit conditioned on this prefix and both remaining counts. Forced choices occur only when the remaining count is zero or equals the number of remaining positions. Multiplying these sequential probabilities gives a normalized law on every feasible fixed-count pattern; teacher-forced NLL is exact, and later-side probabilities can depend on the earlier selected identities.

This head is identity-sensitive within fixed counts and can express the matching-side example in `ALGEBRA.md`; a potential depending only on counts cannot. It uses the same permitted TRAIN visible context, with counts/prefix teacher bits only in the auxiliary likelihood. The target predictor keeps its ordinary native count-free completion/one-decode serving route. An auxiliary head is not an extra prediction ensemble.

Freeze native slot order, endpoint-exchange policy, feature construction, all head dimensions/initialization, optimizer groups and exact normalization in its own source packet before any outcome is seen. Canonical CSR ordering introduces an order convention that must be disclosed and checked; symmetrizing endpoint orientations, if chosen prospectively, pays both full auxiliary evaluations. There is no author-code or runtime qualification of this proposed adapter. It is an attributed autoregressive structured-single control, not a native KREPE/DiGress/PIFM reproduction. Its extra parameters, sequential work and graph retention are fully charged; equal information and competence do not mean identical parameter or wall-clock budgets.

## Predictions that can fail

`J_K` should improve informative-context conditional identity competence, not merely uniform-prior count entropy, and should improve served ranking against P0 and the matched controls. Compare old J_P count versus conditional identity terms using its count-reweighted posterior mixture. Retain positive/zero competence and source count diagnostics so offset/calibration damage is visible. Arrangement probes use a prereleased TRAIN-only set of mask contexts and the uniform fixed-count baseline; they do not choose a checkpoint or count as independent graph samples.

A result confined to conditional NLL fails the useful-ranking hypothesis. A result explainable by reduced auxiliary signal remains a regularization finding. S_K matching the candidate defeats the bank-necessity interpretation; infeasible or unqualified S_K leaves that interpretation unsupported. J_K matching J_K_sep defeats the claim that using one member identity across sides adds utility. F_K, derived in ALGEBRA.md, is a possible separately preregistered analogue of old F_P; it also changes pooling/conditioning order and conditional unary marginals, so it is not substituted for J_K_sep's matched per-side comparison. A favorable one-seed result requires a separately fixed replication rather than retrospective tuning.
