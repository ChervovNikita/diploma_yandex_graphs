## What the diagnostics add

E's BASE accuracy gain coexists with more common rivals; rival removal need not serve truth. The newly closed affine probe fails its private-specific/untouched-anchor criteria, so it supplies no decoder-capacity explanation. Weak-member competence claims need actual member evidence; pooled utility can survive weaker members, but it does not make them stronger.
