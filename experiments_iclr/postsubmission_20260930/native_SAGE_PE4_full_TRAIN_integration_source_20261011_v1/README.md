# Native SAGE PE full TRAIN qualification and finite consumer

Source integration only. The sealed PE packet and exact F owner are preserved. This folder supplies **one actual full-TRAIN qualifier** and a small source consumer; root owns execution, qualification, scheduling and fresh paired evidence.

## One full TRAIN case

Qualification uses seed 7301, the factual 11,701×300 float32 X and full directed E, and only the compact 580 TRAIN ids/labels. It opens only `train_npz`. VALID remains a config path and is neither hashed nor deserialized in this mode. There is no VALID scoring, TEST access, toy graph or hypothesis grid.

Four ordinary native SAGE bodies use the sealed PE width 59 and the existing independent constructor/dropout seed laws. Their initialized values are packed without a reset. All 24 grouped parameter tensors map to all 96 native parameter tensors; their values, private coordinate ranges, distinct storages and optimizer ownership are checked.

Two updates compare full TRAIN logits/hidden states, mean own-member CE, every member's live finite gradients, Adam parameters/moments/steps and exact dropout-stream consumption. The reference uses the same mean CE scale and one AdamW over the four private bodies; it is not an unscaled-I4 optimizer claim. The qualifier then saves the entire packed/native model, both optimizers and both sets of member streams, destroys them, restores every state exactly and verifies TRAIN replay. This is 32 route trajectories, four discarded backwards and four Adam calls. All work is discarded.

Fixed float32 tolerances are declared in `qualify_full_train.py`. Gradient/parameter parity, stream replay and all-parameter restoration are engineering checks; none is a predictive utility criterion. Scalar maximum discrepancies, progress, discarded work, checkpoint bytes and actual wall/CUDA/RSS costs are retained. Failure preserves the latest pending phase and counts. No runtime or cost pass is claimed here.

## Root execution contract

The sole CLI is `run.py --release ROOT_RELEASE.json`. It checks the literal authorized allocation and sole GPU before project metadata, then verifies the action's root-bound config, PE/F/native/current PyG sources, safe roles, actual runtime and live supervisor/watchdog identity. A positive finite wall/CUDA/RSS budget and an external pending-call watchdog are required. Qualification allows at most 300 seconds; fit allows at most 86,400 seconds. These are admission ceilings, not cost forecasts. Root chooses actual budgets.

The release templates are disabled. Fill path/bytes/SHA256 receipts after deployment; owner child/parent/PGID/watchdog fields describe the actual run. Root must arrange that live external owner before starting the child. Runtime versions must equal the current root admission.

Qualification mode directly consumes the prepared TRAIN pack and never instantiates `Family`, whose original initializer reads VALID. Fit mode requires the bound exact-source/same-runtime qualifier PASS and a compact endpoint-VALUE native-closure receipt. It also uses the sealed PE `root_fit_admission` receipt required by `family_class`. The original `Family.fit`, recipe, three seeds, strict selector, probability pool and restore remain unchanged. Only progress gains finite budget checks; the external owner covers blocked calls.

Root schedules the three PE banks after endpoint native closure and admits the eventual paired reader against **fresh current-runtime E-family BASE and capable same-role anchors**, retaining full-width I4. The immutable PE source's old F reference label is not permission to reuse historical cross-runtime scores. This consumer closes only the PE arm and supplies no comparison verdict or calibration choice.

`SOURCE_BINDINGS.json`, `STATIC_SOURCE_CHECKS.json`, the disabled templates and `SEAL.json` bind the integration. Preparation used stdlib source inspection, AST compilation and hashes only. No numerical/model/data imports, execution, fit, remote access, reviewer or mutation of either sealed dependency occurred.
