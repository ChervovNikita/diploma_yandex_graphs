# Inactive Physics core selected-state export

This separate callable preserves the sealed core V5 source and fitting recipe. It exports label-free CAL/CONFIRM predictions after root admits all90 selected states. It adds no update, qualifier, target reader, calibration or score. Source syntax/interfaces were inspected only.

`selected_export.export_all(family,complete_fit_path,role_blocks,output,root_validate,release)` expects the root-admitted Physics V5 Family with safe TRAIN/SELECT already loaded, training_only=false, exact ten cfg seeds and no active model. complete_fit_path is the core COMPLETE_FAMILY.json with its fixed50banks/80fits; source validates the full roster and original selected-state receipts. role_blocks all ten seed strings each exact{cal_ids,confirm_ids}: immutable absolute path/bytes/sha256 receipts.

Release fields: status="ROOT_SELECTED_EXPORT_ADMITTED",joined_selected_states90="ROOT_VERIFIED_COMPLETE",limits exact{wall_seconds,cuda_bytes,rss_bytes}. Root supplies a finite external watchdog. Callback `root_validate(family.cfg,action="fixed_Physics_selected_core_export",source_receipt=...,complete_fit_receipt=...,role_blocks=...,release=...)` must return custody status="ROOT_SELECTED_EXPORT_ADMITTED" and bind source/runtime/provider/prospective membership, all90 selected state closure and these80 core checkpoint receipts. There is no automatic admission based on a source seal.

For each paired block, activate its tiny safe TRAIN/SELECT arrays. For each fixed BASE/E4/N4/equipped_M1/equipped_I4 bank, construct original models with `f.make(seed,member,"baseline",True,members,architecture)`, restore strict model/optimizer/route streams from each pinned checkpoint, then use `f.logits` once per route over the34243unionCAL/CONFIRM IDs. Shared4 has one optimizer/checkpoint and four routes; I4 has four separate own models/checkpoints; M1 has one. The full graph remains complete. Actual inherited selected.pt key is `step`; the bank RESULT field is `selected_step` (V5 README used shorthand for checkpoint wording; this exporter reads the actual unchanged key).

Each `<ARM>_seed<seed>/selected_CAL.npz` and selected_CONFIRM.npz has exact{ids,member_log_probs,native_member_argmax,native_pool_argmax}: int64[rows],float32[M,rows,5],int64[M,rows],int64[rows]. M=4 except equipped_M1M=1. Native decisions are computed directly from float32 raw logits and their softmax probability mean before the common float64 calibration reader. No targets/errors/metrics are added. CAL150,CONFIRM34093. Original checkpoint/source files remain unchanged.

Return/write `COMPLETE_SELECTED_CORE_PREDICTIONS.json`:50records/80fits, each record{block,seed,arm,status="SELECTED_COMPLETE",members,fits:[{status,selected_state_receipt,costs,...}],selected_CAL_archive,selected_CONFIRM_archive,...}. Combine with native meanSAGE10records/10fits in root's complete60-bank/90-fit closure. All60 predictionbanks must close before CAL truth/temperature fitting, and all60 fixed temperatures before one scorer-only complete CONFIRM truth release.

No dataset/labels/tensors/predictions were read, numerical library imported, model executed, remote call made, test/fit/qualifier or reviewer launched here. Execution and common readout remain root responsibilities.
