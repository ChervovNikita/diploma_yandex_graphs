# Paid native acquisition and source label stages

This disabled packet ports four staged-posterior and five query/value-gate conditions onto newly acquired native Polynormer models. It uses all 20 WikiCS masks and all 10 Amazon Photo masks. These are development datasets already encountered in this research, not untouched confirmation data. Roman Empire, Amazon Ratings, Minesweeper, Questions and Tolokers are excluded for every method.

## Paid acquisitions and comparisons

Native M1, native independent four-member ensembles and actual original GNNM boundary R/S/B remain comparisons. Original GNNM has 126 new-data fits, including search; no original-paper experiment is rerun. Every native acquisition receives 5,000 full optimizer updates. Local training lasts 100 updates; the native source then restores its first best local SELECT model/Adam state while keeping end-local RNG and proceeds through its global branch. The source's two-view own-CE objective and private streams are retained. The standardized bridge performs streamed per-view reverses, rather than claiming bit equality with the historical public Session summed backward or published author CLI.

Native search uses two fresh seeds, nine declared points (three learning rates × three dropout triples), and split 0. M1 and original GNNM are selected separately. Two extra paid native search acquisitions per dataset then supply the label search captures. Comparative cohorts use three fresh seeds on every mask. Each cohort pays for M1 body 0, three additional independently initialized M1 bodies, and original GNNM. M1 body 0 is reused exactly in its genuine I4 bank.

## Label operators and ownership

The nine arms retain the exact source label operators: four posterior conditions (C4, nonlinear joint four-head single, four untied correctors on one shared frozen native capture, one path), and five matched receiver-gated conditions including permanent value-class erasure. The untied-corrector source uses CE/4; it is not four independent GNNs. Its four private Adam owners are all charged on every complete label cycle. Nonlinear joint readout has one active optimizer and one replaced, unstepped constructor object.

The native acquisition is completed and selected before one unscored active-head capture. Its detached H and native logits are reused by the nine declared arms in that exact mask/seed cohort. Label fitting has no native gradients or native optimizer updates, but its acquisition is not free. Every label fit starts fresh source maps/Adam and runs 5,000 complete old-state label cycles. Label learning rate is chosen independently from .0005, .001 and .002 on the two search seeds. No old checkpoint, outcome, teacher or historical fitted label state is inherited. Historical authorization remains unresolved and is excluded from new ancestry.

The source draws a uniform half-TRAIN query set and removes every query label from context. The training value correction (A−1)/(A−Q) is applied once; serving uses scale 1. The source bounded mixture uses native weight .2 and label weight .8, with its structural no-anchor fallback. The receiver gate is 2 sigmoid(A stopgrad(Hquery)+b), multiplying the source message. A and b start at zero. The erased condition removes visible value-class identity while preserving original CE targets.

## Provider and source adaptations

Hidden width 512, label width 64 and attention width 64 stay fixed. Photo's eight classes are bound explicitly in the original factory guard, gate helper CLASSES, and nonlinear posterior output/shape guard. The source mathematical operators remain unchanged. Source dependency resolvers point to hash-bound modules, without reopening historical release or checkpoint routes. The exact original public factor MANIFEST is included in source custody.

All model selections use first maximum SELECT accuracy, every update/cycle, with checkpoint 0 and early stopping disabled. Native capture reconstruction decodes SELECT labels through the adapter constructor but computes no SELECT metric; it never reads CAL/evaluate targets. Banks are exported with endpoint IDs only. A common scalar calibration is fitted after serving aggregation for 500 updates, followed by development evaluation after global closure gates. Native capture has its own phase and is excluded from the whole-search closure roster to avoid a dependency deadlock.

## Accounting and readiness

The finite packet has 1,444 model fit groups: 526 newly paid native bodies and 918 cached-native label fits. It charges 2,056 active optimizer owners, 10,280,000 model Adam calls, 24,340,000 source TRAIN forwards, 21,280,000 source TRAIN backwards, 204 unstepped replaced Adam constructor objects, 94 captures, 22 HPO selections and 1,080 exported/calibrated/evaluated banks. The 90 I4 banks reuse their exact M1 body 0. Scalar calibration adds 540,000 updates.

The engineering qualification uses synthetic CPU inputs only, denies every optimizer step, tests all 18 arm/class combinations and two source gate derivatives, and checks full engine state restore. Pure metadata tests verify masks, costs, source ancestry, reference matching, distinct I4 members and phase acyclicity. Actual controller ingestion verifies the disabled packet and actual custody/source hashes. GPU reservations, wall estimates and two-job memory feasibility are placeholders, not admission or an ETA. Resource qualification, host synchronization and human GO are still required before training.
