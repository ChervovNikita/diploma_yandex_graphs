# Recent shared graph ensembles: one bounded source update

11 October 2026. Three targeted official arXiv metadata searches, one new primary method scope, zero full-paper reads. Saved scopes were reused; blocked bodies were not retried. No dataset, prediction, model, fit, qualifier, reviewer, remote scientific execution, framework or manuscript was accessed/created. Physics/Penn protocols remain fixed.

## Result

The new source is [*Invariant-Based Weight Sharing for Message Passing*](https://arxiv.org/html/2605.25750v1), arXiv2605.25750v1, submitted 25 May 2026, introducing **ShareGNNs**. Venue/acceptance was not verified; call it a preprint. It supplies a relevant structural-conditioning principle, but **does not supply the requested persistent predictive ensemble**. Its parallel heads are representation heads combined into one predictor. This distinction prevents treating “shared” or “multi-head” as evidence of a four-member own-risk/probability-mean method.

The limited search did not identify a new exact deterministic persistent shared-weight graph committee with E's member-conditioned VALUE operation. This is a result of these queries/scopes, not absence-of-prior or novelty clearance. Saved Kim graph-BE, ECC/NNConv, FiLM, sheaf transport and ensemble ancestors remain material. Retrieved NodeNAS, EnMCS and other titles were metadata/abstract discovery only; none receives method credit here.

## Exact inspected ownership, objective and serving

| Item | ShareGNNs, inspected scope |
|---|---|
| Parameters | An unordered learned parameter pool per encoder/decoder layer. Ordered invariant triple tau(v,u)=(l(v),l(u),distance(v,u)) indexes one learned scalar omega_tau. Every pair with that triple reuses the scalar, including across graphs. Invalid signatures receive zero weight. Node-invariant labels also index learned bias/pooling vectors. |
| What “label” means | Atomic number, degree, WL hash or pattern-count hash: an invariant structural identifier. This is not the supervised target class of a node. |
| Message operation | Dynamically assemble a node-by-node matrix Theta(G) from that pool and apply a nonlinear Theta(G)X update (with the feature transform shown in its GCN comparison). Valid non-neighbor pairs may communicate. Ordered signatures permit directional weights. |
| Multiple heads | Each head has its own parameter pool and possibly its own invariant labeling function. Head representations are concatenated and combined by a feed-forward layer. There are no separate persistent class predictors with separate own selectors in this scope. |
| Objective/setup | The inspected classification-configuration paragraph uses graph-level cross-entropy, tanh, Adam, LR.01 on real datasets/.1 on synthetic,200 epochs and25 epochs without validation-accuracy improvement. There is no member-loss mean, committee-CE or ensemble regularizer. Main method only says ordinary backpropagation; an exact sum/mean reduction over examples was not independently audited. |
| Serving | Encoder layers followed by invariant-weighted graph pooling, producing one graph-level C-dimensional class vector. Multi-head representations merge before that output. There is no arithmetic average of separately served predictor probabilities. |

In the inspected real-data recipe, initial X is constant ones, biases start at zero and other weights at.001; the authors state input order is its only random factor. A separately described random-input variant adds Gaussian noise. Neither creates a bank of persistent ensemble members. Classification uses graph-level datasets; this is not an authenticated node-classification SAGE baseline.

## Structural signatures versus E's live endpoint states

ShareGNN conditioning is **fixed by the public input structure**. Pairs sharing an integer signature receive the same learned scalar even when their current node states differ. There is no generated per-member feature-coordinate matrix or learned member identity in this default operator. Parameter sharing means tying weights across structurally equivalent node pairs.

E conditions its two VALUE builders on the ordered **live hidden endpoint states of each private route**, then applies a small generated block matrix before the existing scalar SAGE mean. Hidden states and builder factors evolve during training, so the map can differ across edges and members even on one fixed support. E's native dense weights/builders are shared across predictors, with private fast factors and four continuing states; own route CE is averaged and probabilities are averaged only for selection/serving. Parameter sharing here also ties predictor weights, a different ownership axis.

These operations can be composed, but neither contains the other's whole current recipe automatically. ShareGNN's structural identifiers can expose degree/pattern distinctions that a particular learned h failed to retain. E's continuous state conditioner can distinguish messages that the same fixed structural signature groups together. Neither possibility diagnoses the current errors or guarantees better predictions. Conditioning messages on graph structure is now additional explicit 2026 ancestry, not a new novelty claim for E.

## Is there a defensible next ingredient?

**Conditionally yes: a small, frozen structural cue supplied to an existing endpoint conditioner is a defensible separate hypothesis after complete confirmation.** Ordered endpoint degree descriptors are an example of permitted graph-only input; no target label or fitted error enters it. On E's current adjacent-edge support, shortest-path distance is normally constant 1 (0 for self), so distance alone adds little information. A structural cue can test information retention without importing a new all-pairs backbone. Such a future operation is an adaptation of known structure-aware conditioning, not a ShareGNN reproduction or a new ensemble primitive.

Its decisive comparison would require the current state-only E, a receiver/common structural-cue control, and equally informed capable M1/genuineI4; a tied structural conditioner would address private builder ownership if that claim is pursued. Improved served rankings and member competence are required. If the receiver/common cue or single explains the gain, the narrower result is useful structural conditioning, not an ensemble-specific endpoint mechanism. A complete negative confirmation does not license a cue/label/invariant rescue grid.

The published all-pairs construction is not a defensible automatic drop-in for the current large node graph. The source charges pairwise-distance preprocessing O(n(n+e)) and pair-mapping O(n²) time/space; its own limitations acknowledge quadratic memory and domain-chosen invariants. Valid-signature cutoffs can reduce actual work but change the declared model. Extending support beyond the current 530417 Physics entries, replacing raw 8415 features by constant ones, or adding graph-level invariant pooling would alter information, task and costs. No such port or fit is proposed here.

These established alternatives make weight storage, own-member competence and actual shared-state computation separate comparison questions. PE's completed narrower-width result does not settle all three. E currently has supported development accuracy with weaker members and substantial edge-conditioned work; the literature provides no warrant to call it a general training/serving efficiency winner.

**Disposition:** stop at this one new method scope. Preserve E's attributed endpoint utility claim and the efficient-comparator boundaries. A bounded structural cue could become a later ingredient only under a new prospective question after complete confirmation; no current source, study, metric or fit is changed.
