## The C_mu law and mean interface

For each query, eta_i=2.5(s_i-6)+log(.1) is computed by the complete native
depth-zero scorer on every native residual counterpart. The density is

`p(z|C)=exp(sum_i eta_i z_i + g_C(K_L,K_R))/Z_C`.

The two-layer width64 slot map has input195: outer transformed slot feature,
counterpart feature, symmetric endpoint sum, native eta and a two-coordinate
left/right role. It is evaluated with original and exchanged roles. The
context has512 vector entries: endpoint sum/product, native common sum/mean,
and separate left/right slot-map sum/mean. Eight visible scalars are appended:
log-degree sum, absolute log-degree difference, log common size, log left
size, log right size, log total size, mean sigmoid(eta) and mean sigmoid(eta)^2.
Empty sums/means are zero. Degrees/supports are from the permitted masked
graph before encoder edge dropout.

For every feasible(k,l), ten hypothetical features are appended: normalized
k,l; log1p(k),log1p(l),log1p(n_L-k),log1p(n_R-l); and the four zero/full
indicators. A shared530→64 ReLU→1 head evaluates all pairs. Its original and
side-exchanged evaluations are averaged to make the potential exactly
endpoint/side-exchange symmetric. This full nonlinear two-sided head adapts
the existing memo's context specification; it is not an unrestricted table
and does not exhaust arbitrary same-count spatial dependencies.

The FP64 log ESP recursion retains reachable states only. All count pairs
enter logsumexp of `log A_L(k)+log A_R(l)+g_C(k,l)`. The exact auxiliary is
`(log Z_C - sum eta_i Z_i - g_C(K_L(Z),K_R(Z)))/(n_L+n_R)`, with an exact
zero for empty support. Separate positive/negative **all-query** means and
lambda1 preserve the original reduction. Query NLL uses nonreentrant
checkpoint recomputation, so it retains neural context/eta but not every
query's DP/potential table for auxiliary backward. Higher derivatives are
not claimed; first-order numerical qualification remains pending.

For completion, a detached full count-pair probability is obtained from that
same law. Its left/right count marginal probabilities seed independent ESP
reverse passes to obtain every unary mu_i=E[Z_i|fixed C]. Eta and g are treated
as independent, detached density inputs for this readout. **The neural context
and potential stay fixed**; differentiating log Z through g(eta) would add an
unwanted context derivative and would not compute mu. The density-training
gradient does differentiate through the learned context, as required.

Native common neighbors retain weight1; every residual slot gets detached
`1.05*mu_i`. One live outer native feature route and one nonlinear decode
produce the target logit. This is `D(E[Z])`, not `E[D(Z)]`; there are no latent
draws and no decoder-expectation claim. It deliberately adapts the memo's
four-draw target interface to the pooled mean-completion question. The full
correlated law is trained even though serving exposes its unary marginals.
