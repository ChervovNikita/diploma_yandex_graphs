# Independent assessment: graph-conditioned mixing of member hidden states

7 October 2026. Idea/literature assessment only; no manuscript-review or acceptance verdict. No model implementation, training, graph data, checkpoints, experimental outcomes, private server access, root ledger/status, or earlier proposal/artifact modification. Fresh public literature retrieval and bounded method-source inspection are recorded separately.

**Finding:** the sketch is a reasonable adaptation of intermediate feature sharing, but the general operation is established. Cross-stitch, NDDR, deep fusion, input-dependent head interaction and layerwise graph mixtures cover its central ingredients. Keeping four reciprocal BE streams with individual supervision is an explicit implementation difference from the inspected graph mixtures, not a demonstrated novel principle. Escaping a final convex-pooling barrier is mathematically possible and supplies no accuracy guarantee.

## What the sketch actually computes

Let A(v) have nonnegative rows summing to one and g_m(v) lie in [0,1]. The proposed update is

```text
h'_m(v) = sum_k B_mk(v) h_k(v)
B_mk(v) = (1-g_m(v))*1[k=m] + g_m(v)*A_mk(v).
```

It is a node-dependent cross-stitch matrix with a residual identity component. Constant B is cross-stitch-like feature sharing; arbitrary fixed channel transformations include the broader NDDR family. Dynamic B cannot generally be absorbed into one fixed linear layer, but attention and intermediate routing already implement dynamic mixtures. Including m among the attention sources creates redundant identity mass: the effective foreign-state fraction is `g_m*(1-A_mm)`, so reported g alone does not measure exchange.

Viewed on states indexed by (graph node v, member m), this is attention over same-node edges between member copies, followed by ordinary graph edges within each copy. The expanded computational graph is a coupled, wider message-passing network. Four terminal predictions and private factors can be retained, but their errors and gradients become coupled; independent ensemble-member interpretations do not follow.

## The common-wrong-class barrier and the required placement

For a fixed node and true class y, if some competitor k satisfies `p_m(k)>p_m(y)` for every member, every nonnegative weighted average of those probabilities also prefers k. Input-dependent weights do not change this pointwise fact. The analogous statement holds for convex averages of existing logits.

Convex hidden mixing followed by the **same pointwise affine readout** also cannot repair a shared wrong-class logit margin: `W*sum_k B_mk*h_k+c = sum_k B_mk*(W*h_k+c)`. Calling the operation intermediate does not suffice when the remaining computation is this shared pointwise affine map. Spatially constant member mixing also commutes with a common linear graph operator.

Mixing **before a remaining nonlinear block** removes that algebraic constraint. A toy shared wrong-minus-truth margin `f(h)=ReLU(h)+ReLU(-h)-.5` is positive at hidden states +1 and -1, but negative at their mean 0. Both unmixed paths are wrong and the fused state is correct. This is an existence example with no graph and no accuracy implication, and is already consistent with prior feature-fusion methods. For a common pointwise downstream map, staying inside the same affine region preserves the barrier. Nonlinearity permits escape; its mere presence does not guarantee escape.

**A remaining graph message step supplies another route, even if it is linear.** If B varies by node, mixing and graph propagation need not commute:

```text
(P B H)_m(v) = sum_u P_vu sum_k B_mk(u) h_k(u)
(B P H)_m(v) = sum_k B_mk(v) sum_u P_vu h_k(u).
```

There is generally no single convex coefficient vector on whole-member final predictions for the first expression. With two incoming neighbors, member contributions (2,-1) and (-1,2) each sum to wrong-minus-truth margin +1. Selecting the -1 contribution from each neighbor before summation yields margin -2. Thus node-dependent exchange before propagation can escape the barrier without requiring a downstream activation. This is a capacity/example result; it does not establish that a learnable gate will identify useful contributions. Dynamic graph evidence selection itself has close GAT/GMoE ancestry.

For the supplied native Polynormer structure, one precise location is **on recurrent x immediately after block 1 accumulates its output into x_local, before block 2 begins**. The accumulated first-block contribution is the original member state; block 2's `h_lins`, `GATConv` and `lins` all receive the exchanged recurrent state. Subsequent accumulated contributions derive from that state. The following ReLU, neighbor-dependent attention and `LayerNorm(h*x)` product remain downstream. This fixes the otherwise ambiguous treatment of the native skip accumulator and places exchange before another local message computation. It can recombine donor features and neighbor responses before the next prediction exists. It is a placement description, not an implementation qualification or selected experimental recipe.

There is an important private-readout exception: BE factors can make effective affine heads different even with shared dense weights. Then late hidden mixing can already escape the barrier by applying one member's readout to another's state. For instance, states (1,0)/(0,1) and wrong-minus-truth heads (1,-2)/(-2,1) give each own path margin +1, but both heads give margin -.5 on the mean state. This is readout recombination, not evidence that graph-dependent nonlinear composition was required. A graph-mechanism claim must distinguish it.

## One falsifiable distinction worth retaining

The narrow hypothesis is: **node-dependent recipient exchange before another graph propagation step usefully recombines different donor information at different neighbors, beyond static cross-stitch or the same exchange applied after propagation.** The precise structural distinction is the noncommutativity above: for a common frozen linear P, constant B commutes, whereas node-dependent B generally does not. This supplies a falsifiable placement/mechanism distinction without declaring a novel fusion principle. Define “graph-conditioned” explicitly: existing hidden states already contain graph information. If the gate additionally uses a label-blind neighbor summary, specify that summary and exclude node IDs or stored labels; otherwise the claimed conditioning is hidden-state attention.

A direct mechanism diagnostic freezes one trained state, blocks exchange to obtain four counterfactual terminal predictions, and asks whether enabling exchange repairs nodes with a common wrong competitor in all four blocked predictions. Such repairs establish escape from convex aggregation of those particular counterfactual outputs. They do not establish a gain over independently trained references: blocking exchange after training can make the counterfactual bank incompetent. The decisive serving quantity is clean full-population net repairs minus new errors, with pool NLL and mean/worst-member competence.

For that placement claim, retain static cross-stitch as the closest operational reference and compare exchange before versus after propagation using the same precomputed gate values in a frozen-state mechanism diagnostic. A common frozen linear propagation subcase isolates the commutator; native attention/nonlinear blocks introduce additional effects and need separate interpretation. If the effective B is constant, the isolated commutator is zero, or late readout recombination explains the repairs, reject the proposed neighborwise-composition explanation. Claiming an additional neighborhood-summary benefit also requires a same-node-state-only gate control. These are claim-identifying controls, not an admitted compute grid or a claim that the method will help.

## Concrete risks before any expensive evaluation

If four hidden states are identical, any row-stochastic mixture returns the same state. The exchange-direction gradient is zero; with exact g=0, attention parameters receive zero task gradient even when states differ. Unit private factors, identical stochastic views and symmetric optimization can therefore make the module inert. Near-identity initialization limits disruption but neither creates complementary information nor protects competence.

Own supervision does not stop homogenization or donor domination. With ordinary backpropagation, each member's loss also trains other members through exchanged states. Repeated mixing can contract differences, and private factors can subsequently restore them; neither outcome should be assumed. Coordinate alignment, norm/sign differences, effective foreign mass, member responses and gate dependence on real neighborhood information require diagnostics. A richer gate can improve capacity or optimization without supporting an ensemble-specific explanation.

**Disposition:** reject novelty of the broad intermediate adaptive-mixing operation. Keep only the explicit same-task/shared-BE reciprocal-stream adaptation and the falsifiable neighborhood-composition hypothesis as unestablished possibilities. The sources support a mathematical route beyond final convex prediction averaging, not a forecast of accuracy gain or a new ensemble framework.
