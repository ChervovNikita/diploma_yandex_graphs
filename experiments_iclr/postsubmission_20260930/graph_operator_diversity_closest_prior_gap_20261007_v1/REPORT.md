## Can private affine factors change neighbor dependence?

Write a feature map as `A_m = diag(r_m) W diag(s_m)` (up to row/column convention). For a **fixed linear** graph operator P, feature scaling commutes with propagation: `P(H diag(r_m)) = (PH) diag(r_m)`. A depth-L **single linear chain** has the form `P^L X B_m`. Members select feature directions but cannot change that path's P^L spatial coefficients or recover a signal in `ker(P^L)`. With scalar input/output, the path's neighbor Jacobians are proportional to the same P^L row. Final-head-only factors cannot recover evidence erased by every retained upstream path.

This restriction is **not a theorem about a residual/root-plus-neighbor GNN**. Its linear expansion can be `Σ_k P^k X B_m,k`: private root and neighbor transforms change hop weighting, and a retained raw/root path can preserve information lost by P. Even `h_m=a_m Px+b_m x` gives different root-versus-neighbor reliance without nonlinear gates. Fixed per-layer P therefore does not universally imply identical end-to-end graph dependence. The actual factor placement, skip paths and state-sharing rule were supplied only at a high level and were not source-audited here.

A nonlinear private path is different. Its Jacobian contains node-dependent activation derivatives between propagations. In vectorized form, a layer contributes `D_m,l (A_m,l^T ⊗ P)`; the diagonal gate D varies across nodes and members and generally does not commute with P. Input factors can change preactivation signs through common feature mixing; nonlinear gates can therefore change actual evidence dependence. Private biases, GELU, normalization and residual branches add other effects. Conversely, positive homogeneous rescaling, normalization cancellation or equal gate patterns can leave dependence effectively unchanged. Shared W also learns from the sum of member/auxiliary gradients, so own-member label losses do not mean independently learned shared features. Neither universal collapse nor useful specialization follows.

**A simple representability witness, derived here:** two neighbors have `x_a=(1,0)` and `x_b=(0,1)`. Before neighbor pooling use common `w=(1,1)`, ReLU, and private input factors `r_1=(1,−1)`, `r_2=(−1,1)`. Member 1 passes a and suppresses b; member 2 does the reverse. With `q_va=q_vb=1/2`, both pooled features equal 1/2, and the same class margin `h−1/4` predicts the same positive class. Transferring edge mass by `q_va=1/2+δ`, `q_vb=1/2−δ` produces margins with opposite derivatives, +1 and −1. Thus private factors can change neighbor evidence while preserving the base prediction. If common pooling happens before this private nonlinear map, the same construction loses that distinction. This is an algebraic existence example, **not an executed model, training result, exact normalized GNNM witness or guarantee**. Actual normalization and factor placement must be audited before transferring it.

For attention, private Q/K modulation can change `softmax(Q_m K_m^T)` when scores are recomputed per member. Value-only factors with common Q/K cannot change the current attention weights, though they can affect later layers. Q/K inverse rescaling, softmax row shifts and output compensation can leave predictions invariant. A diversity statistic on factors, hidden vectors or attention maps alone cannot establish different useful evidence.

## One falsifiable gap and the next action

Keep **`init+contrast` versus `init`** as the primary pilot, with the specified single, ordinary independent and packed untied controls. Add one prospectively fixed diagnostic to those existing arms: on a fixed permitted development node set and label-free list of incident-edge/neighbor-feature interventions, measure finite changes in **class log-odds** `z_m,y−z_m,c` or log-probabilities. Normalize adjacency consistently after each edge intervention. Use the same interventions, scales, RNG/view streams and pooling contract across arms; retain response magnitudes and a numerical floor before comparing angles. A row-mass-transfer probe, as in the witness, removes the simple confound of different total neighbor mass. Charge all probe forward passes. No probe or fit was executed here.

Measure response shape beyond a single per-member amplitude: subtract each node/probe's across-member mean response, report the residual response Gram/effective rank, and compare whether a least-squares scalar rescaling of the init response explains the contrast-arm response. For an attention backbone, separately record member attention weights under the same intervention; weights and final margin responses can disagree. Also report class/difficulty-stratified member losses, exact paired errors and the served pool's NLL/accuracy. Class strata and intervention selection must be fixed before outcomes; development labels score the diagnostic rather than select favorable neighbors or augmentations.

**The gap is supported only if** the contrast package changes graph-evidence response shapes beyond scaling/precision noise and the declared pool improves under the predeclared pilot criterion against init and competent controls. A rising residual distance with unchanged margin responses supports the nuisance-coordinate explanation. Different responses with a weaker pool falsify useful complementarity in this pilot. A pool gain with unchanged response shapes leaves another explanation, such as ordinary view regularization or changed optimization, open. If the contrast package includes both view alignment and cross-member residual contrast, the primary comparison cannot assign its gain to residual repulsion alone; one alignment-only ablation is the specific attribution control if that attribution is later needed. No coefficient grid is suggested.

A controlled synthetic witness would strengthen mechanism identification: generate two independently sufficient graph evidence channels for the same label, randomize which channel is corrupted across samples, and hold graph support/noise/capacity fixed across the stated arms. The relevant outcome is recovery from complementary evidence plus pooled utility, not planted-channel embedding distance. A synthetic result establishes that mechanism in its generating task; it cannot certify real-graph causal sufficiency or novelty. This witness is a prospective specification, not a request to create or train data/models now.

## One distinct extension if the factor-only mechanism fails

If the diagnostic shows that the private factors cannot alter useful graph dependence, place private capacity **on graph coefficients before the contested common pooling**. A small controlled version uses fixed label-free edge descriptors φ_vu and private coefficients β_m. Let `g_m,vu=tanh(β_m^T φ_vu)`, `μ_m,v=Σ_u P_vu g_m,vu`, and

`P_m,vu = P_vu [1 + ρ(g_m,vu−μ_m,v)]`, with row-stochastic P and fixed `0≤ρ≤1/2`.

Each P_m keeps the original graph support, nonnegative weights and row sum 1; ρ=0 exactly recovers the fixed operator. This changes evidence allocation rather than separating an arbitrary hidden coordinate. Learn the private β and shared feature matrices together under the same own-label losses; the current contrast package can be retained initially to isolate the operator capacity change. Compare against shared β and the same-operation untied control before attributing a benefit to member-specific coefficients. Private scores/propagations and gradients remain paid work. If the current backbone already has recomputed private attention, this is largely a constrained attention parameterization and may add no distinct capacity.

This is a genuinely different intervention from class-centered residual contrast **within the current model**, not a new graph operation claim. Learned graph filters, attention diversity, SuGAr edge-weight diversity and DIVE masks require credit. Its worthwhile question is whether this tightly constrained graph-side capacity repairs a demonstrated restriction at a smaller total cost than the competent untied ensemble. No second generic diversity loss, teacher/student stage, router, RL layer or broader sweep is justified by the present evidence.
