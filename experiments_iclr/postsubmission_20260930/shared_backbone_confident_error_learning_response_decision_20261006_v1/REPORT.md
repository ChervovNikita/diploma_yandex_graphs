## Can a shared GNN correct a common confident mistake?

It can in principle, if permitted labels and the actual private/shared update path can move the relevant true-versus-competitor margins. A unanimous wrong prediction does not imply identical private learning derivatives. In this architecture the private stem acts before native propagation, so an impossibility theorem for heads on one fixed shared embedding cannot simply be imported.

Two limits are decisive. First, if every member gives the same wrong class a larger probability than the true class, every nonnegative scalar-weighted probability pool retains that ordering. Learning must change predictions or supply a different predictor; confidence weighting alone cannot repair this case. Second, if all information available to every private path erases the distinction needed by the target, no downstream learner can recover it. Saved representation-game/adapter conclusions distinguish that information loss from insufficient private capacity or a short update budget; neither failure is established by correlated mistakes alone.

The response rule also needs productive member heterogeneity. Identical item-wise response costs across members center to zero. Uniform Q then remains a fixed point of the original balanced entropy/Laplacian solver in real arithmetic. The all-member own-CE anchor can still correct a mistake, but there is no adaptive specialist allocation in that case. Differing costs or balanced assignments alone do not establish useful correction: response is measured on S, shared credit uses R, and complete served generalization remains a separate question.

Private learning response is therefore a plausible measurement for *which member's declared update helps*, not an intrinsic capacity certificate independent of parameterization/optimizer. The Euclidean private coordinates, step, graph, supervision and query objective must stay matched. A fixed own-CE anchor helps define competence but does not guarantee it after finite optimization.
