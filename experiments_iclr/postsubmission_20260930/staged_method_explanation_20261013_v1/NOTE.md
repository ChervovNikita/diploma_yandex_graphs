These are finite candidate procedures, controls and diagnostics, not established improvements. The actual v29 configuration records were read from the disabled, hash-bound master. No training, tensor scoring, new resource probe or 18.77 operation was performed for this note. Original-paper experiments remain excluded; original GNNM is a comparison on new data.

The common purpose is prediction quality: give routes useful differences while keeping a substantial computation or representation shared. The candidates below achieve this in different places—hidden-state processing, private gradient credit, initialization, label-based correction, or final aggregation. They are not interchangeable names for one architecture.

A *paid source* is a newly trained native model whose own selected checkpoint is an explicit dependency. A continuation cannot begin with fabricated features or a historical model: it restores that exact source and records its cost. A genuine independent ensemble has four separately trained, optimized and selected bodies; four routes or four correctors on one frozen representation are not counted as four independent GNNs.

## 1. Retained propagation/transformation histories (P/T)

**Idea.** Ordinary message passing alternates neighbourhood propagation and feature transformation. This continuation lets each route mix four two-operation histories: propagate twice, propagate then transform, transform then propagate, and transform twice. It tests whether keeping different intermediate histories helps more than simply perturbing the final classifier.

**Architecture and ownership.** A selected two-layer meanSAGE model supplies a frozen width-32 first-layer representation. Two fresh continuation blocks contain distinct learned maps for the four operation histories and a gate conditioned on the current representation and its one/two-hop changes. The maps and final native head are shared. In `private4`, each route has its own gate offsets: 32 trainable coordinates across two blocks, four routes and four choices. A residual readout starts at zero and has fixed scale 0.25, so the candidate initially preserves its acquired representation/head prediction. `middle_state_mean` averages the first-block states before the second block; it deliberately removes the individual histories at that point.

**Controls and their purpose.** `head_only` isolates gains from continuing the classifier. `mixed_single` has the same operation menu without four private histories. `bias_coordinate_single` uses redundant coordinates whose mean starts as the same single-state gate: it checks whether parameterization/optimizer geometry, rather than route diversity, explains a result. Genuine mixed-single and bias-coordinate I4 banks use four own source/continuation bodies. `separable4` shares one frozen stem but gives four branches disjoint continuation/head maps, checking whether much more private capacity is necessary. Full-native ordinary/factorized continuations keep the entire acquired native model trainable for the second stage; they address the extra training opportunity of a two-stage candidate. They do not match FLOPs or every parameter count.

## 2. Private recurrent graph memory (GRU)

**Idea.** A node's immediate neighbourhood representation may omit how information is arranged across the graph. Graph tours give a recurrent module a longer ordered context, while four persistent tours give routes different contexts without four full native backbones.

**Architecture and ownership.** An acquired width-32 meanSAGE model provides frozen first-layer slow maps; its tail stays live. Four graph-only randomized DFS forest tours include every node and every arrival/return occurrence. A reset-after GRU processes both directions of each component, averages directional states and then all occurrences of each node. There is no truncation. `GM4` shares the slow recurrent matrices but learns four private factor/bias rows. `GN4` instead puts private factors/offsets in the native maps and shares ordinary memory; its first hidden paths stay live rather than using the fixed cache. The GRU's output readout starts at zero, residual scale is 0.25, fast factors start at one, and the input update-gate bias is increased by log(99). These choices preserve the acquired predictor at initialization and make the memory update initially conservative.

**Controls.** `B4`: four no-memory tail views. `G1`: ordinary memory tied across tours. `GF1`: one factorized memory. They separate memory, factorization and private-route effects. `GI16` and `GFI16` are four independent complete G1/GF1 learners, each with four tours, serving 16 predictions; this checks whether a shared four-route method can compete with real source diversity. Full-native P1/F1 continuations match the two-stage optimizer opportunity. GM4 and GN4 have different private capacities, so they cannot isolate placement alone.

**Actual plan.** The same WikiCS20/Photo10 masks, LR/dropout nine-point domain and 5,000 + 5,000 AdamW recipe as P/T. Training streams four own CE/4 backwards, followed by the native first-layer penalty (coefficient 0.05) and one optimizer update. Serving averages probabilities. Total: 3,014 fit groups: 1,052 source acquisitions and 1,962 continuations. Tour construction is graph-only; derived hidden features require the paid source. ## 4. Graph-informed private-head initialization with finite TRAIN trials

**Idea.** Instead of random route separation, choose small initial private-head directions from graph-structured training errors. The design tests whether a useful direction matters beyond arbitrary diversity of the same initial magnitude.

**Procedure.** On Amazon Photo, a native Polynormer-r source performs 200 local updates, restores its earliest best local model **and named Adam state** by pooled SELECT NLL, and performs 50 global updates. That fixed-last 250-update warm checkpoint is paid once per applicable source block. A common descent move supplies a shared head center. Cubic graph filters split TRAIN classification error into four components; vector–Jacobian products translate these components into private-head directions. The bank is centered and projected away from the ordinary common gradient, with a fixed deterministic rank/sign rule. Three direction pairs are considered. One common plus at most nine discarded one-Adam-step TRAIN trials select among graph, node-permuted and random spans. Only **pretrial** states are returned; discarded trial optimization is charged and does not give a candidate a secretly trained initialization.

`common_only` isolates ordinary common descent. `fixed_first_graph_pair` tests the benefit of selection. `selected_permuted_span` disrupts graph alignment while retaining the selection procedure. `selected_random_span` tests unstructured directions. Matching preserves the initial mean logits and a prescribed disagreement magnitude; no general second-order optimality or Hessian theorem is claimed. The actual continued model has all live shared/private parameters trainable; the head is not permanently frozen.

**Actual plan.** Five candidate arms continue for 4,750 updates. Cold native M1/I4 and original GNNM pay 5,000 updates (200 local + 4,800 global). ## 5. Label-only posterior correction and receiver value gates

**Idea.** An acquired backbone may produce useful embeddings but miss local label information. A separate corrector learns to use visible TRAIN labels, conditioned on node embeddings, without changing the backbone. This is a quality diagnostic/extension of a learned shared representation, not backbone distillation.

**Ownership and controls.** A newly trained/selected native Polynormer is captured once as detached hidden vectors (width 512) and native logits. Four private BatchEnsemble correctors (`C4`) share that frozen capture. A nonlinear joint four-head single predictor tests whether four branches are necessary rather than a larger joint readout. Four fully untied correctors on the same capture test private capacity; they have four optimizers but are **not** an independent GNN ensemble. One-path correction is the basic single-route control. Every label width and attention width is 64.

Five matched gate variants multiply label messages by `2 sigmoid(A·stopgrad(H_query)+b)`, starting at exactly 1 because A and b are zero. The class-identity-erased variant removes class information in visible values while keeping original supervised targets; it tests whether a gain actually relies on informative labels. Each update uniformly hides half the TRAIN nodes' labels, excludes all query labels from context, and applies the declared visibility correction once. Serving combines native and label probabilities with fixed weights 0.2/0.8 and retains the no-anchor native fallback. No CAL or evaluation labels enter correction fitting.

**Actual plan.** WikiCS20/Photo10. Native acquisition: 5,000 updates with depth 7/width 512, source local stage of 100 updates followed by global training. Native HPO: LR {0.0005, 0.001, 0.002} × (input/local/global dropout) {(0.5,0.5,0.5), (0.5,0.3,0.5), (0.5,0.5,0.3)}. Each corrector performs 5,000 complete label cycles; label LR independently chosen from {0.0005, 0.001, 0.002}. Two search seeds, three comparative seeds; own earliest SELECT-accuracy maximum among positive updates, no early stop. Total: 1,444 fit groups: 526 new native acquisitions + 918 label fits; 94 exact native captures are reused within declared cohorts. Four untied correctors pay four optimizer maps per cycle; the complete accounting is 2,056 active optimizer starts and 10,280,000 Adam calls.

## 7. Frozen-feature refits and learned final aggregation

These source-specific studies distinguish a representation problem from a weak final head or poor aggregation. They use current WikiCS mask 0 and three fresh seeds; they do not expand their conclusions to all masks by assumption. All native donors are paid and selected before postfit work starts. Backbones and feature banks are then frozen.

### Direct head refit

A native Polynormer single, its true I4, a unit-factor contrastive BE model and original GNNM are trained for 1,100 updates. On acquired width-512 hidden vectors, `BE_factor_refit` keeps the shared-W/R/S affine parameterization; `BE_full_refit` gives the same BE representations separate full affine matrices. Ordinary I4 and single full refits receive the same solver. This tests whether shared head capacity/conditioning accounts for inferior individual members while retaining their actual representations. TRAIN-only RMS scaling preserves the initial effective logits, and the L2 penalty acts on class-centered effective matrices, coefficient 0.001/2.

Each refit is one float64 CPU LBFGS trajectory: LR 1, history 10, strong-Wolfe search, max 1,000 internal iterations and max 50,000 evaluations, gradient tolerance 1e-6, change tolerance 0. That one trajectory is not one ordinary SGD update. The plan has 30 groups: 18 native acquisitions + 12 refits.

### Affine capacity control

Width-128, depth-2 SAGE E4/equipped M1/I4 sources use LR 0.001, dropout 0.2, AdamW weight decay 0. A shared affine residual and private per-route affine residual start at zero, leaving native predictions exactly unchanged. BE-head continuation trains the original factorized head and subtracts a fixed copy; the other residual controls freeze the original head. This compares more head capacity with continuation of the same head, including equally processed M1/I4 references.

Native and head fits each have cap 1,000, patience 300, minimum 301 and positive first-best SELECT accuracy. Total 51 groups: 18 donors + 33 fresh head fits; I4 member-0 heads are reused exactly, not refit twice.

### Learned reliability aggregation

GCN, GAT and SAGE width128/depth2 sources compare ordinary M1/I4, all-map-factorized M1/I4, shared4 and original GNNM. A 56-parameter scorer sees each route's entropy, top-two margin, agreement with other routes, agreement with its neighbouring nodes' predictions, and agreement with neighbours of its peers. It outputs soft weights over already-computed routes and pools probabilities; all routes still execute. The scorer has no node/member/class identity input. `reliability_self` substitutes the node probabilities for neighbour context, isolating graph context. Global/member temperature and linear stacking are calibration/capacity controls; M1 reliability has no weighting effect and is an explicit no-fit alias.

The SELECT nodes are assigned five fixed folds (seed 11709). Each operator is trained on four folds for exactly 500 float64 Adam updates, LR 0.01, then serves its held fold without epoch selection. Unseen query IDs get a predetermined fold assignment. Reliability penalizes deviation from uniform weights with coefficient 0.01; stacking has fixed 0.01 mean-square shrinkage. Native source cap1,000/patience300; operator fixed500. Total: 1,170 groups: 90 native acquisitions + 1,080 fold operators. Original GNNM receives the same learned-serving extensions, as well as its uniform reference. This prevents attributing generic post-processing gains specifically to GNNM.

## 8. Structural and count-conditioned link prediction

### Shared structural interaction

On CiteSeer HeaRT, a shared NCN/pureGCN backbone (hidden256, one encoder layer) normally summarizes common-neighbour features. This extension also enumerates actual edges **between** common neighbours. A shared symmetric MLP (768→64→32) builds a message from two witness embeddings and the query endpoints. Each route has a private structural gate and readout; both begin at zero, so the added residual initially vanishes. Its base private factor/normalization parameters remain present. All backbone/message/private coordinates train jointly.

`structural_tied` ties new gate/readout rows. `informed_single` and `informed_independent4` give the same structural information to competent single/independent references. `structure_blind` uses every unordered common-neighbour pair without checking its edge; `count_only` uses five classical count features instead of learned pair embeddings. They separate private sharing, extra information, actual adjacency and scalar counts; equal nominal parameters do not imply equal effective capacity or compute. Fresh native single/I4 and original GNNM references are paid separately.

Three paired seeds, no HPO: 18 source cells + 15 fresh reference fits = 33 groups. ### Cardinality-aware completion (C64)

On ogbl-collab, one native NCNC width64/depth1 encoder/scorer predicts which residual neighbours might complete a query's common-neighbour pattern. A small learned count head (270→16→16→1; 4,625 parameters) predicts a law over **all possible counts**. Given a count, a finite-support distribution selects a set of neighbours, rather than treating each completion independently. Four sampled patterns are decoded nonlinearly and their raw scores averaged (`D4`). `M4` instead uses independent Bernoulli completion from the same acquired/selected state and same random-key family. M4 has no separate training/selection: it diagnoses the completion law on the D4-selected model, not an independent benchmark.

The count head and encoder/scorer train jointly. Its supervision is complete TRAIN-edge membership, never unknown future links; the query-record batch is removed before support coalescing. Count likelihood coefficient1 is added to source link BCE. Neural computation is float32; full count dynamic programming is float64, without a hidden support cap or fallback. Three paired seeds, fixed100 epochs, 17 complete minibatches of65536/epoch (source tail drop64940), evaluation batches131072; encoder LR0.0082, decoder/count LR0.0037, Adam weight decay0. ### Count-conditioned pattern learning

`J_K`, `J_K_sep` and `W_K` retain native private pattern completion and mean-raw-logit serving. They change an auxiliary training objective: given the observed TRAIN count, learn which residual neighbour subset is present. `J_K` models left/right subsets jointly with one shared route-mixture responsibility; `J_K_sep` mixes each side separately; `W_K` averages each route's conditional negative log-likelihood, encouraging every route to fit the observation. These comparisons test whether coherent route responsibility helps, rather than merely increasing embedding distances. Teacher counts are auxiliary TRAIN information only and are unavailable to serving. The native main BCE plus auxiliary coefficient1 train all live model parts; checkpointed autograd does not change the architecture or loss.

The same fixed100/17-batch/LR/source-selection recipe applies. Nine conditional fits (three objectives × three seeds) and three D4 fits share 15 newly paid native/original references, giving 27 total groups. The bucketed exact conditional-law implementation is a computationally equivalent alias, not another scientific hypothesis or extra fit.
