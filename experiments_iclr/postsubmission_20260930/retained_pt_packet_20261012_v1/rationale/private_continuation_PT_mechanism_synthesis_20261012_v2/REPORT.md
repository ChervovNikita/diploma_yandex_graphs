## What the actual source changes

Core v2 creates four deterministic continuing states from the same frozen H0, using a common operator bank in each block. Each transform role is physically tied across routes; PT, TP, TT1 and TT2 have **distinct** maps, and blocks are distinct. The common gate is evaluated on each route's current `[H,|PH−H|,|P²H−H|]`; only its four-coordinate e per route/block is private. This is not four freely parameterized node controllers.

After block one, the private states enter their own block-two operator/context computation. The matched middle-state control broadcasts their mean instead, retaining private block-two e, four complete own losses and four final predictions. This removes first-block history while also changing training gradients and reusable computation. The source's common residual/readout and native decoder are unchanged.

**Conditional mechanism:** different paths can retain several class-relevant feature/neighborhood cues until a later nonlinear update, whereas one d-dimensional mixed state may compress those cues too early. The updated route states can then change both the evidence transformed/propagated and the next operation weights. Mean own CE can encourage each resulting prediction to remain competent. None of these ingredients guarantees complementary decisions: an ordinary full-operator single may learn a sufficient representation, shared maps may restrict specialization, and own losses can drive every route toward the same solution.

## The graph-specific distinction and its qualifier

For the **same** affine T with no active ReLU/clip, row-stochastic P gives `P(HW+b)=(PH)W+b` in exact algebra. Nonlinear T generally breaks this equality: transforming each neighbor before averaging can retain an activated cue that transforming the neighbor mean handles differently; row clipping adds another state-dependent scale. However, native `F_PT` and `F_TP` use different W/b. Their observed disagreement therefore combines **map choice and placement**. It is not an isolated noncommutation measurement. Commuting P/T also does not force the whole bank to collapse: different roles and route-dependent path combinations can remain.

Node-dependent mixing creates another ordinary graph effect. For a node gate Γ and state Z,

`[P(ΓZ)−ΓPZ]_v=sum_u P_vu(Γ_u−Γ_v)Z_u`.

Routing can therefore determine which source-node feature reaches a recipient before its next graph update. A capable one-state mixture already has this effect. The candidate's narrower distinction is that several recipient histories persist through it. The operations use the inherited graph and feature information; they do not create observations or learn new support. This is a structured wider network, not a new ensemble expressivity principle.

## Limits over the strong references

| Reference or limit | Consequence |
| --- | --- |
| Full-operator one-state single | Same information, P/T choices and repeated context routing. Any gain may reflect retained state capacity, optimization or own supervision; a finite-width bottleneck is a hypothesis, not an observed source defect. |
| Bias-coordinate single/I4 | Extra e coordinates can change optimization while leaving the single's function class unchanged. Core v2 includes this adopted reference; beating the original single alone cannot identify continuation utility. |
| Equally equipped I4 | With a common permissible ancestor, independent bodies can copy the candidate maps/head and absorb each route's e into their final gate biases. Tying cannot enlarge that unrestricted architecture family. Actual I4 has independently selected ancestors/caches; this argument guarantees neither a matching acquired predictor nor training success. Candidate utility must be demonstrated against those complete fitted procedures, with their costs. |
| Identical effective route gates/states | The deterministic continuation collapses to one mixed predictor; four tail TRAIN draws do not create four eval functions. Different gates can also produce equal states when operators agree. |
| Different latent states | They can lie in Wo's nullspace or leave all served decisions unchanged. At Wo0 all predictions remain source-contained despite initialized route differences. Hidden distance, operation disagreement and gate entropy are insufficient. |

The four e rows decompose into a common effective bias and route contrasts; common bias can be transferred between beta2/e without changing gates. The shared objective couples every map update. Four states are thus neither independently acquired evidence nor four independent training samples. P/T sharing can amortize parameters and impose a useful constraint, but extra propagated states/tapes remain paid work. Zero Wo protects the initial function only; it supplies no later correctness guarantee. The saved staged gradient path remains: upstream memory is delayed at update one, first gate maps ordinarily until update three.
