## Fixed family

The prospective root amendment `PILOT_AMENDMENT_ROOT_before_fits_v2.json` is bound by SHA256. Five arms are profiled: differentiable current mean, detached current mean, exact members, single BASE and naive shared sampler. This is **30 future fits**: two complete official graphs × five arms × three seeds, 100 full epochs and validations. Detached uses the same stopped mean in both branches. Its fixed-state forward equals the candidate, but its local adjoint is `Qᵀ U_m`, while the candidate adds `(P-Q)ᵀ mean(U)`. A tiny runtime algebra check precedes profiling. Its full-P adjoint is not allocated because that input is explicitly detached; a guard refuses gradient-bearing input. This changes measured memory/training cost and is reported.

Complete model interfaces subclass the sealed parameter/block and sparse-autograd classes. They replace only fixture-size interfaces, without changing or monkeypatching any original fixture guard. The ordinary BASE forward is reproduced from the source-equivalent blocks with complete-size checks. Native original SAGE gather/scatter controls use the same isolated member dropout masks through parameter-free dropout modules.

## Profile and forecast

Every arm's packed/serial applicable paths, lazy/cached naive forms and checkpoint options are considered. Native exact/BASE are additional controls. Each variant starts from fresh source seed0, executes at most five complete training-label-only engineering updates, and discards all weights. Four timed updates stress all colors; inference uses fixed evaluation colors, one warmup and three timed forwards. These short timing units are not scientific fits or convergence measurements.

Full-width complete-feature frozen-source logits are compared member-at-a-time with streamed error reductions, including BASE. No output stack or predictions are saved for that comparison. Native resource failures are preserved as explicit equivalence limits. All-gradient fidelity remains established only in the bounded mechanics fixture. Native profiling can remain an inference contender even when native training is too large; memory-failed inference cannot be selected.

Validation/final evaluation timing is **label-free proxy work**, including complete validation/test-node reductions and member-probability diagnostics. No target assignment or predictive score is computed. The forecast uses maximum measured unit times plus 25% margin and includes all 30×100 train/validation units, final proxy work, 60 warm/timed predictions per seed, per-fit graph/model/optimizer setup, complete-input H2D and execution-path switches. Actual engineering failures and setup are charged by root's prior accounting. This is a short-unit resource forecast, not a long-run guarantee.

CPU/disk prior fields must account for acquired data, failed artifacts and earlier work **excluding** preparation/profile components explicitly summed in this packet. The forecast requires ≤6.5 GPU hours, ≤60 GiB reserved peak, ≤16 preparation/audit CPU wall hours and ≤200 GiB extra disk. Scientific admission always remains false; root must audit completed supervisors and freeze execution policies separately.
