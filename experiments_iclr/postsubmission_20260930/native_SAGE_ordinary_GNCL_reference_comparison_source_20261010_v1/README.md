## Learning change

For the unchanged four-route bank's current TRAIN logits, define

`F = mean_(m,i) CE(z_m(i), y_i)`

`L = mean_i -log(mean_m softmax(z_m(i))[y_i])`.

The new arm differentiates **J=.5F+.5L through every shared and private parameter**, then makes one native AdamW transition. Its same-bank control differentiates F exactly as the original source does. L uses `log_softmax` and member `logsumexp` without a clamp; it is CE of the actual served probability mean, not CE of mean raw logits. All TRAIN logits come from the same old-state native four-route forward and member streams. There is no detached responsibility, weight selector, nonowner KL or separate gradient permission policy.

GNCL (`2011.02952v2`, saved Eq5/author-code scope) and learner-collusion work (`2301.11323v1`, saved own/pool and probability-mixture gradient scopes) supply the objective ancestry. This is an adaptation to the native bank's actual probability serving. It is not a literal reproduction of every published GNCL architecture, pool or optimizer.

## What the references mean

Shared GNCL versus shared own isolates this fixed learning-objective change at the same bank and selector. Genuine I4 has four independent complete bodies, unscaled own gradients, separate optimizers and separate own checkpoint selections. It is a capable practical reference, with different storage, optimization and selection opportunities.

A jointly optimized untied bank would instead keep four bodies in one coupled J objective and select one coherent bank checkpoint. It is neither genuine independently fitted I4 nor a single shared bank. That control is not added here. The present test can establish useful ordinary supervision and practical quality/cost against capable references; it cannot isolate a tying-by-objective interaction or prove a sharing-specific learning benefit. A weak terminal single or a joint untied bank renamed I4 cannot replace the genuine references.
