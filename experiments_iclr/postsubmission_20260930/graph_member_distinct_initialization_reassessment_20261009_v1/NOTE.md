# Member-distinct initialization at a native graph predictor

9 October 2026. Fresh theory/prior reassessment; existing packets and studies
are unchanged.

Different private parameter values can give different initial predictions,
different accessible training directions, or only different optimizer geometry.
These are distinct properties. Centered or antithetic perturbations do not
guarantee competent members. Exact initial native predictions can coexist with
different new training tangents, but that construction already has strong
zero-output-adapter ancestry. There is no new initialization principle to
promote from this assessment.

The remaining precise question is whether an attributed member-distinct start
at the new compact relational parameter sites helps ordinary-F training beyond
its zero start and equally disturbed generic starts. Graph-specific attribution
also needs an aligned-versus-misaligned graph-orientation control. The pending
operator panel is separate; this note does not extend or change it, repeat its
fixed-core proof, or authorize a fit.

## What an antithetic start preserves

Fix one initial deterministic predictor, every shared parameter, graph support,
normalization mode and stochastic realization. Let `p_i(phi)` be its class
probabilities, and initialize four private relational offsets as
`epsilon*(h_1,-h_1,h_2,-h_2)`. For a common differentiable Jacobian,

\[
p_{im}=p_{i0}+\epsilon J_i h_m+o(\epsilon),\qquad
\frac14\sum_m p_{im}=p_{i0}+o(\epsilon),\qquad
\ell_m=\ell_0+\epsilon g^Th_m+o(\epsilon).
\]

Thus the extra pooled change cancels to first order. If the probability/loss
maps have bounded second derivatives in a common neighborhood, the remainders
are O(epsilon²). Individual losses generally move in opposite directions to
first order. Projecting every h orthogonally to g removes that first-order
TRAIN-loss change, but can also remove the useful prediction tangent and gives
no finite-loss or accuracy guarantee. Positive curvature can increase all
member risks at second order. A fresh native reset is not itself evidence of a
competent starting predictor; no pretrained donor is assumed here.

Internal sigmoid, attention normalization and downstream nonlinearities prevent
zero-sum parameters from giving exact zero-sum predictions in general. Separate
dropout masks also give different realized Jacobians, so parameter centering
need not cancel one stochastic update's pool. Cancellation in expectation would
require an identical member path law and suitable differentiability/integrability;
it does not identify finite Adam trajectories. Argmax accuracy is discontinuous:
a sufficiently small offset preserves decisions only when the relevant initial
margins and sensitivity bounds supply an actual nonzero safe radius.

No universal nonzero radius can be selected from the words "zero sum" or
"antithetic." Choosing a large graph-sensitive direction increases predictive
disturbance at the same parameter norm; it can weaken members. Radius matching
must concern the actual prediction map, with finite loss damage disclosed.
Four antithetic rows of the displayed form span at most two member-contrast
directions, whereas four generally centered rows can span three. Controls must
retain the same pairing/rank template; different contrast coverage can otherwise
explain a difference attributed to graph orientation.

## Exact function preservation is a different option

For current `FactorLinear`, outside bias b and any scalar `c_m>0`, the transform
`r_m -> c_m*r_m`, `s_m -> s_m/c_m` preserves `W(x*r_m)*s_m+b` exactly in real
arithmetic. Every native nonlinear/graph operation then sees the same inputs.
With unchanged Adam, however, the physical input/output-factor learning rates
change. The saved reciprocal-scalar assessment already derives the exact
row-rate/epsilon equivalence. This is a generic optimizer-diversity question;
it does not supply different initial relation functions. No duplicate gauge arm
or renamed graph initializer is justified.

An added branch `Y=Y_native+Phi_m B_m`, with `B_m=0` and finite member-specific
`Phi_m`, can preserve each initial native function while giving tangent space
`{Phi_m Delta B}`. The outgoing derivative can be nonzero; the incoming
dictionary derivative is initially zero and may become live later. This is the
saved outgoing-zero/LoRA/EVA/AdaptFormer construction, and it changes the
architecture or its restricted parameterization. It is separate from merely
initializing the existing compact delta banks.

Distinct incoming matrices are not sufficient. Antithetic dictionaries
`Phi,-Phi` have the same span and the same `Phi Phi^T`; with identical paths,
their first plain outgoing-gradient steps produce the same function change.
Sign/permutation reparameterizations can likewise be equivalent under Adam.
Different tangent spaces or non-equivalent actual physical update directions
must be demonstrated at the full predictor, rather than inferred from factor
distance. Full-rank coordinate changes may instead create only known
optimizer/preconditioning differences.

## What counts as graph steering

A direction must survive the full graph prediction Jacobian. A class-common
logit shift is softmax-null. A common incoming-neighbor score shift cancels
from row softmax; native receiver-side GAT scorer changes can be null when
all relevant LeakyReLU preactivations remain in the same linear region.
Constant aggregated values can make attention changes prediction-null. Any
normalization-invariance claim must bind the actual affine parameters and
epsilon rather than assume an idealized normalization.

The compact pre-sigmoid delta has a real possible core tangent, established in
the separate note. That does not ensure a nonzero full-network probability or
class-margin tangent for every graph, channel or node. Graph covariance and
graph-filtered residual orientation already have prior/project ancestry.
Applying them at the new delta coordinates tests a site interaction, not an
invented graph-aware initializer. Edge covariance of graph-derived features is
also distinct from feature covariance of the same features; the latter is not
a graph-free representation baseline.

Useful graph steering would change task-relevant neighbor/evidence margin
responses and later net repairs. Nonzero hidden spread, factor norm, attention
variation or prediction sensitivity can instead reflect nuisance/confidence
changes. No loss term rewarding a wrong member, teacher acquisition, contrastive
repulsion, learned diversity coefficient or learned serving router is needed
for this question. Ordinary F remains the continuation objective.
