## 1. What the fixed-key objective actually specifies

For each route, a shared bare bias-free auxiliary map gives normalized queries `q_i = A h_i / ||A h_i||`. Its dictionary consists of fixed normalized TRAIN feature keys from the assigned context `X`, `X−PX`, `PX` or `P²X`. The outside-log target is a same-class, self-excluding weighted distribution `Q_i`; the denominator contains all other TRAIN keys.

The saved exact reduction is

`L_i = log Σ_j∈E_i exp(q_i·k_j/τ) − q_i·μ_Qi/τ`,

where `μ_Qi = Σ_j Q_ij k_j`. Thus the **entire dependence on Q is its first key moment**. Two Q rows with the same mean give identical loss for every query. The positive component is class-conditioned kernel-smoothed graph-feature alignment; the other component is the dictionary log partition. Dictionary geometry can matter beyond the target mean, but higher-order properties of Q cannot enter this loss independently of that mean.

The exact alignment control already specified is `R_i = (1−q_i·μ_Qi)/τ`, without normalizing the mean. Then `L_i−R_i = log Σ_j∈E_i exp(q_i·k_j/τ)−1/τ`. This is an algebraic attribution, not a proposal for another candidate.

Fixed heterogeneous keys can avoid the automatic cancellation of same-class positive cosine tangents when live student peers coincide. That distinction survives only if target means differ in a relevant tangent direction and survive the shared projection and native Jacobians. Shared A can absorb or annihilate the signal; native gradients can cancel. This is neither evidence that the previous model collapsed nor a collapse-avoidance or accuracy guarantee. The failed raw reconstruction increment already shows why an asymmetric nonzero gradient is insufficient.

## 2. Closest newly checked graph collision

[Joshi et al., *On Representation Knowledge Distillation for Graph Neural Networks*, arXiv:2111.04964v4](https://arxiv.org/html/2111.04964v4), **§§2.2 and 3 only**, specifies Graph Contrastive Representation Distillation (G-CRD).

G-CRD contrasts a student's node representation against the teacher representation of the same node, with other teacher nodes as distractors (Eq. 7). Teacher and student features enter learned projections and cosine similarity (Eq. 8). A single GCN projection followed by normalization and activation is an explicit graph-aware alternative to an MLP projection (Eq. 9). The representation auxiliary is combined with supervised learning and optional logit KD in Eq. 3. The inspected method therefore already covers node-level graph representation alignment, teacher/student dictionary contrast, auxiliary projections, graph-aware acquisition and supervised training.

The present recipe differs in identifiable ways: its keys are permanently fixed filtered input features; it needs no independently learned GNN teacher; its target is a distribution over other same-class nodes rather than an identity match; and it persistently assigns four context objectives to native factorized routes through one ordinary shared auxiliary map. Those differences define a construction worth testing. They do not establish a new graph contrastive principle. No exact equivalence between G-CRD and the complete candidate is claimed.

No experiment, appendix, pseudocode, author implementation, information-theoretic proof, numerical result or published-version equivalence was audited. The method's stated mutual-information and topology-preservation interpretations are not adopted as guarantees. The paper's claims about direct feature mimicking are not imported as evidence against the exact moment control.

## 4. One falsifiable interpretation and strongest comparator

**Interpretation:** persistently allocating the four class-conditioned graph target fields across the native routes yields useful task decomposition under sharing: it acquires route corrections that survive native probability averaging more effectively than giving every route the complete common objective. The contribution, if supported, is that concrete allocation and acquisition recipe at its actual budget.

**Strongest comparator for this interpretation:** the already specified common shared model, with the same bare A, initial bytes, own CE, native route computation, keys, targets, self exclusion, schedule and selection rules, where **each route minimizes the average of all four complete `(K_m,Q_m,E_i)` losses**. Each dictionary retains its own log partition. Averaging Q against a selected or union dictionary is not this comparator.

This comparator receives all the same target information. If it matches or exceeds the private assignment in served quality and proper risk, the proposed accuracy benefit from persistent allocation is unsupported. A change in auxiliary loss, gradient norm, embedding spread or route disagreement does not rescue that interpretation. Any accuracy advantage must survive introduced harms and be retained by the serving pool; the broader sharing attribution still needs the capable single and genuine I4 references already specified.

This is a same-information comparator with a larger auxiliary computation, not a matched-cost comparator. It computes 16 route/dictionary objectives versus four for private assignment. Saved forward arithmetic is 1.703808B versus 492.768M auxiliary MAC per update, without a runtime forecast. Matching quality at lower measured complete acquisition cost could still be an efficiency benefit even if the accuracy interpretation is refuted. Report the actual cost rather than interpreting equal step counts as equal expenditure.

The exact moment control has a separate, already declared role: if it accounts for useful accuracy, credit fixed graph-feature target alignment and the allocation recipe. If the full dictionary term adds utility, credit dictionary-assisted acquisition. InfoNCE and graph contrastive distillation remain prior in either case.
