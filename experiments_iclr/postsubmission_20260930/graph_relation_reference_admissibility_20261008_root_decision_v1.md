# Root decision on the conditional reference packet

8 October 2026. The sealed agent packet is a useful source-only plan. It is not
an execution release. Current graph12/Mol18 sources, outcomes and gates are
unchanged, and the next candidate remains fixed before comparative opening.

The six completed plain Wiki24 single/ordinary records are retained as historical
practical references. Matching recorded input hashes and four core files does
not certify a fresh execution equivalence or remove the different checkpoint
selection rules. Their recorded scores are unchanged. No repeated reference
fit is required merely because ordinary pooled accuracies happen to coincide.

The packet correctly identifies missing single-view-opportunity and untied
recipient/selector controls. Twelve fresh comparator bundles are a conditional
proposal, not a launched grid. Existing reference evidence may support a narrower
declared historical comparison; it cannot silently replace the separately
registered fresh comparator stage.

The proposed new-split and ogbn-arxiv confirmation contexts are **not admitted**.
Root rejects automatic transfer of WikiCS's numerical training recipe to a new
graph as sufficient baseline preparation. A new graph must first use a verified
published dataset-specific backbone recipe and establish credible native
baseline competence. Any justified bounded development changes must be recorded
and frozen before held-out scoring. The sealed agent proposal is preserved as
written; a later adopted protocol must be a separately recorded successor.

A different split number or optimizer seed does not itself make evidence unused.
Actual role and prior outcome exposure determine that claim. New graph acquisition,
qualification, fits and held-out scoring remain disabled by this note. A useful
current pilot must be followed by its necessary controls and unused confirmation;
none of the source inspection here constitutes a performance improvement.
