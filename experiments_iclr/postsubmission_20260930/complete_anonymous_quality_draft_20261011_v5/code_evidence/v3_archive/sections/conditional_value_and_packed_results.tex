\section{Conditional neighbor values and packed controls}\label{sec:conditional-values}
The preceding study leaves a member-quality limitation: sharing can improve the pool while its members remain weaker than independently acquired models. We therefore test a direct change to the graph evidence each route receives. Endpoint-conditioned E4 transforms nonself neighbor values before the native SAGE mean. Two shared affine builders use the current source and receiver states to produce paired $4\times4$ maps; their product acts across the four 32-channel groups of the width-128 value. Private factor vectors select each route's builders. Factual edges, self values, root maps, native normalization, feed-forward maps and dropout remain in the native computation. Conditional messages and paired endpoint maps have established ancestry \citep{simonovsky2017ecc,brockschmidt2020film,bodnar2022sheaf,bourgerie2026deepnsd}; this is their declared placement in a shared native SAGE procedure.

The comparison gives the same endpoint operation to a factorized single and four genuinely independent models. A receiver-conditioned N4 arm has the same parameters and matrix action, with context formed from the receiver state and its SiLU transform. It asks whether the source state adds value beyond receiver conditioning. BASE is an unchanged internal-factor shared bank acquired within this family. Training, native selection and probability averaging follow the fixed own-loss recipe; the earlier internal-SAGE outcomes remain a separate study. Appendix~\ref{app:E-PE} specifies all arms, calibration and costs.

E4 reaches 81.1971\% raw pooled accuracy, versus 80.6282\% for BASE and 80.8937\% for equipped I4. Paired gains are 0.5688 points with descriptive 95\% interval $[0.1146,1.0231]$ and 0.3034 points with interval $[-0.3560,0.9628]$, respectively. All three seed differences are positive, but the I4 interval includes zero. E4's raw and calibrated NLL and Brier are worse than I4's. Its mean calibrated-NLL harm of 0.0160 passes the predeclared practical allowance; that practical screen is distinct from a noninferiority conclusion. The same development nodes informed native selection before calibration, so this is not unused confirmation.

N4 reaches 81.0517\%, accounting for about 74\% of E4's BASE gain, with slightly stronger average members than E4. The endpoint increment is 0.1454 points, with descriptive interval $[0.0015,0.2893]$. Against BASE, E4's mean members improve 1.0729 points, covered alternatives decrease by 106, and pooling losses decrease by 196, leaving 90 more correct decisions. Against equipped I4, E4's mean members remain 0.7632 points weaker. This pattern supports reporting competence and pool retention together; it does not attribute the benefit to builder-private parameters or establish a new geometry mechanism.

For storage context, we adapt Packed-Ensembles with four untied width-59 SAGE bodies and $\gamma=1$ \citep{laurent2023packed}. Width is fixed by BASE's full parameter cap before scoring: PE4 stores 215,508 parameters, BASE 216,674, and E4 237,474. PE4 reaches 79.7876\% accuracy; E4 gains 1.4094 points, with descriptive interval $[0.9820,1.8368]$. PE4 has better raw NLL (0.6956 versus E4's 0.7611), while E4 has better raw Brier. This is one narrower packed adaptation with a coherent bank selector; the equipped full-width I4 remains the quality reference. PE calibration was not added. Equipped I4 stores 902,400 parameters. Recorded activation costs remain in the appendix; fewer stored weights supply no compute or memory advantage here.
