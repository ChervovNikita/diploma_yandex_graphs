B Residual network initialization
To train residual networks without using BN, one need to initialize them carefully, so we used the
following procedure, denotingn the fan-in of the layer:
1. We use the He initialization for each layer directly preceded by a ReLU (He et al., 2015):
W ∼ N (0, 2/n),b = 0.
2. Each layer not directly preceded by an activation function (for example the convolution in a
skip connection) is initialized as: W ∼ N (0, 1/n),b = 0. This can be derived from the He
initialization, using the Identity as activation function.
3. Inspired from Goyal et al. (2017), we divide the scale of the last convolution in each residual
block by a factor 10:W ∼ N (0, 0.2/n),b = 0. This not only helps preserving the variance
through the network but also eases the optimization at the beginning of the training.
C Initialization of ϵ
Both KFAC and EKFAC are very sensitive to the the damping parameterϵ. When EKFAC is applied
to deep neural networks, we empirically observe that addingϵ to the eigenvalues of both the activation
covariance and gradient covariance matrices lead to better optimization than using a ﬁxedϵ added
directly on the eigenvalues in KFE space. KFAC uses also a similar initialization forϵ. By setting
diag(ϵ′) = ϵI +SA ⊗ √ϵIdout + √ϵIdin ⊗SB , we can implement this initialization strategy directly
in the KFE.
