Single8 attribution controls: callable prospective source
=======================================================

Read SCIENTIFIC_QUESTIONS.txt for questions and limits decided before the
optional virtual contrast control was implemented. This directory changes no
public V2, frozen core, original family, active job, ledger or publication file.
It contains no queue, launch script, resource/parity fixture or adoption. All
numerical calls default to refusing execution. No numerical framework/model,
dataset, checkpoint, score, TEST, server or GPU was used to prepare it.

API
---
single8.control_spec(name): stdlib-only declaration for single8_own,
single8_alignment or single8_virtual_contrast.

single8.make_session(task, control, seed=6101, device='cpu', polynormer=None,
                     ncn_model=None, ncn_utils=None, public_root=None,
                     later_execution_authorized=False)

single8.run_complete(task, control, train, valid, output, seed=6101,
                     device='cpu', polynormer=None, ncn_model=None,
                     ncn_utils=None, public_root=None,
                     later_execution_authorized=False)

task is wikics, collab or molhiv. public_root defaults to the sibling exact
portable_internal_be_public_interface_20261007_v2 directory. Relocation is
supported only with the same hash-sealed V2 bytes. Native source arguments use
the original public pinned sources: WikiCS requires polynormer, Collab requires
ncn_model and ncn_utils, Molhiv requires neither. Inputs remain the original
public numeric TRAIN/VALID NPZ contract; this adapter adds no official data
provenance claim, export/download path or dataset transformation.

No call with later_execution_authorized=True is part of this preparation.
That flag acknowledges a distinct future adoption by the caller; it is not an
approval/release system and does not itself provide authority. No command-line
entry or process launch is supplied. A later authorized researcher can call
run_complete with the same task/train/valid/native-source arguments used for
the public driver and a fresh output directory. Calls must be serial in each
process because the unchanged public argparse main consumes sys.argv.

For a later manual Session use, train_step(batch, labels) runs all eight full
supervised views and one Adam step. Before inference use session.model.eval(),
then session.forward(batch) and session.serving(logits). forward refuses TRAIN
mode so it cannot accidentally replace eight-view training with a single pass;
serving refuses a virtual four-view bank. This remains deterministic native
single-body evaluation, with one served member and no stochastic averaging.

Implementation and source invariants
------------------------------------
The adapter constructs public Session with arm='single' and delegates its model,
native initialization, optimizer, source finite checks and serving. There is
one body, one optimizer and no private factor installation. Four separate
training-view stream states use the existing seed+1009*m+300001 mapping, each
twice per update in all-A then all-B order. Every forward uses source member0
of that same body. No stream-specific parameters/features or decoder exist.
own_supervision sees the full labels for all four A and all four B views.
The .5*(own_A+own_B).mean() reduction equals the mean of all eight losses.

Alignment is core alignment_loss on the exact deterministic source bounded
index selection; its mean already averages four stream pairs. Virtual contrast
adds core residual_member_contrast on those same four stochastic views, with
the original 0.05/0.05 weights and 0.2 temperature. The maximum512 auxiliary
objects do not truncate any own-supervision object. Native graph/dropout and
batch/negative sampling recipes stay unchanged. Multi-view repetition is not
extra unique labels, independently learned members or independent evidence.

run_complete imports a private in-memory copy of the exact public training
module and substitutes only Session/recipe/snapshot-metadata/write-metadata
interfaces on that copy. It calls the original main; no epoch loop is copied.
Data helpers, full horizon/update/population checks, evaluate and strict first
maximum selector are the originals. Original module aliases/sys.argv are
restored after their limited use; no source is edited. The separately declared
recipe's control list is outside the frozen eight-arm recipe.

Selected snapshots remain joint source model/optimizer snapshots. Additional
metadata records all four training-view RNG states, control definition and
actual source-work counts. The source one-member serving streams remain in the
original field. WikiCS local transition restores selected local model and Adam
only and retains live end-local training-view RNG, exactly the source policy.
The public full driver has no exact resume claim; this wrapper also refuses
the Session continuation helpers to avoid an incomplete view-RNG restart.

RUN/PROGRESS/COMPLETE/FAILURE add explicit control provenance and work counters.
Before COMPLETE, the adapter checks the original full step counts, eight
successful forward/supervision views per completed update, one Adam call per
update and all complete own-label presentations. Failed updates retain actual
counts reached; source FAILURE and partial artifacts remain, without retries,
subsets, altered seeds, schedule shortening, checkpoint rescue or deletion.
Unused source single own-best/local artifacts remain as in the public single
driver; they do not replace the joint selector or create view selection.

Future evidence boundary
------------------------
LATER_COMPARISON_PLAN.json is a concrete, disabled later matched comparison,
not an extension of current Wiki24 or portable24. It pairs the three prepared
controls with five unchanged public baselines, including ordinary independent4,
on five reserved confirmation seeds (eight arms, 40 outcomes per adopted task),
after full candidate/failure accounting and unused-seed custody. Source supports
all three complete task paths, but current runtime, full costs and predictions
are unmeasured. If a future run is warranted, qualify the real input/compute
path separately; there is no micro-parity or synthetic performance claim here.

Own-view count does not equate memory, elapsed compute, parameter capacity or
deterministic single inference with BE mean-member inference. Costs and native
control competence must be reported alongside predictions. Null/failure results
close the declared recipe and cannot be rescued by hidden response separation.
No novelty or ensemble necessity claim follows from these controls alone.

V2 narrow confirmation-plan correction
--------------------------------------
The source adapter is byte-identical to V1. V1 remains immutable. The corrected
prospective roster adds ordinary independent4 and be_init_contrastive minus
independent4, so later goal confirmation includes the ordinary ensemble on the
same five unused seeds and matched execution context. This is preparation, not
evidence or adoption; no automatic all-task campaign or compute follows.

Existing baselines use the original public driver; run_complete remains only
the three new single8 controls. Ordinary independent4 retains four bodies, two
own views per body, four Adam calls per batch, mean-member serving and each
member's own-selected checkpoint bank. WikiCS restores own-local model/Adam
and retains live RNG. It is not converted to a joint candidate selector. Its
four own selection curves and terminal complete bank evaluation are reported;
identical selector opportunity versus the joint candidate is not claimed.

independent4_contrastive is excluded. It would require a separate justified,
fixed later comparison and adoption; it is not silently added to this roster.
