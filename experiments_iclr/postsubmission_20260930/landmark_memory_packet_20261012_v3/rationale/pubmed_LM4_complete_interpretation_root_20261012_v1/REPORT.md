# Completed PubMed private landmark-memory study

All 36 fresh fit groups and 54 optimizer trajectories completed. The whole readout closed all 39 CAL endpoints before releasing 39 development records and 156 contrasts. This is development evidence on an encountered graph, not confirmation.

## Finding

LM4 did not improve the selected source. Its mean accuracy was 90.8308%, exactly the source accuracy for each of the three seeds. LM4 minus the equipped independent ensemble was [-0.07599, +0.37994, +0.37994] percentage points, mean +0.22796. This fails the frozen all-positive rule and supplies no gain beyond its source. Calibrated NLL was 0.247214 for LM4 versus 0.237463 for I4[S64], a worse difference of +0.009752. All combined criteria failed; member competence protection passed.

The complete acquisition metadata verifies that all three LM4 trajectories, and all B1/B4/S64/FS64/T16 controls, selected checkpoint **0** after 100 executed continuation updates. The fixed strict integer-accuracy selector therefore served the inherited source state. The independent continuation controls sometimes selected steps 2–18. Equal selected predictions are not evidence that a learned memory is useful, nor proof that the mechanism could never learn. They are evidence that this training/selection procedure failed to choose an improvement.

## Consequence for the new study

Preserve this failed outcome. Future tests need full declared continuation budgets and learning curves, including SELECT accuracy and proper loss at checkpoint 0 and every evaluation point. A standardized selector with an explicit proper-loss tie rule may be studied prospectively; it is not a retroactive repair of this result. Matched references must receive the same training opportunity. No rescue fit was launched.
