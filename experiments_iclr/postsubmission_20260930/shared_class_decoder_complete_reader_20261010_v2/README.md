Prepared on 10 October 2026 as source only. This folder creates no owner, fit,
retry, tuning grid or scientific launch. The root controls execution through the
existing runtime after the complete study closes.

## Runtime admission

`analysis.py` first checks the literal scientific hostname and sole GPU UUID.
It requires the authorized repository research root. It then checks the frozen
decision, configuration, learning sources, qualification and immutable count/math
helper. Both successful finite owners and both 21-bank completion headers must
pass before complete result objects are loaded. The new header has 30 optimizer
fits; the original native header has 39 fits.

The native extension appended its 39-body count, declared arms, decoder counters
and graph preparation record after the `results` boundary. The reader compares
the actual pre-results header explicitly, then checks all appended metadata,
the full 21-bank / 30-fit / 39-native-body roster, route seed laws, selected steps,
native and five-step decoder operation counts, and exact arm semantics.

All 21 new archives, all 15 immutable original reference archives (33 selected
fits), and all 30 new selected checkpoint paths and hashes are admitted before
NumPy imports. All 36 archive schemas and ordered VALID identities pass before
matrix extraction or scoring. Every file is rehashed around its payload read.
The original reference checkpoints are preserved as metadata and are not loaded.

## Authorities and decisions

Exact archived float32 member and pooled errors drive decoded and native counts.
Native arrays are the archived native component at the decoded-selected state.
The pinned helper supplies stable FP64 log-softmax NLL, paired summaries, class
and member quality, coverage decompositions and repair/harm flows. FP64 decision
discrepancies are recorded separately. Native states include decoded selection
and stopping, so their contrasts cannot isolate pure training effects.

The primary shared-four / graph-P / common-B candidate is scored against all
six new controls and all five original references. Frozen acceptance requires
nine accuracy contrasts: 0.2 percentage points over the equipped genuine
factorized I4, 0.1 points over the other five new controls, and 0.2 points over
the original shared, ordinary I4 and factorized I4. Each requires all three
seeds nonnegative and at least two positive. Eight NLL contrasts require at
most 0.02 mean and 0.05 per-seed deterioration against every new control and
both original raw I4 references. Original M1 comparisons are contextual.
Member quality remains diagnostic; there is no individual-member veto.

## Learned matrices

After complete custody, `torch.load(..., weights_only=True, map_location='cpu')`
only extracts `model.class_decoder_B` from all 30 new checkpoints. No model,
optimizer or data loader is constructed; no forward, gradient or re-decoding
runs. All 39 matrices are exported, including all private-B matrices, together
with the decomposition `B = HBH + JBH + BJ`, means, norms and residuals.
Here `J = 11^T / 10` and `H = I - J`. With normalized class states and row
stochastic P, `JBH` is a constant class-bias contribution and `BJ` is a softmax
null shift. This is established gauge arithmetic; matrix magnitude does not
establish graph utility. The retrained P=I control addresses neighbor-graph value.
Raw checkpoints remain on the scientific host.
