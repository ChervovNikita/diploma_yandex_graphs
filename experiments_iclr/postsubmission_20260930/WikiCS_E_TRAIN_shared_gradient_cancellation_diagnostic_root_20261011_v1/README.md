# TRAIN gradient diagnostic

One next-dropout gradient measurement at each selected WikiCS checkpoint. The fixed roster is BASE/E4/N4/equipped M1/genuine equipped I4 at three paired seeds:15 banks,24 selected states and51 own-loss backwards. There are no parameter updates or new validation/test scores.

The shared Euclidean mean-loss gradient is the mean of the four unscaled route gradients. Pair comparisons are within a shared bank only. Private factor rows are disjoint; their orthogonality is not predictive diversity. All groups, pairs, missing groups and zero norms are retained.

The240second external owner waits for its actual child and terminates/reaps it on timeout. CUDA/RSS caps are checked internally. Runtime and input hashes are checked before use. Normal execution overlaps the existing acquisition jobs. No parity collector is required.

A small mean-gradient ratio must be interpreted with route magnitudes and pair cosines. This one checkpoint/dropout measurement does not measure the complete training history, AdamW update, causal harm, novelty or improved prediction. A failure closes the diagnostic without a survivor summary or automatic retry.

Source was read by root, and exact forward/stream/loss scope was checked by the combination researcher. This is a research diagnostic, not manuscript review.
