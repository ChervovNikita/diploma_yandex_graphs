# Graph tangent initialization: targeted literature and control review

## Decision

Retain the graph-band supervised tangent initializer as an **unestablished proposed extension**. Its useful unit is the complete operation: an identical warm predictor, graph-filtered training CE cotangents, VJPs into active route-private boundary factors, centered gradient-orthogonal route motion with a common descent component, finite functional checks, bounded training Armijo checks, and ordinary member-loss continuation. The reviewed ancestry does not disqualify that extension. Neither this source review nor its local training certificate establishes held-out utility or originality.

Add **one unchanged warm-copy continuation arm** to a separately frozen prospective protocol. It isolates warm cloning and ordinary stochastic continuation, which the existing common-descent arm does not isolate because that arm takes an extra supervised step. Consider a warm full-weight ensemble as a strong quality reference only if the intended claim includes superiority to copied warm ensembles. Do not add a new omnibus tuning grid.

This lane read one new full primary paper, StarSSE, and a second recent graph method, FAGEL, through its publisher abstract and pinned author source. FAGEL's full paper was unavailable in the retrieved subscription preview. FoRDE and the graph/factor priors below were reused from cached conclusions. MORGAN remains metadata/abstract only. Broad noisy searches and failed retrievals are not evidence that other close methods are absent.

## StarSSE: operational source findings

Verified title: **To Stay or Not to Stay in the Pre-train Basin: Insights on Ensembling in Transfer Learning**. Canonical primary is [arXiv 2303.03374v3](https://arxiv.org/html/2303.03374v3). The saved unversioned HTML explicitly identifies v3 and its date. The primary links the [author repository](https://github.com/isadrtdinov/ens-for-transfer), pinned here to `8984ccc5b02c2a1cf475d15376dd7f1202d60082` (20 February 2024).

Section 5.4 states that all later models start with the first target-fine-tuned model's weights and use SSE-cycle schedules independently. The author loop implements the logical star sequentially: after a checkpoint, `star_fge` reloads the **first model's full state** (`training/train.py:169–172`). It does not reload that first checkpoint's optimizer moments. `reset_optim_state=True` is the ResNet/BYOL base default; the checkpoint handler empties optimizer state and resets the scaler (`train.py:158–160`). SGD is constructed over all model parameters, with momentum 0.9 in the base recipe. The cyclic cosine scheduler restarts by modulo cycle length (`utils/lr_schedule.py:112–132`). Thus source-supported native rays have fresh momentum state at each branch, not copied warm Adam moments.

The inspected code saves each member's `softmax(logits)` (`train.py:162–167,184–189`). The scoped primary/code read did not resolve a complete native ensemble reducer. This report therefore does **not** assert an exact StarSSE pooled NLL contract. Native serving must be separately qualified if implemented. The candidate's already fixed raw-logit primary pool is retained.

The pinned `configs/resnet/resnet_starsse.py` imports `ResNetBaseConfig` but declares `Params(BYOLBaseConfig)`, with no such import. Its shown recipe also labels the run BYOL. The valid BYOL StarSSE file and the shared loop support the mechanism, but the ResNet launcher is not a verified runnable recipe. Preserve the source discrepancy; do not silently repair and call it native replication.

The paper's diversity analysis normalizes prediction disagreement by maximum individual error. It reports that stronger exploration can increase diversity while weakening individual models and worsening ensemble/OOD quality. This supports the existing member-quality, residual/error-overlap, and pooled supervised checks. It supplies no guarantee for Squirrel or Photo and no reason to choose a diversity metric as the selector.

Exact line scopes and preserved passages are in `READ_SCOPES.json` and `evidence/PRIMARY_PASSAGES.json`. Scope includes §5.4, relevant setup/ancestry, targeted Appendix B/C/J passages, and a small beginning of Table 3; it does not claim a cover-to-cover paper read.

## FAGEL: recent graph lead and limits

Verified title: **FAGEL: Fast and Accurate Graph Ensemble Learning Using Staged Training and Diversified Sampling**. The [publisher primary preview](https://link.springer.com/chapter/10.1007/978-3-032-37657-2_35) gives first-online/published date **8 September 2026**, ECML PKDD 2026, authors Jiajun Shen, Yufei Jin and Xingquan Zhu, and the author repository. Its citation/copyright says **2027**; retain that discrepancy rather than correcting the record. No arXiv version was found by the narrow FAGEL search; its one result was an unrelated embodied-agent paper. This is not a general absence claim.

The abstract and README describe a fixed-sampler supervised phase until validation plateaus, then continued training under varied hop/fanout configurations, with selected snapshots and residual weighted aggregation. The repository is pinned to `02bdc6dc745a84bc7f947edaa98336adc2e63e28` (4 September 2026). Source confirms one full GCN, one Adam optimizer constructed before the loop, ordinary CE, two neighbor loaders, top-K validation-accuracy snapshots, and full-model state reloads for serving.

Source does **not** implement the prose exactly in the inspected efficient function: `plateau_mode=True` at initialization; sampler phases toggle every `cycle` epochs immediately; `max_plateau_trials=1` breaks on the first patience threshold. The default `inference=True` path loads pre-existing top-checkpoint weights after constructing a fresh optimizer. The top-level `main` contains only commented calls, and README instructions name `train.py`, absent from the pinned tree. No execution was performed. These observations prevent a claim that the repository is a qualified native reproduction of the publisher operation.

`TwoStageEnsemble.forward` computes a raw-logit mean, softmax-normalized **global** model weights, and `mean + tanh(alpha) * (weighted − mean)`. A defined node-attention MLP is unused in this forward. The aggregator is trained by CE and selected with validation accuracy. Since `tanh(alpha)` can be negative, the effective interpolation need not remain convex. The inspected method also has simple mean-logit inference paths. Neither supports changing the candidate's fixed selector or adding learned fusion without a separately declared comparison.

No full paper or theoretical proof was read. In particular, the abstract's embedding-diversity theorem and claimed speed/accuracy gains remain attributed publisher claims, not verified evidence for this proposal. Native sampling/GCN results cannot be transferred to full-graph PolyFormer/Polynormer by naming an adaptation FAGEL.

## Fair controls and complete costs

### Recommended narrow addition

**Unchanged warm-copy GNNM continuation:** use the exact matched warm checkpoint/function, copy all four routes with private factors at one, install no expansion displacement, and resume the same ordinary mean-member CE continuation. Preserve warm shared-weight/bias optimizer moments; new private factors have empty moments, exactly as in the proposal. Use the same independent dropout streams, absolute native stage schedule, four frozen configurations, paired seeds/splits, validation selector and raw-logit primary pool. Charge warm training, model copies, complete K4 continuation and serving. It has **zero** initializer VJPs, graph-band propagation, JVPs, and line-search forwards. Ordinary continuation costs still apply. Retain failure/status cells and do not relabel it cold native BE or common descent.

This arm is required for a claim that expansion itself adds utility. It provides a direct falsifier: if the proposed expansion fails to improve over unchanged cloning, the claimed value of the initializer is unsupported, even if warming or stochastic route continuation helps relative to a cold ensemble.

### Strong quality reference when copied warm ensembles are in scope

**Four untied warm copies:** branch four independent full backbone/head states from the same common warm checkpoint, then continue every copy on the fixed admitted graph/native schedule with independent dropout streams and equal bounded tuning. Match checkpoint/stage and inherit warm optimizer state under an explicit full-weight state map. Charge all private model storage, optimizer state, four continuations, all serving passes, and shared warm acquisition. This is a copied-warm graph quality reference; it is not native StarSSE. Native StarSSE instead retains a center, trains K−1 cosine rays, and resets optimizer state. A native StarSSE-style graph arm would require a separate predeclared schedule/optimizer amendment and cannot obtain a wider cycle grid for free.

If the report only claims incremental benefit within shared-W factor GNNM, prioritize unchanged warm-copy continuation and keep the already required cold untied reference. If it claims to improve copied pretrained ensembles generally, the warm untied reference becomes required for that claim. No optional reference may be selected after seeing final outcomes.
