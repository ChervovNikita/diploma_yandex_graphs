# HGEN baseline readiness on the fixed DBLP splits

3 October 2026. Source and recipe assessment only. **The preserved author implementation can plausibly be made syntactically runnable with a small mechanical repair, but the saved evidence does not recover a unique faithful recipe for the published regularized HGEN baseline.** An explicit author-code default variant is identifiable; it has `lambda_cov=0` and therefore no active diversity penalty. Fair evaluation on the fixed HGB-DBLP development splits would require a prospective adaptation declaration and numerical/resource qualification. This packet performs neither a repair nor a run.

## What is recoverable

The complete five-file author tree is preserved at commit `3caba805b2c3e16ee2dfd7d56d7e79405f66fd01` (29 August 2026), with all eight retrieval-receipt hashes verified. It postdates the 2025 paper; no evidence binds this revision to the paper's reported experiments. Source: [author repository](https://github.com/Chrisshen12/HGEN). Publication: Shen et al., *HGEN: Heterogeneous Graph Ensemble Networks*, IJCAI-25, [DOI 10.24963/ijcai.2025/685](https://doi.org/10.24963/ijcai.2025/685), saved `arXiv:2509.09843v1`.

The intended DBLP `run_Multi` path is clear: author features only; APA, APTPA, APCPA (C=conference), in that order; three independently constructed GCN learners per view; a biased input linear projection, two PyG `GCNConv` layers, LeakyReLU(0.1), input feature dropout 0.1, hidden width 64, attention width 8; learned node fusion within each view; separate biased view decoders; **sum** of view class logits followed by `log_softmax`. TRAIN NLL uses that fused predictor. Adam defaults are lr 0.001, weight decay 0.0005, at most 500 epochs and patience 50. These are CLI defaults, not recovered paper-selected hyperparameters. Neither mean member logits nor M4 shared/private HGT factors belong in this baseline.

The Gram matrix is built from mean-pooled fused view embeddings over **all target nodes**, without labels. That transductive feature operation can be preserved with heldout labels closed. It is an uncentered Gram matrix, includes its diagonal, and is not a normalized correlation matrix. Changing to TRAIN-only pooling, an off-diagonal penalty, or cosine/covariance normalization would alter the method.

## Scientific differences that cannot be called syntax fixes

**Residual fusion differs from the paper.** Paper Eq.6 adds `1/k` to every allele weight. Code `model.py` 156 applies `a_0` to the first learner; lines 161–162 apply `a_j+1/k` only to later learners. Thus the source is order-asymmetric and differs from the printed all-member residual. Preserving source behavior and implementing the paper formula are distinguishable variants. Neither can be silently selected as the recovered author experiment.

**The penalty differs, and its selected coefficient is missing.** Paper Eq.9 prints `lambda*||S||_1`. Code `train.py` 216–219 uses `lambda_cov*(torch.norm(S,p=1))^2` (entrywise absolute sum squared with no `dim` specified); CLI line 322 sets `lambda_cov=0`. The square changes the gradient scale as embeddings evolve and cannot generally be repaired by a constant coefficient change. The saved paper implementation paragraph (§4.3, block 57) says a grid selected hidden dimension, layers, dropout, learner count and regularizer strength; it supplies neither chosen DBLP settings nor that selected coefficient. A coefficient mentioned in a regularization illustration is not the chosen DBLP reproduction recipe. Default zero is an identifiable unregularized author-code variant, not evidence for regularized HGEN.

**Deleting the unused pass changes seeded execution.** `model.py` 204–218 runs all nine learners and stacks unused outputs, then lines 251–265 run them again for the actual fusion. The first pass contributes no loss gradient but consumes dropout RNG draws and retains temporary tensors/graphs. Removing it is an efficiency/RNG adaptation, even when the distribution of dropout masks is unchanged. Likewise, unused allocated linear modules consume initialization draws. Preserve both initially for source correspondence; do not prune them as an invisible mechanical fix. The literal forward performs 18 learner evaluations, each with two GCN layers, rather than nine.

**The selector does not evaluate the saved state.** `train.py` 208–227 obtains dropout-active TRAIN-mode predictions before the optimizer step, uses their VAL accuracy after the step, then saves the post-update weights. Final prediction is recomputed in eval mode. The selected score and saved model therefore refer to different states and modes. The smallest coherent evaluation adaptation retains accuracy and patience 50 but evaluates VAL after the update in eval mode, then saves that exact state. Replacing accuracy by a common benchmark VAL-NLL selector is a further declaration; do not try both and choose the favorable result. Tie handling, checkpoint eligibility and exact replay must be fixed before outcomes.

## Author recipe versus our paired evaluation

The README advertises HGB data, but DBLP code actually calls `torch_geometric.datasets.DBLP`, uses its built-in masks, and derives class count from all target labels (`dataset.py` 35–55; `train.py` 146–152). Changing the seed changes initialization/dropout, not those supplied native masks. This is not automatically the same topology, feature ordering or split protocol as fixed HGB-DBLP. Data identity has not been checked here.

For the paired benchmark, a separately declared HGB-DBLP adaptation must consume the existing complete label-free topology and matching author features, the explicit frozen TRAIN/VAL descriptors, and the TRAIN class schema (four classes). The saved qualification specifies seeds 131/137/139/149/151 and 974/243 development splits; this packet has not opened those descriptors or labels. Build binary meta-path **support**, not path-count edge weights, and qualify target ordering, repeated-path deduplication and GCN self-loop/normalization semantics against the pinned PyG primitives. Preserve all target nodes, including isolated nodes. Do not call the author downloader or derive class count from target-complement labels.

Source evaluation computes test accuracy and OvR AUC, whereas our development comparison needs served VAL NLL and Micro/Macro-F1 at the same declared selected state. Report the HGEN learned fused predictor, not individual learners or a substituted arithmetic pool. Closed TEST labels stay closed. A fixed-split adapted result would support that adaptation; it would not reproduce the original paper's native-test result or its undisclosed grid selection.

**Missing authoritative source:** the exact DBLP experiment command/config and runnable implementation corresponding to the camera-ready result, including selected `lambda`, regularizer reduction/square, residual treatment of the first learner, and the selection/checkpoint rule. The complete preserved repository contains no config, run command, supplementary material or historical result-version binding; its README's camera-ready link is empty. The main saved paper defers dataset detail to Supplement B/Appendix and describes a grid without its chosen recipe. The relevant missing authority is that author experiment release or matching camera-ready supplement/author clarification, rather than a new local hyperparameter grid.
