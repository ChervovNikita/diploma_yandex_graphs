When an otherwise valid freeze uses a PHASE-relative study descriptor and the evaluator runs outside PHASE, this lookup addresses a different CWD-relative directory. A valid complete study can therefore fail evaluation after admission, or verify an unrelated graph-schema copy instead of the source run's file. This does not produce a favorable subset or alter the scientific gate. The supplied template uses an absolute study path and avoids this trigger. Resolve the graph-schema directory from `verify(frozen['study']).parent`, retain the already verified study path, or explicitly reject relative study descriptors before payload access.
