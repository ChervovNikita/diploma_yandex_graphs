## Requirements and commands

Use Python3.11, NumPy1.26.4, Torch2.1.2, PyG2.7.0 and SciPy. CPU and CUDA builds are explicit device choices; neither portable path has been trained by this source preparation. No installer is supplied. Copy this entire directory to an ordinary authorized machine. Work and output directories must be fresh.

```sh
python /path/to/package/cli.py prepare --work /path/to/work --download
python /path/to/package/cli.py fit --work /path/to/work --output /path/to/SW4_10103 --device cuda:0 --arm SW4 --block 10103
```

Use `--raw /path/to/ms_academic_phy.npz` instead of `--download` for an existing pinned public archive. Use `--device cpu` explicitly on a CPU machine. Full fixed fresh acquisition replaces `--arm SW4 --block 10103` with `--all`; all references then require fresh fits. The finite `--wall-seconds` limit only terminates and retains a failed attempt; it does not select a scientific horizon. No width, initializer, optimizer, gate, order, residual or training-horizon arguments exist.

The original own-view loss, native optimizer, exact latest-tied SELECT rule, independent body selectors, persistent route RNG and strict selected restore are retained.
