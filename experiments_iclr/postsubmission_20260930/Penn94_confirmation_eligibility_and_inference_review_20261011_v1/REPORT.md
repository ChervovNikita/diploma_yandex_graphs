## Recommended exact primary rule

For block b and comparator R, obtain integer raw correct counts on the **same full CONFIRM denominator n**. Define

`d[b,R] = 100 * (correct[b,current] - correct[b,R]) / n` percentage points.

Use all ten paired differences. Compute their arithmetic mean, unbiased sample SD and SE = SD/√10 in float64 without rounding before decisions. For positive-effect inference use the predeclared one-sided paired t test `H0: μ_R ≤ 0` versus `H1: μ_R > 0`, `t_R = mean / SE`, df=9, `p_R = t_survival(t_R,9)`. Source-pin the CDF/quantile implementation before fitting/scoring. No t test on member scores or node errors substitutes for this bank-level pairing.

Apply Holm at familywise α=0.05 across exactly these **four** primary p values. Sort ascending by `(p,contrast_id)`; compare ranks r=1..4 with `0.05/(5-r)` and stop rejecting at the first failure. Adjusted p at rank r is `min(1,max_{j≤r}((5-j)*p_(j)))`. Map back to the fixed contrast names. The complete primary confirmation requires **all four** adjusted p≤0.05 **and all four observed mean gains≥+0.2 pp**. Missing native pairs or nonfinite raw scores prevent the complete-ten-seed confirmation; do not shrink the sample or substitute a seed.

This follows the earlier proposed positive-effect-plus-practical-point-estimate design. It supports “evidence of a positive conditional gain, with observed mean at least 0.2 pp.” It does **not** support “the true gain is established to exceed 0.2 pp.” That stronger claim requires root to freeze a margin-null test `H0: μ_R ≤ 0.2` before fits; it must not be introduced after scores. Do not add an all-ten-positive accuracy veto from the earlier three-seed development screen; report every sign transparently.

Predeclare the degenerate case: if all ten integer correct-count differences are identical, SD=0, so paired t inference/intervals are undefined; record that fact and use p=1 for the confirmation decision, with no automatic alternate test. The t reference is exact under independent normally distributed block differences; with ten fixed seed identifiers its use is a model-based assumption/approximation, not guaranteed by a large-sample argument or by those identifiers alone.
