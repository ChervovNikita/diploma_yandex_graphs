# Source-only prospective frame mechanism analysis

This implements the already frozen Citeseer mechanism description. It has not been executed, imported as a runtime module or tested on scientific payloads. No checkpoint, prediction, history, input, metric or remote state was accessed during preparation.

The script waits for both the complete 36-fit cohort and successful complete analysis v2. Execution also requires an exact root-reviewed admission receipt binding the cohort freeze, analysis RESULTS and START, served prediction file, this script and its source manifest. It authenticates all 36 physical terminal hashes before opening payloads. The receipt must be prepared after successful analysis; the accompanying schema is a description, not an execution admission.

After those gates, it verifies the acquired TRAIN/VALID identities and reads only their positive-edge text. The graph strata use undirected observed TRAIN topology, with no self loops. Common-neighbor zero/positive and the three fixed minimum-degree bins are two separate partitions. Every bin, including empty bins, keeps all seven families and all six paired contrasts. Each positive retains its complete fixed 500-negative ranking. No subgroup chooses a model or rescues an unsuccessful aggregate result.

Selected framed checkpoints supply their prospective frame rows/axes. Norm and off-axis energy are reported for all 21 framed fits. Pairwise Householder map distances are computed only within private-frame banks and same-four-frame single checkpoints, where frames share one encoder coordinate system. Shared-frame and independently trained one-frame checkpoints have no unique within-model frame pair and retain empty pair lists. Independent-encoder vectors are never pooled for map distances.

Vector norm depends on scale gauge and is not transform magnitude. Learned coordinates across architectures/checkpoints are not semantically aligned. Map differences establish neither complementary predictions nor a causal quality benefit. The current runner saves averaged validation logits, so this script performs no member-logit analysis, model inference or axis-reset experiment.

The original native single remains ordinary independent-ensemble member zero in each prospective block. The complete terminal registry must retain the initial baseline reuse and the 35 remaining unique fits. Config, input, selected checkpoint, served prediction and downstream result identities are preserved in output provenance. Failed attempts retain partial files; pre-output failures print a receipt for outer client custody. No files are deleted or retried.

Three blocks on one validation-selected split support descriptive diagnostics only. The implementation performs no significance tests, TEST scoring, fits, optimizer updates, reselection, coefficient/bin tuning, source-paper reading or canonical-state edits. It cannot establish novelty, generality or superiority.
