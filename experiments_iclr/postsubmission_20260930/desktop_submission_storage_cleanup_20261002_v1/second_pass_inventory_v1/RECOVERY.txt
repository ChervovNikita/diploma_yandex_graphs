Recover the 48 offloaded historical research files

The private archive location, byte count and SHA256 are in COLD_CLEANUP_RECEIPT.json.
The archive is self-contained: 47 SHA256-named objects reconstruct all 48 exact
project-relative file paths, including the factor tar and both publication copies.
It includes the exact COLD_FILE_MANIFEST.json, this guide and the recovery source.

Copy cold_research.objects.tar.gz from the authorized server using existing SSH
credentials. Verify its SHA256 against the cleanup receipt before recovery.

Run:
python3 -B recover_cold_files.py cold_research.objects.tar.gz NEW_RESTORED_PROJECT

Choose a new directory under an existing canonical parent. Recovery verifies
every object and the manifest, creates only the 48 historical files, and restores
their original file permissions and modification times. No archived code runs.
Existing destinations are refused. Restored ownership belongs to the restorer.
Temporary objects plus reconstructed files require about 1.77 GB of extra space,
in addition to the compressed archive itself.

The recovered directory mirrors the original project-relative paths. Existing
research sources and historical compact decisions/protocols/locks/summaries stayed
local. This archive contains no active model/data/runtime or real Git objects.
