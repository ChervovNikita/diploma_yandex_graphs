Constructor: adapted_public copies only the pinned Session.__init__ AST, inserts
one install call immediately before its original nested optimizer factory, then
compiles that constructor in a fresh namespace/subclass. The original public
module/class is not patched. Installation checks a fresh shared M4 unit arm and
the absence of optimizers. Native reset and BE installation have already occurred;
the private hook copies local att_src/att_dst rows without another RNG draw.
Original Adam then sees the registered private banks. This is not an optimizer
retrofit. The only deepcopy operates on AST/config data, never an installed model.

Routing: the wrapper captures the original bound ensemble.member_forward and
passes the same member through private scorer context and original BE context.
Session.forward uses it for both shadow views, context replay uses it for all
eight VJPs, and evaluation/serving uses it too. Later cost instrumentation wraps
this callable rather than bypassing it. Selector state is restored in finally;
parametrizations are neither cached across members nor left selected. Native GAT
forward/global QKV/value maps remain intact. This relies on the existing sequential
member execution; concurrent member forwards are unsupported.

Targets/public calling: only shared_common/shared_route are exposed. The CLI
consumes an explicitly SHA-bound numeric archive, copies its arrays, makes them
read-only, records content hashes, validates current TRAIN IDs/labels and the
exact CPU/device panel, and retains the original TV differentiation gate with no
regeneration/retry. Logical same-class/self/permutation contracts are validated;
generation custody and arbitrary-NPZ official provenance are explicitly not
certified. The published context generator remains available to callers. There
is no author-host/archive dependency or author six-fit admission in this wrapper.

Driver/snapshots: inherited context code retains complete580 two-view own CE,
residual-free fixed-target alignment, original1100/100local schedule, one Adam
after full replay accumulation, original strict-first joint development selector,
joint local model/Adam restore with live streams, mean-probability serving, and
complete call/count checks. The new snapshot wrapper adds adapter/portable/hook/
constructor-AST hashes and actual private parameter-bank/count metadata to the
original state/RNG/config/epoch/global snapshot. COMPLETE binds selected.pt's hash.

One custody limit: the snapshot's run dictionary is not annotated in place by the
JSON writer, so isolated selected.pt does not carry the successor train.py hash
or context-manifest field added to RUN/COMPLETE/PUBLIC_COST. Preserve these receipts
with the selected state to retain the complete training-entry binding. This is
not a member routing or optimizer defect.

Serving reconstruction builds the private banks/wrapper before strict state_dict
loading, checks private arm/source/AST/count/model-recipe identity, restores the
saved Boolean global flag explicitly, switches to eval, and blocks train_step.
It performs no reselection or optimizer/RNG-history restore. The caller supplies
a trusted in-memory selected dictionary and the pinned public/native dependency;
the function is a serving primitive, not a standalone checkpoint-custody verifier.
