## Why sharing might matter—and why I4 might win

Class coordinates have the same meaning in every route. A single compatibility
law can be estimated across several private predictive views while one common
body learns features useful to that law. With few TRAIN labels, this constraint
may reduce unstable route-specific relationship fitting and improve competent
rankings. This is a regularization/estimation hypothesis, not four independent
observations or a variance theorem. Near-identical views provide little benefit;
one global law can be wrong for heterogeneous regions. Repeated messages can
amplify common errors, overconfidence or collapse useful alternatives.

Ordinary I4 receives the same decoder and can benefit equally or more from better
neighbor predictions. Sharing B alone may explain any gain. A capable single may
already learn everything needed. These are essential falsifiers, not secondary
ablations. A decoder gain over plain native models alone does not solve the
shared-ensemble goal.
