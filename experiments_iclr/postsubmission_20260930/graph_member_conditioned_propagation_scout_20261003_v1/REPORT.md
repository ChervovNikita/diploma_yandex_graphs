# Member-conditioned propagation: collapse boundary and negative scout

3 October 2026. **No distinct next quality method is promoted.** Member-dependent graph kernels can change which evidence reaches a prediction, a more concrete mechanism than hidden-coordinate separation. But the shared-linear collapse applies only to a restricted architecture; the live HGT/CP contract already permits member-dependent attention through private nonlinear states. The simplest additional relation-conditioned attention proposals are either an exact null under its normalization or a private version of existing typed score parameters. This is a bounded no-gap finding, not proof that such an ablation cannot improve quality or that every structural-kernel extension is already published.

## 1. Exact shared-linear collapse, with assumptions

Use row states H_m^ell and one fixed node operator P, common across members and layers. Suppose H_m^0=X and every layer is linear with node-independent feature weights:

```
H_m^(ell+1) = P H_m^ell W_m^ell.
```

W_m may be fully private or generated by arbitrary BE input/output factors around shared matrices. There is no intervening activation, feature normalization, node gate, nonlinear attention, member-dependent graph mask or stochastic serving map. Then exactly

```
H_m^L = P^L X (W_m^0 W_m^1 ... W_m^(L-1)),
mean_m H_m^L = P^L X W_eff,
W_eff = mean_m (W_m^0 W_m^1 ... W_m^(L-1)).
```

A final affine member classifier can be absorbed into the corresponding product and averaged bias. The feature matrices need not commute: their multiplication order is preserved. For common layer-dependent P_ell, replace P^L by the ordered product P_(L-1)...P_0. The identity is for **fixed fitted weights and the served mean logits**; separate-member training may still regularize the learned W_eff differently. W_eff is an unrestricted effective matrix, not necessarily realizable by a single network with every original bottleneck/rank/factor constraint. For example, averaging rank-one effective matrices can raise rank. Thus this is a one-propagation-bank collapse, not a blanket equality to every constrained single-model class.

**Bias convention matters.** With bias added after propagation,

```
H_m^(ell+1) = P H_m^ell W_m^ell + 1 b_m^ell,
```

the final bias field is the sum over ell of

```
P^(L-1-ell) 1 [b_m^ell W_m^(ell+1) ... W_m^(L-1)].
```

If P1=1, it collapses to a constant effective output bias. Otherwise retain the known structural columns P^k1; calling it a constant bias is wrong. Bias inserted before P has one extra P in its corresponding term. This convention must not be silently transferred to HGT's biased value/relation branch.

**Self/root terms change the bank.** If a layer is P H A_m + H B_m, the result lies in a polynomial bank sum_(k=0)^L P^k X C_mk (plus the bias fields). Each C_mk sums the ordered feature-matrix products along its paths; noncommuting A/B cannot be reduced to scalar binomial coefficients. Averaging members averages C_mk. With several fixed relations P_r, retain products along relation sequences, generally noncommuting; they do not all become P^L. This is the R-GCN/SIGN/filter-bank boundary, not a new collapse theorem.

**Nonlinearity already invalidates the identity.** ReLU/GELU/tanh, data-dependent normalization, endpoint-dependent gates or attention can prevent folding the mean into one effective feature matrix even when the underlying sparse graph is common. Different P_m also remove the one-P^L form: mean_m P_m^L X A_m is a multi-operator bank. For fixed linear kernels it still folds into one affine classifier on that known bank, already the multiscale/view/filter family. Neither varying kernels nor varying nonlinear routes guarantees label-relevant complementarity.

## 2. What the actual current HGT contract permits

The saved [implementation README](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/graph_heterogeneous_private_modulation_implementation_20261003_v1/README.md>), especially its recurrence/normalization description, binds the current operation:

- Each member retains its own hidden states, Q/K/V, attention frames, messages, recurrence and dropout stream.
- Message scaling uses Gamma_mrj=b_mj+c_m q_r u_j after the relation value transform, before relation messages are combined.
- Attention softmax is **separate inside each canonical relation**, followed by an equal cross-relation mean; zero-degree rows remain zero in that mean. It is not the global cross-relation target-neighborhood softmax described in a different pyHGT implementation.
- Biased typed output/skip, optional LayerNorm and dropout, input adapters with tanh, and the classifier remain.

Consequently, “output-only CP” here means output of the relation value map, not only final classifier output. It affects private states used by later Q/K evaluations. With identical first-layer Q/K inputs and native parameters, that layer's edge weights agree; once hidden states differ, subsequent attention **can already differ by member**. This is a capability statement, not a measurement of divergence or utility. There is no evidence here that all trained kernels actually differ, or that any difference is useful.

The shared-linear theorem therefore does not explain a known collapse in this HGT family. A test on a common-P affine toy would settle a toy implementation identity, not the live committee's quality limitation. No such numerical gate is proposed.

## 3. One proposed structural change assessed

The candidate family was a static, compact member-by-relation attention adapter before softmax. Its intended quality mechanism is explicit: change which neighboring evidence a member emphasizes before it is averaged, rather than merely rescaling the already averaged value vector. That distinction is real at a fixed layer, but the proposed simple realizations do not supply the requested distinct method.

### Additive relation/head log-prior: exact null here

For scores a_mrhuv, add a learned beta_mrh constant over the source neighbors u of target v within relation r. Under the bound current normalization,

```
alpha'_mrhuv = exp(a_mrhuv+beta_mrh) / sum_w exp(a_mrhwv+beta_mrh)
             = alpha_mrhuv.
```

The beta derivative is identically zero for every nonempty relation neighborhood. Negative/signed beta, CP factorization, different member coefficients or TRAIN supervision do not change the null. Empty relation-neighborhood handling remains its unchanged zero convention. A beta that varies within that neighborhood is a different operation.

If instead softmax were global across relations, the same bias would be nonnull:

```
alpha'_uv = exp(beta_r) alpha_uv / Z_v,
Z_v = sum_r exp(beta_r) sum_(u in relation r) alpha_uv.
```

This is a normalized positive mixture of existing relation messages with a target-dependent normalizer. A node-independent post-value gate cannot generally absorb Z_v, but typed relation/semantic attention is established. Substituting global normalization into current HGB-HGT would also change its native architecture; it is not an implementation of the stated simple adapter on the preserved contract. Softmax remains nonnegative: a signed log-prior does not create signed edge transport.

### Score multipliers or Q/K factors: nonnull but known attention

A member-specific multiplier mu_mrh on an endpoint score a_uv can change within-relation ranking:

```
alpha_u/alpha_w = exp(mu_mrh [a_uv-a_wv]).
```

A negative multiplier can reverse ranking. It does not make the resulting attention weights negative. A static value factor applied after attention cannot change this ratio at that same layer. Thus directly conditioning scores is a genuine *site/capability distinction* from post-value scaling.

However, the retained HGT method already has relation-conditioned score parameters. Copying/conditioning those parameters by member is an untying of existing typed attention, with the remaining core shared. Applying BE or conditional diagonal factors to Q/K is likewise ordinary parameter-shared attention. Replacing the coefficient table with c_m q_r u_h is known conditional tensor gating, not another structural-kernel principle. The precise current score-table dimensions/sites would require source binding before exact training equivalence; no binding or driver is attempted here.

Ordinary member CE can teach these parameters useful neighbor choices. It also allows identical kernels, overfit specialization, or changes that improve only average member competence. It adds no requirement that different members correct complementary errors. Nonnull kernel derivatives, more edge-weight spread, attention entropy or hidden separation cannot substitute for improved served NLL/F1. The current CP also already changes later structural use through recurrence, so a direct score adapter would concern *additional first-layer/local score freedom*, not invention of member-conditioned propagation.

**Decision: no distinct next method/experiment from this scout.** The null additive-bias candidate is mathematically excluded on the current normalization. The nonnull static score/QK alternatives have a real attention-placement question, but this scout supplies no supported incremental learning criterion beyond untying native attention and applying known conditional adapters. Known ingredients do not automatically reject a valuable complete composition; here the proposed complete change itself is the named parameter-sharing/placement relaxation, with no further mechanism yet specified. A bounded empirical ablation could be useful as an ordinary attention-placement control, but it should not be promoted as a new structural-diversification method merely because a full published HGT recipe with identical settings was not located.

The strongest scientific correction to carry forward is that current private nonlinear HGT already escapes the one-P linear boundary. A positive future quality result must distinguish extra score freedom from post-value adaptation, ordinary native attention and heterogeneous view ensembles, while measuring actual served predictions. This report establishes no result about that utility and recommends no duplicate run, heldout opening or expansion of the live studies. Scarce GPUs did not enter the disposition.
