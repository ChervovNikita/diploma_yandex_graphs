<span id="id1"></span><h1>Quickstart<a class="headerlink" href="#quickstart" title="Link to this heading">#</a></h1>
<p>To get started with Chemprop, first install the package using the instructions in the <a class="reference internal" href="installation.html#installation"><span class="std std-ref">Installation</span></a> section. Once you have Chemprop installed, you can train a model on your own data or use the pre-packaged solubility dataset to get a feel for how the package works.</p>
<p>Let’s use the solubility data that comes pre-packaged in the Chemprop directory:</p>
<div class="highlight-text notranslate"><div class="highlight"><pre><span></span>$ head tests/data/regression.csv
smiles,logSolubility
OCC3OC(OCC2OC(OC(C#N)c1ccccc1)C(O)C(O)C2O)C(O)C(O)C3O,-0.77
Cc1occc1C(=O)Nc2ccccc2,-3.3
CC(C)=CCCC(C)=CC(=O),-2.06
c1ccc2c(c1)ccc3c2ccc4c5ccccc5ccc43,-7.87
c1ccsc1,-1.33
c2ccc1scnc1c2,-1.5
Clc1cc(Cl)c(c(Cl)c1)c2c(Cl)cccc2Cl,-7.32
CC12CCC3C(CCc4cc(O)ccc34)C2CCC1O,-5.03
ClC4=C(Cl)C5(Cl)C3C1CC(C2OC12)C3C4(Cl)C5(Cl)Cl,-6.29
...
</pre></div>
</div>
<p>Now we’re ready to train a simple Chemprop model:</p>
<div class="highlight-bash notranslate"><div class="highlight"><pre><span></span>chemprop<span class="w"> </span>train<span class="w"> </span>--data-path<span class="w"> </span>tests/data/regression.csv<span class="w"> </span><span class="se">\</span>
<span class="w">    </span>--task-type<span class="w"> </span>regression<span class="w"> </span><span class="se">\</span>
<span class="w">    </span>--output-dir<span class="w"> </span>train_example
</pre></div>
</div>
<p>This will train a model on the solubility dataset (<code class="docutils literal notranslate"><span class="pre">tests/data/regression.csv</span></code>) and save the model and training logs in the <code class="docutils literal notranslate"><span class="pre">train_example</span></code> directory. You should see some output printed to your terminal that shows the model architecture, number of parameters, and a progress bar for each epoch of training. At the end, you should see something like:</p>
<div class="highlight-text notranslate"><div class="highlight"><pre><span></span>───────────────────────────────────────────────────────
   Test metric             DataLoader 0
───────────────────────────────────────────────────────
    test/mse             0.7716904154601469
───────────────────────────────────────────────────────
</pre></div>
</div>
<p>With our trained model in hand, we can now use it to predict solubilities of new molecules. In the absence of additional data, for demonstration purposes, let’s just test on the same molecules that we trained on:</p>
<div class="highlight-bash notranslate"><div class="highlight"><pre><span></span>chemprop<span class="w"> </span>predict<span class="w"> </span>--test-path<span class="w"> </span>tests/data/regression.csv<span class="w"> </span><span class="se">\</span>
<span class="w">    </span>--model-path<span class="w"> </span>train_example/model_0/best.pt<span class="w"> </span><span class="se">\</span>
<span class="w">    </span>--preds-path<span class="w"> </span>train_example/predictions.csv
</pre></div>
</div>
<p>This should output a file <code class="docutils literal notranslate"><span class="pre">train_example/predictions_0.csv</span></code> containing the predicted log(solubility) values for the molecules contained in <code class="docutils literal notranslate"><span class="pre">tests/data/regression.csv</span></code>.</p>
<div class="highlight-text notranslate"><div class="highlight"><pre><span></span>$ head train_example/predictions_0.csv
smiles,logSolubility,pred_0
OCC3OC(OCC2OC(OC(C#N)c1ccccc1)C(O)C(O)C2O)C(O)C(O)C3O,-0.77,-1.0349703
Cc1occc1C(=O)Nc2ccccc2,-3.3,-3.0304263
CC(C)=CCCC(C)=CC(=O),-2.06,-2.0320206
...
</pre></div>
</div>
<p>Given that our test data is identical to our training data, it makes sense that the predictions are similar to the ground truth values.</p>
<p>In the rest of this documentation, we’ll go into more detail about how to:</p>
<ul class="simple">
<li><p><a class="reference internal" href="installation.html#installation"><span class="std std-ref">Install Chemprop</span></a></p></li>
<li><p><a class="reference internal" href="tutorial/cli/train.html#train"><span class="std std-ref">Customize model architecture and task type</span></a></p></li>
<li><p><a class="reference internal" href="tutorial/cli/train.html#train"><span class="std std-ref">Specify training parameters: split type, learning rate, batch size, loss function, etc.</span></a></p></li>
<li><p><a class="reference internal" href="notebooks.html#notebooks"><span class="std std-ref">Use Chemprop as a Python package</span></a></p></li>
<li><p><a class="reference internal" href="tutorial/cli/hpopt.html#hpopt"><span class="std std-ref">Perform a hyperparameter optimization</span></a></p></li>
<li><p><a class="reference internal" href="tutorial/cli/fingerprint.html#fingerprint"><span class="std std-ref">Generate a molecular fingerprint</span></a></p></li>
</ul>

<ul class="simple">

<li><p>Train a model with <code class="docutils literal notranslate"><span class="pre">chemprop</span> <span class="pre">train</span> <span class="pre">--data-path</span> <span class="pre">&lt;input_path&gt;</span> <span class="pre">--task-type</span> <span class="pre">&lt;task&gt;</span> <span class="pre">--output-dir</span> <span class="pre">&lt;dir&gt;</span></code></p></li>
<li><p>Use a saved model for prediction with <code class="docutils literal notranslate"><span class="pre">chemprop</span> <span class="pre">predict</span> <span class="pre">--test-path</span> <span class="pre">&lt;test_path&gt;</span> <span class="pre">--checkpoint-dir</span> <span class="pre">&lt;dir&gt;</span> <span class="pre">--preds-path</span> <span class="pre">&lt;path&gt;</span></code></p></li>
</ul>
