## 1. Frozen experts: counterfactual route value and router-only correction

**When Are Experts Misrouted? Counterfactual Routing Analysis in Mixture-of-Experts Language Models**, [arXiv2605.07260v1](https://arxiv.org/html/2605.07260v1). Read§2,§3.1,§4 and§5.1 only; source HTML SHA96b3833b299be6d8216a40a64af600f3b6718e6a5ab5842ace871528f46d3190. No empirical-result section, author code, figure pixels or full-paper/proof audit.

The method fixes a pretrained sparse MoE. On a verified-correct trajectory, it compares the standard token/layer top-k route with32 sampled same-cardinality alternatives from a32-expert candidate pool, recomputes selected gates, and executes the rest of the model with all weights fixed. The realized next-token probability is a local route-value proxy. This measures *currently reachable expert capacity*, not gain from updating an expert.

Its Expert Preference Optimization samples alternatives for current hard tokens, keeps a lower-CE route if found, and fits only the final-layer router through a CE-gap-weighted DPO-style preference loss. All experts and other routers remain frozen. The reference router is frozen; chosen-only versus rejected-only experts receive score changes. Generating verified trajectories and evaluating alternatives are paid work; equal route cardinality is not a declaration of equal total training cost.

The fixed-top-k derivative in Eq3 gives zero task-loss derivative with respect to unselected scores for that cell; the shown balance gradient uses router statistics rather than alternative expert outputs/losses. This supports a specific missing *token-level route-value* signal. It does not prove that ordinary training can never change routes: other tokens, representation updates, load balancing and boundary crossings can change them. The diagnostic also conditions on successful trajectories and sampled alternatives, rather than certifying all hard problems or globally best routes. Local next-token CE is not complete reasoning success.

**Relevant comparison:** frozen-capacity competence allocation is direct recent ancestry for counterfactual expert valuation. Our candidate changes private weights with an own-CE probe and uses learning-margin delta, while Q allocates training and does not gate serving. Because every branch already receives own supervision and the pool serves every branch, the sparse unexecuted-expert blind spot cannot simply be transferred to this dense GNN bank.

## 2. One shared policy: current counterfactual competence and decision-specific credit

**CounterRoute: Self-Routed Reasoning via Hierarchical Counterfactual Credit Assignment**, [arXiv2609.29109v1](https://arxiv.org/html/2609.29109v1). Read§2 and complete§3 text/equations only; source HTML SHAf509f6073c5e1fe876dfbc3979dd5f9e6c6840b89eb4f8620204dee58162dad8. Appendix algorithms/gradient proof, author code, images and empirical results were not audited.

One shared policy chooses thinking versus no-thinking and then generates a mode-conditioned answer. Paired updates force both modes under the same current parameters/prompt, sampleK responses per mode, and estimate their reward difference minus an efficiency-prior margin. That margin is not measured token/latency cost.

The signed bounded between-mode advantage replaces the first routing-token credit; within-mode GRPO advantages train later response tokens. These disjoint signals update the SAME shared parameters, not separate private member banks. Self-routed updates use ordinary full-sequence GRPO; a curriculum retains paired mode coverage. The paper explicitly describes the forced-mode routing update as an intervention-based surrogate, not an unbiased gradient under natural route sampling. Paired rollouts and changing curriculum have different full costs.

This is concrete prior for refreshing counterfactual utility as a shared model learns and assigning credit to the decision responsible for an outcome. However, its utility is current conditional reward, not before/after private SGD learnability; it does not differentiate through a virtual private optimizer, perform theta+ original-phi recommit or serve a fixed four-member probability mean. If all sampled rewards within a mode are identical, the displayed centered within-mode numerator is zero; under ordinary stabilization it supplies no differentiating response advantage. Dense supervised CE can still have informative gradient in jointly wrong cases if the model's parameter path can express the correction, but that possibility is not a guarantee.

## The sharper falsifiable gap, without a new grid

**Can finite private learning response improve complete served prediction beyond allocating existing competence and ordinary dense corrective training?** These primary methods make the distinction precise: current route/mode value, improvement after a declared private update, and the ownership of shared credit are different operations.

The already defined current-margin control is the nearest matched current-competence test; the matched live first-order utility remains necessary to isolate finite response beyond gradient utility. Competent same-bank own/pool training, capable single and untied ensemble references remain necessary for complete prediction/sharing claims. A literal LLM router or GRPO port would change architecture, labels/rewards, serving and costs; this scout does not add one to the GNN pilot.

A claim of correction learning would be weakened if gain is explained by choosing already competent paths or reproduced by ordinary dense training/current margins. It would require complete served benefit with member competence preserved beyond the matched references, under prospectively fixed comparison/qualification. Better sampled-route headroom, balance, response magnitude or S/R diagnostics cannot substitute for that endpoint. This is a methodological question, not an invented contribution or a paper theorem for the candidate.
