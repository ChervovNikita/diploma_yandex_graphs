MEMBER-PRIVATE TYPED PROPAGATION: A BOUNDED QUALITY-GAP CHECK
4 October 2026. Research memo; no method or execution adoption.

FINDING

No defensible new graph-specific propagation or initialization mechanism was found. The strongest newly read negative check is GTN: it already learns ordered typed paths, applies shared dense feature maps to different graph channels, applies channel nonlinearities, and combines the results. MUG already runs one shared encoder over multiple meta-path views. These are closer precedents than a generic final-head ensemble. Persistent private nonlinear trajectories leave a meaningful empirical utility question, but that question extends the saved member-filter review; it is not a newly discovered mechanism or a cleared novelty gap.

One testable hypothesis remains: when different schema-valid typed neighborhoods carry complementary label-relevant evidence, keeping member states separate through repeated nonlinear propagation, while tying dense maps, can improve a fixed pooled predictor over a competent shared multichannel representation with equally capable heads. A useful result must survive the complete-path-bank, learned-channel, exact BatchEnsemble and independent-ensemble comparisons below. No source inspected here establishes that advantage. Different paths, different initializations, coefficient separation and auxiliary likelihood fit do not imply complementary correct predictions.

EVIDENCE THAT CHANGES THE CLAIM

1. Yun et al., Graph Transformer Networks: Learning Meta-path Graphs to Improve GNNs, arXiv:2106.06218v1, 11 June 2021. New scoped primary method read: PDF pp. 3-6, Sections 3.2-3.5, Eqs 2-21; visual checks pp. 3-6. https://arxiv.org/abs/2106.06218v1

GTN learns each path step as a softmax convex mixture of relation adjacencies (Eqs 3-4), composes those steps (Eqs 2,5-6), and uses multiple learned graph channels. Including identity allows shorter paths. Eq 8 expressly shares W^(l) across channels, applies sigma to each channel, then aggregates them; classification uses dense/softmax layers and CE. Thus typed path selection, path ordering, distinct nonlinear channel responses and a shared dense backbone are established together. Recasting these channels as members changes objective/serving placement, not the underlying graph operation.

FastGTN rewrites adjacency products as successive feature transports (Eqs 9-15). The equality derivation assumes every candidate adjacency is row stochastic; it does not qualify arbitrary typed zero-row kernels, a changed normalization, or nonlinearities inserted between the reassociated linear steps. Native multilayer/multichannel Eqs 16-17 use channel-indexed W_c and fuse channels into a common Z^(l+1). Tying those maps would be a restriction, not the printed native formula. Section 3.5 also constructs a sparse nonlocal adjacency from the average current channel states (Eqs 18-21). Therefore state-informed graph construction and efficient path evaluation are also prior. Neither this method scope nor its abstract speed figures certify the paid cost or quality of an ensemble with persistent private states. Proofs, results, author code and mini-batch recipe were not audited.

2. Shan et al., MUG: Meta-path-aware Universal Heterogeneous Graph Pre-Training, arXiv:2602.22645v1, 26 February 2026. New scoped primary method read: PDF pp. 3-5, Definitions 3.1-3.3 and complete Method, Eqs 1-14; visual checks pp. 3-5. https://arxiv.org/abs/2602.22645v1

MUG learns meta-path context embeddings by skip-gram, freezes and concatenates them with attributes (Eqs 3-6), aligns dimensions (Eqs 7-9), and explicitly computes Z_phi=GNN_shared(A_masked_phi,X_unify) for every path view (Eq 10). Its objective combines reconstruction, alignment and global scattering (Eqs 11-14). Shared weights do not mean one graph pass: each view is encoded. Definition 3.2 freezes the universal encoder on unseen graphs. This is a recent shared-encoder/path-view precedent, not a predictive member ensemble. Its homophily rationale does not establish performance on heterophilous typed neighborhoods. The prose seeks reduced dependence on dataset-specific aggregation, while Eq 14 still contains beta_phi and Eq 12 describes semantic attention; this scope does not resolve every final aggregation/implementation choice. No source code, complete protocol, result or strongest-backbone claim is adopted.

OPERATION BOUNDARY AND FALSIFIABLE HYPOTHESIS

For a target type T, let P and Q be valid closed typed-walk operators T->T, for example paper-author-paper and paper-venue-paper. Products such as PQ are dimensionally valid. For cross-type relations use compatible rectangular compositions; arbitrary differently typed adjacency products are not meaningful.

A candidate family can retain H_m^(l+1)=sigma[sum_r alpha_mlr P_r H_m^l W_l], with a common W_l and separate H_m^l. This is an attributed parameter-sharing ensemble of established message-passing operations. Noncommutation of P and Q only says ordered responses can differ; labels might depend on neither. The scientific hypothesis concerns label-aligned information in those different nonlinear trajectories, not noncommutation by itself. Shared W_l still acts on every H_m^l; storage sharing and batching do not eliminate that arithmetic.

The narrow prediction is that any reliable gain over equally capable heads should appear where private responses capture different TRAIN-defined error-relevant neighborhoods and should diminish when a capable common backbone retains those same responses. Prospective diagnostics should separate response difference, member correctness, error overlap and the chosen pooled prediction. TRAIN-only response/gradient alignment is an explanatory diagnostic, not a guarantee and not a new regularizer. Distinct initializations must be compared within the same architecture and objective; no novel initialization rule emerges from these papers.

Three failure/equivalence cases are decisive. (i) With one-stage node-independent linear path mixtures, a complete shared token bank of all the same ordered path responses plus a capable nonlinear private head reproduces the member exactly. (ii) A linear mean-logit ensemble with a common classifier collapses to the mean filter; private classifiers give an ordinary multiple-basis predictor. Mean probabilities are a different served object and must be declared. (iii) Filters applied after a shared stem erased the relevant evidence cannot restore it. Repeated nonlinear neighbor propagation can leave the fixed linear-cache family, but a sufficiently capable multichannel backbone can itself compute those trajectories. The distinction is then allocation, inductive bias and paid resources, not an unexplained function-class novelty.

FAIR PROSPECTIVE CONTROL ROLES

These are requirements for interpreting a separately authorized empirical study, not a launch, tuning grid or compute request.

* Common routes plus the same private heads, nonlinear depth and member loss: isolates allowing private propagation coefficients. Matched versus independent initializations isolates the initialization question.
* Complete ordered meta-path cache plus capable private nonlinear heads, including identity/residual evidence: tests one-stage information claims. Charge construction, storage, label propagation and training/serving access. An incomplete cache is not the exact absorption control.
* GTN/FastGTN learned channels and a competent SeHGNN/HGT/Simple-HGN single predictor: tests known typed capacity and shared-view alternatives. A tied-map channel adaptation must be labeled; keep normalization and nonlocal operations explicit. Recent REEF/MUG/DRA belong only where their pretraining and task setting are genuinely comparable.
* Exact all-layer BatchEnsemble and an independent ensemble on the same competent backbone: tests whether private typed operators add value beyond existing private-state ensembles and whether sharing loses useful capacity. Retain every member-dependent message/attention operation and account for complete work.

Hold observable inputs, splits, label access, member count, optimization opportunities and serving aggregation fixed for the mechanism comparisons. Do not match only nominal width or parameter count. Report paired pooled quality and complete paid training/serving cost; compare efficiency along actual resource constraints rather than crediting free caches or free pretraining. Oracle member selection is a diagnostic, not the served predictor. Low member error overlap without a useful fixed pool does not support the hypothesis.
