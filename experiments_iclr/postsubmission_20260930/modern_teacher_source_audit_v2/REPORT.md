For native v2 partials, compare their emitted admission, input_identity, preprocessing and source_seal to the audited tested admission/input/preprocessing/source seal. Root reports that such artifacts exist, but they were outside this immutable source-only audit and were not accessed. ### REPLAY_1 — correction records replay disagreement and continues

`prototype/correction_screen_driver.py:475–483` restores the selected checkpoint, recomputes logits, loads the selected saved logits and records the maximum absolute difference. At `488–490` those recomputed logits enter correction input preparation. No reference shape/dtype/finite check or frozen-tolerance assertion gates this continuation. `prototype/modern_teacher_adapter.py:279–291` checks checkpoint metadata and state loading, not saved-output parity. The explicit strict replay assertion at `prototype/modern_teacher_driver.py:249–263` only runs for a short qualification.

Thus a scientific selected checkpoint with finite replay disagreement beyond the frozen logit tolerance can still produce a successful correction terminal and SCORE_FREEZE. This is a missing source validity gate, not an observed replay failure. Add a driver-only comparison before input preparation: exact FP32 reference shape/dtype, finite values and `rtol=1e-5, atol=1e-6` assertion against the saved logits. Retain the replay receipt, charge comparison/transfers and propagate failures through the existing terminal ledger.
