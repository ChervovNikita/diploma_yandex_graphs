The interfaces are head_only, mixed_single, private4, middle_state_mean and I4_mixed. Each actual body takes four TRAIN tail-dropout draws with caller-owned persistent context(view) streams. Ownership inspections choose no optimizer law.

Biases/final gates/Wo draw nothing and start zero; private e uses onehot-.25.
