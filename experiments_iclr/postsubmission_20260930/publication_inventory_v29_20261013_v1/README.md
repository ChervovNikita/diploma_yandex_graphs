## Verify or restore exact source paths

`restore_publication_sources.py --repo-root <checkout>` verifies every archive member and the compressed master metadata without importing or running model code. Add `--restore` to create absent source paths with exclusive writes. Existing equal bytes are verified and retained; an unequal existing file or symlink is rejected. Dependencies and data providers require their separately declared preparation and admission.

The seven source files restored during this preparation have a fresh `MISSING_SOURCE_PIN_RESTORATION_RECEIPT.json`. Their expected hashes and sizes came from frozen v29 study receipts, and their bytes matched authorized v2 source copies exactly. Restoration does not establish historical custody.

## Scoped publication review

Staging requires `--stage` and the separately reviewed `PUBLICATION_CONTROL_BINDING.json` SHA256; the allocation identity, expected HEAD, existing branch, every file hash, and an empty index are checked first. Optional commit uses an explicit message file. The helper does not push.
