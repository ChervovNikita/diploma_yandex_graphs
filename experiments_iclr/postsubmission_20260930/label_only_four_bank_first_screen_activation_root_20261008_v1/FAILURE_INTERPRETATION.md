# Preserved first scientific launch failure

The enabled v1 campaign launched on the authorized allocation at 18:15 UTC. Its first seed completed one native update, all four correction-bank updates and the prescribed development evaluation, then failed while serializing the training trace. The native API returned three detached scalar tensors; the JSON writer accepts standard Python values.

The parent and worker exited and were reaped. Their terminal receipts, sampled costs and logs remain preserved. No partial comparative score or selected checkpoint was opened. Selected states remain closed on the server.

This is an implementation failure, not evidence for or against the method. A fresh successor may change only scalar trace serialization and its explicit source bindings. It must run the complete unchanged three-seed protocol in a new output; the failed v1 output cannot contribute a result or be overwritten.
