Class-centred residual contrast: exact algebra and parameter-update caveat

Source inspected: frozen v4/objectives.py residual_member_contrast. No numerical gradient/forward/fit/checkpoint experiment was executed for this analysis. This is an algebraic assessment, without a novelty or invariance claim.

1. Representation-coordinate statement
For each selected class c, member m and view v with n_c>=2, let A have n_c representation rows and H=I-11^T/n_c. The auxiliary branch computes R=H A and then per-row normalization and contrastive comparisons. Centers are differentiable; classes with fewer than2 selected rows contribute no residual term. A classwise common vector translation A->A+1b^T leaves R unchanged. Consequently the residual-only representation gradient is G_A=H G_R, and its row sum within that selected class/member/view is zero (up to floating-point error), including through the normalization chain. Original representation tensors are not replaced by centered tensors for prediction.

This applies to the selected auxiliary objects (at most512) and their current TRAIN-label class centers. It is a loss invariance in representation coordinates. The wording that centering preserves class means algebraically must not be interpreted as a theorem that training freezes the learned class mean or class information.

2. Shared parameter update
Representations are functions a_i(theta), with example/view/member-dependent Jacobians J_i. For the residual term alone, ordinary SGD gives delta_theta=-eta*sum_j J_j^T g_j. For a class evaluation mean mu_c=(1/n_c)*sum_i a_i(theta), its first-order change is delta_mu_c=-eta*Jbar_c*sum_j J_j^T g_j, where Jbar_c is the mean evaluation Jacobian. A zero sum of g_j does not imply a zero sum of J_j^T g_j or a zero change of mu_c when Jacobians differ. Contributions from other classes, views and members through shared parameters can also move this mean. Actual Adam preconditioning/momentum and the joint CE/alignment objectives add further reasons mean preservation does not follow.

Only special cases justify a mean-preserving step: directly optimizing independent representation rows with uniform Euclidean steps, or a restricted parameter direction whose identical Jacobian makes all centered gradients cancel. A common additive representation bias has zero direct residual gradient, but other parameters can still move the class mean. These special cases are not guaranteed by the nonlinear graph backbone/private factors.

3. Counterexample using the normalized member contrast form
Use two TRAIN objects in the same class with x1=1,x2=2; two members; identical two-view realizations. Member1 representations are a_i=(w*x_i,x_i), member2 representations are b_i=(x_i,0), w>0. Centered normalized directions for each object are matching signs times u1=(w,1)/sqrt(w^2+1) and u2=(1,0). Positive similarities are1; same-object cross-member negative similarity is c=w/sqrt(w^2+1). The symmetric residual loss reduces exactly to L=log(1+exp((c-1)/tau)). Its derivative is L'(w)=sigmoid((c-1)/tau)/(tau*(1+w^2)^(3/2))>0. The member1 class mean is mu1=(1.5*w,1.5), so an SGD step changes its first coordinate by -1.5*eta*L'(w), although the residual representation gradients sum to zero within each class/member/view. This is a mathematical counterexample for the same normalized contrast structure, not a claim that a measured native model follows this trajectory.

4. Practical interpretation
Class centering removes the empirical class-mean component from auxiliary comparisons at that forward pass. It does not ensure class information, member competence, calibration, evidence specialization or useful ensemble errors are preserved. The fixed panel checks actual decision margins, response to public-input interventions, competence and common errors; an unseen-population gain and the declared capable8-view single control remain necessary for stronger attribution. No DICE conditional-MI result, independence theorem or new scientific principle is established.
