# Evidence-response diversity in a shared GNN: drop as a new mechanism

9 October 2026. **No new mechanism hypothesis is retained.** Diversifying the feature/edge responses behind correct predictions is already a central purpose of input-gradient ensemble regularization. A shared-body graph version could answer a bounded empirical question about useful complementarity at a paid capacity and compute budget, but this is an attributed adaptation. This report does not establish an unoccupied methodological gap, positive utility, or an experiment release.

The main predecessor is the saved 7 October [graph-conditioned functional diversity assessment](../graph_conditioned_functional_diversity_gap_20261007_v1/REPORT.md). It already reaches this conclusion for graph margin responses and compares FoRDE, function-space repulsion, SuGAr, HGEN, CDLG and attention disagreement. The present scope adds the original Gradient Alignment Loss (GAL) method and the original attention-map Gram penalty, verifies several publication identities, and supplies a concrete nuisance counterexample. It reads no gate15 or relation12 outcomes.

For node v, true class y and fixed competing class c, define the shift-invariant decision margin `f_m=z_(m,y)-z_(m,c)`. For a fixed intervention T_k, let `d_(m,k)=f_m(T_k G)-f_m(G)`. This is a useful predictor response: it includes message values, attention, nonlinear paths and the decoder, and survives compensated hidden-coordinate changes. For a small differentiable intervention, `d_(m,k)≈J_m δG_k`. A cosine/kernel on d is therefore a projected input-gradient diversity objective; finite differences use perturbed function evaluations. This graph projection can be computationally useful without constituting a new evidence-diversity principle.

Correctness gating does not remove the nuisance failure. Consider a binary task whose true decision depends on signal s and is independent of nuisance n. A shared representation `(s,n)` with two member output factors can implement margins

`f_1=s+εn`, `f_2=s−εn`.

On any finite set with `s>0` and `|εn|<s`, both members are correct. Their normalized margin-gradient cosine is `(1−ε²)/(1+ε²)`, reaching zero at ε=1, entirely by adding opposite nuisance dependence. True-label log-probability gradients have the same directions up to positive scalar factors. A repulsion loss gated on correct predictions therefore rewards this behavior too. For both positive margins, sigmoid is strictly concave: `(sigmoid(s+εn)+sigmoid(s−εn))/2 < sigmoid(s)` for nonzero εn. The probability pool remains correct but becomes less confident in the true label and its NLL worsens. This analytical counterexample is not a fit or a model execution.

Attention orthogonality has a separate failure. For an attention output `o=Σ_e a_e t_e` with fixed message values, `∂o/∂b_e=a_e(t_e−o)` for softmax scores b. If every t_e is equal, distinct or disjoint attention maps produce identical outputs and zero score sensitivity. If the task-visible values differ, identical attention maps can have different downstream sensitivities. Thus attention-map spread, prediction-response spread and complementary correct decisions are three distinct claims.

Edge deletion also changes degree normalization and available information. The fact that a predictor was correct before deletion does not establish that the original label remains appropriate afterward, that the removed edge was causal, or that a margin drop identifies robust signal rather than a spurious correlation. A stop-gradient gate, confidence floor or absolute derivative threshold may fix numerical issues, but none eliminates the nuisance counterexample. Normalizing nearly zero response vectors can manufacture diversity, while unconstrained response scale can exaggerate apparent evidence strength.

**Disposition: drop sensitivity/attention repulsion as the new-method direction.** The narrowly defensible empirical gap is whether an attributed graph-response diversity adaptation produces complementary correct predictions in this constrained shared-body architecture at the cost paid by a competent single model and ordinary independent ensemble. No distinct operator or update consequence that is missing from GAL, FoRDE, shared-representation attention diversity and graph subgraph diversity was demonstrated. This scoped overlap is not a universal absence or novelty certificate.

No active hypothesis or new pilot is retained. If this empirical question is explicitly reopened later, one representative test would compare a single predeclared graph-response objective with the same objective after fixed, member-specific permutations of intervention identities. The permutations preserve each member's response values/norms and every perturbation forward, while breaking which edge/feature intervention is considered shared evidence between members. Match architecture, initialization, own CE, views, label/update/selection budget, perturbation magnitude and all paid work; use one predeclared strength rather than a grid. This control tests whether the correspondence of graph evidence matters beyond generic response repulsion. A result can support that correspondence hypothesis but cannot create novelty retroactively. The regularizer-off shared arm, capable ordinary single and full independent ensemble remain the required quality references.

The failure criterion is decisive: stop if response/attention separation grows without better unperturbed heldout pooled quality, if it trades away member competence and produces no collective recovery, or if the permuted-evidence control gives the same ordinary quality gain. Diagnose actual common wrong-class margins, pool rescues and harm; a larger angular-diversity score or robustness to the chosen training perturbations is insufficient. A claim against an ordinary independent ensemble requires its complete matched control, not a weak member or fitted TRAIN outcomes. No test or strength was selected using gate15/relation12 outcomes.
