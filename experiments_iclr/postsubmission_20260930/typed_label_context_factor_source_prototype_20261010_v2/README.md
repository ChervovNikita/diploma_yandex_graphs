## Mechanism and information increment

The complete pinned SeHGNN HGB IMDB architecture already receives 25 propagated
feature channels and 12 propagated positive TRAIN-label channels. All 37
channels, 512 widths, five Bernoulli outputs and six original factor sites remain.
Only the two existing grouped projection affines gain member-owned conditional
output modulation. All native slow weights are shared in the shared conditions;
native running buffers stay member-owned.

The **only added information is three observed-label masses**, computed with the
native diagonal-removed MAM, MDM and MKM operators. The 15 signed balances are
deterministic transformations of the short positive channels and those masses:
positive-only zeros can mean an observed negative or an unavailable label, while
mass distinguishes them. The generator receives 18 encoded values, not 18 new
information channels. This packet does not claim first use of TRAIN labels,
label-conditioned prediction, FiLM, low-rank weights or context masking.

At each conditional site `delta = tanh(field H) U`. Private H uses a dedicated
CPU generator; U starts at zero; there are no generator biases. Multiplication
adds `delta * (native affine minus bias)` to the existing factor affine. The
additive control adds `delta` instead. Native bias stays outside output scaling.

At U=0 every conditional function equals its original point-factor function on
the same inputs. Different H matrices provide private U-gradient paths; they
do not initially produce different functions or useful competence. The context
contribution to the H gradient is initially zero. U gradients can also be zero.

## Targets, batching and pooling

Exactly two dedicated seeded halves partition the complete frozen TRAIN set.
There is no retry or favorable-half selection. Each half must contain positive
and negative observations for every label; otherwise the declared run fails.
The native generator=None DataLoader is constructed before the native model.
Its complete shuffled TRAIN permutation is filtered into the two query halves.
Each queried label is excluded from its context, including the global field.

Every TRAIN target is supervised once per member per epoch. Half losses are
weighted by query count. Half tapes are freed after backward. A shared bank uses
the mean of four own losses; the matched untied bank uses the sum of unscaled
private-body own losses. One external native Adam update follows the complete
paired epoch. Two native BatchNorm updates and dropout calls per member differ
from the old one-context batch schedule; all six controls use the paired schedule.

**TRAIN diagnostics use only each row's excluded-target complement context.**
They never use the other context containing that row's label. This restriction
also prevents an own-label contribution through the all-movie global field.
VALID labels are never predictor inputs. VALID serving averages raw logits over
both frozen TRAIN contexts within each member, then averages raw member logits;
sigmoid and the native 0.5 threshold follow. This is a frozen prospective rule,
distinct from the completed pilot's probability mean. Historical scores are not
matched references and are not recalculated or reused here.

The two calls per member can each batch its TRAIN query half with the complete
VALID set. M4 therefore uses eight body calls for complete known-role evaluation,
with TRAIN predicted once and VALID twice per member. For a separate non-TRAIN
prediction cohort, serving costs two complete calls per member. M1 uses two calls.
There is no TEST file, membership, truth or scoring interface in this packet.
