## Source, topology and live memory

positive-step selected checkpoint with real size/SHA256 authority. The
continuation makes a fresh empty optimizer. Graph, raw X, source, parent and
derived hidden hashes are retained. Ordinary meanSAGE width32 supplies the
selected first and last aggregate/skip/bias maps. Its first slow maps freeze,
and its native tail remains live. Undropped clipped/ReLU H is computed only
after source restoration. GN4 computes live first-factor/offset hidden paths
and has no fixed H cache or first dropout.

GRAPH-only preparation binds actual component counts and four persistent

support is unchanged. Each tour includes all nodes and all occurrences,

gather/inverse maps preserve every occurrence, and batch_sizes remains CPU.
All payloads are hash bound and guarded against mutation. No label, source
model, hidden cache or optimizer enters tour preparation.

effective slow/fast products on every view. Gate order r/z/n, reset-after
candidate, input z bias+log99, uniform slow weights, ones fast coordinates,

component resets h0 to zero. Forward/reverse outputs average within component
positions, then over all node occurrences. No truncation, detachment, derived
