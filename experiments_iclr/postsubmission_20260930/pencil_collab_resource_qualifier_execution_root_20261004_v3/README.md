## Verification and limits

`check_client_source.py` uses local stdlib hashes, JSON and AST only, and parses generated remote snippets without executing them. Its saved result is an author check, not an independent client review or numerical qualification. The source review's runtime limitations remain: v3 full-workload compatibility and physical behavior are unobserved until the authorized attempt; the v2 partial TRAIN failure and clean physical closure remain recorded evidence. Sampled RSS, CUDA allocator peaks, current GPU availability, and finite final publication/exit tails retain the source's disclosed limits. A successful resource attempt cannot establish predictive quality, numerical parity, or completion of the official 20-epoch scientific fit.

Client source files are sealed read-only. This execution directory remains writable for future root receipts; the client manifest covers prepared payloads only and is not an inventory of future execution outputs.
