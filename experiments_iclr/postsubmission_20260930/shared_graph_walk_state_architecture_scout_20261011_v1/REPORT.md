## The one fixed architecture

Use the demonstrated ordinary source meanSAGE law: raw binary sparse features,8415→32→5, p=.4 input dropout, aggregate plus skip, row clipping, first ReLU only, final logits clipped, TF1 Adam.001, source first-layer L2.05 and latest tied minimum total SELECT. The factorized controls preserve their exact effective-weight regularizer and private factor/bias law. The source ordinary single and the factorized single remain different learners.

For each block, build four label-free randomized DFS spanning forests from the loop-free undirected support. One private CPU torch Generator draws randperm(N) for roots first, then randperm(deg(v)) for each stable sorted loop-free neighbor list in ascending node-ID order, including empty lists. Save pre-root/post-neighbor generator states; iterative DFS draws no more randomness. No source/dropout RNG is consumed. This is a randomized DFS forest, not a uniform spanning-tree sampler. Emit every root and every arrival/return in the depth-first tour. For C connected components and N nodes, each tour contains exactly

\[
L=\sum_c(2N_c-1)=2N-C \leq 68{,}985.
\]

The root/neighbor shuffle law is symmetric under relabeling with ideal independent uniform draws, but a finite fixed seeded realization depends on node IDs; it is not exactly equivariant. There is no canonical ordering or finite-four-tour invariance claim. No extra ID experiment is added.

Consecutive tokens within a component follow actual graph edges. Isolated nodes appear once. Reset the state between components. Forests and tours persist unchanged through TRAIN, SELECT, CAL and serving. All native graph operations still use the unchanged complete original adjacency, including its existing loops. No feature edges or labels choose traversal.

After the native first-layer clip and ReLU, compute node projections once:

\[
u_v=\tanh(H_vW_u+b_u),\quad
a_v=\sigma(H_vW_a+b_a),\quad
q_v=(1-a_v)\odot u_v.
\]

Gather these into the tour and run the same channel-wise recurrence forward and backward within each component:

\[
s_t=a_{v_t}\odot s_{\mathrm{previous}}+q_{v_t},\qquad s_{\mathrm{initial}}=0.
\]

Average the two directional states over all occurrences of each target vertex to obtain z_v. Inject one residual before the second native layer:

\[
H'_v=\operatorname{clip}\!\left(H_v+0.25\,z_vW_o\right).
\]

There are three32×32 matrices and two32-channel biases, adding3,136 parameters. Set W_o=0, b_u=0 and b_a=log99, giving initial retention .99; W_u/W_a use Glorot uniform from an isolated CPU stream. Zero output initialization preserves the corresponding unaugmented native initial function in exact arithmetic; re-clipping can introduce floating roundoff. This is not bitwise certification and does not guarantee the subsequent learned trajectory.

SW4 shares these scan maps and native slow matrices. Its four native private factor/bias routes use their respective persistent tours. There is no hidden peer communication, detached state, pooled-loss training, diversity objective, scan penalty or separate scan optimizer. Each route's supervised loss remains its own CE.

### Why members might become more competent

The first native layer already encodes local feature evidence from all original neighbors. The scan can carry a transformed version of that evidence across successive real edges beyond the native two-layer radius. A route can retain a useful earlier signal that another tour passes through a different state history. Keeping the native paths and starting the added output at zero makes this a competence-preserving design intention, not a deletion of source evidence.

The intention can fail. A32-channel state is a severe compression bottleneck; it cannot recover any distinction already erased by the first layer. Long scans may dilute minority-community signals, and source row clipping can reduce a correct native representation after an unhelpful residual. Tree backtracking repeats evidence and causes substantial contextual degree bias. Averaging a target's own occurrences does not correct donor multiplicity. Shared maps may learn nearly identical predictions in all routes. The tied single and independent bank may therefore be superior.

## Full paid work and practical implementation

The planned implementation projects u/a once per node, then gathers a/q to tour positions. For SW4 with h32 and four routes, one forward adds:

- At most275,940 tour occurrences and551,880 directional token evaluations.
- At most17,660,160 scalar channel state evaluations.
- Exactly3MNh²=423,849,984 dense projection MACs, plus nonlinearities, gather/scatter, recurrence, clipping and indexing.
- An avoidable implementation projecting every occurrence would cost706,408,448 MACs; it is not the intended implementation.

Using inherited complete raw feature nnz1,137,311 and declared adjacency support530,417, the native four-route sparse/dense matrix-work estimate is 413,804,372 MACs. Native plus projected scans total 837,654,356 MACs, approximately 2.024 times the native estimate before scan overhead. This arithmetic ratio is not a measured speed ratio; first-layer sparse kernels, scan bandwidth and launches matter.

A candidate TRAIN update plus one SELECT forward adds roughly 1,695,399,936 dense scanner MACs when counting two projection gradients in addition to the training forward, then SELECT. Live scan backward, occurrence reductions and all native training work remain extra.

A single four-route FP32 token tensor costs 33.684MiB; a four-route node tensor costs 16.842MiB. An illustrative unfused tape with five token arrays and four node arrays is 235.79MiB, before one/two token workspaces, gradients, native tape, optimizer, sparse storage and allocator overhead. Four int64 tour index lists cost at most 2.105MiB. None of these is an actual CUDA/RSS peak.

The pair operator

\[
(a_2,q_2)\circ(a_1,q_1)
=(a_2\odot a_1,\ q_2+a_2\odot q_1)
\]

is associative. The nominated practical implementation uses vectorized doubling in a custom first-order autograd function. It retains carry coefficients and states, not every level of the eager autograd tape. The backward uses the reverse adjoint lambda_t=g_t+a_(t+1)*lambda_(t+1), then dq_t=lambda_t and da_t=lambda_t*s_(t-1), with component resets. Original q=(1-a)*u gradients remain live through the ordinary autograd chain. Set only the carry coefficient to zero at each component start, retaining q; reverse within each component.

This implementation requires O(MLh logL) tensor work and O(MLh) saved/working scan storage. At maximal L=68,985 it has 17 doubling levels, 1,041,674 valid affine-pair compositions per route/direction, and about 800,005,632 scalar arithmetic operations for both directions/four routes. TRAIN forward plus manual adjoint plus SELECT add roughly 2,400,016,896 such operations. These are in addition to the projection MAC counts. The 2.024 matrix-work ratio excludes this scan work; counting two operations per MAC plus pair compositions gives roughly 2.99 times native forward arithmetic, still not measured runtime. Bandwidth/launches can dominate.

A Python per-node CUDA loop would require tens of thousands of launches, and a naive eager differentiable doubling retains O(MLh logL) tape; neither is nominated. An O(MLh) fused scan is a possible later implementation optimization, not an assumed available kernel or another architecture variant.
