## Sole source change

The four-frame native single still consumes the same four reflected products in one xijlin and has one encoder/context/target trajectory. Its pair-map blocks are now

`[W0,W1,W2,W3] = [Wnative,C,C,−2C]`, `C=Wnative/4`.

The initial four axis-frame products are duplicate copies of `h_u⊙h_v`. Their map sum is Wnative in exact algebra. W0 remains the original native recursive map; extra blocks cancel initially. Arithmetic/copy initialization consumes no RNG. A wider floating-point reduction can differ from the native map; the fixture uses the declared `128*float32_epsilon` relative/absolute tolerance and makes no exact GPU claim.

All four vector paths now have available anisotropic cotangents at initialization, instead of three being suppressed by zero columns. This does not force nonzero gradients for every input: encoder ReLU can zero an axis at both endpoints, and particular decoder cotangents can cancel. The fixed-positive-h check isolates accessibility; full encoded TRAIN gradient zeros are recorded separately.

## Unchanged controls and counts

The factory still returns exactly three classes: `shared_frame_f4`, `same_four_frames_native_single`, and `independent_native_single_one_frame`. Shared F4 has one common learned H; the independent single requires explicit `axis_index`, with a later bank passing0,1,2,3. Ordinary singles have no trainable r/s and retain native affine/LN operators. The four-frame single owns its own learned vectors; it is not coupled to candidate fit outcomes.

Original depth_zero/completion/decode, graph masking, module/dropout order, singleton native loss and raw-logit serving remain inherited. Recursion supplies d features and uses W0; the outer target supplies4d and uses all four blocks. There is no separate learned recursive map or frame average.
