# Fit-facing interface

This packet supplies an encoder and a direct mathematical reference. It adds no trainer, loss, dataset loader, release gate, optimizer, resource gate or launch command. No numerical import or check has been executed here.

`SharedPowerHLGNN(in_channels=512, hidden_channels=512, K=15, dropout=0.3, alpha=0.5, members=1, private_alpha=False)` accepts the same `x, adj_t, edge_weight` as the pinned native HLGNN. Its `forward` returns `[N, H]` at `members=1`, and `[M, N, H]` for multiple members. Source defaults use the native KI initialization, including unnormalized free learned coefficients and their initial float64 dtype. The module supports KI only; the author's alternative SGC/RWR/Random initializers are outside this minimal implementation.

The fitting caller owns **one** learned node-ID embedding matrix `X` and passes it without detachment. Its gradient is the sum of every member's legitimate demand through the common powers. The module owns one shared linear map/bias, member input/output diagonal factors and bias offsets when `M>1`, and either one common coefficient vector or one free vector per member. M=1 stores no adapter parameters and retains the native state-dictionary keys `temp`, `lin1.weight`, `lin1.bias`; a fresh native state can be copied in memory for the reduction check. No pretrained or fitted state is needed.

For a direct/factored comparison, pass an identical **differentiable** `dropped_x` to both paths, or replay the exact same RNG state. The module otherwise samples one input dropout context per call, shared by all members. The fixed dropped tensor must keep the original shape, dtype and device; it must remain connected to `X`. Independent member dropout masks are a different training recipe and are not represented by this shared basis. Append the constant channel after dropout, as the code does; native affine bias is not dropped.

`private_alpha=False` shares the free learned hop coefficients. `private_alpha=True` creates `[M, K+1]` unconstrained learned coefficients for `M>1`; no softmax, positivity constraint, unit-sum normalization or diversity penalty is imposed. All rows start from the native KI vector. Default identity adapters and identical coefficient rows give an initially identical encoder for all members. They do not guarantee symmetry breaking or specialization. Any asymmetric initialization or different predictor initialization is a later explicit fit choice, rather than a result of this packet.

The operator is fixed across members and across the compared direct/factored forward, and is normalized with the same native `gcn_norm(..., dtype=torch.float)` call. Retain the native TRAIN adjacency, current target inclusion and graph weights; no per-member graph edits, edge attention, target masking, inter-hop nonlinearities, validation insertion or dropout after propagation. Those alterations invalidate this exact comparison. The graph may change between training calls only if **every member and both implementations receive the same new graph context**, and the powers are recomputed for that context.

Use `storage="aggregates"` for streamed accumulation or `storage="powers"` for an explicit shared power list. Neither caches powers across calls. Learned DDI embeddings and changing dropout make a persistent training cache stale. Both paths retain ordinary PyTorch autograd, including gradients of the input embedding, shared dense parameters, private affine factors/bias offsets, and hop coefficients. No peer-gradient suppression, stop-gradient or custom backward is implemented.

At M=1 the native Hadamard pair MLP can receive the returned `[N, H]` without a shape change. A later multi-member fit can apply the same native predictor architecture to each route and average raw pair scores at serving. It must declare whether predictor weights are shared or private and charge those parameters/work; this encoder does not make that choice. The native loss can be averaged over members using identical TRAIN positives and native sampled negatives, reducing exactly to the native loss at M=1. The actual WeightedHingeAUC/AUC branch is inherited from the owning TRAIN weight contract, not supplied here.

A representative DDI source integration keeps width 512, K=15, dropout 0.3, batch 65,536, three negatives, the full 500 epochs, fresh encoder/embedding/predictor/optimizer per seed, and VALID-only selection with held TEST unavailable. Direct and factored routes use the same candidates, target graph, parameters, dropout context and scalar objective. Exact equivalence concerns tied parameters and contexts; it is not equality to an independently fitted ensemble with separate embeddings and dense maps.

Future joint-versus-independent-side conditional auxiliaries can consume route representations during training. Their counts/responsibilities must remain absent from served pair scores. This packet implements neither auxiliary, and the interface does not establish a learning benefit.
