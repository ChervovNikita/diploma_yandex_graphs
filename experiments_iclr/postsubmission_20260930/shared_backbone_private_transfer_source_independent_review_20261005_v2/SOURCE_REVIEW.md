The current nonlinear architectures are expected to connect at least one mixed path; the existing code would fail the gate instead of silently passing. This does not weaken qualification but would mislabel a fully zero-path fixture as a runtime failure. No source edit is requested before the first bounded gate solely for that hypothetical case.
