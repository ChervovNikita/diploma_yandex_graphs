## H1 Shared ordered path acquisition inside four routes

**Falsifiable hypothesis:** adding a common ordered-path block inside all four native routes, with route-private factors and ordinary true-label CE for every route, can acquire and serve additional correct alternatives on a fixed baseline strict-rival cohort and improve full-population utility over native shared F and capable same-information controls.

The proposed operation is specific enough to distinguish it from the side diagnostic: a nonlinear node encoder and ordered multi-node path block are learned **inside the four-route factual forward**. Native route factors modulate the common path transformation; each route receives both its native hidden state and path output before its predictive readout. All routes observe the same complete label-free path inputs and raw/topology components. All TRAIN labels supervise every route; the ordinary mean-own-CE objective and coherent bank selector remain. The common path parameters receive gradients from all four route losses. There are no acquired teachers, teacher targets, error-cohort training, route-owned label subsets or later student/F retraining.

Ordered node encodings before aggregation can change factual class rankings beyond the present scalar pool. That operation can address the mathematical obstruction by changing member functions; the error counts do not establish that the current network lost this particular information. Ordinary own CE does not guarantee preserved member competence, and the end-to-end change cannot inherit the frozen F-plus-S memo's exact function-preservation claim. [P1, P2, M]

**Ancestry:** PathMLP supplies nonlinear node encoding, feature-similarity paths, ordered concatenation and path prediction; native BatchEnsemble/TabM supplies common weights and private factors. H2GCN and the saved hop/filter/fusion scopes already cover explicit ego and wider-neighborhood observations. The saved common/assigned path-cohort proposal is a local ancestor. This hypothesis changes a served observation within known primitives; it has no novelty guarantee. It is different from E4's live one-edge endpoint VALUE transformation and leaves E4's source untouched.

Essential controls are:

- C: the selected ordinary own-CE native shared bank under one bound source/role policy.
- A: the shared four-route union-view path architecture above, with its raw mean served.
- A_order: the same trained architecture, node tuples and budget with a fixed label-free per-node/per-path scramble of non-root positions during both training and inference. A single global position swap would only relabel inputs. This control tests consistent order semantics, with recoverable order and topology branches disclosed.
- A_M1 and A_I4: a capable full union-view single and four complete genuinely independent full union-view bodies with their own optimizers/checkpoints. They are comparison fits, not teachers. No control receives only one route's context.
- A_joint: four disjoint full-width union-view bodies with matched initial route functions, mean-own-CE and coherent bank selection, removing parameter sharing. Retain the matched native joint and native I4 contrasts so the change in the sharing advantage is visible.

The sharing question is substantive only if A's gain is not explained by the capable path single/I4 or untied joint bank. Report `A_shared − A_joint` beside `C_shared − C_joint`, and the analogous I4 contrast; these are full-procedure contrasts, not same-state causal interventions. If all architectures improve similarly, credit path information/architecture. If A improves C while losing the same-information capable references, do not credit a shared-ensemble advantage.

Before any future execution, root must bind one finite architecture, path construction, actual source, total acquisition/selection/serving work and comparison margins. The former side diagnostic's 18-body cap does **not** cover these integrated controls. The deployed A has four predictive routes with an added path computation; a common encoder does not establish a timing saving. No length/count/objective grid or independent-teacher acquisition is retained.

H1 fails its utility prediction if acquisitions do not survive serving, harms offset repairs, or A fails its predeclared full-population capable-reference comparison. A gain with adverse protected NLL remains an accuracy finding with a confidence limitation. Mean competence changes are explanatory unless a future protocol prospectively makes them a gate. No path-specific superiority can be claimed if A_order explains the gain. The particular integrated hypothesis is untested; the completed key/affinity failures do not refute it.

### Why no current combination qualifies

Original graph serving repairs **281 covered BASE pooling losses and harms 202 correct predictions**, for +0.499305 pp. It corrects zero original strict rivals. Its NLL is 0.968328 versus BASE's global-temperature 0.682065, and the complete capable-reference protections fail. These repairs and genuinely newly acquired coverage are disjoint **by baseline error category**; their marginal counts are not evidence of favorable interaction on the new bank. [B, H]

The closest actual four-cell bootstrap-plus-graph comparison proves some interaction: it rescues 49 of 126 newly acquired alternatives lost by native averaging and retains exact ingredient-exclusive repairs. It also loses 77 acquisitions, erases 48 previously served alternatives and creates 34 harms where both ingredients are correct. The complete 79.591708% SAGE package loses equally graph-processed ordinary I4 at 81.064341% at every seed and fails its final reference rules. That exact combination is tested and closed. Its rescue fraction is not transferable to affinity or paths. [H]

Fixed key and affinity fail the unchanged shared comparison and their private-attribution rules; neither is an earned A ingredient. Large residual pooling losses and distinct repairs do not justify appending B. H2 therefore remains **withheld**, without a combination fit or a promoted attribution control. New-bank repair survival is unmeasured, not generally refuted. H2 is falsified for an eventual eligible A if scorer harms or lost A repairs offset rescues, or protected final quality fails its fixed equal-processed references. A positive interaction alone cannot rescue inferior final predictions.

Retain H1 as one source-design question for future shared-backbone acquisition. Retain H2 only as a conditional evaluation of that same future A after useful acquisition is established; it adds no current branch. Keep the frozen F-plus-S side memo as an acquisition diagnostic that cannot identify new sharing. Preserve every completed recipe closure, confidence tradeoff and paid cost.
