# Disabled numerical qualification worker

`qualify.py` defaults to `DISABLED` before any numerical/source import. Root may pass `--execute-authorized` **after source review**, using a new output directory for each identity. This preparation performed AST/source checks only; no Torch, native import, dataset/checkpoint/result read, SSH or fit occurred.

The exact immutable repaired G0V2, native port, adapter and native model bytes are pinned in the worker. Numerical execution uses the existing allocation `anogena-2-0`, native_ncn venv Python, and repository `.venv/lib/python3.11/site-packages`. It installs nothing and changes no host configuration. Source files must be present under the supplied `--source-root` with those exact bytes. Total deadlines are fixed at 180 seconds synthetic and 900 seconds full; root owns transport/execution and preserves any external kill receipt. Tolerances and the three finite-difference scales are fixed in source, without retries.

## Synthetic engineering mode

Generate 15 artificial nodes/features, a fixed reciprocal graph and artificial class indices. **No dataset labels or data files are read.** Preserve the actual 300→512→5, ten-local/one-global native architecture and all four private branches; the callback still evaluates one branch per call. Tests cover sparse graph products and every solver prefix's positivity/descent, dense/sparse assignment values and cost derivatives including gamma0 and permutation orientation, every member's full logits/shared/private first gradients, dense/sparse complete native outer derivatives, full shared directional finite differences, stopped-Q versus independent fixed-Q derivatives, unused local-head tangent, an uncommitted complete response episode, and native/input/RNG restoration. Synthetic targets are algebraic inputs, not predictive evidence.

On the allocated host, the command shape is:

```text
<native_ncn .venv/bin/python> -B <worker>/qualify.py --execute-authorized --mode synthetic --source-root <phase-source-root> --output <fresh-engineering-output>
```

## Separate full-Amazon mode

Require a passed synthetic `RESULT.json` with matching immutable pins, a source-reviewed **enabled accessor revision** with an explicit SHA256, and an existing safe public+B projection. The separate prospective W/S/R V2 accessor is pending/disabled and its projection is absent. Roles are A 2449, B 9797, W 4898, S 2449, R 2450; acquisition later uses W only. This worker does not flip an accessor release flag or call the stock V6 loader. The stable interface is `load_public_b(project_root, public_b_dir, device=...)`; it returns full raw public features/native graph, W/S/R labels from B, and A IDs only. This qualifier fits none of those populations.

```text
<native_ncn .venv/bin/python> -B <worker>/qualify.py --execute-authorized --mode full --source-root <phase-source-root> --output <fresh-full-output> --synthetic-pass <passed-synthetic-RESULT.json> --accessor <reviewed-enabled-accessor.py> --accessor-sha <exact-reviewed-sha256> --public-b-dir <safe-public-B-projection> --device <authorized-device>
```

Default full mode builds a fresh seed17 global/eval native family, inventories native GAT aliases, checks full sparse products/feasibility and calls the complete public `native_sparse_episode` live-Q derivative/core/recompute/returned-commit path, then discards every constructed state. It checks that returned private values equal a fresh response at theta+ from the original phi. It reads no A label, VALID, TEST or checkpoint, performs no optimizer/fit/selection, and leaves the native family unchanged. The receipt charges actual whole-process peak RSS and, for an authorized CUDA device, allocated/reserved peak memory. Instrumentation, state snapshots and the independent recomputation contribute to these peaks. Timings include qualification work and are not a training performance claim.

Add `--full-fd` for the three fixed full-graph central-difference scales and stopped-Q/unused-tangent checks. Without this flag the receipt explicitly leaves full-graph directional FD unqualified; resource/higher-order completion alone does not admit a scientific fit. Fixed tolerances/scales are in source and must be reviewed before execution. No tolerance change, backbone freeze, detached live Q, alternate graph or automatic retry is implemented.

## Failure receipts

The fresh output's `RESULT.json` begins `RUNNING` before runtime imports, records each check before it starts and after it completes, and ends with an actual failure traceback or an engineering-only pass. A kill/OOM retains the last started stage in the running receipt; root must preserve the process/transport failure separately. The worker does not silently retry or overwrite an existing execution directory. Source bytes remain immutable. The explicit authorized engineering caller temporarily enables only the loaded port's process-local entry gate around the complete public call and restores it to false in `finally`; G0's gate remains false and accessor flags are never altered. Native parameter aliases, modes, attributes, buffers, inputs and RNG are checked after the run.
