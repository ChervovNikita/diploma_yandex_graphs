# Minimal baseline calibration outline from the current contracts

This is preparation for a separate prospective calibration contract. It authorizes no fits, tuning, data access or outcome reads and makes no external method choice. The v2 30-fit plan and its thresholds remain unchanged. The external calibration scout owns primary recipe/result evidence and the choice of a stronger relevant baseline.

Start with one exact native anchor. Bind the authored native model/release version and Amazon Ratings command to the already-declared raw FP32 features, native graph preprocessing, complete official TRAIN labels, masks, 200-local/2500-global schedule, optimizer, stage restoration, native VALIDATION accuracy selector and checkpoint semantics. Record any paper-versus-release recipe distinction explicitly. Existing source/native runtime qualification can establish implementation correctness; it cannot establish competitive accuracy. The three predeclared native-member0 fits already supply the internal native-single anchor, and the 12 native-member fits already supply its fixed conventional ensemble. Reuse those declared fits for characterization rather than adding duplicate internal fits or choosing a favorable member.

For external empirical calibration, use one reference with evidence that can match the actual protocol. The matching contract needs the same graph/feature/label identities and official masks, the same prospective split/seed blocks, all-TRAIN supervision and the same reporting endpoint. A published TEST mean across ten official masks is useful recipe context; it is not a minimum acceptable score for selected VALIDATION on the current three blocks. If no external result has that matching endpoint, preserve the external source/recipe and plan a reproduction on the same inputs instead of inventing a numerical competence floor. Keep validation selection, training duration, preprocessing and hyperparameter-selection differences visible. A stronger method should retain its own defensible authored recipe; forcing an unrelated architecture into Polynormer's two-stage schedule would not establish its strength.

The smallest initial matched empirical addition is one externally sourced strong single recipe on the three paired blocks: three additional calibration fits in a separate preserved contract. This is sufficient to ask whether the current native control is competitive with that specific recipe at the current development endpoint. It cannot establish broad ensemble superiority or independent heldout performance. If the broader claim is ensemble accuracy over competitive conventional ensembles, specify four independently initialized versions of that same external recipe with a fixed probability mean and per-member selection before outcomes. Member0 remains its single alias: 12 total external fits across the three blocks, or nine more after the initial three, with no best-member or extra pool selector. The required scope depends on the intended claim; a small calibration should not be renamed a global ranking.

Before any calibration outcome, freeze the external source/recipe, seed policy, endpoint, permitted baseline development budget, cost reporting and interpretation of weak or failed baselines. Report measured native and external baseline quality, member competence, accuracy/NLL/macro-F1, selected stages/updates, completion failures and complete cost/peak-memory records. Preserve first results. Any tuning needed to make a baseline competitive must be a new prospective baseline-specific development contract with disclosed label history, never post-outcome weakening or TEST-driven adjustment.

Broad accuracy language remains unavailable from the three selected-VALIDATION blocks alone. After a useful development screen and an audit of measured competitor strength, bind a separate competent-baseline comparison to the audited heldout endpoint and disclose consumed Amazon split/TEST history, as the existing confirmation contract requires. Native source qualification, relative gains over the present references and external competitiveness are three distinct pieces of evidence; none substitutes for the others.

Literature memory was consulted, but no primary retrieval/reread, external method adoption, numerical result reproduction or experiment was performed for this outline. The outline adds no accuracy floor and does not modify the current 30-fit gate.
