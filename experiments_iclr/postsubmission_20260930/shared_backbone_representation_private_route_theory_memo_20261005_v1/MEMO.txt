SHARED BACKBONES: WHERE PRIVATE ROUTES CAN CHANGE REPRESENTATION
5 October 2026. Analytic memo from saved method notes/index69 and source text only.

Useful conclusion

A useful modification is to place nonlinear or structural corrections before a common aggregation discards label-relevant distinctions. Adding private output capacity after that loss cannot repair it. Linear feature factors alone can also leave the graph-space obstruction unchanged. This supports testing a richer common information bank or upstream private routes; it does not require an ensemble. A capable single receiving the complete bank can represent the same pooled predictor. Components being established prior does not make their useful composition unworthy of study.

1. Exact representation potential under a proper loss

Let S contain the fixed learned parameters, training history and any other global serving state. Let R be ALL inputs the existing serving readout can consume, including graph/query context and all accessible shared states. Private members and their deployed pool are measurable functions of (R,S). Let B be an added upstream input/aggregation bank. For finite labels Y and unrestricted probability readouts, define L*(R)=inf E[-log p(Y|R,S)]. Then

    L*(R) = H(Y|R,S),
    L*(R) - L*(R,B) = I(Y;B|R,S) >= 0.

Proof: conditional log loss equals conditional entropy plus the expected KL divergence from the true conditional label law to the readout. Its infimum is obtained at that law; subtract the two entropies. Thus B has strict oracle log-loss value exactly when it contains conditional label information. Mere route disagreement or I(B;input|R,S)>0 is insufficient. A transformation B=f(R,S) has zero value in this statement.

For square-integrable scalar Y and squared loss, the exact difference instead is

    E[( E[Y|R,B,S] - E[Y|R,S] )^2].

This follows from the conditional-mean projection identity. Extra information changing only conditional variance can help log loss while leaving optimal squared-loss prediction unchanged. Nonzero conditional mutual information does not guarantee better classification accuracy or link-ranking MRR.

These are population information identities under a fixed joint law, not generalization bounds. They require adequate readout capacity/optimization and do not prescribe an MI estimator. No IID assumption is needed for the algebra, but correlated graph labels do not become independent samples. A finite learner may lose more through estimation, training or capacity than B supplies. No new empirical gate is proposed.

2. A graph-space obstruction that feature factors cannot remove

Fix a linear propagation P on node features X. Suppose the complete backbone input to all later operations is PXW+b (possibly followed by arbitrary deterministic nonlinear processing); no raw-X/hop-zero bypass is available. For any nonzero Delta with P Delta=0, X and X+Delta have the same complete backbone state for EVERY learned feature matrix W. Consequently any later heads, their training objectives and their pool assign the same served prediction to both inputs at a fixed S.

Private linear feature matrices/gates before this propagation do not help:

    P(X W_m) = (PX) W_m.

This applies to that linear site with node-independent feature factors. It does not say that an entire nonlinear BatchEnsemble/TabM network is restricted this way. Node-dependent gates, nonlinear preaggregation messages, raw-feature access and changed graph operators violate the premise.

For a complete linear bank B=(P_1 X,...,P_M X), indistinguishable perturbations are exactly the intersection of ker(P_m). Its graph-space information is strictly richer than PX only if at least one added operator detects a previously lost direction (assuming the original PX is retained). This is a full-state criterion; a query-local readout can discard further information. Detecting a direction is only representation capacity: Proposition1 still asks whether it matters for Y. A polynomial bank using only positive powers of P cannot recover ker(P); a hop-zero I channel can retain it.

3. Exact graph witness and an inexpensive repair

Take a three-node triangle with one self-loop per node and normalized propagation P=(1/3)11^T. Query node r. Compare feature worlds

    X0=(0,0,0)^T,  X1=(0,1,-1)^T.

Both have the same graph, root feature0, degree2 and entire propagated feature bank PX=0. Any learned linear input projection/bias and downstream head on that bank has identical inputs. Set the synthetic node label Y to1 when the two nonself neighbor messages have positive variance, otherwise0. With equally likely worlds, the best R-only log loss is ln2 and squared error is1/4.

Retain one extra second-moment channel B_r=[P(X elementwise-squared)]_r. It is0 for X0 and2/3 for X1, so its oracle log loss/squared error is0. A simple nonlinear transform before aggregation also separates the worlds: P ReLU(X1)=1/3 at every node, versus0 for X0. These are symbolic evaluations, not executed fixtures or dataset results.

The practical intervention is therefore a preaggregation statistic/message channel, or full raw/hop-zero retention followed by an adequate nonlinear neighborhood readout. A root-only raw skip is insufficient here because X_r=0 in both worlds. One shared richer encoder/readout can perform the repair. Four private output heads, independent copies of the same restricted linear encoder, or extra optimizer history cannot create this missing distinction. The witness diagnoses no error on the present data; singular/near-singular propagation, relevant feature variation and the claimed label dependence must actually be present.

4. What this says about the saved NCN implementation

Current F4 is NOT a pure post-aggregation-head bank. models.py:49-57 applies each route's private nonlinear xlin to every shared h BEFORE the common-neighbor sum (lines53-54). Those routes can already recover some distinctions between neighbor multisets that a fixed mean of h would lose. Adding a quantile/moment adapter must be compared against that competent operation.

There is nevertheless an earlier boundary: all these routes receive the same encoded h. The saved one-layer puregcn serving source uses a linear input map followed by looped normalized propagation, without an input nonlinear activation; dropout is off in serving (vendor NCN model.py:23-34,129-132,171-184; constructor in models.py:15-17). On the deliberately constructed triangle it has the stated graph-kernel collision, and later private xlin cannot recover it. This source-level witness is not a qualification, current graph diagnosis or expected performance claim. More general encoders with nonlinear messages, skips or richer context can defeat it.

5. Representation versus training/history, and a falsifiable relevance claim

Private adaptation/history can change which theta/phi are learned, improve approximation to the conditional predictor or regularize finite-sample learning. It can also train a richer R if the encoder family permits one. It supplies no new per-query serving information once S and R are fixed, and cannot eliminate a collision that holds for every parameter setting in the restricted architecture. The active learning rule may have useful optimization value even when all candidate functions fit in a capable single's class. No recomputed-commit identity or history-benefit guarantee is asserted.

A later authorized experiment could test relevance with a fixed encoder/interface, a competent flexible R-only readout, the same readout given B, a common richer-bank single, private-bank routes and same-operation untied routes, with paid schedules and selection opportunities disclosed. This is a conceptual falsifier, not a new arm grid or change to any frozen study. If B supplies no replicated complete-task proper-loss improvement under adequate readout training, its proposed missing-information explanation has no demonstrated relevance. If the R-only control matches it, suspect existing context/capacity/optimization rather than an information repair. If the common-bank single matches private routes, retain architecture utility but no private-route advantage. If untied routes match or beat sharing, no sharing benefit is identified. MRR/accuracy require their own direct evaluation; subgroup disagreement cannot replace complete-task prediction quality.
