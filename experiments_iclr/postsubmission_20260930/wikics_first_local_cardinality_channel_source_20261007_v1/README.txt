One exact observation/channel
-----------------------------
Count d_v from edge_index[1] of the actual incoming Tensor message multiset.
The pinned source's GATConv is source_to_target, add_self_loops=False, bias=False,
with no edge features/residual projection. Runtime verifies these restrictions
and rejects a different GAT layout. The prepared graph's supplied loops,
duplicates and order are retained; no coalesce, self-loop insertion, degree
repair, outgoing count or VALID-label normalizer is introduced.

  S_v = log1p(d_v) / mean_{u in complete TRAIN IDs} log1p(d_u)
  N'_m(v) = N_m(v) + a_m S_v N_m(v)

The TRAIN mean must be finite and strictly positive. There is no epsilon or
fallback scaler. Complete TRAIN IDs are the580 original ids from the original
role loader; no y or held-out ids/labels enter the normalizer. The graph is the
original transductive topology. The actual degree cache is built once from that
role and bound to it. Every Session.forward checks exact Tensor topology equality
once, then the hook verifies that its actual edge object is that bound active
forward's object. Direct model forwards, recursive/concurrent calls and changed
topology are rejected; use the Session interface. This narrow binding does not
implement a topology-intervention framework.

The sole hook is on body.local_convs[0] OUTPUT. It changes N before the native

Two shared-BE forms; same-access native controls
----------------------------------------------
kind=shared: one zero-start scalar a_shared on the one shared body.
kind=centered: one zero-start a_shared plus four zero-start slots u:
  a_m = a_shared + u_m - mean_j(u_j).
The four slots have three functional member contrasts. The actual active member
comes from the original first GAT FactorLinear's member_context. Autograd sees
the entire live u vector in EVERY member hook: da_m/du_j=delta_mj-1/4. There is
no detach, per-member gradient mask or post-update substitute centering. The
shared scalar receives exact mean-own risk ONLY. The slot vector is appended
to the internal block and receives its existing fixed policy objective plus
the unchanged internal alignment A. No loss-strength coefficient is learned.

All coefficients initialize to literal zeros without RNG use. For finite N and
S the hook is N+0=N, including unchanged native stochastic-stream consumption.
This is algebraic source recovery, not a numerical parity test or runtime proof.
The residual is always evaluated so zero coefficients retain their gradients.

Native single: one zero-start degree scalar on the native body; its original
two-view own-risk backward/Adam update is unchanged.
Ordinary untied4: one zero-start degree scalar independently owned by EACH
native body. Four independent own-risk optimizers and own checkpoint selection
remain unchanged. Sharing/centering a coefficient across those bodies would
couple them and violate ordinary untied selection; this source does not do so.
The four independent scalars give every path the same degree observation and
scalar form as the BE member paths. kind=shared is the only accepted CLI kind
for these native controls; here it means a scalar within each separate body,
not one shared between independently trained/selected bodies.
