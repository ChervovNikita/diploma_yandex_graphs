THE PROPOSED MODEL AND TWO DIFFERENT OBJECTIVES

Fix a query context x containing the declared supports and counts, and let each endpoint component be a normalized feasible-subset law. Write a_m=q_Lm(S_L|x), b_m=q_Rm(S_R|x),

 qJ = (1/M) sum_m a_m b_m,
 qF = [(1/M) sum_m a_m] [(1/M) sum_m b_m].

With positive feasible likelihoods, r_Lm=a_m/sum_j a_j and r_Rm=b_m/sum_j b_j give

 B(S,x)=qJ/qF=M <r_L,r_R>.

For log-likelihood features ell_Lm=log a_m, ell_Rm=log b_m, this is simply

 log B = log M + logsumexp(ell_L+ell_R)
                    - logsumexp(ell_L) - logsumexp(ell_R).

There is no additional information in the score beyond the two soft responsibility vectors. They can be query-context-dependent; calling them global node communities would overstate their interpretation. Tying their computation to private filters changes the feature learning, not this score family.

If Y=1 is assigned qJ and Y=0 qF, with a prior pi(x), the local generative model is P(Y,S_L,S_R|x)=pi(x)^Y[1-pi(x)]^(1-Y) q_Y(S_L,S_R|x). It is normalized when both laws share declared supports and counts and the component laws are normalized. Its conditional log odds are logit pi(x)+log B.

Two training choices must not be conflated:

* Class-conditional generative fitting uses -Y log qJ -(1-Y) log qF, plus the prior term. The negative term reconstructs two marginals; it does not directly push negative responsibility vectors apart. Their relative component-label alignment is immaterial to qF.
* Conditional BCE on logit pi(x)+log B directly trains the label discriminator and includes the class normalizer pi qJ+(1-pi)qF. It need not fit the absolute endpoint likelihoods or identify their latent interpretation. It is not the same objective as class-conditional reconstruction, nor the current same-law auxiliary.

For the displayed source reductions, J_K_sep-J_K=log B/d where d is the slot denominator. That difference is a tempered score, not the literal log Bayes factor. Using it as a calibrated Bayes factor would change the model. A density-ratio interpretation also requires the actual class-conditional query distribution to match the hypothesized qJ/qF laws; native sampled nonedges are not automatically samples from qF.

STRICT LIMITS

Identifiability and meaning. Simultaneous member permutations leave all probabilities unchanged; duplicated components are unidentifiable. Conditional link BCE identifies only the discriminative score on the sampled queries, not true latent graph communities or calibrated endpoint densities. Normalizing each law is insufficient to identify components in a two-view mixture. A copied component family gives qJ=qF and B=1; no inevitable specialization follows. The identity laws can instead separate nuisance degree/candidate patterns. Fixed-count conditioning removes a common logit offset, not candidate-specific popularity. If x already contains the full allowed graph and determines S, conditioning on S adds no graph information; possible gains concern a restricted readout or optimization.

Expressiveness. Because both endpoint component laws normalize, qJ and qF have EXACTLY THE SAME left marginal and EXACTLY THE SAME right marginal at fixed x. The hypothesis allows label-dependent association only, not label-dependent individual endpoint marginals. It can be misspecified when positives and sampled negatives differ in individual endpoint composition, even if both are graph informative. The common-member law also imposes same-role compatibility; ordinary mixed-membership B can represent cross-role interactions. Query-specific responsibility features can partly evade a global assortativity interpretation, but then the latent-community explanation becomes weaker.

Calibration ceiling. Since responsibility vectors are simplex vectors, 0<B<=M for strictly positive feasible laws. Consequently

 P(Y=1|S,x) <= pi(x) M / [1-pi(x)+pi(x)M].

With M=4 and a balanced class prior, the upper probability is 4/5. With a rare population edge prior it can be much lower. This is a model restriction, not evidence about current weights or data. Increasing a score temperature or learning an unconstrained scale may improve empirical fitting but forfeits the stated literal Bayes-factor semantics. An estimated intercept is legitimate only under its declared sampled/population prior interpretation. Native ranking scores and AUC training are not automatically calibrated population link probabilities.

Sampling and sparsity. A native negative is an unobserved/sampled pair unless genuine absence is established; it need not have independently drawn latent endpoints. A class prior of one half from balanced auxiliary strata is a sampling prior, not the graph's edge prevalence. Conditional negative-sampling probabilities, degree exposure and query-specific support selection can change the class-conditional laws. Calibration requires a declared target sampling distribution and any appropriate prior/proposal correction. The MMSB sparsity discussion is especially relevant: unlinked does not inherently mean structurally incompatible.

Degenerate supports. For n=0 or k in {0,n}, a fixed-count endpoint law has one possible subset, hence every component probability is one and that endpoint responsibility is uniform. If EITHER endpoint is degenerate, B=1 regardless of the other side. M=1, or identical components on either side, also gives B=1. Such queries contain no structural shared-versus-independent signal for this law and must not be discarded to manufacture discrimination. If the observed subset is outside the declared support, zero densities can make the ratio undefined; support changes cannot be hidden inside the label.

Leakage and local probability scope. A successor must evaluate both hypotheses on the same label-blind allowed context. Query edges and reverse edges, supports, identity subsets, counts and cache provenance must obey the same exclusion contract across origins. An auxiliary teacher may supply hidden TRAIN observations for supervised training, but a served density ratio cannot obtain withheld validation/test edges, their counts or unknown teacher subsets. Batch-wide positive masks can cause a train/serve context shift, and origin-dependent support construction can leak the classification target. These are prospective limits, not a fresh verdict on the separately audited frozen sources. Multiplying overlapping query-local laws does not produce a normalized whole-graph generative model without a compatibility argument.

ONE FAIR FALSIFIER

The defensible claim is only that normalized endpoint identity-law features provide useful predictive bias beyond known latent compatibility. A prospective falsifier is a competent discriminative mixed-membership compatibility model with the same GNNM private-filter architecture, same full allowed endpoint/context observations and common auxiliary supervision, comparable paid parameters/work and equal optimization opportunities. It learns simplex responsibility features directly and a symmetric group-affinity/link readout; for directed tasks use the corresponding directed affinity. It must be allowed the graph/identity information the proposed density features use. A head denied those observations is not a fair control.

Specify generative fitting versus conditional BCE and the actual served predictor before interpreting this comparison. If that matched ordinary compatibility model matches or improves the successor's prospective heldout link prediction and calibration under the same sampling/masking contract, reject the claim that normalized shared-versus-independent endpoint laws supply necessary predictive value. Better qJ reconstruction, higher positive overlap, concentrated members or an oracle-selector gain would not rescue it. This is one comparison role, not a pilot recipe, tuning grid, compute request or current-queue change.
