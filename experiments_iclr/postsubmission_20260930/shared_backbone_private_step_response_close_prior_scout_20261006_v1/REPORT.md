## Exact primary comparisons

### MetaGC — closest added graph precedent

Jo, Hyeonsoo; Bu, Fanchen; Shin, Kijung. **Robust Graph Clustering via Meta Weighting for Noisy Graphs.** CIKM2023 identity, DOI10.1145/3583780.3615038; inspected [arXiv2311.00322v1](https://arxiv.org/pdf/2311.00322v1), not the accepted ACM body. Exact version equivalence is unverified. Read physical pp3–5, §§3.1–3.4/Eqs1–11 and complete Algorithm1; p5 algorithm/update equations visually checked.

The GNN/MLP clustering model returns soft node×cluster assignments P. A separate meta-model produces positive **node×node** weights V using adjacency, features, Adamic–Adar topology and pair loss (Eqs1–3). These weight decomposed modularity-based pair losses plus a collapse regularizer (Eqs6–8). Algorithm1 line4 samples two uniformly random **disjoint node batches** B_C and B_M. §3.4 explicitly avoids requiring known noise-free validation graph data. Its printed update order is:

```text
w′ = w − η Σ(i∈B_C) ∇w L_i(w, θ)                    [Eq9]
θ⁺ = θ − μ Σ(i∈B_M) ∇θ Q̃_i(w′)                      [Eq10]
w⁺ = w − η Σ(i∈B_C) ∇w L_i(w, θ⁺), evaluated at w     [Eq11]
```

The final update starts from original w, rather than committing w′. This directly precedes training-only same-graph feedback and original-state recommit. Q̃ is the unweighted printed modularity meta-objective; its signs, convergence, accepted-version implementation and quality are not certified here.

The active map instead uses finite S competitor-loss response after each private own-CE step, a constrained **node×member** Q generated by response/graph/balance operations, and shared prediction θ optimized through Q and private adaptation against R mean-member/pool loss. All four persistent branches serve their arithmetic probability mean. MetaGC uses a separate learned pair-weight generator and one clustering predictor, with a collapse penalty rather than exact per-member column mass. These delimit a composition difference requiring the existing comparisons; they do not certify a new principle or benefit.

### EEML — old metadata lead, now a bounded method scope

Li, Geng; Ren, Boyuan; Wang, Hongzhi. **EEML: Ensemble Embedded Meta-learning.** [arXiv2206.09195v1](https://arxiv.org/pdf/2206.09195v1), 2022 preprint; accepted venue/version unverified. Read §3.2/§4.1–4.3, Eqs2–10 and Figure1 caption, physical pp4–6. This upgrades the previously saved metadata-only lead, with no repeat full-paper/code credit.

Eqs2–4 define MAML-style adaptation/meta gradients. §4.1 clusters those task-gradient embeddings by cosine K-means; §4.2 initializes separate experts as copies of a common θ_clu and weights task–expert losses by softmax cosine similarity (Eqs5–6). §4.3 adapts experts on a new task's labeled support and combines predictions using task similarity and support error (Eqs7–10). Gradient-informed specialization and competence-aware collaboration are ancestry. Its task-distribution experts/meta-test adaptation/weighted serving differ from fixed-node private competitor response, tied deployed core and unchanged all-member probability serving. No balanced node×member graph allocation or exact complete-map overlap is established by this scope. Printed voting normalization is not implementation-certified.

### Differentiable model selection — allocation/serving precedent

Kotary, James; Di Vito, Vincenzo; Fioretto, Ferdinando. **Differentiable Model Selection for Ensemble Learning.** [Official IJCAI2023 proceedings PDF](https://www.ijcai.org/proceedings/2023/0217.pdf), DOI10.24963/ijcai.2023/217. Read §§3–4.4/Eqs1–14 and complete Algorithm1, physical pp2–5/printed1955–1958; p5 visually checked.

A selection net predicts per-example model scores, a fixed-cardinality knapsack/top-k layer selects pretrained members, and selected probability vectors are summed/softmaxed (Eqs4–14). Forward selection is hard; backward uses a sampled perturbed-optimizer transformation. §4.4/Algorithm1 explicitly optimize **only the selection net**. This is differentiable ensemble allocation ancestry, rather than an inspected private-learning response objective. It changes serving by selecting a subensemble; the active Q instead changes training while all four branches serve. No gradient-estimator guarantee, code reproduction or accuracy claim is transferred.
