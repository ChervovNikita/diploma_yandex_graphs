MolHIV private-path CPU representative worker — source preparation only
====================================================================

This packet prepares one bounded real-data engineering check. It has not been
executed or numerically imported during preparation. It qualifies no runtime,
scientific fit, quality, adopted GNCL strength, GPU path, or full training horizon.
Root supplies the actual interpreter/dependencies and performs any separately
authorized execution. This packet performs no server access or staging.

Scope
-----
Three fresh matched publicV2 be_init models, seed6101, use the published complete
interface's SteeringSession with alignment_private, hidden_private, and
gncl_private. GNCL lambda0.5 is hardcoded as an explicit INTERFACE FIXTURE ONLY;
it is not empirical strength adoption, tuning, mode selection, or a strength
recommendation. Model parameters and persistent member dropout streams must
match before each fresh fixture. No resource weights are accepted as input.

Each fixture consumes the existing exact portable MolHIV TRAIN/VALID NPZ files.
The original label-free geometry scan selects epoch68/index166 (zero-based):
128 graphs,3948 nodes,8404 edges. The batch is rebuilt by the unchanged public
data.molecular_batch helper; positions and original graph IDs are checked.
Epoch68 describes its permutation source, not68 trained epochs. The separate
8430-edge batch is not covered; its26-edge excess remains explicit.

Each fixture performs exactly one unchanged two-view update. Runtime observation
wraps and forwards the real underlying calls without a reference update or
gradient recomputation: two Session.forward calls; two autograd.grad returns at
the same old parameters; one native Adam call. Actual finite own/private/supplied
gradient tensors and their exact None names/counts are recorded by permission
group. The supplied gradient must reference the correct returned collection's
storage. The actual exhaustive parameter catalog is saved once, and matched
between fresh modes. Shared, internal-private and boundary-private groups must
each have a genuine nonzero parameter change. Individual tensors may legitimately
remain unchanged or have None gradients; no every-parameter-change gate exists.
The original finite_state helper checks model/Adam state, and initialized Adam
states must record one transition. No tiny synthetic or numerical parity gate.

The unchanged public train.evaluate checks all4113 VALID graphs/33 batches and
finite member/served prediction populations. Its quality values are used only
by the original joint selector and remain inside private resource artifacts.
The original train.py selector statements are extracted through AST, as in the
prior MolHIV GPU representative worker; the scientific epoch loop is never run,
patched or shortened. Original joint_snapshot creates the checkpoint with the
published interface's method identity. A cached-score tie invokes the same
strict-first selector and must preserve the file. This second selector event
does no second update. Snapshot epoch1/2 are representative selector indices;
the run annotation explicitly disclaims scientific epochs and scientific fit.
Reload restores model/Adam/member streams, then all4113 graphs are served again
through original validation_batches/forward/serving/finite_predictions. There
is no TEST reader/scoring, VALID quality output, prediction export or comparison
of mode quality. Selected snapshots contain closed selector values; keep all
weights/Adam/RNG/predictions and those artifacts on the execution host. Never
use these resource weights as scientific fit starts.

Bound and failure preservation
------------------------------
watch_cpu_once.py adapts the existing WikiCS CPU owned-child wait/TERM/KILL
pattern. It is a small CPU parent, not a resource supervisor or detector.
Its sole subprocess is check.py in a fresh owned process group. It reads only
its own parent/child /proc stat identities; no other-job/process/GPU inventory,
nvidia-smi, resource supervisor, detector, admission gate, or allocation Wiki24
file is accessed. CUDA_VISIBLE_DEVICES is empty. OMP/MKL/OpenBLAS/NumExpr and
torch intra-op threads are2; torch inter-op threads are1. CUDA initialization
must remain false. Root chooses PYTHONPATH through repeated --dependency-path;
inherited PYTHONPATH is replaced, and PYTHONHOME is removed.

The inclusive parent active cap is300s plus at most10s cleanup (310s hard cap).
On active timeout it sends TERM only after matching child PID/start ticks and
process group, then KILL after up to5s if necessary, and waits within the hard
cap. An unreaped child or a cap overrun cannot produce a successful receipt.
There is no retry, resume, shortened fallback, next queue cell, or automatic
follow-up. Worker failure/partial mode artifacts, traceback log and parent
terminal metadata are retained. A timeout is incomplete work, not a passed
qualification. Success requires all three fixtures and a reaped exit0 child
within the active cap. The fullWiki24 allocation remains unchanged.
