learned-private-route plus four-function serving package improve useful
prediction beyond one capable full-width body receiving the SAME eight
stochastic own-loss views and four factual Qm relations?

internal_be_single8_attribution_controls_source_20261007_v2/single8.py
(its source is preserved from v1). It has four persistent streams, two views
per stream, mean-eight own CE, one native body/Adam, and single-body eval.
However, single8_alignment calls the original class-full cross-view loss;
single8_virtual_contrast additionally uses the residual proxy. Neither accepts

one total.backward(), rather than the current sequential VJP replay.

The current public context method registry implements shared COMMON/ROUTE/

## One function and exact objective

Current WikiCS BE private parameters are every FactorLinear.r and .s row.
With all rows fixed to one, each dense map is
    F.linear(x*1, W)*1 + b = Wx+b.
The one shared body, attention vectors and normalizations then contain no
member-dependent trainable function. In eval mode, with dropout disabled,
all four member indices implement the same mathematical f_theta. This holds
for the current stateless WikiCS body, with no added private-attention bank,
member-specific graph or mutable normalization state. It is one predictor,
not four independently trained predictors. It does not guarantee bitwise
repeatability of sparse CUDA arithmetic or equality to an unwrapped native
Linear's fused-bias arithmetic; retaining the factor wrappers avoids changing
the candidate's arithmetic path gratuitously.

Retain four original streams seeded seed+1009*m+300001. Let CE_m be the mean
of two complete 580-node own CE views and A_m the symmetric cross-view
alignment on the original 512 panel with the SAME factual frozen Qm. Train
    L = (1/4) sum_m CE_m + 0.05*(1/4) sum_m A_m,
at tau 0.2, with both views differentiated and no residual/projector. This is
the current shared ROUTE scalar objective with private factor gradients removed.
It is NOT four Adam updates, a fourfold loss coefficient, or alignment to
Qbar on every stream. Teacher targets remain external and nondifferentiated.

Alignment is linear in Q. Under identically distributed stochastic views at
fixed theta, the expected average Qm alignment equals alignment to
Qbar=(1/4)sum_m Qm. The finite eight-view gradient estimate and its variance
still differ from a two-view Qbar estimate; Adam and checkpoint selection need
not produce equal trajectories. Qbar therefore does not discard all factual
graph information. Native single and singleQbar remain capable, legitimate
comparators for their declared total-learner questions; this additional
control addresses a finer attribution to private routes versus view averaging.

## Work, optimizer and serving distinctions

Per update under the CURRENT context replay:

                                      ROUTE BE   Frozen-unit single   Native/singleQbar
Distinct stochastic TRAIN views          8              8                   2
Executed backbone forwards                16             16                  4
  (shadow + differentiated replay)       8+8            8+8                 2+2
Member/view VJP collections                8              8                   2
Output-cotangent collections              1              1                   1
Fresh Adam optimizers / updates           1/1            1/1                 1/1
Own label-view presentations            4640           4640                1160
Served deterministic functions            4              1                   1
Full-development body calls/epoch         4              1                   1

Over 1100 epochs, the frozen-unit replay has 17,600 executed TRAIN forwards,
8,800 VJPs, 1,100 cotangent collections/Adam updates, 5,104,000 own label-view
presentations and 1,100 validation body calls. ROUTE has the same training
counts and 4,400 validation body calls. M1 context replay has 4,400 TRAIN
forwards, 2,200 VJPs and 1,276,000 own label-view presentations. Direct public
M1 training without replay has two forwards, not four. The saved Single8
adapter has eight forward tapes and one backward invocation per update;
it is not an already-qualified execution/resource match to current replay.
View count alone does not establish equal wall time, memory or trainable size.

Freezing removes private-factor trainable capacity and Adam moments while
preserving stored factor rows and all trainable native shared parameters.
Report trainable versus stored parameters separately. The intended inference
control is ONE member0 eval call and its softmax, not four stochastic predictions
or a manufactured four-member coverage bank. Candidate mean-probability
serving versus single-function serving is an explicit intended difference.
Even a positive paired result would not isolate capacity, training route
specialization and inference ensembling into separate causes.
