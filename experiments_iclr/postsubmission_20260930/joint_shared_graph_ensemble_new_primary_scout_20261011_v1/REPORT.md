## 3. One distinct avenue considered, left unpromoted

**Node-conditioned allocation of propagation and nonlinear transformation along private continuing states** is conceptually different from tour recurrence and landmark write/read memory. A shared stem and feature maps could feed four private controllers that select P/T compositions, preserve each route's changed state into later graph propagation, and receive own class CE rather than only a final gate loss. No independent bank would need pretraining.

**Conditional hypothesis:** if a finite-width ordinary routed predictor blends two useful neighborhood/feature cues into one continuation state and later propagation weakens a class-relevant cue, separate route controllers could choose different P/T mixtures, retain the resulting nonlinear states and propagate them separately. Own class losses could make these alternatives competent across the population, allowing the fixed mean to repair common source errors without introducing larger harms. Controllers should condition on each current private state and its graph context, rather than only static node IDs or raw-X edge weights. This remains a conditional mechanism, with no observed causal premise that the current strong sources suffer that bottleneck.

The distinctive graph path is a repeated node-adaptive operator before later nonlinear propagation. A varying node gate D generally does not commute with graph propagation P (`DP != PD`); later private states therefore need not reduce to a single cached, globally weighted hop bank. This is an ordinary operation-ordering fact. GNNMoE already supplies P/T allocation and repeated continuation; Node-MoE supplies graph-conditioned filter selection; saved BankGCN/private-filter and continuing-exchange work supplies further close collisions. Adding private controllers, own CE and a probability mean is a structured multi-route network built from those known ideas. It can also be expressed as one wider grouped predictor. A capable single with sufficient width, full operator access and residuals may retain both cues without four outputs; no ensemble expressivity separation follows.

There is no matched complete evidence that the current competent sources lose useful P/T-allocation information, or that such controllers would acquire alternatives that survive the original mean. Prior filter/hop failures do not disprove every repeated adaptive architecture. A narrow low-pass single would be an inadequate comparator; a competent adaptive routed single can already use the same operations.
