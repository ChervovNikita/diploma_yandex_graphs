# TRAIN-label-conditioned wrong-class diversity

8 October 2026. Inactive assessment of saved conclusions; no new primary read,
scientific code, score calculation, server action or experiment admission.

**Recommendation: park this as a new graph-method proposal. Retain it as one
attributed ADP comparator for later review after the currently preparing
relation-credit12 study closes.** It is a distinct objective from the closed
hidden-diversity and scalar-context studies, so their negative results do not
falsify it. The consulted ledger documents the known-objective control as
proposed only, with zero contrastive fits; no executed ADP control was found in
that entry. A previously saved 8 October all-wrong-pool note already identifies
ADP as the direct wrong-class-evidence diversification prior. This note does
not reissue an experiment or change an existing decision.

For a TRAIN node with true class y, let u_m be member m's probability vector
with coordinate y removed and then L2-normalized. Pang et al.'s ADP
(arXiv:1901.08846v3, Sections 3.1–3.3) minimizes

    sum_m CE(p_m,y) - alpha H(mean_m p_m) - beta log det(U_y^T U_y),

where U_y has columns u_m. Thus excluding the label from diversity while
retaining own-label supervision is already established. A pairwise proxy,
removed entropy term, block restriction or regularized determinant would be an
explicit adaptation. The saved primary scope is sufficient; it was not
reopened. The original evidence concerns independent image networks and
adversarial robustness, with an unlimited-output-capacity analysis. It gives
no shared-GNN competence or accuracy guarantee. Four members and ten classes
avoid the dimensional obstruction M>C−1 found previously on DBLP/binary tasks;
that only removes one obstruction to defining the native objective.

The hypothesis is plausible at the prediction interface. If one wrong class c
beats y in every member, the fixed probability mean also favors c. Training
that changes incorrect-class allocations can remove this strict common rival
and sometimes repair the pool even while every member remains wrong. Own CE
and probability-pool CE scalar values do not detect an exact redistribution
of wrong-class mass that leaves all p_m(y) fixed; this statement is about the
loss values, not equality of their parameter gradients. ADP directly measures
part of that redistribution. Its diversity can nevertheless rise through
changes in small tail classes while the dominant common rival persists.
Breaking the shared rival is necessary for a strictly correct pool, but the
complete requirement is positive pooled truth margins against every rival.
Changing the rival's identity alone is insufficient.

Member competence remains decisive. Removing y from the penalty does not
protect p_m(y), and ensemble entropy can compete with confident classification.
Stronger mean members with lower any-correct coverage already show why average
member quality alone is inadequate. Angular spread or increased logdet is no
success criterion. A later, single prospectively fixed ADP comparison would
need net served-pool repairs and improved whole-population accuracy/NLL while
respecting predeclared mean/worst-member competence and coverage tolerances.
Report acquired-correct-member repairs and all-wrong pooled-only repairs
separately, together with introduced errors. If only wrong-class diversity or
rival churn rises, or useful repairs require weakening members, park the
remedy; no coefficient sweep follows from that outcome. This is a falsifiable
future condition, not run admission or a new frozen gate.

The present observation identifies common prediction errors, not recoverable
neighbor information. ADP allocates class evidence but supplies no new graph
features or graph-evidence ownership. If the live shared representation has
lost the distinguishing information, a diversity penalty cannot reconstruct
it. DIVE and SuGAr already diversify graph masks/edge evidence; their methods
and serving rules differ, and neither proves that output ADP obtains useful
neighbor specialization in this shared backbone. GNCL already trades own and
pool risk, while the internal graph-responsibility and relation-credit
proposals supply different guarded mechanisms. No additional graph-specific
mechanism, novelty clearance, duplicate current arm or tuning grid follows
from wrong-class diversity alone.
