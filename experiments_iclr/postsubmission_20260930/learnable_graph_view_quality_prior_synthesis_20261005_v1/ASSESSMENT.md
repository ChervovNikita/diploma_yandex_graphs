# Learnable graph views: quality synthesis against the fixed-view plan

**Do not open a learned-view-plus-Jaccard method lane from this evidence.** Task-adapted graph views could improve member specialization, but learned views, shared feature transforms, graph attention and structural repulsion are already occupied. The precise worthwhile next control is **ordinary view-augmented native independent4 under the same native-graph probability pool**. That control is distinct from both the plan's native-only independent4 and its copied boundary-family untied sharing control. No plan, source, settings or launch is changed here.

## What the existing plan actually tests

The fixed-view30-fit protocol and its sources were inspected without reading outcomes. Its members receive complete TRAIN supervision on the native graph and their assigned fixed graph view. The views delete equal-class or different-class edges with TRAIN-TRAIN endpoints; degree-stratified random-null views control deletion budget. The persistent and temporally shuffled assignments compare exposure persistence; tied and untied persistent families compare ownership of the same initialized architecture.

The adapter runs a complete member-specific nonlinear trajectory through the native local graph-attention layers and global body. It shares interior weights, while private factors occupy the feature stem and prediction boundaries. The local loop runs in both training stages. **The native constructor already uses GATConv.** Different private stem states can therefore produce different learned neighbor attention even with tied attention weights. Sharing weights does not make member messages or attention coefficients identical.

All fixed-view members are selected and served on the **native graph**, with an **arithmetic mean of class-softmax probabilities**. That is the actual endpoint for this plan, not mean-raw-logit pooling or validation selection of a single member. Learned views that remain active at inference would change the serving graph and target; learned views used only for training would instead be an adaptive augmentation mechanism.

Source evidence: bank `PROTOCOL.json` objective/final; `driver.py:24–76`; `bank.py:69–128`; bound native constructor and boundary-forward excerpts in `SOURCE_BINDINGS.json`. These are source facts, not achieved quality or current runtime-state claims.

## Where learnable views might add useful evidence

The fixed equal/different-class categories are coarse. Class-discordant edges can carry valid heterophilous/boundary information, while some same-class edges can be nuisance. A task-trained view could select different informative neighborhoods within those categories, or condition on features in label-unobserved portions of the graph, using gradients from TRAIN supervision. Members might then preserve different predictive pathways rather than merely endure preset deletions.

This is plausible when informative alternatives exist, the learned scoring class can recognize them, and the shared feature maps remain useful across those alternatives. It can fail through overfitting TRAIN topology, removing scarce support, retaining only easy shortcuts, collapsing all masks, or making weak members that dilute the pool. No saved source establishes that the fixed-view plan has one of these deficiencies. No score or dataset is used to assert a regime.

The operation must act before the relevant information is lost. Learning a final-head view label or reweighting already compressed features cannot recreate missing neighborhood evidence. Existing full member trajectories provide the right location for a structural intervention; they also already provide learned attention and considerable nonlinear capacity.

## Why additional masks are not automatically a new mechanism

For any normalized attention rule `α_uv ∝ exp(s_uv)`, multiplying positive edge gates `g_uv` and renormalizing yields `α'_uv ∝ exp(s_uv + log(g_uv))`. This is an exact conditional algebraic identity: such gates act as attention-logit biases. If an extra pairwise mask MLP enlarges the score class beyond the existing GAT parameterization, the effect may be richer attention capacity. The identity does not claim the restricted current GAT weights can represent every new score function.

Hard support masks add deletion, sparsity and stochasticity. DIVE already learns those masks; DropEdge and the current fixed-view plan provide augmentation controls. A diversity auxiliary can favor disjoint isomorphic spurious motifs, giving low mask overlap but identical errors. Sparse independently sampled masks can lower realized overlap without changing the learned member distributions. Conditional embedding or residual spread has its own saved nullspace/quality limitations.

Thus the required distinction is **useful prediction changes at retained competence**, not smaller mask Jaccard, more distant embeddings, or the name ensemble. Adding pooled supervision would also require attribution to the saved individual/pool objective families. Adding an adaptive router or switching to the best member would change this plan's fixed endpoint.

## One precise small control worth pursuing

Prepare a **separate prospective ordinary native view-augmented independent4 comparison**, without replacing or amending the existing30-fit plan:

- Use the conventional native full-network members and their ordinary independent acquisition, with the same fixed semantic graph views, complete TRAIN supervision, native CE anchor and assigned-view CE exposure used by the bank.
- Preserve native-graph serving and the arithmetic probability pool, along with the existing task schedule and declared checkpoint policy. No best-member selection or learned fusion. Account for all member acquisition, view forwards, selection and storage.
- Keep the existing untied-persistent bank as the matched architecture/initialization sharing control. It deep-copies the initialized tied family and retains corresponding private factor rows; it is valuable, but is not the conventional independently acquired native ensemble.

This control answers a precise utility question: **does conventional independent training receive the same benefit once it is given the views?** A gain against native-only independent4 can be an augmentation gain. A tied-versus-untied bank contrast can establish a bounded sharing effect, but does not automatically establish superiority over independently initialized native models with the same augmentation. The conventional control closes that interpretation gap without introducing a new learned-mask architecture.

No new numerical setting, graph, seed, fit budget, threshold or source implementation is chosen. Any additional comparison needs its own prospective admission; the existing plan is unchanged.

## Conditional learning question, not an admitted method

If learning views is later pursued, two contrasts are essential:

1. **Learning contrast:** learned task-conditioned views versus the fixed semantic and retention-matched random-view controls, with the same predictor/edge-score capacity and native serving pool. Include the overlap-off version of the same learned-mask architecture so Jaccard's effect is not confounded with the mask scorer.
2. **Sharing contrast:** tied versus competent untied/view-augmented independent predictors under the same view opportunity and fixed pool. If each ownership condition learns different views, the contrast estimates the combined ownership/view-coadaptation mechanism; a pure tying claim needs the same frozen or replayed learned-view schedule, with any donor acquisition cost charged.

Reject the proposed useful specialization if pooled quality does not improve at retained member competence; if random-view or ordinary independent augmentation matches it; if extra attention capacity explains it; or if the gain requires selected-single serving. Diagnostics may locate different error patterns, but cannot replace predictive utility. No numerical criteria are set here.

Differentiable learned gates also require an explicit message-weight/attention hook. The current driver passes discrete fixed `edge_index` tensors; changing an edge-index selection alone does not provide gradients to mask probabilities. DIVE's ambiguous printed sampler/straight-through/Jaccard specification cannot be copied silently. A proper adaptation must bind sampling, gradients, edge symmetry/self-loops, retention, normalization and inference behavior, and charge dynamic graph work. This assessment writes no hook, harness or launch.

**Disposition:** learning graph views is a plausible attributed architecture/augmentation extension, not a supported distinct method contribution. Reject a Jaccard-only lane. The exact conventional view-augmented independent4 control is worth pursuing because it tests a concrete quality explanation left open by the existing plan. No empirical gain or publication conclusion is inferred.
