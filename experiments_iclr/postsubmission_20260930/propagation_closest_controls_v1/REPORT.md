# Closest methods and one direct control

30 September 2026. Source and analytical work only. No dataset, model, checkpoint, score or remote allocation was opened. This proposal precedes new training outcomes and does not authorize fits or amend the root's protocol by itself.

## Recommended comparison

Add one **detached current-member mean** arm if complete-data engineering can admit all five arms within the existing cap. It uses exactly the candidate's current normalized member states, exact common aggregation, sampled residual operator and forward arithmetic. Its only change is to stop gradients through the mean in both branches. This tests whether learning benefits from propagating the common component of the local gradient through the full graph.

This is the strongest cheap **causal mechanism control** available from the current source. It is an ablation of this proposed method, **not a reproduction of Chen's temporal CVGCN or SGCN++**. It cannot establish superiority over those complete published methods. A claim of broad state-of-the-art scalable GNN or efficient-ensemble superiority would still require those comparators and architecture-specific adaptations.

For normalized states `Z_m`, let `B = mean_m Z_m`. The candidate supplies `P B + Q (Z_m-B)` to each member. The control instead uses `Bstop = stop_gradient(B)` and supplies `P Bstop + Q (Z_m-Bstop)`. Forward values agree at fixed states and a fixed mask. The control has a cheaper backward pass because its exact common aggregation has no input gradient; measure this cost difference rather than presenting both complete training workloads as equal.

The exact adjoint derivation is in `FORWARD_AND_ADJOINT.md`. The candidate locally propagates the average upstream gradient with `Pᵀ` and gradient contrasts with `Qᵀ`. The detached arm propagates every gradient with `Qᵀ`. This is a precise local distinction. LayerNorm before this operator, member nonlinearities after it, dropout, losses and changing parameters prevent a claim of exact or unbiased whole-network optimization.

## Novelty claims to reject

- “A new control-variate principle for GNNs,” “first mean/residual decomposition,” “first coupled sampled-difference method,” and “first gradient variance reduction for GNNs” duplicate inspected prior ideas.
- “Unbiased GNN predictions/gradients” or “preserved ensemble prediction/learning” do not follow from a local linear identity. Chen and GraphSAINT explicitly expose the nonlinear limitation; SGCN++ supplies a substantially different algorithm and assumptions.
- “One pass makes graph ensembles computationally efficient” is insufficient. MIMO, grouped/narrow ensembles and shallow graph ensembles already address efficient inference, and packed execution can still do four members' edge-channel work.
- “No prior ensemble-centered sampling exists” is unsupported. One bounded arXiv query combining graph, ensemble and control variate returned no entries; that is a search limitation. Earlier GEENI is still abstract-level evidence, and _Graph ensemble neural network_ (Information Fusion 2024) is still metadata-only in `closest_graph_ensemble_sources_v1/REPORT.md`. These remain unresolved access gaps, not cleared novelty objections.

The defensible prospective idea is narrower: **route common member states and common local adjoints through an exact graph operator while sampling only contrast components, with four full-width nonlinear members retained**. The decomposition is elementary linear algebra. A methodological contribution would require reproducible quality/cost benefits, useful ensemble gains and a passed direct-control comparison on both complete tasks. No such outcome is supplied here.
