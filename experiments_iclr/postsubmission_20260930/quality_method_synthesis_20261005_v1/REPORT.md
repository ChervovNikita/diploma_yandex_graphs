## What the candidate changes

The current NCNC implementation has one shared node encoder. Its outer target decoder gives every member the same vector `h_u ⊙ h_v`. Private maps occur after that compression. This is more restrictive than four separately encoded endpoints: two pairs with the same coordinatewise product are indistinguishable through this outer product branch, irrespective of its subsequent diagonal factors or nonlinear maps.

For example, `(e1,e2)` and `(e1,e3)` both produce the zero vector. This is a local interface collision, not a collision of the full native model: common-neighbor features, recursive completion and a learned shared encoder can distinguish the cases through other paths.

The candidate applies one learned Householder reflection to both endpoint states before the product:

`p_m(u,v) = (H(v_m) h_u) ⊙ (H(v_m) h_v)`, with `H(v)=I−2vvᵀ/(vᵀv)`.

A nonaxis reflection introduces symmetric cross-coordinate interactions before they are discarded. The native decoder, target loss, observed graph and mean-logit serving remain the previously specified operations. Member-axis initialization preserves the original product exactly, while permitting nonzero tangent gradients through anisotropic decoder weights. This is an initialization convenience, not evidence of useful specialization.

This synthesis differs from embedding repulsion: it changes the information entering the served scorer. It also avoids the matching-likelihood problem, in which an auxiliary joint law can improve while every served mean logit stays fixed. Actual learning can still leave this adapter useless.

## A precise local capacity limit

For one linear product-readout row with weights `c`, the pair score has symmetric matrix `H D_c H`. Let `q=vᵀv`, `w=D_c v` and `α=vᵀD_c v`. Its change from the original diagonal matrix is

`Δ = −2(vwᵀ+wvᵀ)/q + 4αvvᵀ/q²`.

Every column of `Δ` lies in the span of `v` and `w`, so its rank is at most two. Orthogonal conjugation also preserves the eigenvalues of `D_c`. Thus a single reflection rotates a restricted interaction geometry; it does not supply unrestricted new bilinear capacity. An isotropic dot-product row is exactly invariant. A mean of linear reflected branches is one symmetric bilinear score and is representable by a full symmetric-bilinear single.

These statements apply to the fixed endpoint states and linear readout. They do not prove containment of the complete nonlinear NCNC ensemble with its context branches, and they do not predict accuracy.

A combination of familiar ingredients can be a useful method, but neither the exact implementation difference nor this report clears methodological novelty.

## Controls and how the ordinary ensemble can win

An independent ensemble given the identical reflection operation has independent encoders, decoders and frames. It can represent the shared model by tying its weights, and can also learn endpoint geometries that the shared encoder cannot supply simultaneously. Any shared-model quality advantage must therefore arise from estimation, regularization or optimization under the stated finite training protocol; it cannot be universal function-class superiority.

The necessary comparisons are:

1. Unmodified F4 and F4 with one common learned frame, to test whether private rather than common interaction bases matter.
2. Competent native single and ordinary independent four, to retain the requested quality objective.
3. Ordinary independent four with the identical private-frame operation, axis assignment, schedule and eligible selection opportunities. Without this arm, an adapter gain can be misattributed to sharing.
4. A capable single with the same four reflected-product feature vectors concatenated before one target decoder. It should receive its own learned frames and a competent decoder, rather than averaging away the supplied features. This separates multiple useful interaction features from the need for multiple predictive routes. Architecture, loss scale, parameter counts and selection must be fixed prospectively.

The existing proposed two-frame dense single is a useful richer-bilinear comparator, but does not by itself isolate four feature frames versus four predictions in the actual nonlinear model. Neither single control should be described as an exact whole-network capacity match. Do not turn these distinctions into an open-ended control grid: qualify and freeze one competent same-operation single before a representative screen.

## Falsification and continuation decision

The private-frame explanation fails in the screened setting if a common frame matches it, if useful off-axis movement fails to emerge, or if its served quality does not improve. The shared-ensemble explanation fails if the capable same-operation single or ordinary independent ensemble with frames matches or exceeds its quality. Better auxiliary fit, embedding distances, parameter counts or a favorable seed do not rescue either claim.
