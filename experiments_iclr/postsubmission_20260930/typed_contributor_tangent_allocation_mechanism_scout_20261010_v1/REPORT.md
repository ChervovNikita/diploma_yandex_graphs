## New scope: CorDA limits the claim

CorDA forms the activation second moment `C = XX^T` (called covariance in the paper), decomposes **`WC`**, and reconstructs with `C^-1`: `W_hat = U Sigma V^T C^-1`. It describes diagonal regularization when inversion is unreliable. It selects either bottom contextual components to preserve knowledge or top components to adapt the previewed task. Both modes use `W' = W - BA`; the pretrained residual is frozen and the initialized factors are trained. Thus the initial total `W' + BA` equals `W` by construction.

This is direct ancestry for context-dependent covariance orientation and function-preserving low-rank initialization. It is not an ensemble or graph-type allocation method in the read scope. The proposed hypothesis below instead uses an outgoing-zero additive branch with a trainable shared core. It does not silently replace CorDA's `WC` by `WC^(1/2)`, transport its knowledge-preservation claim, or adopt author-reported performance. EVA, LoRA/PiSSA, LoRA-GA and shallow-ensemble covariance orientation were already saved and remain attributed.

## H1: common evidence anchors plus one typed contrast tangent

**Eligible setting.** At least two native graph contributors (canonical relations or fixed meta-path channels) already provide vectors `z_it` of the same latent width `d`, after the native type maps and before native fusion. The graph, maps, contributor order, split and training recipe are fixed. Do not subtract incompatible raw heterogeneous features. A native single retaining these contributors must be competent first.

**Concrete proposed mechanism.** Use four members and a fixed rank-four private additive branch at this location. Every arm receives the identical concatenated contributor vector `z_i = [z_i1; ...; z_iT]` and adds `B_m A_m z_i` to the same native hidden output. Initialize every `B_m` to zero. All `A_m`, `B_m` and the shared core subsequently follow the same own-member factual objective and deployment policy.

Let `L = [I ... I]/sqrt(T)`, `s_i = L z_i`, and `P = I - L^T L`. From FIT inputs only, at one identical predetermined warm state, choose three leading eigenvectors of `E[s_i s_i^T]` and lift them by `L^T` as common incoming rows. Choose the four leading nonzero eigenvectors of `P E[z_i z_i^T] P`; member `m` receives the `m`th one as its fourth incoming row. Normalize all incoming rows to the same prescribed row norm. Fix tie-breaking and eigenspace degeneracy handling before any outcome is read. If three common and four contrast directions are unavailable, declare this rank-four proposal ineligible rather than silently lower ranks or fill with selected noise.

This reserves three of four private slots for common evidence and allocates one initial slot per member to an across-contributor contrast. The allocation is an initializer, not permanent ownership: incoming factors may move during training. No spectrum cutoff, rank split, coefficient, layer, donor scheme or horizon is selected by VALID.

**Prediction.** Where informative contributor differences are underrepresented by a common fusion tangent, this allocation improves actual member competence relative to equal-capacity global/random initialization and yields useful deployed repairs after accounting for harms. An ensemble claim additionally requires improved deployed pooling utility against a capable same-information single. The common rows are a design choice, not a competence guarantee; choosing leading variance directions is not choosing leading label information.

**Exact limited information argument.** For a genuinely linear sum bottleneck, changes `delta_z` in `ker(L)` leave the common sum unchanged while a contrast incoming row can have `a^T delta_z != 0`. At `B=0`, the predictor is unchanged but the outgoing-factor tangent can use `A z`. This is a symbolic possibility. If native attention/fusion already processes all contributors, the lost-information argument does not apply; only allocation of the initial tangent is under test. No finite dictionary is claimed to capture all graph information or to be injective.

**Why this differs from saved proposals.** It does not add a private native propagation block, generate new neighbors or anchors, apply a nonlinear map to individual neighbors, or initialize from a pooled graph-left SVD alone. Its testable ingredient is a common/contrast decomposition across *existing typed contributors*, with a fixed overlapping common subspace and one distributed contrast slot. Typed branches, context covariance, orthogonal dictionaries and shallow sharing are all established ingredients; their composition is not certified novel.

## Competent comparisons and falsifiers

The first comparison uses the **same private branch, contributor inputs, parameters, row norms, warm state, training steps and deployed pool**. Change only the initialization rule:

1. Candidate: three common rows plus one assigned typed contrast row.
2. Same anchors plus one of the four leading unconstrained residual-covariance directions after projecting out those anchors. This isolates contrast restriction from ordinary activation orientation.
3. Same anchors plus a matched random residual row.
4. A capable all-global rank-four activation-covariance initializer, with the same architecture. This tests the cost of reserving contrast slots.
5. A predetermined FIT-supervised gradient/VJP orientation on the same contributor inputs and branch, with the same rank and normalization. This tests whether plain task orientation explains any benefit. No live action screening or trial-dependent selection is added.

Use a separate initializer-alignment falsifier: independently permute FIT target-row assignments of each contributor within predeclared type/degree strata before computing **only** the contrast covariance. Keep the factual common anchors, actual model inputs and inference graph unchanged. This preserves each contributor's marginal values while disrupting targetwise cross-contributor alignment. A global renaming of relation IDs is not a meaningful control: the common/contrast projector is equivariant to that renaming.

Also require: a competent native single, genuine independent4, a capable single with the **same contributor information and total adapter budget**, and a capable post-fusion/node-only private alternative under declared parameter/compute matching. The latter tests location/information; the identical typed-branch comparisons test initialization. Do not obtain matching by padding with redundant copies of node features. A same-information single can concatenate the member dictionary rows: for a fixed shared hidden state and linear sum of adapter outputs, `sum_m B_m A_m z` collapses to `[B_1 ... B_4][A_1; ...; A_4]z`, rank at most 16. Nonlinear member recurrence can break this equality, but does not remove the need for a capable single comparison.

Report native task metrics for every member and the fixed deployed pool, pool-minus-member-mean, full-population repairs/harms and common-wrong repairs where the frozen task allows them. Preserve all failures. Source utilization, covariance energy, dictionary orthogonality, disagreement, BCE or an initialized tangent check cannot substitute for these outcomes.

Reject the claimed graph allocation benefit if it fails to beat the same-capacity global/random controls; reject targetwise graph alignment if the donor-permuted initializer works equally well; reject an ensemble advantage if the capable same-information single matches it. Reject a competence claim if stronger pooling conceals weaker members. Signal entirely in the common subspace, low-variance label signal, nearly redundant contributors, arbitrary latent coordinate alignment, or harmful fourth-direction tails are explicit failure cases.
