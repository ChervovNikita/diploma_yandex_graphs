## First candidate: estimate joint member reliability across the graph

At a fixed set of labeled fusion nodes, measure each member’s prediction error and which member errors occur together. Transport those small error-moment matrices through a fixed visible graph, then estimate node-specific convex probability weights. This could distinguish two individually competent members whose errors repeat from members whose errors complement one another. It can fail when graph neighbors have different error patterns or calibration labels are sparse.

For four members, the matrix contains ten unique scalar fields. Full cross-moments are exactly reconstructible from individual squared error and pairwise prediction disagreement. That identity is known ensemble algebra; the proposed component is its explicit local graph estimator and constrained pooling rule. It is not a new independent labeled statistic or an accuracy theorem.
