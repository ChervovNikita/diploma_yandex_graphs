# Disabled normal77 read-only observation source

`OBSERVE.py` prepares the exact inputs of the immutable relation18 root assembler. Source preparation used stdlib AST/JSON/hash checks only. It did not execute the entry, inspect live processes, query a GPU, open outcomes/checkpoints/arrays, import numerical providers, or call a remote route.

Root stages this immutable packet and supplies a separate hash-bound copy of `OBSERVATION_INPUT_TEMPLATE_DISABLED.json`, with exact completed relation FAMILY/PARENT_OWNER/activation LAUNCH/lane closures, original12 UNION_CLOSURE and both original owner receipt bindings. No COMPLETE/RUN outcome files, state checkpoints, input data or prediction archives are opened. Immutable reader/assembler source hashes are checked as source files, not imported as entry programs.

## Actual identity and resource observations

Saved PID/start/group/session identity comes from the original receipts. One `/proc` stat scan and direct saved-PID stat observations inspect only numeric birth/group/session metadata; no process command line or executable is read. If the same PID/start tuple is still present, even as a zombie, original absence is not claimed. A reused numeric PID with a different birth is an unrelated identity. Its command line is never inspected, it is never signalled, and its CUDA rows are not counted as original ownership.

Group absence is checked against saved pgid/sid. A replacement numeric group is excluded only when its leader has a different birth and every observed group member belongs to that replacement session and starts at or after the replacement leader. Otherwise a nonempty group is unresolved, rather than treated as absent. Missing originally saved group fields remain explicitly unavailable. The detached relation parent has complete saved group metadata and must have actual group absence.

Actual `nvidia-smi` metadata supplies compute rows, exact physical inventory and GPU0 free bytes. Commands have ten-second timeouts; there is no retry, watcher, sleep, signalling or model/allocation call. The historical collector's observation is taken from the exact already-bound original-route attestation and CHILD_OWNER/CHILD_TERMINAL receipts. Its anogena PID is never looked up on normal77.

Installed version metadata is read with `importlib.metadata.version`, which imports no Torch, NumPy or other numerical provider. Actual hostname, repository, interpreter, PYTHONPATH, package versions and inventory are compared to the immutable reader runtime. CUDA environment during metadata observation is disclosed separately. Fresh physical readiness stays false when observed free memory is below the existing threshold; no resource value is invented.
