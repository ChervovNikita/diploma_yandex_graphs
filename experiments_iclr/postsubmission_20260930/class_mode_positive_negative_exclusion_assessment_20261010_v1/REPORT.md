## Exact retained operation

Use the existing native SAGE model, active internal private factors, output-head input H, native optimizer/selection/restoration lifecycle and mean-probability serving. At each update obtain every route's H from the **same single factual forward** used for own CE. No second forward, projection/retrieval head, cross-route negatives, learned targets or serving adaptation is added. Own CE remains the mean of all routes' CE on all 580 TRAIN nodes. The auxiliary reaches the live upstream parameters; the downstream classifier receives CE through its normal path, not a direct context loss.

Prepare four fixed signatures from public features/edges: X, X−PX, PX, P²X. P is the saved row-normalized destination aggregation of deduplicated directed edges plus exactly one self-loop; it prepares signatures and does not alter native SAGE propagation. For each signature/anchor, select the top 16 **other** same-class TRAIN nodes by cosine, or every other same-class node when fewer exist. Stable TRAIN-row order resolves ties. Zero signatures use the saved zero-cosine/stable-order convention. Normalize the selected Boolean row to fixed uniform weights Q_r. Require at least two TRAIN examples in every class before release; do not repair failed support by changing the rule. Q_r has zero diagonal and row mass one.

For route m, normalize all 580 H vectors with the existing epsilon 1e−12 and form its cosine Gram scores S_m=cos(H_m,H_m)/0.2. Write P_r(i)=support(Q_r(i,:)) and D(i)={j:y_j≠y_i}. Retain E_r(i)=P_r(i)∪D(i), which excludes both exact self and unselected same-class nodes. The one retained candidate is

```
ell_r(S) = mean_i [ logsumexp_(j in E_r(i)) S_ij − sum_j Q_r,ij S_ij ]
A_PRIVATE = (1/4) sum_m ell_m(S_m)
J_PRIVATE = mean_own_CE + .05 A_PRIVATE.
```

The positive average is outside the log. Q and E are fixed, stopped, TRAIN-only arrays. All different-class TRAIN candidates remain; there is no negative sampling or label-prediction-based false-negative detector. This is a provisional **single-view/all580/self-excluded native adaptation** of the saved cross-view/512-panel/self-positive rule. It is not a replay of that old recipe and changes no old source or outcome. The fixed .05/.2/top16 choices are attributed inherited choices, not optimized values or competence guarantees.

This changes a route's training dependencies. It does not add feature-neighbor message paths or new observations to the predictor. Private SAGE factors can, through nonlinear message/feature computation, alter class margins under these gradients; they may also satisfy the auxiliary in prediction-invisible directions or learn nuisance context. Factual context modes and missing paths remain hypotheses, not diagnosed causes of existing errors.
