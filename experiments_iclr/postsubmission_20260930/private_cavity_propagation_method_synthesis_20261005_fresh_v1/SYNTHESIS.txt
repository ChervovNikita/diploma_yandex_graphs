Private return-message factors: a bounded method synthesis
5 October 2026. Proposal only. No implementation or scientific execution.

Scientific conclusion

The nonbacktracking/cavity backbone is established. The candidate below is exactly an edge-operator bank with restricted parameter tying. It is not a new propagation principle, a novelty clearance, or evidence of a predictive gain. The remaining defensible question is empirical: does assigning a small private factor specifically to immediate-return evidence give a shared neural graph ensemble a better learning bias than factorizing the entire incoming aggregate? A positive result could support this precise sharing bias, with credit to the existing propagation and ensemble methods. It could not support a claim that directed messages, learned backtracking weights, or private factors are new.

Failure being hypothesized

For fixed, linear node propagation P, a feature-axis private matrix F_m acts on H as P H F_m. Feature transformations commute with left multiplication by P. Without nonlinearities or skips, L such layers retain the common spatial operator P^L even when member channel maps differ. All members therefore count the same immediate-reversal walks. This is a representational observation for that restricted model, not proof that the actual nonlinear GNNM makes correlated errors because of walks. Independent models using the same fixed linear propagation have the same limitation. Attention, nonlinearities, skips, and capable operator banks can already change the conclusion.

The hypothesis concerns ambiguity inside the sum: incoming evidence that continues along a new edge and evidence that returns over the edge just traversed are transformed together. A global private feature mask cannot choose between them after summation. Immediate returns can repeat source information or degree/popularity effects, but can also preserve useful context. Removing every return is consequently not the proposal.

Exact prospective operation

Use the same simple undirected graph in every arm, obtained by the declared common symmetrization/coalescing policy. Represent each non-self edge by both orientations. Keep self information in an explicit root term. Let E_m^l be an array of shape [2|E|, d] for member m=1,...,4. There are no new edge labels, target labels, graph views, or likelihood auxiliaries.

For e=(u -> v), define the weighted incoming total and remembered return:

  S_{m,u}^l = sum_{w in N(u)} a_{uw} E_{m,w->u}^l,
  R_{m,u->v}^l = a_{uv} E_{m,v->u}^l,
  C_{m,u->v}^l = S_{m,u}^l - R_{m,u->v}^l.

Weights a are fixed by the common operator convention; the unweighted sum gives the clean derivation below. If a mean is used, both C and R use the ORIGINAL denominator d_u. A d_u-1 cavity mean is a different model and must not be substituted. Set S=0 for isolates. Initialize E_{m,u->v}^0 from the same node representation H_{m,u} already available at the replaced GNNM site. Use two return-aware propagation steps, an explicit root/initial-state skip, and incoming aggregation back to nodes before the existing task readout.

At step l, share W_l and U_l. Retain the ordinary private feature factors r_m^l,s_m^l and add only a private vector q_m^l:

  E_{m,u->v}^{l+1} = sigma(
      E_{m,u->v}^0 U_l
      + [(C_{m,u->v}^l elementwise r_m^l)
         + (R_{m,u->v}^l elementwise (r_m^l+q_m^l))]
        W_l elementwise s_m^l).

Equivalently, the bracket is S_{m,u}^l elementwise r_m^l + R_{m,u->v}^l elementwise q_m^l. Each q is an unconstrained signed trainable vector: it can attenuate, cancel, or amplify returned evidence. Set q=0 initially, so the intervention does not begin by arbitrarily suppressing returns. At the first step E^0 is identical across outgoing edges of one source, so q=0 reduces to an ordinary node aggregate plus the explicit root term. With q remaining zero and otherwise matched node updates, the outgoing edge states remain source-only by induction. The actual GNNM residual/norm conventions must be preserved to claim a baseline embedding.

Train by the existing mean of the four member task losses. Serve the declared uniform member pool, matched across all ensemble arms. No inference gate, specialization loss, label reconstruction, pooled-only optimization claim, or extra initialization search is introduced. Shared weights still receive all member gradients. This does not eliminate interference or guarantee different q vectors.

Exact equivalence and attribution boundary

Write B for the incoming edge transition that excludes reversal and J for the weighted reversal operator. With row-feature convention, F_m=diag(r_m) W diag(s_m) and G_m=diag(r_m+q_m) W diag(s_m), the layer is exactly

  sigma(E_m^0 U + B E_m F_m + J E_m G_m).

It is therefore an existing B/J relation/operator bank with tied feature maps and private diagonal adapters. A learned scalar backtracking coefficient kappa_m is the special case q_m=(kappa_m-1)r_m. The algebra does NOT distinguish the candidate from learned backtracking-coefficient models; the two new scopes did not establish which earlier paper first used every such scalar coefficient. No third primary scope was added to manufacture an absence claim.

Yang et al., arXiv:1904.01561v4, Sections 3.1-3.2, already use directed bond states, exclude the reverse message, add an initial-edge-state skip, return to atom states, and train end to end. Section 3.6 explicitly averages independently initialized/trained D-MPNNs. Its zero-return operation is G=0, obtainable here with q=-r. This candidate differs by allowing learned returns and restricting their private capacity; it does not invent directed-bond reasoning or directed-model ensembling. The molecular native input/readout is different from the proposed citation-node task.

Chen, Li and Bruna, arXiv:1705.08415v4, Sections 4.1-4.2, already combine learned graph operators, nonbacktracking line-graph states, and node/edge incidence maps. Its current v4 title is Supervised Community Detection with Hierarchical Graph Neural Networks; do not silently label this exact retrieved version with a later publication title. Appendix A.3 also relates nonbacktracking inference to I,D,A/Bethe-Hessian operators. These scopes establish learned node/edge operator-bank ancestry, not the candidate's predictive utility.

Saved R-GCN conclusions (index v56 record 86) establish relation-specific propagation with shared bases/block decompositions. Labeling B and J as two derived relations supplies no new sharing primitive. Saved GNN-FiLM conclusions (record 111) establish featurewise message modulation. BatchEnsemble supplies the private diagonal factors. D-MPNN reverse exclusion is already an echo-removal operation; a named new 'echo cancellation' principle would be misleading. Separating ego/root from neighbours is also established and does not remember which incoming edge produced a particular return.

A capable single B/J bank can include this complete forward function. Packing the four streams into one model and optimizing its pooled task loss gives identical trainable parameters, information, and forward work. An unrestricted single bank can additionally learn separate B/J maps or a joint stream readout. The candidate has no demonstrated expressiveness advantage over those single models. A win would measure sharing/individual-supervision bias, which are attributed ingredients.

Analytic distinctions and counterexamples

Take scalar, linear, unweighted propagation with E_{u->v}^0=x_u, omit the root for this calculation, and let F=f, G=g. After one edge update and incoming node readout:

  z = f A^2 x + (g-f) D x,

where D is the degree diagonal. This follows because the no-return aggregate excludes exactly one copy of x_v for each edge entering v. On an irregular graph D x generally cannot be represented by a fixed scalar combination of I x, A x and A^2 x for all x. It is nevertheless covered by a competent I,D,A model; this is not a new graph operator or an expressiveness theorem for the actual nonlinear architecture.

On a d-regular graph, D=dI, so this two-step scalar construction collapses to an ordinary A^2/ego filter. With all-one input it adds no distinguishing signal on regular anonymous graphs. Equivariant B/J processing cannot distinguish graph automorphisms with identical available features. At larger depths B and J need not commute, but that observation does not confer a novelty or quality guarantee.

For a consistently normalized row mean P, the corresponding two-step return term is diag(sum_u P_vu P_uv)x. It is a degree-dependent diagonal correction. It is constant on regular unweighted graphs and varies on irregular graphs. Therefore a degree/normalization explanation may suffice; include degree-aware and ego/skip capacity in the single bank.

An isolated two-node component is a useful counterexample to indiscriminate suppression: C is always zero. Without a root/restart, fixed nonbacktracking propagation loses its signal after the first step, while a return can retain it. Trees with leaves have related boundary effects. A skip can already repair some of that failure, so it must be present in controls. At deeper steps a reverse message can also contain neighbours-of-the-neighbour, not only the ego feature. Short cycles and repeated collaboration/citation motifs can carry useful target signal; immediate reversal is not synonymous with nuisance.

Treat self-loops explicitly. If a loop is included as an ordered edge, its reversal is itself; J subtracts it from C and then the return map adds it back differently. That makes an ordinary self/root transform look like a return intervention and can explain a spurious gain. The proposed comparison instead removes loops from the directed-edge bank and gives every arm the same explicit root/self term. Removing loops without that shared root comparator would also be an unfair comparison.

Representative falsifier, no execution

Use COMPLETE ogbn-arxiv, official temporal split, TRAIN labels only, and the same symmetrized input graph and available node features for all arms. This is a representative sparse real citation task, not a synthetic demonstration or selected subgraph. The hypothesis is about repeated local evidence, so it should first survive this complete setting. Current collab outcomes and the frozen joint-auxiliary cohorts are neither consulted nor used to tune this proposal.

Keep a competent ordinary single and ordinary independent4 on their locked native SAGE recipe. A credible starting reference is the standard full-batch 3-layer, width-256 SAGE recipe: Adam lr 0.01, dropout 0.5, 500 epochs, validation-selected checkpoint. This schedule is a prospective standard reference from background knowledge, not newly source-qualified by this packet; any adopted native control recipe takes precedence. Before a later implementation, freeze its exact operator/norm/residual recipe and verify that the single is competently trained. Do not shorten that control to fund the candidate or declare competence from a parameter count. A modern already-qualified single is an additional reference if the project has one.

First complete cohort: seeds 17/29/43, one graph, no hyperparameter search, seven arms: (1) ordinary single; (2) ordinary shared4; (3) candidate; (4) true same-forward single B/J bank trained with pooled loss, given the candidate's paid training budget; (5) ordinary independent4; (6) independent4 with the same B/J return split; (7) candidate with a fixed wrong-return pairing. The first cohort has 21 arm/seed cells, 39 individual fits when independent members are counted, and is an exploratory screen, not a definitive statistical claim. Offer the B/J single separate maps/joint readout if the tied version is materially less capable within the candidate's paid budget; a restrictive single cannot establish the contribution. All added edge-state passes, preprocessing, dense edge maps, selection and failed runs count toward cost. Sharing W saves parameters, not member edge-state arithmetic or activation memory. Resource feasibility and source qualification remain unresolved.

For wrong-return pairing, fix one label-free neighbour permutation pi_u at each source u. For output u->v use a_{u,pi_u(v)} E_{pi_u(v)->u} as R, with C=S-R. This preserves S and the incoming message multiset at each node; it breaks the identity of the edge just traversed. Keep degree-one neighbourhoods unchanged and report that the intervention has no power there. Freeze the permutation before fitting. At q=0 the paired operations are exactly equal; after learning they differ only through the remembered edge pairing, with matched factors and work. This is a mechanism intervention, not a new model selected after seeing validation.

Abandon the return-specific interpretation if correct pairing fails to improve held-out validation accuracy/NLL over wrong pairing and the capable single bank, or if q stays functionally irrelevant. Abandon the practical ensemble-extension claim if the candidate fails to beat BOTH the competent ordinary single and ordinary independent4 on the paired complete-task screen at its full paid cost. A gain over ordinary independent4 accompanied by equal or better independent4-B/J supports an architectural return-aware bias; it does not establish a benefit from parameter sharing. A gain only over fixed nonbacktracking models supports retention of useful returns, already anticipated by the operator-bank controls. Require subsequent independent confirmation before claiming a reliable quality gain. Three seeds do not justify a strong significance, graph-population, or novelty conclusion.

Disposition

Retain exactly one untested sharing-bias hypothesis if the parent wants a representative experiment. Do not promote cavity/nonbacktracking factors as a newly invented graph ensemble method. The prior-to-operation equivalence is explicit, and the strongest single can represent the candidate. No genuinely distinct principle surviving this equivalence was established in this bounded pass; an empirical contribution remains possible only through the specified comparisons.
