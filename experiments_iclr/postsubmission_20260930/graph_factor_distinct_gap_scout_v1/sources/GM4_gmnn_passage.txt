161: Here, the distribution of 𝐲n\mathbf{y}_{n} is characterized by a softmax classifier, which takes the object representation 𝐡ϕ,n\mathbf{h}_{\phi,n} learned by a GNN model as features, and we denote the GNN as GNNϕ\text{GNN}_{\phi}. 162: The framework is related to the label propagation methods (Zhu et al., 2003; Zhou et al., 2004), which also update each object label by combining the surrounding labels. However, these methods propagate labels in a fixed and linear way, whereas GNNϕ\text{GNN}_{\phi} is in a learnable and non-linear way.
163: One notable thing is that when defining pϕ​(𝐲n|𝐲NB​(n),𝐱V)p_{\phi}(\mathbf{y}_{n}|\mathbf{y}_{\text{NB}(n)},\mathbf{x}_{V}), GNNϕ\text{GNN}_{\phi} only uses the object labels 𝐲NB​(n)\mathbf{y}_{\text{NB}(n)} surrounding the object nn as features, but GNNϕ\text{GNN}_{\phi} is flexible to incorporate other features. For example, we can follow existing SRL methods, and take both the surrounding object labels 𝐲NB​(n)\mathbf{y}_{\text{NB}(n)} and surrounding attributes 𝐱NB​(n)\mathbf{x}_{\text{NB}(n)} as features in GNNϕ\text{GNN}_{\phi}. We will discuss this variant in our experiment (see Sec. 6.4).
164: Another thing is that based on the overall formulation of pϕp_{\phi}, i.e. Eq. (1), each object label 𝐲n\mathbf{y}_{n} should only depend on its adjacent object labels 𝐲NB​(n)\mathbf{y}_{\text{NB}(n)} and object attributes 𝐱V\mathbf{x}_{V}, which implies GNNϕ\text{GNN}_{\phi} should not have more than one message passing layer. However, a common practice in the literature of graph neural networks is to use multiple message passing layers during training, which can well model the long-range dependency between different objects. Therefore, we also explore using multiple message passing layers to capture such long-range dependency (see Sec. 6.4).

183: 4.4 Optimization
184: To optimize our approach, we pre-train qθq_{\theta} with the labeled objects. Then we alternatively optimize pϕp_{\phi} and qθq_{\theta} until convergence. Afterwards, both pϕp_{\phi} and qθq_{\theta} can be used to classify unlabeled objects. In practice, qθq_{\theta} consistently outperforms pϕp_{\phi}, and thus we use qθq_{\theta} to infer object labels by default. We summarize the detailed optimization algorithm in Alg. 1.
185: Fig. 1 presents an illustration of the framework. For the central object, qθq_{\theta} uses the attributes of its surrounding objects to learn its representation, and further predicts the label. In contrast, pϕp_{\phi} utilizes the labels of the surrounding objects as features. If a neighbor is unlabeled, we simply use a label sampled from qθq_{\theta} instead. In the E-step, pϕp_{\phi} predicts the label for the central object, which is then treated as target to update qθq_{\theta}. In the M-step, qθq_{\theta} predicts the label for the central object, which serves as the target data to update pϕp_{\phi}.
