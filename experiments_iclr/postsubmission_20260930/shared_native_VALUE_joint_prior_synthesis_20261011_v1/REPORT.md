## 1. Exact operation and what is already known

At each layer, the two affine builders receive `[h_u^m,h_v^m]`. An affine
builder has the effective member matrix

`a_m(z) = diag(s_m) W diag(r_m) z + b`.

This is the ordinary BatchEnsemble matrix parameterization applied to a
conditional generator. It is not a newly inferred member latent variable or a
new training objective. The bounded outputs produce

`F_src = I + tanh(a_src)/2`, `F_tgt = I + tanh(a_tgt)/2`,
`T_(v<-u)^m = F_tgt^T F_src`.

The same 4-by-4 T acts on the four-by-32 view of a 128-channel source VALUE.
Equivalently, the full channel map is `T ⊗ I_32`; after a fixed channel
permutation, it applies the same small matrix to 32 four-channel chunks.
Small matrix actions and tying a graph hypernetwork across chunks are already
in GNN-FiLM's §2.1 discussion. Generic edge-conditioned VALUE matrices are
already ECC/NNConv, and paired learned endpoint maps are already NSD/DNSD.
The precise native SAGE placement, bounded paired parameterization and factor
ownership form the declared composition, without establishing a new primitive.

E4 keeps the factual support, self VALUE, native root map, scalar mean, native
normalization/FFN/dropout/head, complete own CE, and probability mean. These
choices make the adaptation and its comparison interpretable. They do not
transfer sheaf-Laplacian guarantees, curvature, uncertainty guarantees, or
generalization theory to E4.

### Why the receiver control is revealing

In N4, `T_v^m` depends only on the receiver state and its SiLU transform and is
constant over that receiver's nonself incoming edges. For incoming record count
`d_v > 0` and self-record multiplicity `q_v`, its neighbor mean is exactly

`T_v^m * (sum_(u != v) h_u^m / d_v) + q_v * h_v^m / d_v`.

Thus N4's matrix action can be placed on the nonself aggregate, with the native
self contribution kept separately. This is ordinary receiver-conditioned graph
aggregate capacity. The identity uses linear matrix action and the retained
scalar mean; it is not an equivalence to all of GNN-FiLM Eq.8, which applies an
edgewise nonlinearity before summation. E4's source-dependent T generally cannot
be pulled out this way. A positive E4−N4 contrast supports the declared endpoint
construction, while leaving the need for builder-private parameters unresolved.
