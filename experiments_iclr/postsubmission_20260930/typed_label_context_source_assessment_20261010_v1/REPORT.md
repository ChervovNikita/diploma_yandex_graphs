### 3. Restrict TRAIN diagnostics to excluded-target contexts

Paired TRAIN loss uses the opposite half and excludes the query's labels; no VALID/TEST target enters context. However generic V1 serving accepts arbitrary IDs and evaluates both contexts. One context then contains a TRAIN query's own labels. Diagonal removal does not fix the global control: `context.py:143` averages the field over all movies, so a query's label can diffuse to other rows and return through that mean. This is a TRAIN diagnostic/training mismatch, not observed VALID/TEST leakage.

Restrict two-context serving to non-TRAIN IDs; score TRAIN only through each row's complement context, including its global summary, or construct a genuinely query-excluded summary.
