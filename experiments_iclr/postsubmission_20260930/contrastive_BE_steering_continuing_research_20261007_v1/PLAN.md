## Evidence and first decision

Closed Wiki24 selected development evidence supports an alignment/competence
signal, not a useful-diversity result. Unit plus the contrastive package gains
0.5056 percentage points in three seeds, mainly from stronger members. Its
pool-minus-member benefit is only 0.051 points and it trails independent4 by
0.4108 points. Rademacher first factors add coverage but lose about 1.20 points
of member accuracy. Large hidden separation is therefore not our objective.

Wiki12 will identify alignment, residual repulsion and their interaction using
the unchanged twelve fits. No partial comparative outcomes are accessed here.

The first new hypothesis is **graph-context-conditioned positive alignment**:
retain own supervision for every route and object, but align each route with
same-class examples selected using a different fixed graph-evidence context.
Unlike the current all-same-class positive relation, this may retain useful
within-class structural modes. Unlike raw member repulsion, it supplies a
label-compatible target for what different routes should represent. The idea
requires direct prior comparison and a simpler shared-context control.

This is a conditional hypothesis, not an established gap or method. Context
choices must not be selected from development outcomes. Multiple routes with
different positives can still learn identical predictions; greater coverage
can still weaken competence. Whole-population net quality is decisive.

## Deliberately conditional ideas

- Small near-unit asymmetric initialization is a component ablation, not the
  central contribution or a novelty claim.
- A learnable nonnegative diversity coefficient cannot be minimized jointly
  without a constraint: it can vanish and evade the objective.
- A constrained auxiliary update must protect an actual task functional and
  name the protected block/population; first-order TRAIN protection is not a
  validation guarantee. Existing GEM/PCGrad and saved class-private guard
  hypotheses must be credited and not duplicated.
- Reinforcement learning requires a sequential decision and useful reward not
  supplied more directly by differentiable supervision. No such need is
  demonstrated yet.
- Improved serving remains conditional. An unchanged convex probability pool
  cannot repair an object with one common wrong class above truth in every
  member, so first improve member class rankings.
