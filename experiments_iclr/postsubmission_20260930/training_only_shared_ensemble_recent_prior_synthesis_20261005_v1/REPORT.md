## 1. ABMLL: efficient global/local factors, with resets and test adaptation

The current primary title is [Meta-Learning at Scale for Large Language Models via Low-Rank Amortized Bayesian Meta-Learning](https://arxiv.org/html/2508.14285v3), Liyi Zhang, Jake Snell and Thomas L. Griffiths. The first version is19August2025; the inspected latest version is1April2026. Version1 used a different title and mean/variance formulation; I do not assume version equivalence.

**Method scope:** v3 §3.1, §3.3 Eq1, §4 Eq2/global-local definitions, AppendixA.1 Algorithm1, and AppendixA.3's optimizer paragraph. These specify pretrained weights plus global and task-local low-rank mean/log-variance factors and an expected-likelihood/KL objective. The four factor pairs represent global/local mean/variance roles; they are not four ensemble members.

Algorithm1 makes local gradient updates in task parameters, then a global update. After each task it assigns the local adapter factors from the global factors. Its test section copies weights for an unseen task, performs local likelihood adaptation, evaluates the remaining data, deletes the copy and reloads the original weights. AppendixA.3 names AdamW and five inner steps. This is efficient meta-learning with explicit private/local parameter ancestry, but it differs from the candidate's carried rows and served commitments.

The selected algorithm does not explicitly define the full differentiation path through AdamW, old-moment detach semantics, optimizer-history carry/reset, or candidate-style recomputation after the shared commit. Its outer objective depends on the prior/posterior, but that alone is insufficient to certify exact differentiation through the optimizer response. No author code was read. Task datasets use `D_i` notation in inner/outer objectives; they are language-model tasks rather than endpoint-excluded graph queries. No fixed four-member mean-logit serving is prescribed.

## 2. METDG: shared graph encoder and generated predictors

[Meta-Learning Task Relations for Ensemble-Based Temporal Domain Generalization in Sensor Data Forecasting](https://pmc.ncbi.nlm.nih.gov/articles/PMC12298271/) was published16July2025, DOI10.3390/s25144434. I inspected publisher article version `PMC12298271.1` through EuropePMC JATS XML: complete §3, including Algorithms1–2, plus §5.3 implementation details only.

METDG partitions historical time series into chronological domains and support/query sets. A shared diffusion-convolutional GRU encoder uses sensor adjacency; Gaussian domain representations pass through cross-domain attention and a decoder that generates domain-specific two-layer MLP parameters. Query MSE and a variational objective train this system by backpropagation. §5.3 names Adam. Algorithm1 does not unfold a private optimizer response or specify persistent per-domain Adam histories.

The primary methods narrow the abstract's ensemble/no-additional-tuning wording. After training, stored domain representations are reused. Algorithm2 takes an unseen domain's support set, generates its latent representation, attends to the stored representations, generates one predictor and evaluates its query set. No gradient update is listed at testing. This is support-conditioned parameter generation; it is not a prescribed mean of four stored output predictors. The exact support-target contents and author implementation remain uninspected.

METDG therefore supplies recent ancestry for a shared graph-capable encoder, task-specific predictors and testing without gradient tuning. Its fast map is amortized generation rather than private learning; its persistence is in stored domain representations; and its graph is sensor adjacency for forecasting. It establishes neither link-query endpoint exclusion nor the candidate's private-state/commit/serving operator. Its theory and published performance are not transferred to this hypothesis.

## One falsifiable interpretation that fixed30/39 cannot identify

If the alignment of carried private Adam history with each row is an essential source of predictive benefit, then **after nontrivial distinct private histories**, keeping current weights, queries/supports, masks and learning rates fixed while cyclically permuting complete old `m/v/step` histories among equally shaped rows should worsen prospectively evaluated aggregate query prediction relative to aligned histories. A changed response alone would establish a mechanical dependence, not predictive value.

The existing fixed30/39 study has no optimizer-history alignment intervention. Live/detached conditions carry the same type of state, so their contrast identifies current-response credit under that recipe rather than a benefit of history alignment separate from weights and current gradients. Matched-random controls address episode eligibility; capable/untied controls and descriptive F4–F1 companion contrasts limit sharing/member-count attribution. None resolves the optimizer-memory interpretation above.

This is one conceptual falsifier for interpreting a possible scientific claim, not a new arm, grid, run, accuracy threshold or retrospective acceptance gate. The unchanged original30 promotion/attribution policy and complete39 descriptive-only analysis remain intact. A favorable fixed-study result could support the tested graph recipe while leaving this stronger stateful-memory explanation unresolved.
