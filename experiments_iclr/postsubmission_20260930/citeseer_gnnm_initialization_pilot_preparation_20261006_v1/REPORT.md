## Conditions and fixed contrasts

Five same-architecture/loss/budget/selector shared F4 conditions are: original all-layer Rademacher fast factors; stronger TabM-like firstR standardnormal/otherfactors1; neutral warm r=s1; balanced graph-variation covariance firstR perturbations around1; and matched feature-covariance perturbations around1. Only the first xlin inputR is perturbed in the latter three randomized-firstR conditions. The two covariance conditions use identical white directions, four contrasts(+z1,-z1,+z2,-z2), the same parameter slot and one fixedRMS1.

Graph covariance is the TRAIN edge hidden difference second moment; feature covariance is centered node hidden covariance. Both use the same warm graph-derived representation, so the contrast tests additional TRAIN edge-pair covariance information. It does not compare a wholly graph-free backbone. Covariance directions remain fixed after initialization.

The fixed unitRMS is a heuristic motivated by TabM's recommended firstR N(0,1) scale; shifting around a trained identity is an experimental choice and has no finite competence guarantee. TabM p6/p14 and pinned author code establish first-adapter randomization/oneslater. Neutral BatchEnsemble warm lifts, copied competent-model ensembles and antithetic contrasts are prior principles (BE/Plex/StarSSE and standard antithetic sampling); this experiment makes no novelty claim.

## Warm lift and competence controls

Dense maps, encoder, private native LayerNorm affine constants/eps, bias and beta are copied exactly. The rank-one affine map uses fused native bias arithmetic `linear(x*r,W,b)*s+b*(1-s)`, algebraically the same `linear(x*r,W)*s+b`; at r=s1 it follows the native deterministic path exactly. Every initializer uses the same kernel. Neutral/native controls are checked against full TRAIN native logits before fit; nonzero perturbations are never labelled function- or competence-preserving. Balanced contrasts give only a local first-order cancellation at a common differentiable point before FP32 rounding, not finite nonlinear preservation.

A competent native single and four fully independent native warm copies are included. Each independent copy has its own optimizer/dropout/negative/episode seed(seed+5member), concatenates allfour inner streams like the single, and pays60 full cycles. The shared F4 gives each member its own route list. Consequently independent and shared training exposure/compute are explicitly different; all costs are charged. The independent ensemble uses the same12 pooled VALID selection opportunities. Old random-start J4 scores are descriptive references only.
