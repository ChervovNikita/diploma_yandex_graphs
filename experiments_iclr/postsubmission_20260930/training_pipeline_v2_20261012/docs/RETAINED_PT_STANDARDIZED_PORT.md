# Retained supervised P/T v2: disabled new-role port

This port binds the retained P/T prototype v2 to complete WikiCS20 and
AmazonPhoto10 provider roles. It prepares a finite, disabled development
study. It does not reproduce an archived training recipe, establish novelty,
or provide accuracy evidence. Scientific fits require resource qualification,
master adoption, the user's review, and explicit GO.

## Preserved equations and history controls

The graph is the provider's complete binary coalesced `A[dst,src]`, with
exactly one self entry and exact positive row degrees. No weights, loops,
support unions, input normalizations, or degree clamps are added. Raw X is
unchanged. A selected ordinary native P1 ancestor supplies the undropped,
frozen `H0 = ReLU(clip(P(XU0)+XV0+b0))` and its native head initialization.

Each of two blocks retains all PP/PT/TP/TT operations, ReLU and clipped
intermediates, and context `[H, |PH-H|, |P²H-H|]`. Role maps PT/TP/TT1/TT2
are distinct and tied across routes. Final gate maps and Wo start zero.
Only e[2,4,4] provides the source private history coordinates. The residual
is `clip(H0 + .25 H2 Wo)`; there is no extra intermediate activation/dropout.
The same dropped tail D feeds both head aggregate and skip maps. Each actual
P/T body has four TRAIN tail draws and mean own CE plus the constant frozen
first-layer `.05` penalty. Serving pools member probabilities.

The roster retains head-only, mixed single, private4, middle-state mean,
bias-coordinate single, and genuine mixed/bias I4. I4 has four separate
source fits, continuation fits, optimizers, SELECT states, and RNG streams;
M1 is fixed body0, reused for the I4 bank. Bias-coordinate single uses the
mean of the same 32 coordinates in each single-state gate. It starts
function equivalent to mixed single and isolates optimizer redundancy.
Middle-state mean averages/broadcasts differentiable states after block1;
it changes both forward histories and backward coupling. PT/TP use distinct
maps, so this design does not isolate mathematical noncommutation.

Initial zero Wo blocks upstream gradients while the head and Wo can move.
Zero G2 can delay G1 gradients further. QA must not demand every parameter
group receive nonzero gradients by update2.

## Explicit new matched controls

Continued ordinary P1 and factorized F1 load their own selected 5000-update
source weights and continue all native parameters for another 5000 updates
with a fresh AdamW. Four stochastic own TRAIN views per body are an explicit
new adaptation; eval remains one native prediction. Their own M1/I4 banks
reuse fixed body0. These controls match the 5000+5000 optimizer-update budget.
Label uses and forward costs are reported separately: mixed-single and
multi-prediction arms reduce their supervised losses differently. Source and
continuation costs are retained separately. Source dropout HPO does not silently become continuation dropout:
the continuation rebuilds its native topology with its selected new dropout
binding, then loads source weights.

Separable4 is a new capacity control: one paid selected ordinary body0 stem
and one shared frozen H0, with four disjoint mixed continuation/head bodies
and one joint mean-own-loss optimizer. The frozen first layer is actually
shared. Each continuation body has four TRAIN draws, giving sixteen total;
eval has four predictions. It is not an exact prototype arm, an independent
teacher ensemble, or a parameter/compute matching claim. Its greater private
map/head capacity and additional forward cost are declared.

Original GNNM is freshly paired on both new providers using the actual
TABMModel SAGE width128, depth2, LayerNorm/GELU/residual, source BEBlock
routes and mean raw logits. Native meanSAGE and P/T width32 are source-fixed.
Original GNNM is a stronger-capacity width128 comparator, while the native
meanSAGE/P/T procedures retain width32. It is not a width-matched attribution
control. Fresh original GNNM pays5000 updates; P/T and continued-native pay
5000 source plus5000 continuation updates. Only the continued-native controls
match that optimizer opportunity. FLOPs, route counts, memory and wall time
are not equal; separable4 has16 TRAIN draws versus4 for other continuations.
The runtime reports source Model/TABM calls, native layer calls, P/T banks,
retained T maps, graph propagations and tail dropout draws separately.

## Paid ancestry and phase closure

Factories receive explicit `execution_context` with registry/output root
and optional root-verified paid checkpoint entries. A continuation declares
`lifecycle` schema `paid-parent-continuation-v1`, exactly its direct paid
source `parent_fit_ids`, `new_optimizer=true`, and
`parameter_initialization=selected_parent_no_optimizer_reuse`.

The adapter requires complete matching source registry contracts, full
source horizon, own positive selected step, authenticated selected checkpoint
path/size/SHA256, matching source pins and role custody, and matching
split/seed/body. It restores the actual selected state, computes H0 at that
time, and retains its actual hash. Nonpersistent graph/cache version guards
and checkpoint custody reject mutation or changed ancestry. No H0 or source
state receipt is fabricated during preparation. Source optimizer state is
restoration evidence; the continuation creates a new empty optimizer.

The search DAG is source9×2 → source selector → selected-source anchors →
continuation9×2 → own continuation selectors. These direct dependencies
close before the whole-search barrier allows comparative training.
Comparative continuations depend on their paid comparative sources and
their own search selector. Whole comparative closes before bank exports;
CAL uses one scalar after the serving pool, with 500 float64 Adam updates
at LR `.01`; whole CAL closes before heldout scoring. Fit adapters can open
only GRAPH/TRAIN/SELECT. Exports open label-free CAL/evaluation IDs;
separate declared endpoints own CAL and evaluation targets.
