# GNNM large-study preparation

Status: **preparation in progress; no approved run manifest and no benchmark launch**.

This package replaces fragmented training loops with explicit data, source, budget and selection contracts. Original GNNM's five original datasets are excluded. Its unchanged model family is retained as a required reference on new compatible node datasets. Original reported scores remain unchanged.

## Available components

- Full-budget trajectories and complete TRAIN/SELECT curves; virtual shorter-budget endpoints do not terminate the main trajectory.
- Independent process/fit registry, actual optimizer counts, sample-weighted epoch means and retained failures/costs.
- Exact selected-state restore and interrupted-fit continuation from the latest trajectory state.
- Original node scaffold with eight operators, original boundary GNNM, internal-factor ports, coupled untied controls and scalar representation-loss connections.
- Pinned PolyFormer mono model/preprocessing/Adam groups and molecular GINE connections. Source attribution stays distinct from an author-protocol replication.
- Two slots per GPU, fixed assignments across three GPUs, memory-aware admission, and distributed phase closure before later training/scoring.
- One detached startup command per host after approval; frozen runtime packages prevent subsequent source edits from changing an admitted run.

Allocation CPU snapshot `qa/cpu_multitask_source_v7` passes66 engineering checks with no skips. Later molecular endpoint extension passes32 targeted checks in `qa/cpu_molecular_endpoints_v8`. Fixtures establish software behavior, not predictive quality or convergence. The pipeline does not claim universal compatibility.

## Data prepared on the allocation

Cora, CiteSeer and PubMed use their public split with the validation population divided prospectively into SELECT/CAL. WikiCS keeps20official split masks. Amazon Computers/Photo and Coauthor CS/Physics each have10fixed class-stratified masks. Graph/provider/source and every role file are fingerprinted. Export reads label-free endpoint IDs; only the admitted CAL and evaluation jobs open their respective targets. All eight data packets are development evidence; unused confirmation is not inferred.

Datasets and checkpoint artifacts remain on the server. Local files contain source, compact receipts, method conclusions and decisions.
