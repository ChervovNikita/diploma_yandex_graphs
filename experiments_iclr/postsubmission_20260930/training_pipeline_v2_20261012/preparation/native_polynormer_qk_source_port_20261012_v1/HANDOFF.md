## Exact initializer and transition

The adapter reuses original source Ensemble/native constructors and source
FactorLinear. It extracts original `_attach`, `_global_forward` and
`_streamed_f_step` mathematically unchanged except two complete-TRAIN counts
and declared Adam LR. It does not call the old route-bound `make_session`/
`install` or edit old source/runtime guards. Generic current-study GO governs
new scientific fits.

It retains two full own-CE views, view-then-member streamed backward at one old
parameter state. Genuine I4 uses separate one-body fits with source-derived
base+1009*body native/dropout identity. Shared BE uses the source first-stem
Rademacher seed+900001, later unit factors and one active Adam. An original
BEBlock subclass places source Xavier W/R/S/B at native input and both native
prediction heads; it does not install internal factors and serves mean logits.

live end-local global/private RNG, then set native `_global=True`. External
capture/restore carries streams, NumPy, steps/failure/operator-work counters,
local best model/Adam snapshot, branch flags and every factor/boundary/wrapper
member selector. Generic selected checkpoints include the actual local/global
branch. Full-budget5000 extends historical1100 explicitly, with no early stop.
