# Concrete callable interface

The root obtains already-loaded `rt, engine` from the sealed native seam. This packet never invokes its public runner, loads a dataset or imports a provider. The public native driver remains unchanged and installs no bank.

1. Native `prepare_static` / `prepare_seed` construct the full contexts. The literal source-view constructor separately rebuilds all25+12 channels after deleting both raw directions for each real family, with all node populations retained. Supply those actual `NativeFamilyView` objects, whose role/target tensors are the same objects as the full SeedContext.
2. Native `engine.make_model(rt, full_ctx, costs)` provides the exact ordinary initialized/placed prototype. Root separately controls the ordered seed loop and its single master GradScaler.
3. `BankSession(rt, engine, adapter, helper, full_ctx, views, prototype, scalar, costs, config=BankConfig())` installs M4 and constructs the deduplicated Adam. The default configuration rejects use. Enablement requires the exact bank seal, native qualification/full-view/role SHA bindings, source review admission, four explicit distinct member RNG seeds, and a fixed bijection of director/actor/keyword/None to the four members. No hidden RNG seed policy is supplied.
4. `session.train_epoch()` consumes the original generator=None native train loader once, verifies the complete TRAIN batch, streams four BCE/4 backward calls, takes one native AMP Adam step if GradScaler permits, and returns native own losses plus private own displacement blocks. Skipped scaler steps are counted as skips through the actual Adam-step counter, and yield zero displacement. Native member BatchNorm state advances only here.
5. `session.correct(own_displacements)` is available only when the frozen config explicitly enables source corrections. It performs all20 old-state complete-TRAIN reference paths (four TRAIN factual, twelve TRAIN family probes, four eval factual); constructs the unchanged helper's Bernoulli credit plan; streams all11 required differentiable replays; constructs the guarded private direction; tries the helper's fixed `(1,.5,.25,.125)` scales until acceptance. It reports zero/rejected/accepted status, L2 dose, slope, guard values/violations, precision and complete row binding. It neither receives nor changes optimizer moments in the helper; caller integration verifies the own optimizer and scaler exactly preserved.
6. `session.native_forward(member, source_or_None, mode, replay_token)` is the actual unchanged-helper callback. `None` resolves to full SeedContext; a family resolves to its real reconstructed context. Source plan tokens use only complete TRAIN IDs. Known-role serving tokens concatenate complete TRAIN IDs followed by complete VALID IDs and permit factual eval only. No unassigned row prediction/target or TEST interface exists here.
7. `session.evaluate()` serves each native member with all full inputs in FP32 and returns complete TRAIN/VALID marginal BCE, each member BCE, pooled F1 and owned output tensors. No source-supply mixture is served. `session.snapshot(...)` captures all bank parameters/buffers, deduplicated Adam, scaler, member/master RNG and policy/role/view identity. `session.restore_selected(...)` preflights duplicated slow aliases and verifies exact restoration and ownership.
8. `fit_bank(session, identity)` runs the actual native epoch/selection/patience loop. The source policy is fixed for the fit, with at most one correction construction per own epoch; there is no objective retuning after outcomes. The function returns scientific state/history for the root's already authorized caller; it adds no file writer, launcher, supervisor, role splitter or scheduler.
9. `reconstruct_selected(...)` constructs a fresh native model, adapter, Adam and **separate** fresh GradScaler, restores selected state and serves all-full known roles. It returns output drift diagnostics without an exact-output/tiny-tolerance gate. The caller's active master scaler is not passed and global streams are restored.

Do not place/retype/reset the installed bank. Reconstruct instead. Native factor names and six placements are those in the sealed adapter; the native model and helper source bytes remain unchanged.
