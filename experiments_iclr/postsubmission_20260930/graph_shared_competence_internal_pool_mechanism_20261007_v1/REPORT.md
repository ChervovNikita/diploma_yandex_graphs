## Recommendation

**Rank 1: test the complete own-core / internal-GNCL / own-boundary allocation as a graph ensemble method.** Its plausible mechanism is competence-supported specialization of internal graph computations, rather than rewarding hidden disagreement. On probability-pooled WikiCS, the mixture gives a path more supervised credit on nodes where it already contributes more correct-class probability. Shared weights and input/classifier factors retain equal mean-own supervision. A positive, matched comparison can establish a useful distinct operational method built from attributed components; component ancestry is not a reason to dismiss that possibility.

**Conditional fallback: add one degree-sensitive cardinality channel at the first normalized local aggregation, with shared versus member-specific coefficients.** This adds an observation that the current normalized attention can provably miss in a restricted witness. It is an adaptation of PNA degree scalers. Do not promote a constant root/neighborhood gate: much of that proposal can be absorbed by existing fast factors, leaving mainly optimizer bias or special bias/attention-coupling differences.

Both rankings are prospective. Historical errors motivate the question but do not establish its cause or predict success.

## 1. What the completed errors actually justify

The root-identified summaries support a **competent-but-common-error** problem, not universal weakness of shared members. Ordinary sharedjoint had better aggregate MRR than jointly trained native four in the supplied completed comparison, yet more common negative slots and lower Hits10. Live transfer reduced overlap while weakening members and expanding the union of errors. Graph-conditioned initialization could improve mean member MRR while losing all three final-pool comparisons to particular copied controls. A copied warm bank is not four independently acquired native donors.

Thus neither “make members stronger” nor “make members disagree” is sufficient. Useful complementarity means retaining enough correct evidence to improve the declared pool, with net repair after counting newly introduced errors. A selected common-error cohort alone can make a failing method look useful. These are development findings on already exposed selected states, often at different cycles and with different architectures; they do not identify tying, information erasure or a historical gradient as the cause.

## 2. Exact current method and derivable mechanism

The adapter manifest is `217a093438eac20f68b80fc2d543bfa8cf7ffd15926044fef8d08ad9f4436baa`; the full wrapper manifest is `aa55302f80629971819469e29b6b8c39636825ea2e01ca6c18f019a85de88b0a`. These exact bytes were checked. The source audits each parameter role and preserves the native shared four-member architecture, two stochastic views, actual task pool/reductions, original optimizer groups and one simultaneous Adam transition.

Let θ be shared weights, ψ private input/score boundaries, φ existing internal factors, and A the unchanged alignment auxiliary. The source supplies

```
L_own = mean_m L_m
J_λ = (1−λ)L_own + λ L_pool
V = (∂_θ L_own, ∂_ψ L_own, ∂_φ[J_λ + .05 A]).
```

The displayed alignment coefficient is the existing source value, not a new proposal. Both gradient collections use the old state; the φ pullback traverses real shared operations without upstream detachment. No numeric λ is adopted by this report or the saved interface. Use one separately frozen value and no grid. At λ=1, internal factors lose the mixture's individual-risk floor; boundary own risk does not restore that missing φ term.

For a WikiCS node v, set `q_m=p_m(y|v)` and `r_m=q_m/Σ_j q_j`. The exact supervised internal logit cotangent is

```
[(1−λ)/M + λ r_m] [p_m−onehot(y)].
```

Shared and boundary parameters instead receive their mean-own cotangents with coefficient 1/M. This is ordinary mixture-loss responsibility, not a new equation or router. For λ<1 the coefficient has a positive floor `(1−λ)/M`; it does not bound a parameter-gradient norm or guarantee an improved member. Private Jacobians can differ substantially, and shared/head updates can change the same member's predictions.

**Mechanism hypothesis:** the own-trained shared feature basis and boundaries continue fitting every member's supervised task, while internal factors adapt with node-dependent ensemble credit. Because φ includes local GAT feature projections and global key/value/nonlinear transformations, that credit can change which graph evidence a path uses before its classifier. An already useful path can reinforce one local evidence regime while the own component still trains weaker paths. Existing member initialization and stochastic streams supply possible asymmetry; identical paths need not diversify spontaneously. Own-gradient assignment is an objective permission, not functional preservation or a competence theorem.

For Collab/MolHIV raw-logit pooling, the cotangent is instead

`[(1−λ)(sigmoid(z_m)−y)+λ(sigmoid(mean_j z_j)−y)]/M`,

with the source's positive/negative or batch reductions. It is **not** the probability-pool responsibility mechanism: every path sees the same pool residual. The broader method question there is whether different internal Jacobians respond usefully under protected own-core/boundary updates. Do not claim node-dependent winning-member credit for those tasks or ranking gains from BCE alone.

### Null and limited-success interpretations

- **I does not beat O in served quality:** useful internal credit allocation is unsupported on this representative task. Better member means, lower TRAIN risk or more disagreement do not rescue it.
- **I matches P:** boundary protection is unnecessary within the tested recipe; a simpler all-private adaptation may suffice.
- **I matches G:** the internal restriction adds no demonstrated benefit beyond ordinary GNCL applied to the shared architecture.
- **I wins policy comparisons but graph responses are unchanged:** support a useful training allocation for a GNN, without claiming altered neighborhood evidence as the mechanism.
- **Graph responses differ but the pool loses, or common repairs are canceled elsewhere:** specialization is not useful complementarity.
- **Only NLL improves:** investigate calibration as the narrower result; do not claim common-error/accuracy repair.
- **A capable untied bank remains stronger:** report the actual quality/cost tradeoff; do not silently replace the practical claim with member-strength or disagreement claims.

One graph/split and multiple optimizer seeds establish conditional development utility, not graph-population significance. Confirmation and broader task coverage remain separate from this synthesis.

## 5. Smallest stronger fallback: one cardinality-sensitive message channel

### Why the constant gate is low priority

Current FactorLinear is `diag(s_m) W diag(r_m)x + b_shared`. Global amplitude changes on a bias-free fixed linear message map can be absorbed into its output factors. Scaling a biased root branch also scales its shared bias, which the source factors do not do; scaling local GAT values after attention can decouple value amplitude from score temperature because attention vectors are shared. Those are real qualifications to exact equivalence. They do not establish that a new constant gate supplies missing graph evidence. GPR-GNN/MixHop/H2GCN and graph filters also precede root/hop mixing. The constant gate remains low priority as a parameterization/optimization variant.

### A capacity distinction the factors cannot generally absorb

The pinned Wiki native source `9b4e533f46ae7f91a23a552f88bbb47a01359e224b53996cf1a68c10a865f6a8` uses `GATConv(...add_self_loops=False,bias=False)` and then

`N_m(v) + R_m(v) = local_conv_m(x,A)_v + lins_m(x_v)`.

Under the standard normalized GAT operation, with dropout off, no edge features, identical node input features and nonempty neighborhoods, every neighbor value/score is identical within a member. Attention weights sum to one, so `N_m(v)=c_m` regardless of degree. Root maps, shared biases, normalization and global normalized attention are also node-identical. Global r/s factors cannot create a degree observation. Repeating these operations does not remove that invariance. This is a restricted representational witness, not a claim about actual WikiCS features or stochastic TRAIN views.

At the **first local aggregation only**, retain N and add one residual cardinality channel:

```
S_v = log(1+d_v) / mean_{u∈TRAIN} log(1+d_u)
N'_m(v) = N_m(v) + a_m S_v N_m(v)
a_m = a_shared + u_m − mean_j u_j
```

Count d from the actual effective incoming message multiset, preserving the source's loops/duplicates/coalescing convention. The TRAIN normalizer must be positive; no graph/data was inspected here. Initialize all new coefficients to zero, recovering the current forward exactly. There is one shared scalar and four centered private slots (three functional member contrasts), not a new hidden network, teacher, router, depth or graph propagation. Keep all current losses/λ; shared `a_shared` receives own risk and private centered coefficients receive the existing internal objective with the complete cross-member pullback. These are model parameters, not a learned loss-strength coefficient.

For two identical-feature nonempty neighborhoods of unequal degree and `c_m≠0`, `N'_m=c_m(1+a_m S_v)` differs when `a_m≠0`. The restricted invariance is broken by an explicit graph observation. Later layers can suppress that signal, and degree may be irrelevant or confounded on the real task; neither learning nor usefulness follows. Existing r/s parameters are constant across nodes, so they cannot generally absorb this node-dependent multiplier under the witness. The exact survival witness uses neighbor N=e1, root R=e2, h=0 and β=1/2: the native local update returns `[t(d)e1+e2]/2`. Later local layers can carry it unchanged. With D≥3, the pre-global LayerNorm preserves `(u1−u3)/(u2−u3)=t(d)`. Admissible global h/residual and affine-normalization parameters carry this distinction to the final class margin. Pure collinear positive amplitude can be erased; the witness deliberately avoids that case. See [the full parameter witness](</Users/alex/Documents/ChatGPT/anogena allocation/postsubmission_research_20260930/graph_shared_competence_internal_pool_mechanism_20261007_v1/CARDINALITY_WITNESS.md>). This proves possible separation, not that every coefficient changes logits or that training learns it.

**Direct prior:** Corso, Cavalleri, Beaini, Liò and Veličković, [Principal Neighbourhood Aggregation for Graph Nets, `2004.05718v1`](https://arxiv.org/abs/2004.05718v1), §§2.2–2.3, Eqs.6–9. PNA explicitly addresses cardinality loss and uses log-degree amplification/attenuation with multiple aggregators. The fallback uses one zero-start residual degree-scaled **attention** channel in a live shared ensemble, not full PNA's twelve-operator concatenation. Its observation and scaler are prior; the conditional method contribution would be useful member-specific utilization under the current allocation. No PNA theorem or performance guarantee is imported.
