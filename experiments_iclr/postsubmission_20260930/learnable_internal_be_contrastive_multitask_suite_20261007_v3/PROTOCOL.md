Prepared 7 October 2026 before opening candidate/heldout outcomes. This is a source preparation protocol; all execution jobs are disabled. Original manuscript scores and every existing active queue remain separate. No independent teacher bank is acquired for a student. Every scientific cell starts from its own fresh constructor.

The question is whether learned multiplicative factors inside one jointly trained graph backbone, combined with a fixed label-aware contrastive adaptation, improve served predictions while preserving member competence. The primary paired contrast is **be_init_contrastive minus be_init**. Secondary mechanistic contrasts are be_init minus be_unit and be_unit_contrastive minus be_unit. Negative or null primary effects close this particular loss/recipe; hidden separation does not rescue it. No novelty, accuracy, broad graph dominance, or acceptance claim follows from implementation.

## Exact intervention and controls

For a dense map each member computes `(W (x * r_m)) * s_m + b`. W/b and all other common attention, normalization, embedding and virtual-node parameters are trainable. r/s are trainable private vectors, installed in every materialized dense map (including PyG GAT/GCN projections). Molecular pre-message factors are also private trainable vectors. A member executes a complete nonlinear graph path; internal BE does not compute one shared embedding once. No frozen donor or teacher is needed.

Eight predeclared arms, one fixed recipe each: single, single_contrastive, independent4, independent4_contrastive, be_unit, be_init, be_unit_contrastive, be_init_contrastive. The single and untied contrastive controls identify improvements available to ordinary models. The independent4 arm owns four complete parameter sets and optimizers; own losses retain unscaled gradients. It shares the declared object order for aligned comparisons but has persistent member-specific dropout RNG. The independent4_contrastive arm is intentionally jointly regularized through its contrastive terms; call it a packed untied comparator, not independently learned predictors.

All BE factors start at1 except be_init's first input r entries, initialized to independent Rademacher signs by dedicated CPU generator seed `base+900001`. Native matrices use the same base seed across BE arms. Every arm receives exactly two own-supervision stochastic forwards per update, so contrastive arms gain no additional label opportunity. Every member trains on every TRAIN target. No specialist labels, pooled-loss substitute, train-label masking, architecture search, dropout search, or outcome-selected factor distribution is used.

Each plain independent member retains its own local-stage best checkpoint/Adam state for the WikiCS transition and its own best overall checkpoint for final serving. Shared BE uses its pooled local best state. Live end-local RNG is preserved at the transition. Checkpoint selection spans local/global modes and first exact ties. The ordinary independent4 comparator always serves the bank assembled from its four individually selected checkpoints; synchronized pooled values never choose its checkpoints or a different final bank. Each body's serving mode is recorded; the assembled bank is evaluation-only while its four individual checkpoints retain their optimizer histories. Single/independent source trajectories here use two-view CE and are new controls, not aliases of existing native one-view reported numbers. The jointly regularized independent4_contrastive comparator has a pooled selector and is explicitly called packed untied.

## Contrastive pair semantics and failure interpretation

Two views use the **same original graph/features** and independent native model dropout, including NCN's native encoder-edge dropout. The latter drops encoder entries only; its structural common-neighbor decoder uses the same already target-masked support. These are stochastic computation views, not assertions that arbitrary removed chemical bonds or link positives preserve labels. Molecules receive no edge deletion, atom masking, bond masking or categorical corruption. There is no universal graph-view invariance claim.

The optional loss is `.05 * alignment + .05 * residual_member_contrast`, temperature.2, at most512 deterministic aligned objects per update (full objects still receive CE). WikiCS/molecule alignment uses same-member same-TRAIN-label objects in the opposite stochastic view as positives; opposite labels are negatives. This is a coarse supervised objective, not proof same-label chemistry is equivalent. Collab canonicalizes each undirected TRAIN target pair: all repeated/reversed records of that same target are positives across views, and distinct targets are instance negatives, avoiding a claim that every binary nonedge is semantically equivalent.

Residual member contrast centers each view/member representation using only the current batch's TRAIN-label class mean. Positive is the same member/object in the other view; negative is another member, same object, other view. Classes with fewer than two batch objects are skipped; M1 term is identically zero. This pairing is **CDLG-inspired**, and centering is only a proxy motivated by DICE's label-compatibility argument. It is not DICE conditional mutual information, a verified CDLG author objective, an independence theorem or a graph-specific novel principle. Centers remain differentiable. There is no auxiliary private projection head that can absorb the whole objective.

The loss may still diversify irrelevant/gauge directions or weaken member predictions. The main metric, member metrics, and task-labelled common errors judge utility. Contrastive embedding distance cannot establish evidence specialization. A fixed training-only diagnostic panel of target-safe graph sensitivity interventions must be prospectively bound before reading prediction identities; no raw heldout logits are opened by this source packet.

## Closest prior and separate later questions

BatchEnsemble (Wen/Tran/Ba) establishes learned private rank-one maps; TabM establishes first-adapter initialization, own-member loss and collective selection. DICE (ICLR2021,2101.05544) establishes protecting labels while penalizing conditional redundancy; the saved graph estimator recipes are prepared comparators, not completed results. CDLG (2306.11344) establishes same-node/channel positives and cross-channel same-node negatives, with retained printed-objective ambiguities. SuGAr (AAAI2025,2410.22228) combines label contrast with diverse predicted graph evidence. HGEN (IJCAI2025,2509.09843) diversifies graph/meta-path representations. DIBS (AAAI2021,2003.04514) has a shared trainable encoder/private diverse latent predictors. ParetoGNN (ICLR2023,2210.02016) combines graph SSL gradient objectives, not served predictor diversity. FoRDE's task-conditioned functional diversity is a competitor; its frozen polynomial-token Gram identity cannot be transplanted to trainable attention without a new derivation. Saved scoped conclusions are reused; no new paper read count or exact duplicate/novelty clearance is claimed.

A learned positive scalar in a jointly minimized nonnegative penalty has a zero-coefficient optimum absent additional constraints. Adaptive strength would need a distinct outer TRAIN-only quality fold/constraint and a matched fixed-strength control. A convex combiner cannot repair a common wrong-sign competitor; it also needs separate fitting labels. RL would need an actual discrete evidence action and meaningful reward/budget that differentiable optimization does not handle. Those are separate later ablations, not switches in this first fixed pilot.
