# Layerwise member diversity diagnostic

This is a post-selection description of Roman Empire GNNM representations. Run `layerwise_member_diversity.py --self-check` for a CPU-only synthetic check. The analysis command is `layerwise_member_diversity.py --model SAGE` or `--model GAT`, optionally with `--splits` and `--device`. It is not part of training or checkpoint selection. It must not be scheduled while another GPU experiment needs the device.

The SAGE command requires the complete 50-row control matrix and the split-0 pilot adoption audit. The GAT command requires the complete 10-row tying pair and passes `verify_gat_failure_pair.py --complete`. Both commands follow the CSV-selected GNNM checkpoint and prediction paths. The output records SHA256 hashes of source, data, selection evidence, selected checkpoints, and saved predictions, and checks those hashes again before writing. Files go only to `experiments_iclr/layerwise_member_diversity_results/`.

For each selected checkpoint, the script disables dropout and gradients and runs its four members sequentially on the same full graph. A fixed uniform sample of 4,096 node IDs, drawn with seed 0 without labels, supplies the reported hidden states. Hooks capture the input state after GELU, the convolution output in each graph layer, and the state after each residual layer. Each state has shape sampled nodes × 512 channels. The analysis reports mean pairwise cosine distance, median node pairwise cosine distance, and norm-normalized pairwise RMS distance over the six member pairs. It records zero-norm pairs. The final forward logits on the official test nodes must agree numerically with the saved selected logits and exactly in member and pooled decisions. Test labels are never used by the diversity metrics or to choose nodes, parameters, or checkpoints.

Nonzero convolution-output distance shows that the tied graph operation returns different member representations. Nonzero post-layer distance alone may be carried by the residual path. The diagnostic cannot identify a performance cause, isolate neighbor messages from self-loop or root terms, prove that GAT attention weights differ, or generalize beyond these selected runs. Compare layer trends within a backbone, since representation scales and geometry differ across backbones. SAGE and GAT selected depths may differ by split.
