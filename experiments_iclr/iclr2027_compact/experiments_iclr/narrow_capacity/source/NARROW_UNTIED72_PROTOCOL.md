# Post hoc parameter-count sensitivity for the four-graph SAGE grid

This extension is chosen after the original and all-layer outcomes were read. It is exploratory, not a holdout or a causal isolation of capacity: narrowing changes the width and the member-specific propagation capacity simultaneously. All four graphs and all 72 planned runs must be retained and reported together, regardless of sign. The complete source, protocol, width scan, and training matrix must be frozen before the first optimizer step. The independent 72-cell validation-only lock must precede any new test score.

## Deterministic width selection before training

For each original split-0 graph (Cora, WikiCS, Actor, official filtered Chameleon), instantiate the original width-128 TIED model and every integer-width UNTIED model from 32 through 128 on CPU using the exact primary `tuning.make_model` and graph bundle with `include_test=False`. Select the width that minimizes the absolute stored parameter-count difference from TIED128; break a tie toward the smaller width. Record the complete 97-width count curve, target count, selected count, and selected width for each graph in `NARROW_UNTIED72_WIDTH_SCAN.json`. Width selection uses parameter counts only; the counting/training bundle excludes test labels, while the original loader reads full arrays solely to check fixed data fingerprints. Use the same selected width for all six learning-rate/weight-decay candidates and three optimization seeds of a graph. This is a parameter-count sensitivity, not an exact count match unless the reported counts coincide.

## Training and selection

The 72 cells use the original graph tensors, train/validation masks, four-member UNTIED propagation architecture, mean member CE, AdamW, two residual SAGE blocks, dropout 0.2, 1,000 epochs, and original `tuning.train_one` function byte-for-byte. Only `tuning.WIDTH` is set to the frozen graph width and `tuning.ROOT` is redirected to this separate result tree during a cell. Candidates are `(0.0003, 0.001, 0.003) × (0, 0.01)`, with seeds 0, 1, 2. Each epoch uses the original whole-model checkpoint rule: highest pooled validation accuracy, then lowest pooled validation CE, then earliest epoch. A candidate with any nonfinite seed is invalid, but all planned cells still run. For each graph, select by highest three-seed mean validation accuracy, then lowest mean CE, then lower learning rate, then lower decay. Also preserve the declared default `(0.001, 0)`.

An independent verifier checks the exact frozen source/data/width scan, all 72 identities, complete 1,000-row traces or explicit failures, checkpoint identities/hashes, selected validation epochs and metrics, and saved validation pooled/member logits and decisions by fresh replay. It writes an immutable validation-only selection lock. Before any test labels are used for scoring, the scorer requires this complete 72-cell lock, the original 432-cell lock, and the 36-cell same-runtime Cora/WikiCS TIED lock. Score only each graph's selected candidate and declared default (three seeds each, once if identical); independently replay all allowed test scores and decisions. Compare against same-runtime TIED128: the separately repeated Cora/WikiCS TIED36 grid and original GPU77 Actor/filtered Chameleon TIED grid. Report both selected and default paired three-seed differences on all four graphs, with stored parameter counts and candidate choices.
