# Roman Empire fixed-mask SAGE optimization-seed diagnostic

This folder contains the retained v4 source files and configuration, the no-score numerical calibration, six result records, complete validation traces, and selected test **class decisions**. It covers three optimization seeds on one official graph mask. The corrected public Roman Empire graph, full float32 logits, selected checkpoints, and full initial logits are retained in separate author evidence and omitted from this upload-small supplement.

The tied four-member model and an initially matched untied-propagation model use the same boundary projectors, SAGE depth 5, width 512, objective, optimizer, and validation checkpoint rule. The paired initial parameter and CPU/CUDA RNG hashes match exactly. CUDA logits differ by finite-precision scatter variation: six repeated full-graph forwards of each initial model showed within-model maximum absolute variation of 1.0967254638671875e-5, so v4 froze a 2× numerical tolerance before training. Initial hard decisions are not claimed to be exactly identical.

Earlier v1 and v2 pretraining gates stopped before training. V3 stopped after three complete arms because an initial CUDA logit difference of 1.049041748046875e-5 crossed its frozen 1e-5 bound. None of those partial scores is included in the v4 result. The v4 protocol and manifest record these revisions. The study remains post hoc on a favorable graph and cannot establish an across-graph effect.

Run `python verify_fixed_mask_v4_compact.py` with NumPy installed to check retained source hashes, calibration, official test IDs and labels, selected class decisions, validation traces, and all paired differences. The saved pooled class decision was derived from averaged original member logits before compaction; the original prediction hash and derived decision hash are linked in `decision_derivation_manifest.json`. Member hard decisions alone cannot reconstruct the pooled decision, so this verifier checks the stored decision and its provenance hash, then recalculates accuracy. It cannot recompute logit pooling, cross-entropy, or checkpoint outputs from this compact package.

The original environment `pyproject.toml` and `uv.lock` have an identifying project name and are omitted for anonymity. The public Roman NPZ and original processed edge array are omitted for upload size; their hashes remain in the source manifest. `official_labels_mask0.npz` retains the labels and test mask needed for independent class-score checking and is tied to the original public NPZ hash in the derivation manifest. The compact verifier explicitly checks this omission list. Full source/data verification and CUDA checkpoint replay passed in the retained author audit archive.

`calibrate_fixed_mask_v4_public.py` is an optional path-adapted helper for measuring same-state CUDA forward variation on a fresh runtime. It uses no labels or scores. It writes a new recheck JSON and does not overwrite the frozen calibration. The exact executed calibration script and its hash are retained in the author evidence; the public helper is not byte-identical to that script because its local path is removed for anonymity.

Exact replay of the frozen training gate also requires the omitted environment and graph files, which are retained in the author audit archive and identified by hashes in the manifest. Once those files and the pinned runtime are restored, run the preflight, CPU smoke, all-seed GPU initial smoke, six-arm trainer, and CUDA completion verifier in that order. The anonymous compact package supports independent score checking from saved class decisions; it does not claim self-contained checkpoint replay or bitwise retraining. The six results must be considered together; a failed arm does not yield a publishable subset.
