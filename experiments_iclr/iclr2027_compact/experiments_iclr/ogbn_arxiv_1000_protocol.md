# ogbn-arxiv fixed 1,000-epoch repeat (author-only protocol)

**Declared 2026-09-25 UTC, before any 1,000-epoch training or score exists.** This is a post hoc budget sensitivity check after the complete 100- and 300-epoch results were known. It is not an independent graph-task replication or a new hyperparameter search. The 300-epoch validation-selected checkpoints fell at epochs 294–300 and all nine validation traces set a new accuracy best after epoch 275, motivating one additional fixed budget. Preserve and report the earlier results regardless of this repeat's outcome.

## Frozen experiment

- Run exactly **nine fresh arms** in order: seeds 0, 1, 2, each with BASE, ENS, GNNM. Use the unchanged official `ogbn-arxiv` temporal split and loader, all-node features, undirected citation graph, two-block residual SAGE, width 128, LayerNorm/GELU, dropout 0.2, four ENS/GNNM members, and AdamW at learning rate 0.001 with zero weight decay. BASE uses ordinary training cross entropy; ENS uses four independent ordinary member gradients; GNNM uses mean member cross entropy through its shared backbone. Pool ENS/GNNM logits arithmetically.
- Train **every arm from epoch 1 for exactly 1,000 full-batch epochs** with `--max-epochs 1000 --min-epochs 1000 --patience 20 --eval-every 1`. The minimum disables early stopping before the fixed cap. Use the unchanged `ogbn_arxiv_pilot.py` and `models.py`; do not continue a 100/300 checkpoint because those files omit optimizer and RNG state. The single new result root is `experiments_iclr/ogbn_arxiv_1000_results/`, initially absent. No substitutions of seed, arm, architecture, learning rate, epoch count, or result root after opening 1,000-epoch scores.
- Select one complete checkpoint per arm by highest **pooled validation accuracy**, then lowest pooled validation cross entropy, then earliest epoch under the runner's existing tolerance. Restore the checkpoint and check validation metrics before scoring the official test labels once. Retain all epoch histories, checkpoints, selected member logits, indices, labels, metadata, and the attempt log. An interrupted root is incomplete; the dormant one-shot launcher does not silently resume it. A restart requires an audited disposition of every artifact and the same frozen protocol, or a wholly new empty root under a newly declared attempt.

The current pinned SHA256 values are `7abf975fcf900f52a01a51652605b2d2519aaee02918948732ee5401952dd89b` for `experiments_iclr/ogbn_arxiv_pilot.py`, `07a6c1c452486802713a1a040ab24f9e9f8504660d731eb5b6417e2357f0f303` for root `models.py`, `3e9b2157db7cc2ee5f16d9259fdca4a4d35daf94cc8de0bd4454092fee384b6d` for the existing artifact verifier, `ee26cd93647d77c964a554960ab4893fdc95e5bd7d73fd9479e0a8c32a1bde97` for the audited 300-epoch run config, and `6ac7f655985f90184d86b27a934b8a4d5e9a0f50e7a846e188ac3a3cf2033c8b` for the official dataset manifest. `ogbn_arxiv_1000_source_lock.json` binds these plus this protocol, the new one-shot launcher, strict verifier, and focused CPU test. ## Acceptance and reporting

The separate `verify_ogbn_arxiv_1000.py` requires exactly nine canonical directories, no extra or partial entries, exactly 1,000 contiguous validated epochs in each, the pinned configuration and official data fingerprints, validation-only checkpoint selection, strict checkpoint load and SHA256, saved logits/indices/labels checked against OGB, selected validation and test metrics independently recomputed from pooled logits, and both summary files reconciled against every arm. It prints no result report until the complete tree passes. Its `--preflight` checks only the frozen source and provenance files. Before manuscript use, a second author-side audit must replay validation choices before reading test logits and run fresh CPU full-graph inference from all nine selected checkpoints against saved logits and decisions.

Report the 100-, 300-, and 1,000-epoch budgets **together in that order**, with all nine selected epochs and scores, each variant's three-seed mean and sample SD, and all three within-seed paired accuracy differences for each budget. Do not choose a budget by test score, merge seeds across budgets, or infer across-graph uncertainty from three optimization seeds on one official temporal split. Report a complete unfavorable outcome if it bears on a claim. The new budget does not establish convergence by itself: report the best-validation gain after epochs 900 and 950 and the selected epoch for every arm. A best near the cap means the run remains budget-limited; 100 flat validation epochs would demonstrate only an operational plateau within this training trajectory.

An adaptive validation-convergence rule is **not** part of this run. Switching to early stopping, a different patience, or another budget after seeing results would create a new, explicitly post hoc experiment and cannot substitute for any of the nine fixed-budget arms.
