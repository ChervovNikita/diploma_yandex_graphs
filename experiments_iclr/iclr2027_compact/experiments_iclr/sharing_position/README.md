# Anonymous sharing-boundary evidence, decision edition

This folder gives the frozen source and protocols for Roman Empire official mask 0, WikiCS official split 0, and Actor official split 0. Every arm uses two residual SAGE blocks, width 128, four BatchEnsemble members, AdamW at 0.001, and 300 epochs. `private_first` and `private_last` copy exactly one residual block for each member and have equal parameter counts within each graph. The studies were selected post hoc. The first-versus-last direction reverses across the three graphs.

For each of 44 runs, `selected_decisions.npz` contains four individual class decisions, the class decision after averaging raw member logits, official labels, and official node IDs at validation and test. These arrays were deterministically derived from the full audited selected-logit files. `decision_derivation_manifest.json` links each decision file to the SHA-256 of its source logit file, which is also recorded in the original run result. This compact edition can independently recalculate validation and test accuracy, individual-member accuracy, paired effects, validation-trace selection, and retained file hashes. It cannot recompute a pooled decision from member logits, cross-entropy, or checkpoint outputs. Full logits, initial full-node logits, checkpoints, and their CUDA replay remain in the retained author evidence. The published public dataset files are omitted.

Run `python verify_decisions.py` with NumPy. The complete original GPU replay audit JSONs and source/data manifests are included. The Roman graph here has no explicit self-loops; the separate Roman depth grid has one self-loop per node. Do not combine their endpoint means.
